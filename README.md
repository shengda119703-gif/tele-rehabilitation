# 安康 · 居家康复助手

一个产品，电脑和手机两个入口。主导航统一为 **首页、康复、健康、用药、家庭**。手机可以使用独立 APK 在本地运行，也可以通过浏览器连接电脑；这两种宿主的档案分别保存，不能自动混用。

## 打开产品

- **电脑：** 双击桌面“安康康复（最新版本）”，或仓库的 `启动康复助手.cmd`。
- **独立手机：** 使用 `android_offline/` 构建的 APK，在手机本地完成原有评估、训练和健康记录；已发布安装包仍为 0.2.1，本轮新增调度后端源码没有重打包。
- **手机：** 电脑右上角“我的档案” → “连接我的手机”。手机连接同一可信 Wi-Fi，在浏览器打开显示的地址，输入连接码。电脑需保持开启；停止连接即撤销本次连接码。
- 首次使用先建立本人档案。问卷可跳过；没有有效动作评估时先安排评估，不从问卷编造动作能力或处方。

浏览器连接电脑的入口需要局域网服务；独立 APK 的个人流程在本地运行。可选文字备份与家庭服务见 [手机主端说明](docs/plans/PHONE_LOCAL_2026-10-07.md)。局域网 HTTP 下浏览器可能限制直接录音/实时摄像头，可使用拍摄上传、键盘语音或录音文件；异地云端未验收。

## 五个页面做什么

| 页面 | 主要操作 |
| --- | --- |
| 首页 | 今天的安排、康复管家入口、我的记录与周报 |
| 康复 | 训练 / 评估 / 健身三个入口，保留计划和日期管理 |
| 健康 | 我的健康档案、身体指标、上传的报告与图片 |
| 用药 | 按已有医嘱添加药物和时间，逐日逐次记录，保留更正历史 |
| 家庭 | 邀请关联、逐人选择共享类别，只读获准近况 |

电脑实时测量和手机录像保留来源条件。计划和记录在同一数据库，但不能把手机录像与电脑实时结果直接互换为有效训练依据。复杂手动计划编辑保留在电脑；手机可查看电脑计划、安排日期，并执行录像来源的评估/训练流程。

## 首次安装

Windows x64、Python 3.13、Node.js 22+。在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-Rehab.ps1 -IncludeOCR
```

`-IncludeVoice` 安装可选本地语音；`-IncludeLandmarks` 准备腕、踝、手指等可选关键点环境。环境、模型、个人数据和日志均不上传 Git。安装不会自动开启摄像头。

## 主线结构

```text
rehab_codex_single_camera_v2_1/  原生电脑端、测量 Runtime、原业务 UI、测试
mobile_rehab/                   统一手机界面、录像分析和电脑托管连接
android_offline/                独立手机本地宿主、算法与包装
ankang/route1-health-agent/     安康 Agent 与健康业务服务
bridges/ankang/                 Python / Node 本机桥接
docs/                          当前交接、架构、历史和验收
tools/                         检索、验证及兼容独立手机服务工具
deploy/mobile/                 独立手机服务部署材料（独立数据，非默认双端入口）
```

独立 `android_offline/` APK 已于 2026-10-07 恢复到主线。整理前的原交付仍保存在远端分支：

- `archive/pre-unified-mobile-20261006`：整理前 main（`4a4a0b8`），含独立 APK 和原手机交付。
- `archive/pre-unified-desktop-20261006`：整理前桌面产品（`f54935b`）。

归档不删除队友提交历史。保留手机拍摄/上传、分析、结果、体态、健身、资料、OCR、语音、回收站等可复用能力。兼容独立手机服务使用独立数据目录，工具集中在 `tools/mobile-standalone/`；日常使用请从电脑配对入口进入，避免产生两份档案。

## 开发与验收

康复后端最新独立增量：v2正式会话与主要离线训练／录像研究入口的非阻塞资源准入。见 [实现与范围](docs/development/REHAB_COMPUTE_COORDINATION.md) 和 [251／12／19项回归及原生验收](docs/validation/REHAB_COMPUTE_COORDINATION_2026-10-11.md)。不改旧前端／Android／正式权重，v2默认关闭；旧桌面、全部报告作业和跨端调度尚未覆盖，不等于用户端或全产品协调已经更新。

当前电脑版本 **0.20.0**。先读 [当前交接](docs/HANDOFF.md)、[调度逻辑与接入](docs/plans/ANKANG_CARE_COORDINATION_2026-10-10.md)、[本轮验证](docs/validation/ANKANG_CARE_2026-10-10.md) 与 [医学依据](docs/plans/ANKANG_MEDICAL_EVIDENCE_2026-10-10.md)。本地协调支持安排查询、原下一项查询及经确认的逐次服药记录／训练改期；前端确认入口尚待接入。原可选联网康复查询需要有效 API 配置。历史医疗与测量约束继续适用，软件测试不等同于临床效果或真人动作准确率验收。
