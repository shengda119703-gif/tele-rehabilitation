# 安康 · 居家康复助手

本仓库的主线以 **`main`** 为准。当前本地融合发行源码：桌面 **0.25.4**、独立 Android **0.5.4／versionCode 54**、云服务 **0.3.5／schema 4**。保留10月15日伙伴UI，增加账号隔离的云端康复管家、对话同步和医疗工作台联动；公网状态与未验证边界见当前交接。

安康提供电脑和手机入口，主导航为 **首页、康复、健康、用药、家庭**。手机可以使用独立 APK 在本地运行，也可以通过浏览器连接电脑；这两种宿主的档案分别保存，不能自动混用。

## 打开产品

- **电脑：** 双击桌面“安康康复（最新版本）”，或仓库的 `启动康复助手.cmd`。
- **独立手机：** 融合版本 **0.5.4 / code54**；保留本地评估、训练、跟练、自动健身轨迹和手机运动／BLE心率，管家经本人云账号同步。安装包保留原签名，覆盖安装不应先卸载或清数据；真机安装仍需独立核验。
- **手机：** 电脑右上角“我的档案” → “连接我的手机”。手机连接同一可信 Wi-Fi，在浏览器打开显示的地址，输入连接码。电脑需保持开启；停止连接即撤销本次连接码。
- 首次使用先建立本人档案。问卷可跳过；没有有效动作评估时先安排评估，不从问卷编造动作能力或处方。

浏览器连接电脑的入口需要局域网服务；独立 APK 的个人流程在本地运行。公网用户网页为 https://139.224.216.18/ ，官网下载为 https://139.224.216.18/download ，不要求同一Wi-Fi。局域网HTTP可能限制直接录音／摄像头；公网登录、页面和下载已验证，真机采集另验。详见[官网与安装](docs/cloud/PUBLIC_DOWNLOADS.md)。

报告图片可上传、留存和下载原件；报告识字与自动提取已退役，指标需核对原件后手动录入。训练动作识别继续保留。

**个人康复管家：** 对话按本人账号跨端保存；健康资料使用须单独授权。密钥只由服务器管理，正常产品调用经统一网关计量；医生可查看日／月／用途用量和预算、审核规则候选。实际测量仍由原算法产生。服务器尚待管理员填写有效 DeepSeek Key，不把本地解释称为真实模型调用。详见[个人管家与网关](docs/cloud/PERSONAL_ASSISTANT.md)。

**医患沟通有两个入口：** 患者在安康中打开“联系康复医师”，以客服式聊天沟通、发送报告；医生在现有云服务的 `/care` 打开工作台，先看患者列表，点击患者后只有“患者信息、沟通、API 用量”三个页签。网页患者入口为 `/account`。没有真实记录时显示空状态，不预置演示患者、聊天或模拟费用。

患者可授权同步已保存的评估、训练和当前计划；医生查看获准资料、创建并发布方案，患者确认采用前仍需经过原有评估与动作支持校验。聊天不会直接修改训练计划。复用现有云端账号和数据库，源码合并不会自动更新公网服务器。详见[工作台说明](docs/workbench/README.md)和[当前简洁工作台验收](docs/validation/SIMPLE_WORKBENCH_2026-10-14.md)。

## 五个页面做什么

| 页面 | 主要操作 |
| --- | --- |
| 首页 | 今天的安排、康复管家入口、我的记录与周报 |
| 康复 | 训练 / 评估 / 健身三个入口，保留计划和日期管理 |
| 健康 | 我的健康档案、身体指标、上传的报告与图片 |
| 用药 | 按已有医嘱添加药物和时间，逐日逐次记录，保留更正历史 |
| 家庭 | 邀请关联、逐人选择共享类别，只读获准近况 |

电脑实时测量和手机录像保留来源条件。计划和记录在同一数据库，但不能把手机录像与电脑实时结果直接互换为有效训练依据。复杂手动计划编辑保留在电脑；手机可查看电脑计划、安排日期，并执行录像来源的评估/训练流程。

## 首次安装

Windows x64、Python 3.13、Node.js 22+。在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup-Rehab.ps1
```

`-IncludeVoice` 安装可选本地语音；`-IncludeLandmarks` 准备腕、踝、手指等可选关键点环境。环境、模型、个人数据和日志均不上传 Git。安装不会自动开启摄像头。

## 主线结构

```text
rehab_codex_single_camera_v2_1/  原生电脑端、测量 Runtime、原业务 UI、测试
mobile_rehab/                   统一手机界面、录像分析和电脑托管连接
android_offline/                独立手机本地宿主、算法与包装
ankang/route1-health-agent/     康复问答、本地候选清单与健康业务服务
bridges/ankang/                 Python / Node 本机桥接
cloud_service/                 现有云账号、医生网页与医患协作 API
public_web/                    手机本地计算网页的云账号适配
docs/                          当前交接、架构、历史和验收
tools/                         检索、验证及兼容独立手机服务工具
deploy/mobile/                 独立手机服务部署材料（独立数据，非默认双端入口）
```

`rehab_codex_single_camera_v2_1/` 是当前正式桌面程序，目录名为兼容现有环境和数据位置而保留，不是另一套旧版程序。兼容独立手机服务使用独立数据目录，工具集中在 `tools/mobile-standalone/`；日常使用请从上方产品入口进入。
