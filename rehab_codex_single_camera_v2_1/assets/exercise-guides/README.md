# 动作提示图片接入

本轮按用户要求不生成或下载动作提示图片。界面明确显示“动作示意图待补充”，文字步骤、评估与训练不依赖图片存在。

2026-09-09 再次确认仍不生成图片。0.9 已增加远距离大字/大图展示，复用下面同一组路径；默认摄像头镜像不会翻转动作示意图，缺图、错侧和损坏图仍不借图替代。

## 放置位置

每个动作按受试者本人的左右侧分开，图片固定为 PNG：

```text
assets/exercise-guides/
  wrist_flexion/
    left/
      start.png     # 准备姿势
      move.png      # 掌屈动作
      return.png    # 回到起始姿势
    right/
      start.png
      move.png
      return.png
```

动作 ID 与 `app/exercises.py` 一致，三个阶段由 `app/exercise_guides.py` 定义。
例如肩外展为 `shoulder_abduction`，踝背屈为 `ankle_dorsiflexion`，食指近端指间关节伸展为 `index_pip_extension`。
头颈/躯干侧屈的左右指活动侧，前后屈伸的左右指拍摄测试侧，仍与现有任务契约一致。

建议使用横向 4:3 图片、纯净背景，让必要身体部位完整可见。界面等比例缩放、留白，不裁切人体或强行拉伸。不自动镜像，也不借用另一侧、另一动作或另一阶段图片。单张上限 20 MiB、最长边 4096 像素；缺失或损坏时保留文字与明确提示，不阻止启动或训练。

补图后重新打开应用，或切换到其他动作再切回来。图片按需读取，不在每帧反复解码。动作库使用人体部位菜单，不把某一侧的动作图自动当作通用封面。

## 内容要求

- 使用已获授权、经康复人员核对的动作图片，不直接搬运 Keep 的人物、课程封面或品牌素材。
- 对照每个动作的起始姿势、拍摄方向、支撑条件、运动方向和回位文字检查。伸展任务与屈曲任务起点不同，不能共用一套方向相反的图。
- 不通过示意图暗示必须达到固定最大角度，不把体态、肌力或诊断能力画成已支持。
- 先使用匿名示范素材；患者照片不得未经明确同意提交到仓库。

图片仅是指导材料，不参与测量、身份识别、计数或训练目标计算。

完整图片清单见 `../../../docs/assets/EXERCISE_IMAGE_MANIFEST.csv`。清单一行对应一张图片，
可将已生成图片的绝对路径填写到“待导入图片路径”列；接入时再按“项目目标路径”复制并核对。
需要重新生成清单时，在应用目录运行 `scripts/export_exercise_image_manifest.py`。
