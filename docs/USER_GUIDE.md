# 居家康复助手使用指南

适用：0.18.0 自动康复闭环版。当前电脑使用根目录 `启动康复助手.cmd` 启动；换电脑安装见[项目首页](../README.md)。

本版重点是「能顺利做完一次锻炼」：摆好位置后自动进入下一步，重开预览会沿用仍然适用的起点，普通看不清只给一条安静提示，开始前有可取消的 3 秒倒计时。自动测量撑不住时，可以改用**引导计时练习**按提示完成并保存记录。改动清单见[顺畅完成与引导计时](history/SMOOTH_FLOW_V0_17.md)。

新增侧栏“银发健康守护”和“我需要帮助”。活动任务、个人参考变化、本机家属回应及可选手机测试的完整步骤见[银发使用说明](history/SILVER_HEALTH_V0_16.md)。默认不联网；手动求助默认只记录在本机，不代表家人已经收到。

## 评估后自动安排训练

1. 在“身体评估”完成并保存所需动作。系统只采用当前用户、当前输入来源和使用情境下最近 7 天的有效自动评估。
2. 打开“训练中心”，点击“根据评估自动安排 / 继续训练”。系统会显示已经读到的身体测试结果，以及本轮优先安排的动作、侧别、次数、组数和来源。
3. 只确认今天是否有不适或医嘱 / 疾病 / 术后限制；站立动作另确认稳固支撑，档案注明需要协助时确认陪同者在场。这些内容摄像头无法可靠判断，系统不会默认替你确认。
4. 点击“使用这个安排”，再点“准备下一项”。之后按普通流程打开预览、完成机位准备并开始；不需要进入参数表填写计划。
5. 训练中查看次数及“已观察目标达成 / 需调整 / 未能核实”。结束保存后记录疼痛和疲劳；无疼痛、不疲劳可一键记录。回到自动安排继续下一项。

现有 53 项动作和左右侧都能进入自动流程，但必须先有该项有效评估。每轮最多 4 项；完成后重新安排会优先选择尚未训练的动作。明确疾病、术后或医嘱限制时请使用专业人员安排，系统不会自动生成对应治疗处方。完整规则见[0.18 说明](history/AUTOMATIC_REHAB_V0_18.md)。

## 1. 首页与当前用户

主入口为“身体评估”“训练中心”“身体档案”“历史记录”。日常活动、卧室观察和安全提示演示位于“其他工具”，需要单独开始；未启用的场景没有监测。

先在顶部选择当前用户，首次可点“新建用户”。称呼以外的个人信息均可留空；用户填写的信息与摄像头观测分开。切换用户会清空当前目标、起点和训练引用。任务运行或结果待保存时，先结束或处理保存，再切换用户。

身体评估首页显示人体部位导航。点击部位或名称，右侧选择具体动作；可以搜索，或点击“全部动作”。目前有 9 个部位、53 项任务，左右侧独立记录；任务数量包含不同动作方向和起点，不代表独立解剖关节数。

## 2. 先检查摄像头画面

顶部选择要使用的设备，再点“打开摄像头并测试”。这个入口只查看原始画面，不运行姿态模型，不计次数，不产生评估记录。看完点“关闭摄像头”，确认返回后再做正式任务。

软件会优先恢复上次设备；首次只有一个符合选择条件的候选时会选中它，但不会自动打开。多个候选或设备找不到时需要人工选择。刷新只枚举设备；必要时在输入设置中明确切换 DSHOW / MSMF，再重新选择。

相机默认镜像显示，方便对照动作；人体解剖左右、原图坐标和保存数据不交换。镜像可在测试窗口或准备设置中关闭。本次启动内，相机与录像分别保留显示偏好。

如果没有画面，检查 Windows 相机权限、是否被其他程序占用、设备连接和所选接口。成功枚举出名称不代表已经通过画面测试。

### 使用正面＋侧面双摄

在身体评估或训练中选择实时摄像头，插好两个设备后点“刷新”，勾选“双摄：正面＋侧面”。上方设备作为正面相机，下方作为侧面相机；必须选择两个不同设备，均使用当前明确的 DSHOW 或 MSMF 接口。切换动作后，软件按动作定义自动选主机位。

先点“打开摄像头并测试”，确认两幅画面各自可用，再关闭测试。正式预览时按主机位的原动作要求摆放，另一幅图中也要看清同一人的所测侧肩髋或正面双肩双髋。准备设置的确认同时涵盖两路同一人、机位与本人侧别。两路 track_id 不用于自动判断是否同一个人。

主画面承担所选动作的角度和计数；辅助画面显示独立二维躯干或肩线投影。辅助值没有自动训练阈值，不会用另一幅图补主画面的缺失点。两路人员归属明确且主路必要点满足原门槛时，辅助几何缺测仅标记对应项无法评价，不整体否定主结果；主路缺测或缺少人员归属证据时不纳入测量。多人、换人、断流或新配对画面超时会中断任务并释放两路，需重新预览确认。停止采集和隐私暂停均关闭两台设备；“暂停训练”仍保留两路预览。旧报告沿用保存时的规则，不重新计算。

两幅画面按接收时间配对，界面显示接收差；这不代表相机曝光同步。报告保存逐路来源、有效性、辅助值与接收时间差，普通导出不包含设备原始路径。勾选本次骨架保存时授权范围包含两路，默认不保存两路原始画面。小窗口可滚动查看完整数值，也可打开“大字指导”。完整定义和实测状态见[0.13.0 双摄说明](history/DUAL_CAMERA_V0_13.md)。

## 3. 完成第一次肩外展评估

选中动作后默认打开右侧“步骤”。每一步显示当前任务、具体操作和下方主按钮；可切到“动作图解”查看示范文字和图片位，或“设置”修改测试侧、机位与重录起点。拍好画面只表示您已完成摆位，不代表软件已确认可测量。

1. 在“身体评估”选择肩部 → 肩外展，核对当前用户和测试侧。
2. 选择实时摄像头或本地录像，明确自主使用、受控演示或测试情境。
3. 点击“打开预览”。这时可以看画面和骨架，但正式业务尚未开始。
4. 按正面机位提示，让测试侧髋、肩、肘进入画面。画面连续可测量约 1.2 秒会自动进入下一步；暂时看不清时按钮仍然可用，可以自己点“画面已摆好，继续”。腕点可见才能检查屈肘；躯干侧倾还需要双肩和双髋。
5. 到“回到起点，人工核对”时，核对画面为本人、测试侧与机位正确、需要的关节点可见，已回到起点且无不适，再点“已核对，确认准备”。这个按钮本身就是本次人工确认，不用再找另一个确认框；双摄还须核对两路同一人。有陪同要求时仍须单独勾选“陪同者已在场”。
6. 点击“开始评估”。默认先给 3 秒倒计时，期间可点“先不开始”；倒计时只是等待，不产生任何数据。可在“更多设置”里关闭它。开始后按界面等待准备姿势，再在已确认的舒适范围做动作。回到起点才记录一次完整往返。
7. 点击“完成并保存”并等待保存成功。软件留在本次任务，右侧“步骤”显示完成小结，并提供“再做一次 / 换一个动作 / 查看详细数据”；“结果解读”同时打开，身体档案在后台刷新。报告的“详细数据”保留逐次证据和测量条件；关闭重开后仍可从历史记录查看。

运行中还可以点“记一次（我完成了）”自己记录一次完成情况。它记为本人报告，与自动观察到的次数分开保存和显示，不相加。

没有可靠关节点时会拒绝开始或暂停评价；缺测为空值并保留原因，不变成 0° 或“动作差”。当前角度为二维投影观察，评估阶段不会自动开个人目标。

一直看不清、或起点采样反复失败时，可以勾选“引导计时练习（不自动测角度）”继续完成本次活动，见第 4.1 节。

普通与大字指导共用提示策略：短暂识别波动立即停止纳入无效数据、清空当前数值，但不连续弹出调整要求；普通缺测持续 1.5 秒后给一条调整提示，恢复后撤下。同一次准备里再出现缺测时，需要持续 3 秒才会再提示一次；累计看不清约 10 秒后，会在步骤卡里给一条安静的可选建议，不弹窗。多人、身份不明、断流和保存失败不等待这段缓冲。详见[提示策略](history/QUIET_GUIDANCE_V0_14.md)与[本版调整](history/SMOOTH_FLOW_V0_17.md)。

跟踪编号跳动、短暂遮挡不会让您重新点一次“已核对，确认准备”。只有画面里出现第二个人，或者画面里一度没有人超过 2 秒，才会撤销本次核对，并写明原因。

## 4. 其他动作如何准备

| 类型 | 主要准备条件 |
| --- | --- |
| 居家坐站 | 侧面完整任务区域，测试侧肩、髋、膝、踝可见；分别记录舒适坐位与站位基线。达到站位计一次，观察到回坐后才允许下一次 |
| 需要反向起点的动作 | 按该任务记录舒适起点，再按规定方向出去并回到起点；不能用另一动作的起点代替 |
| 肩内收 | 先侧抬臂到舒适起点，点击“记录侧抬臂起点”，倒计时后保持直到记录完成；从该起点向身体收回，再抬回记录起点计完整往返。舒适范围不足、起点无法区分时应停止本项 |
| 头颈前屈 / 后伸 | 指定侧眼、耳、肩、髋进入侧面画面；提示会指出缺失点。头颈侧屈使用另一套正面机位条件 |
| 腕、踝、手指 | 必须先准备可选关键点环境和模型，再遵循动作页面中的拍摄平面、近景及起点 / 方向要求 |

头颈和躯干功能为实验性整体观察，不提供椎体节段测量。手指模型不提供逐点置信度；侧别、手的归属和拍摄平面仍需确认。具体条件以选中动作的“步骤”“动作图解”“设置”和测量说明为准。

需要记录起点、活动方向或坐 / 站位时，均按步骤点击记录，等待 3 秒倒计时后保持该姿势，软件只采集之后的连续稳定新帧。记录完成前主按钮显示“正在记录…”，不会跳到下一步或自动开始评估；下方“取消本次采样”和“停止采集”始终可用。记录失败时先按提示调整，再重试；活动方向只需小幅试动作，不要求达到最大幅度。

头前屈 / 后伸为何需要髋？软件用同侧眼—耳线作为头部参考、肩—髋线作为躯干参考，区分低头与身体前倾，并非在测试髋关节。侧面取景到同侧髋部，不要求另一侧肩，也不必拍到脚或露出皮肤；衣服下的人体轮廓仍需清楚。双摄也不从正面画面借髋点补到侧面。当前保留此测量定义，未新增无髋简化模式。

需要起点的动作会依次显示“记录动作起点”；需要方向的动作再显示“记录活动方向”，仅做舒适小幅试动作后记录；坐站分别记录坐位、站位。记录失败会停留原步骤并显示原因，可在“设置”重录，或改用引导计时。准备时不累计正式次数。

采样时短暂看不到人不会立刻取消：完全看不到人持续约 1.5 秒、画面里出现第二人持续约 0.8 秒才会停止本次采样；采样窗口为 6 秒。跟踪编号重新识别时本次采样继续，但稳定判断仍要求同一次跟踪下的连续画面，不会把两段拼起来。

换设备、动作、侧别、机位或相关输入条件后，需要重新准备。只要用户、输入、画面尺寸、模型、动作、侧别和机位都没变，重新打开预览会**沿用上次记录的起点或坐站基线**，顶部会提示“已沿用”；条件变化时会说明具体原因并要求重录。镜像只改变显示，不会关闭摄像头，只需重新点一次“已核对，确认准备”。坐站与其他起点记录不能从不匹配的来源继承。只拍得到上半身时，先完成相应上半身任务。

### 4.1 自动测量做不到时：引导计时练习

勾选步骤卡或“设置”里的“引导计时练习（不自动测角度）”，本次就按固定节奏提示动作：准备 3 秒 → 动作 4 秒 → 回位 4 秒，循环进行。

- 不需要先记录起点或坐站基线，也不要求当前画面能测出角度，仍然需要可用画面和一次“已核对，确认准备”。
- 运行中可点“记一次（我完成了）”自己记次，点“暂停提示”暂停节奏；暂停期间不累计有效观察时间，继续需要再点一次。
- 报告分别写明：自动观察到的内容、按有效帧统计的**近似角度范围**（未按动作分期，不是一次动作的幅度）、本人自报次数，以及本次没有取得的内容。
- 引导计时记录保存在历史中，**不作为训练所需的评估依据**，也不会把之前成功的评估改写成不可用。需要可比较的测量时，请在取景和光线较好时再做一次自动测量评估。
- 多人、身份不明、画面中断、尺寸变化和保存失败的门禁完全不变，引导计时不会绕过它们。

## 5. 评估清单、身体档案和训练

日常活动、卧室观察演示和安全提示演示现在也有相同的“步骤”卡：打开预览 → 圈定本场景需要的区域 → （活动场景）确认活动许可 → 核对并确认 → 开始观察 → 停止并保存。缺少区域时会写明还差哪几个。

需要连续评估多个项目时，可以创建“本轮评估清单”，人工选择动作和侧别。每项仍独立预览、校准和确认。最新一次证据不足显示需补测；跳过要记录原因，跳过不代表成功。清单关闭后可重开继续，历史评估不会自动填成本轮结果。

身体档案显示当前用户、来源和情境下的评估记录。未评估与无法评价分开；最新失败不会自动回退显示更早的成功。选择可用评估后可进入训练，再人工设置并确认组数、次数、休息和可选目标。目标留空时仅观察，不判未达标。

训练按确认后的组次执行。每组完成后进入休息，下一组须人工确认；休息和暂停不计动作，暂停前的半次动作不拼接。坐站在站起时保留已完成次数，回坐后才进入可继续状态。没有新输入时不补造观察和计时。

训练中心的“我的训练计划”可以保存并复用个人安排：

1. 点击“新建计划”，填写名称，选择动作与本人侧别，点击“添加项目”填写次数、组数、休息和可选目标；一份计划可以有多个项目。
2. 点击“保存到计划库”。计划按当前用户、来源和使用情境保存，关闭软件后仍可重开。
3. 选择项目，点击“使用所选项目”。只有当前有效评估与测量定义相符时才可进入准备；最近一次评估失败时需先补测。
4. 核对并“确认本次计划”，重新预览和确认机位 / 起点，再开始训练。完成并保存一项后，回到计划库选择下一项。

“修改训练计划”只调整本次准备；要长期保存修改，请回到“我的训练计划”编辑并保存。报告保留来源计划版本及本次临时改动。归档的计划可以恢复，归档和编辑不会改写旧报告。保存失败或版本冲突时，草稿保留在编辑窗口。

目标不由最大评估角度自动生成，也不会自动进阶。计划复用不带入上次的相机确认、坐站基线或舒适起点。

计划窗口还可填写出程 / 回程的最短与最长时间，以及连续保持至少几秒；留空只记录。普通关节的保持需要人工角度目标，坐站使用本次确认的站位范围。软件显示当前这一段保持时间，遮挡、离开范围或暂停后从零重新观察，不把分段相加。

结束后报告分别列出出程、峰区停留、回程、最长连续保持及各自目标结果。峰区停留是按本次观察峰值分期后的统计，不代表平衡能力；坐站在确认站起时仍计一次，没有观察到回坐则回程留空。时间未达目标不扣掉已完成次数；缺测时显示原因，不以 0 秒代替。详细定义见[动作时间说明](history/MOVEMENT_TIMING_V0_11.md)。

“暂停训练”暂停计次，画面仍可预览；“停止采集”会释放输入并结束当前任务。最后点击“结束并保存”，可补充或跳过手工感受，随后查看结果解读；感受未填与 0 分不同，修改感受不改变测量结果。

报告另有“本次可以和不能说明什么”一节，区分自动测量、近似观察、本人自报和本次无法取得的内容。结果报告按“康复指标与测试数据 / 这些数字怎么理解”并列展示：可观察投影角及幅度、完整与部分次数、个人目标、出程 / 停留 / 回程 / 连续保持时间、有效观察和可见规则表现。有效观察比例不是识别准确率或动作合格率；缺测不是零；未设置目标不是失败；没有记录到问题不等于完全正常。时间汇总仅取已保存且有效的分项数值，列明记录数。二维结果不能直接称为临床关节活动度、诊断、肌力或疗效，报告不会自动开处方。

## 6. 大字指导和动作图

正式开始后默认进入大字指导，文字默认 36 像素，可调到 48 像素。可在准备设置中关闭自动放大，或主动打开“大字指导”。

Esc 或“返回普通界面”只切换显示，采集继续；停止需使用停止采集 / 结束并保存操作。缺测、断流、休息、暂停时，界面不沿用旧动作图和旧纠错。引导计时下，大字界面同样提供“暂停提示”和“记一次”。

当前阶段文字与图片位已接入，但实际动作示范图尚未补齐，缺图会明确显示。人体导航插图只是菜单背景。补入动作素材前需按[素材要求](../rehab_codex_single_camera_v2_1/assets/exercise-guides/README.md)核对内容、侧别、阶段和来源。

## 7. 录像回放、保存与隐私

在“历史记录”中选择一份康复报告，点击“纵向记录”，查看同一用户、来源、情境、动作、侧别和模式的记录。可更换比较基准和数值指标；选择某行查看具体条件差异，并打开原报告。日期列和详情保留原始 UTC 时间，小窗口可横向滚动。

只有记录条件一致、已结束且有完整动作与有效测量的数据点会连线，失败、缺测、日期不足和条件变化会断开。时间指标显示各次完整动作有效数值的中位数，并列出有效样本数 / 完整动作数；空值不是 0。记录条件一致仍需人工核对未记录的机位、姿势或支撑变化，数值变化不自动解释为康复改善。

“导出纵向 HTML / JSON / CSV”保存当前选择的基准、指标、全部表行及条件说明，并包含 SVG 曲线。若历史已变化，先重新选择基准刷新再导出。导出文件夹非空时不会覆盖已有结果。详见[纵向历史说明](history/LONGITUDINAL_HISTORY_V0_12.md)。

录像始终保留 `REPLAY_FILE` 来源。预览和正式分析分开，计时使用媒体时间；修改起播位置或速度后重新准备。没有可靠媒体时间的文件会停止分析，不能用推理耗时补成视频时间。

默认数据库在应用目录 `data/home_rehab.sqlite3`。当前电脑与同学压缩包中的数据库保持分开；不会因为导入代码而合并个人记录。相同数据目录只允许一个应用实例，数据库升级前生成备份。

默认不录原始视频、截图或逐帧骨架。主动勾选本次调试骨架保存后，才提供相应导出。普通测量报告不依赖录像同意，导出会去除规定的个人自由文本；数据库本身仍属于本机个人数据，应妥善保管。

保存失败时软件保留待保存结果，阻止开始新会话；可以重试，或备份快照到其他可写目录。需要明确丢弃原因才能放弃结果。正常关闭会先处理当前任务；异常断电前尚未提交的内存数据不能保证恢复。

未关闭的安全事件不会随断流、隐私暂停或换场景消失；“已查看”和“已处理关闭”是不同状态。
