# 手机康复网页 · 局域网演示版

更新：2026-10-03。本轮只新增 `mobile_rehab/` 手机入口；原 PySide6 康复、Ankang、Agent 和其他场景不改动。

## 如何使用

1. 在电脑双击根目录 `启动手机康复网页.cmd`，保持服务运行。首次缺依赖时会安装 `mobile_rehab/requirements.txt`，不下载模型。
2. 手机与电脑连接同一路由器，在手机浏览器打开启动窗口列出的 `http://电脑局域网IP:8765`。
3. 输入电脑窗口显示的连接码。不要把连接码和地址公开分享；请仅使用可信家庭局域网。
4. 身体评估：选部位、动作和本人测试侧 → 阅读起点 / 出程 / 回位提示 → 系统相机录像或相册选择 → 授权上传 → 等待分析 → 看报告。
5. 训练中心：按真实评估生成候选建议 → 简短适用性确认 → 生成并保存计划 → 顺序录制训练 → 上传分析 → 保存疼痛 / 疲劳感受 → 查看下一项。
6. 我的记录可以重开报告、回看录像、单独删除原始录像；删除录像不可恢复，但保留评估结果。
7. 双击 `停止手机康复网页.cmd` 可请求停止本工作区服务。窗口运行时也可 Ctrl+C。停止时未完成的分析需重新上传，已保存结果保留。

手机录制建议：横屏、720p 或 1080p、普通录像模式。单项约 15–40 秒，起始姿势先停留约 3 秒；单段最多 2 分钟 / 256 MB。手机锁屏、切换网络可能打断上传，上传成功后电脑独立继续处理。系统相机调用由手机浏览器决定，若未直接打开相机，可先用相机 App 录像再从相册选择。

本机开发验收时 WLAN 地址为 `192.168.1.92`，该地址会随网络改变，不能写死在前端。

## 已接入的功能

- 9 个身体部位、53 项既有动作、左右侧、动作专属取景及大字提示，响应式手机 / 平板 / 桌面布局。
- 原生相机文件入口、相册录像、预览、上传进度 / 取消、排队 / 分析进度、失败后重试、浏览器刷新后重新查询。
- 复用现有 `CameraManager → SourceWorker → VisionWorker → SceneController → Storage`。不创建另一套视频采集或几何计数规则。
- YOLO / 可选 MediaPipe 仍使用电脑上的本地已验证模型；手腕、足部和手指需要原项目可选环境和模型。模型缺失不会自动下载或给出假测量。
- 报告显示观察次数、有效观察占比、二维投影角范围 / 变化幅度、分析时长。缺测保留为空，不能把画面有效率当作动作质量分数。
- 自动计划复用 `general-activity-rules-1`，在访问训练页 / 启动训练时重新检查最新评估、时间、测量契约、计划顺序、感受及规则版本，不沿用旧页面缓存作为执行授权。
- 训练结果显示计划次数完成和原 `observed_quality` 分类，感受保存使用原版本校验；出现不适或明显疲劳不会自动推进。

## 数据与服务约束

- `.runtime/mobile/` 存连接码、视频、任务、日志和手机端独立 SQLite 数据，全部由既有 `.gitignore` 排除。
- 浏览器获签名 HttpOnly / SameSite Cookie，各浏览器记录隔离；不会读写电脑版真实患者库。清除 Cookie / 换浏览器后是新的演示身份，当前无账号找回或跨端档案合并。
- 局域网 HTTP 仅为本地演示，不提供传输加密。不得用于公共网络、直接公网端口映射或正式患者部署。正式部署需要 HTTPS、账号鉴权、加密、隐私管理及临床验证。
- 无跨域开放；写操作需要专用请求头；禁止把用户提供的文件路径或 RTSP 地址作为服务器采集输入。文件名由服务生成，录像 / 报告需要本人凭据。
- 流式上传有字节上限和磁盘检查，总录像预留容量约 2 GB；每浏览器至多 1 个活动任务，全服务至多 3 个，分析串行。
- 每次分析独立子进程，10 分钟超时回收其进程树，源采集仍由原 SourceWorker 独占。重启未完成任务显示失败，不假称成功。重复启动先检查端口，避免覆盖正在分析的任务状态。
- 录像保留在本地直到用户删除。软件重启不会自动删除已完成录像；请用记录页定期清理。

## 本版边界与后续

本版是**录制后分析**，不是手机浏览器实时纠错或远程医疗监护。调用系统相机时网页提示不能覆盖系统相机界面；先阅读提示再拍摄。没有测试数据时训练页不填充演示假计划。

用户尚未购买网络摄像头。本版设备页明确显示未接入，可先上传相机导出的录像；不宣称 RTSP / ONVIF 预览、双路同步、手机远程触发相机已完成。硬件确定后再增加电脑侧受控流接入和 HTTPS / WebRTC。

后续同日按用户授权增加了独立的 8 项常见健身录像分析，见 [健身功能及算法](FITNESS_VIDEO.md)。杠铃物理量分析、家庭全屋监测、健康助手聊天及公共云账号仍未接入手机页。原电脑版功能原位保留。移动浏览器真机拍摄和真人精度需在红米 K60 Ultra 上进一步验证，网页断点测试不能替代真机验证。

## 打不开页面时

先确认电脑服务窗口未关闭、地址是 WLAN 地址、不是 `127.0.0.1`，输入完整 `http://` 地址。如果浏览器强制要求 HTTPS，需后续配置受信任 HTTPS，不要绕过证书安全警告。确认不是访客 Wi-Fi 或启用了客户端隔离。

如 Windows 防火墙阻止，可由电脑管理员**仅允许该 Python 程序的 TCP 8765 入站，来源限制为可信本地子网**，不要关闭整个防火墙。本轮不擅自修改系统安全设置。当前访问码不会解决网络连通性问题。
