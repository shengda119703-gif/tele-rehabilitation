# 康复后端：采样与已知丢帧敏感性实验

日期：2026-10-11。实施基准`2ddbba0`，源码以本文件所在提交为准。对应后端任务书4.3–4.5、11.2及15.1–15.3。本次只增加离线分析工具、确定性测试和必要文档；原协议、滤波、模型、服务、患者库、前端和整个Android保持不变。

## 1. 本次回答什么问题

用同一段已授权录像的原始预测关键点，改变分析采样间隔或明确的输入缺口，观察主指标覆盖、角度差异、准备基线、次数和时间输出怎样变化。这样可以定位采样策略的影响，但没有独立金标准时，不能称为角度误差、计次准确率或可靠性提升。

本机已有两段分析授权录像，未获训练授权、没有专业标注。本次复用原YOLO提取缓存，不重新解码或推理；不训练、不调参数、不启动相机、不访问SQL、不把片段做成正常患者历史。

工具：[sampling_audit.py](../../tools/rehab_ml/sampling_audit.py)；测试：[test_sampling_audit.py](../../tests/rehab_backend/test_sampling_audit.py)；有界执行：[verify_sampling_audit.py](../../tools/rehab_ml/verify_sampling_audit.py)。

## 2. 信息链与固定条件

1. 显式指定忽略目录中原提取的`result.json`，核对分析授权声明、训练为false、专业标签为false及可靠媒体PTS声明。
2. 核对结果SHA256、`pose-frames.jsonl`的SHA256、帧数、有序seq／time、COCO17／原像素语义、固定模型和尺寸、预测关键点结构及原解码像素hash。
3. 九种条件在读取目标片之前固定，不能挑有利帧率或改阈值。每种条件重新创建原`EvidenceAdapter`和`ProtocolEngine`。
4. 仅将本条件保留的原始点送入原因果EMA；缓存中的已滤波指标完全不用。没有未来插值、强制补最后帧或用丢失点计保持。
5. 逐帧保留有效／缺失、原seq／时间、反事实时间与相位；已知丢帧通过原`note_input_gap`打断连续性，最后丢帧亦在finish结清。
6. 私有逐帧结果保存在新的忽略run；Git只收录不含人像、原关键点、文件名及逐帧轨迹的聚合统计。

原缓存没有单独记录关节顺序字段；工具只接受原提取器的`coco17-v1`格式，按原`PoseFrame`固定COCO17解剖顺序重建。不会把未知顺序或MP33当作COCO17。hash用于检查文件身份和一致性，不独立证明数据权利、人体身份或预测正确。

原模型推理可能本身使用跟踪；本次缓存重放只验证原关键点之后的滤波／规则，不能代替降低真实模型推理帧率、重新跟踪、网络传输或手机性能实验。

## 3. 九种预声明条件

| 条件 | 修改方式 | 明确边界 |
| --- | --- | --- |
| reference | 保留全部帧及原PTS | 当前源码复算，不将旧结果直接当新结果 |
| sample_every_2／3／6 | 索引从0开始每2／3／6帧保留一帧 | 代表主动降低分析采样，不自动声明队列丢帧；原seq／PTS不重编号 |
| clock_origin_plus_1000s | 全部时间加1000秒 | 检查时间原点平移，不是时钟同步实验 |
| counterfactual_clock_jitter_12ms | 按固定0、6、12、6、0毫秒序列扰动当前时间 | 反事实时间，非实测网络抖动；扰动后不单调即拒绝 |
| known_loss_every_20th | 每第20帧遗漏，通知原引擎 | 约5%已知丢帧；与主动采样分开 |
| known_loss_middle_10pct | 遗漏索引区间floor(0.45N)到ceil(0.55N) | 固定片段中部，不按预测峰值选择有利／不利窗口 |
| known_loss_final_frame | 遗漏最后一帧，通知后finish | 检查末尾待处理缺口，不补出返回或保持 |

时间变换只依赖本帧及固定索引。中间区间使用离线已知片长定义压力条件，不把它当实时可用特征；未来点不参与当前滤波／计次。

## 4. 指标、公式和不能合并的分母

```text
N = 原缓存帧数；K = 本条件送入判断的帧数；V = 其中主指标可观察帧数
保留帧覆盖 = V / K
原帧保留覆盖 = V / N

J = 两条件同原seq且双方主指标有效的帧集合
d_i = |theta_condition(i) - theta_reference(i)|, i属于J
报告 |J|、mean(d)、最近秩p95(d)、max(d)

已知缺测跨度 = 从首个明确缺测／丢帧到后续有效帧的观察时间跨度
尾部缺测只记录至已知最后输入时间，不延伸到未知录像之外
```

两种覆盖不可互换。抽掉无效帧可能提高V/K，但V/N会下降，不等于识别更准确。主动抽帧后的缺测跨度只覆盖保留下来的观察，本工具不能知道被抽掉帧之间真实身体轨迹；“最长跨度”不是已插值的连续健康观察。

时间分别保留完整次分母、有效完整次数、排除原因和中位数。完整次也可能有部分保持：`target_hold_s`还要求完整周期且`partial_observation=false`。没有完整次或没有保持锚点时保持null，不补0。两条件不按rep_index逐次配对，也不把中位数变化解释为改善。

本工具不输出独立相位事件匹配、指导正确率或真人时间误差。`clinical_accuracy`、`count_accuracy`、`timing_accuracy`均为null；`population_sampling_invariance_validated=false`、`network_or_phone_tested=false`。

## 5. 本机两段录像的实际结果

正式实验`sampling-audit-836750a3`，九条件×两段，共18次缓存重放。参考条件重新得到肩434/443、深蹲48/429有效帧，两者与历史原提取的覆盖和次数一致。媒体PTS跨度分别15.2414秒、14.2667秒；这不是原片容器总时长。

| 动作／采样条件 | 有效／保留帧 | 与reference共同有效帧 | 角度差异p95 | 最大差异 |
| --- | --- | --- | --- | --- |
| 肩外展／reference | 434/443 | 434 | 0° | 0° |
| 肩外展／每2帧 | 217/222 | 217 | 2.456° | 5.513° |
| 肩外展／每3帧 | 145/148 | 145 | 4.391° | 5.516° |
| 肩外展／每6帧，约4.83Hz | 73/74 | 73 | 9.707° | 10.863° |
| 康复深蹲／reference | 48/429 | 48 | 0° | 0° |
| 康复深蹲／每2帧 | 27/215 | 27 | 6.926° | 8.644° |
| 康复深蹲／每3帧 | 13/143 | 13 | 11.410° | 11.410° |
| 康复深蹲／每6帧，约5Hz | 7/72 | 7 | 17.331° | 17.331° |

深蹲每6帧只有7个共同有效观测，p95即该集合最大值，不能拿它推算人群误差。两片各九条件均没有默认1秒稳定准备基线、均0次确认、完整时间统计为空；不能用“次数都相同”证明采样稳健，也不能算漏计率。

加1000秒的角度差异最大约1.75×10^-11°，是本机浮点量级；固定12毫秒反事实扰动的p95差异分别0.827°／1.084°。原深蹲参考最长明确缺测跨度2.267秒，主动每6帧后为3.800秒；肩中部丢帧条件跨度1.552秒。全条件、分母及出处见 [聚合统计](../../reports/rehab_backend/sampling_sensitivity.json)。

这些结果提示：优先补足准备段和清晰膝证据；改变采样率应当作为测量条件记录。不能看到V/K略升就更换为低帧率，也不能靠放松起点／有效关节门槛将这两片做成成功测量。本次没有更改任何生产阈值。
