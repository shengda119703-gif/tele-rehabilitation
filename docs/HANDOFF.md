# 当前交接：安康双端整合

本轮用户已授权：统一电脑与手机产品、整理并上传 main、将重复队友交付保留在分支。历史“不合并 main / 仅 UI 分支”等临时约定已失效，原始记录见 [整合前交接历史](history/HANDOFF_PRE_UNIFIED_2026-10-06.md)。

## 正式入口

- 电脑：`Start-Rehab.ps1` → `app.main` → `ProductWindow`。
- 手机：电脑“我的档案 → 连接我的手机” → `PhoneHost` → `/` 的统一五页界面。`/capture` 复用原手机动作、录像、训练和报告工具。
- 共用：同一个 `ProductBackend` 串行处理安康读写；手机回执走私有队列，不被 Qt 消费。`product/`、`product_daily.sqlite3`、`home_rehab.sqlite3` 在电脑应用 data 目录；手机录像按本人档案隔离在 `data/phone/`。
- 本人手机连接码绑定一个 owner，不允许请求字段切换本人。家庭邀请码仅建立关系，默认不共享。家庭视图只输出获准摘要，不能编辑家人。

## 本轮边界

- 五页逻辑保留；桌面康复突出下一项与下一步，管理操作按需展开；原 Runtime、自动计划规则、人物/时间/否定/假设、撤回和医疗语义未重新设计。
- 手机录像与电脑实时测量同库、分来源。电脑计划在手机可看/安排，执行保留原适用条件；复杂人工编辑在电脑。视频分析不假称真人实机通过。
- 手机需电脑开启及同一可信局域网。没有云账号、跨互联网同步或独立离线 APK；HTTP 的麦克风/摄像头限制在界面提示。关闭连接或电脑后手机无法继续访问。
- 真实手机硬件、跨 Wi-Fi 防火墙、全部动作/双摄真人准确度仍需现场验收。可选模型缺失时显示不可用，不伪造识别结果。
