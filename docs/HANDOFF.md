## 正式入口

- 电脑：`Start-Rehab.ps1` → `app.main` → `ProductWindow`。
- 手机：电脑“我的档案 → 连接我的手机” → `PhoneHost` → `/` 的统一五页界面。`/capture` 复用原手机动作、录像、训练和报告工具。
- 共用：同一个 `ProductBackend` 串行处理安康读写；手机回执走私有队列，不被 Qt 消费。`product/`、`product_daily.sqlite3`、`home_rehab.sqlite3` 在电脑应用 data 目录；手机录像按本人档案隔离在 `data/phone/`。
- 本人手机连接码绑定一个 owner，不允许请求字段切换本人。家庭邀请码仅建立关系，默认不共享。家庭视图只输出获准摘要，不能编辑家人。
