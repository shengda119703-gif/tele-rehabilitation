# 康复随行 Android 手机本地版

## 安装包与运行方式

独立工程在 `android_offline/`，版本 `0.1.0`。安装包由本机生成到：

`android_offline/dist/tele-rehabilitation-offline-0.1.0.apk`

这是手机本地计算版，不是连接 `127.0.0.1:8765` 的网页壳。模型、页面、分析规则与记录都在手机；没有 INTERNET 权限，不需要连接码、电脑、同一 Wi-Fi、组网或运行时下载。通过文件传输把 APK 发给 Android 伙伴，由他们明确允许对应文件管理器安装未知来源应用；不关闭系统安全保护。安装只代表进入试用，不代表真人测量精度或全部手机兼容性通过。

支持 Android 10 及以上；依赖系统 Android System WebView 提供安全上下文、Web Worker、WebAssembly、OffscreenCanvas 与相机 API，较旧 WebView 需要先通过系统正规渠道更新。红米 K60 Ultra 的相机授权、文件选择、温升和速度仍需实机验收。首次加载模型可能较慢；录像最长 120 秒、最大 256 MB，建议先录 15–40 秒。

## 已接入本地版的流程

- 原有 53 项康复动作目录、侧别、正面 / 侧面文字步骤：人体、手部与腕部模型适配、自动舒适起点与方向、二维投影角、完整往返计次、下一步大字提示。
- 原有 8 项健身动作：深蹲、硬拉、卧推、俯身划船、肩上推举、弯举、俯卧撑与固定分腿蹲；关节投影角、往返次数、节奏、曲线和报告。
- 正面 / 侧面自然站姿体态：肩线、髋中心线、躯干倾斜、耳肩偏移、侧面膝夹角。不是骨盆前倾、颈椎或疾病诊断。
- 康复评估 → 身体汇总 → 本人近期评估适配的基础训练计划 → 按顺序录像或相机跟练 → 训练感受 → 完成记录。本版每次最多 4 项，每项 1 组、最多 5 次且不超过评估已观察次数；可在“调整本轮次数”中减少次数，不能增大。无直接指南动作的项目明确为本人评估适配。不自动设置疾病处方或长期加量。
- 健身录像可选三点器械标定：目标纹理模板、同平面标尺长度、自由重量质量 → 实际模板跟踪 → 位移、速度、加速度、器械外力 / 功率估算。纹理或连续跟踪不足时不给结果，不用腕点冒充杠铃位置，不用模拟值替代分析。
- 本机个人资料、10 类手动健康指标、用药记录和今日服用记录、感受记录、资料保存 / 导出原文件 / 回收站恢复、报告 JSON 导出与空档案备份恢复。资料最大 8 MB / 份、50 份 / 64 MB；记录最多保留 250 条。备份包含评估、计划、健康指标、用药与感受，不含资料附件，附件须另行保留。

“53 项接线”是目录与算法适配范围，不是 53 项真人精度验证。腕、踝、手指和轴向项目仍是实验性二维观察；手部模型没有逐点置信度，不伪造可见性分数。肩动作不要求髋点，颈前屈 / 后伸只使用同侧眼和耳。启动不以关节当前可见或人数为前置条件；运行中缺测不补值、不跨缺测计次。坐站在此独立移动测量版本按完整起立—回坐往返计次，与桌面“到站位记次”不混用。

## 与电脑版的关系及暂未迁入

电脑版 / 手机网页 / Python 服务与数据库均保留原状。手机本地版使用独立 `android-local-projection-1`，MediaPipe 33 点 / 手部 21 点，与桌面 YOLO COCO17 不混用、不声称同等读数或跨版本直接纵向比较。视频按浏览器媒体时间轴抽样，推理耗时不是动作时间；模型在独立 Worker 中运行，离开相机 / 退出前停止采集。默认前置相机显示镜像，不镜像送入模型的原始坐标。

录像等待真实解码画面就绪后通过 Canvas 采样，兼容 Android WebView 不接受直接 `createImageBitmap(video)` 的情况。康复录像允许使用片中真实停稳至少 0.8 秒、投影波动不超过 6° 的起始 / 回位片段复核完整时间轴，报告记录 `calibration` 的方法与来源时间；不补缺测、不补造帧或时间。实时模式不能回看未来片段，仍需起始停稳。次数可能随取景 / 解码 / 模型波动，未达到本轮目标不能记成完成。

本版尚未迁入：双摄 / RTSP、家庭在线分享和跨设备同步、医生账号、语音转写、资料 OCR、原 Ankang 完整管家 / 周报 / 通知流程、三维模块。无云端账号登录属于离线运行设计，不是正式多用户远程平台。卸载会删除本机应用数据，先导出备份和原资料。应用禁用 Android 自动云备份；不采集遥测，不把私人录像、模型或签名私钥提交 Git。

器械外力仅按自由重量二维估算 `F=m(g+a)`、`P=Fv`，不是肌肉发力、关节力矩、人体真实功率或爆发力实测。手机移动、目标误跟踪、标尺离面都会影响结果。没有标定 / 质量时不编造物理量。

## 构建和签名

1. 在 `android_offline/` 执行 `npm ci --ignore-scripts`，固定 `@mediapipe/tasks-vision@0.10.32`。
2. 使用官方 JDK 21、Android SDK platform 35 / build-tools 35.0.0；本轮工具在仓库被忽略的 `.runtime/apk-tools/`，不改系统 Java 或原 Python 环境。
3. 原 `assets/models/landmarks-manifest.json` 与两个官方固定模型需在本机，`prepare_assets.py` 在复制前重查 SHA256。模型内置，不自动下载。
4. 用 PowerShell 7 执行 `android_offline/tools/build.ps1`。可显式传 `-SdkRoot -JdkRoot -Python`。生成目录均忽略；无需 Gradle 或运行桌面服务。
5. 首次生成私有 RSA 3072 位测试发布签名；密钥在 `android_offline/.runtime/signing/`，密码由 Windows 当前用户 DPAPI 保护。后续更新必须复用此密钥，不自动覆盖；换电脑需由持有人保留并安全迁移签名材料，不能提交到 Git。此证书是开发试用签名，不是商店认证。

复现规则测试先执行 `prepare_assets.py` 再在 `android_offline/` 执行 `npm test`。Android instrumentation 的源码在 `tests/android/`，`tools/build-test.ps1` 仅把本机提供的两段录像复制到忽略的 QA 安装包；**正式 APK 不含录像、截图、测试桥或测试记录**。

第三方来源及模型哈希随 APK 保留在 `NOTICE.txt` 与 `models/manifest.json`。真实验收范围见 `docs/validation/ANDROID_LOCAL_2026-10-06.md`；编译 / 签名校验不代替系统相机、红米操作或真人精度实测。
