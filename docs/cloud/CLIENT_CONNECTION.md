## 手机

1. 安装新版，进入顶栏“云账号”；或应用设置→“统一云账号与记录”。
2. 登录或注册。登录成功打开该账号独立本地档案；换账号不会合并另一人的本地记录，旧个人／Lin空间保留。
3. 在原康复／健身／体态入口分析自己的录像，或完成并保存跟练。模型和业务规则仍在手机本地运行。
4. 打开“云账号”→“上传已保存结果”，确认上传本人结果。不上传录像、逐帧姿态、私人原件或凭据。
5. 网络中断后点“重试待上传”；云回执不明时也使用原键，不重建另一个结果。
6. “云记录”读取当前账号最近10条；“授权医生”之后，doctor才能看到本人记录。“撤销授权”对新查询立即生效。

联网用于登录和结果交换，不要求手机与电脑同一Wi-Fi，也不再用8765服务的旧连接码。手机首次未登录时仍可使用原本地功能；旧本地／测试数据不能因为姓名相同自动上传到新账号。

## 电脑

1. 用新桌面入口启动。原窗口仍开着时，不打开第二个写入同一data的进程；先由用户自己保存并退出旧窗口，不删锁。
2. 顶栏“云账号”输入同一普通账号，可以注册、登录、查看手机上传的云记录；未建立本机档案也可先登录读取。
3. 要上传电脑结果，先在“我的档案”选或新建本人档案，完成并保存原评估／训练任务。
4. 再打开“云账号”，明确勾选当前本机档案属于该云账号，然后“上传本人已保存结果”。本机档案一旦绑定，不能静默改为其他账号；另一个人先切换／新建本机档案。
5. 查看云记录／授权／撤销与手机同一云身份。手机云结果可以读取，但不反写到原评估SQLite假装电脑重新测量。

## 交换哪些信息

| 原事实 | 可上传字段 | 保留的语义 |
| --- | --- | --- |
| 手机实际完成录像分析job | 动作、侧别、时间、测量版本、原summary、周期标量、条件、原局限；有器械结果时含标定与summary | APK_LOCAL；REPLAY_FILE；零次／null不补数 |
| 本人已提交的手机跟练 | 原COMMITTED练习记录 | SELF_REPORT；不把自报计次改成视觉确认 |
| 电脑本人FINISHED／INTERRUPTED session | 场景、动作、侧别、来源、状态、停止理由、summary、原感受、规则与模型标识 | DESKTOP_LOCAL；不上传原frames／poses／视频 |

服务端来源固定DECLARED，表示客户端声明，不等于医疗核验、设备签名或准确性证明。SYNTHETIC／展示夹具不进个人结果队列。原始payload可在云网页详情读取；有命名的数值显示为指标，不能把无名元数据显示成角度。

## 可靠性与安全

手机PhoneStore内有当前患者独立冻结队列，保留installation_id／operation_id／source_event_id；正常JSON恢复不导入别人的云身份或队列，同账号恢复保留本机待上传队列。Android原生安全存储用AndroidKeyStore AES-GCM，网页JS拿不到令牌／密码。

电脑独立cloud-outbox-v1.sqlite3与原评估库分开，绑定及回执持久化；Windows DPAPI按当前系统用户加密令牌，其他系统仅内存会话。网络由单个后台线程串行处理，不在Qt主线程执行HTTP。上传后本地感受变更不会覆盖云原事实；云修订协议仍待实现。

两端固定公开HTTPS源，不允许重定向带走令牌，不跳过证书验证。服务器收到原键后同事务写结果／审计，COMMITTED才确认；断网／回执丢失保留原队列，换账号只处理当前患者的队列。分页读取近期结果不是提交游标，不称完整双向增量同步。
