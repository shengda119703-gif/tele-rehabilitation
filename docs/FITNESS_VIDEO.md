# 手机健身录像分析 · 第一版

2026-10-03。用户明确要求接入常见健身动作，本轮在既有手机网页新增独立“健身分析”导航；不修改桌面康复算法、康复计划或其他业务模块。

## 使用流程

启动根目录 `启动手机康复网页.cmd` → 手机浏览器打开电脑局域网地址 → 输入连接码 → 健身分析 → 选择动作和靠近镜头的本人侧别 → 阅读取景 / 起点提示 → 录制或选择一组录像 → 授权上传 → 分析报告 → 点击逐次关键时刻回看。

每段录像只做一种动作、一组训练。固定侧面、普通 720p / 1080p、机位不移动、不变焦、不剪接，开头先稳定约两秒。最多两分钟 / 256 MB。没有增加前置关节可见确认弹窗；分析中的缺测不虚构成有效数据。

| 动作 | 主要分期指标 | 本版往返定义 |
|---|---|---|
| 深蹲 | 髋—膝—踝内夹角 | 站位 → 下蹲 → 回到站位 |
| 硬拉 | 肩—髋—膝内夹角 | 俯身起点 → 拉起 → 下放回起点 |
| 卧推 | 肩—肘—腕内夹角 | 稳定推起位置 → 下放 → 推回 |
| 俯身划船 | 肩—肘—腕内夹角 | 舒适伸臂 → 拉起 → 放回 |
| 肩上推举 | 肩—肘—腕内夹角 | 屈肘持握 → 推起 → 下放 |
| 二头弯举 | 肩—肘—腕内夹角 | 舒适伸臂 → 弯举 → 下放 |
| 俯卧撑 | 肩—肘—腕内夹角 | 撑起 → 下降 → 撑回 |
| 固定站姿分腿蹲 | 前腿髋—膝—踝内夹角 | 较高起点 → 下降 → 起身 |

用户选择动作，系统**不自动识别动作类别**。划船指俯身力量划船，不是有氧划船机；分腿蹲不包括交替行进弓步。此处硬拉要求录像包含完整拉起与放回，不把只拍到拉起半程当作完整往返。不要为了软件计次增加幅度、负重或训练量。

## 报告实际提供什么

- 完整往返次数、没有形成完整往返的片段数、可用观察时长占比。
- 主关节平滑二维角曲线，缺测不连线。
- 每次起点、角度峰值、回位的录像时刻，以及逐次角变化幅度、去程 / 回程时间。
- 点击关键时刻暂停并定位原视频；在相近时间与相同宽高比条件下，叠加当时可见的指定侧关节。视频播放后清除旧叠加，不把旧骨架当实时结果。
- 平均往返用时；至少三次时计算用时变异系数，仅描述节奏，不作为“动作正确率”。
- 按动作选择相关指标，有证据才显示膝 / 髋 / 肘角、躯干投影倾角、上臂投影倾角、肩—髋—踝夹角、髋膝投影高度比；附各指标有效样本数与帧覆盖率。卧推不列出无关的下肢指标。
- 划船 / 弯举在三个关键时刻出现较大投影摆幅时提供回看提示。该提示不等于代偿诊断或伤害风险评级。
- 历史页按全部 / 康复 / 健身筛选，列表使用轻量摘要，打开某次结果后才加载完整曲线。

## 算法与测量契约

1. 原 `CameraManager / SourceWorker` 读取录像媒体时间；不新建另一套 `VideoCapture`。
2. 原本地 YOLO11n-pose + ByteTrack 获取 COCO17 关键点；校验原模型 SHA256。模型和环境没有更换或自动下载。
3. `FitnessEngine` 按所选侧计算同尺度像素三点内夹角；仅接受有限、在画面内、置信度 ≥ 0.5 的点，组成角的线段长度至少 8 px。卧推等上肢主测量不强制要求髋部入镜。
4. 主角度使用因果 EMA（时间常数 0.1 秒）。带双阈值、起点停留 0.18 秒、目标区停留 0.1 秒的状态机观察完整往返。
5. 缺测、时间间隔超过 0.3 秒或上下文变化会清空未完成往返。主跟踪目标丢失时不拿已知不同 ID 的旁人替补；跟踪 ID 不是生物身份认证。
6. 峰值采用当前往返最大运动进度的时刻。去程为起点至峰值，回程为峰值至回位；停顿可能包含其中，不能直接解释为精确肌肉离心 / 向心持续时间。
7. 规则版本 `fitness-video-1`。报告保存来源、媒体时间、模型标识、实际画面尺寸、阈值、关键时刻和指标证据。

| 动作 | 起点区角度 | 目标区角度 |

| 硬拉 | ≤115° | ≥155° |
| 卧推 | ≥150° | ≤105° |
| 俯身划船 | ≥150° | ≤85° |
| 肩上推举 | ≤100° | ≥155° |

参数用于第一版测试和动作分段，尚未通过真人数据标注评估其灵敏度 / 特异度；不覆盖所有人体比例、活动范围、负重和动作变式。未计完整不代表动作错误。固定侧面是假设，由用户选择，不假称软件已验证机位。

## 还没有提供的分析

同日后续增补：可选的三点器械标定已接入标记跟踪、竖直速度 / 加速度、自由器械外力与功率估算，以及峰速 / 功率 / 到峰速时间等爆发力相关观察，另有不入用户记录的模拟演示。使用条件、公式和边界见 [器械分析 Demo](BARBELL_DEMO.md)。原人体角度分析与器械报告保持独立。

仍没有自动杠铃类别识别、毫米级精度保证、肌肉发力 / 募集、关节力矩、重量识别、全身真实功率、爆发力能力评级或伤害概率。关节角变化率 **不是杠铃速度**；髋膝关键点相对高度 **不是比赛深度判定**；单侧位不能可靠输出左右受力或膝内扣判定。没有生成健身增肌 / 力量处方。

下一阶段需要真实录像分组标注与误差验证，然后再做专项器械跟踪及长度 / 机位校准。不能仅凭计次软件测试通过就宣称训练动作临床或竞技准确。

## 隔离与隐私

健身任务使用 `mode='fitness'`、`kind='fitness'`，结果保存在自己的任务目录，不写入 `assessments.sqlite3`，不会进入康复身体档案或自动康复计划。API 拒绝跨类别动作、继续使用每浏览器授权、文件配额、上传取消、任务队列、超时回收及录像删除机制。

分析结果含关键时刻的指定侧关节点，属于上传分析的派生数据。删除原始录像后不再可回看，但保留分析结果及其数值证据。当前仍仅适合可信局域网演示，不是正式患者云服务。
