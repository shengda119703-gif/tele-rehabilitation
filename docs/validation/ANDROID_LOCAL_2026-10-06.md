# Android 本地版 0.1.0 验收

本轮由用户明确选择“不依赖电脑的手机本地版”。新增独立 `android_offline/`，不修改原桌面 / 手机服务算法和用户数据。不处理原用户未提交的动作素材。

## 已完成的自动检查

- Android platform 35 / build-tools 35.0.0、Temurin JDK 21 官方工具构建成功；签名 APK 可产生，`apksigner verify --verbose` 通过，v3 签名适用于最低 Android 10。
- 本地算法 / 页面辅助 32 项 Node 测试通过：53 个康复适配器、53 个分期回路的合成指标测试、8 个健身目录、肩 / 颈不依赖髋点、肩内收起点、缺测断开、下一步提示、录像停稳参考复核、近期评估计划 / 最新失败不回退 / 不适不续练、仅减少计划次数、器械模板跟踪与物理量、解码等待 / 超时 / 取消、备份校验与 APK 本地安全约束。合成输入仅用于测试，不进入用户记录，不是人体精度证据。
- Python ZIP 包装 2 项通过，确认 Windows aapt2 的嵌套资产路径转为 `/` 后保留模型原字节；重复路径及目录穿越拒绝。
- 原手机页面 31 项 Node 交互 / 文案回归通过；本轮没有改原页面、服务器和模型。
- JS 语法与官方模型 SHA256 核对通过。正式 Manifest 无 INTERNET 权限、不允许明文 HTTP、不启用自动备份。WebView 仅加载本地 HTTPS assets，禁止文件 URL、远端跳转和 SSL 忽略。资料导出需要系统保存对话框。

## Android 运行验收进度

第一轮模拟器镜像安装因 E 盘空间不足失败，未删除用户文件。测试 SDK 移至 C 盘新建的项目专用目录，AVD 数据在 D 盘项目专用目录；WHPX 可用。测试仅使用独立模拟器，不访问正常患者库，不启动或重启原网页服务。

测试设备为独立 Android 15 / API 35 x86_64 模拟器，WebView 124.0.6367.219；不是红米 K60 Ultra。仅重置本轮模拟器内部测试记录，没有删除或覆盖原录像、桌面库和手机服务档案。

已实际修复：Windows aapt2 嵌套资产路径导致模型 404；Worker 加载不能直接依赖原生 assets 拦截，改由页面预载本地脚本 / WASM blob 与模型 buffer；视频 `seeked` 不等于解码数据已准备好，增加有界等待并用真实视频 Canvas 采样；Android 15 状态栏重叠，系统 inset 改在 WebView 外层容器处理。录像康复起点校准会检查停稳后缀并可利用全片已观察停稳参考复核原时间轴，不修改缺测、置信度或计次门槛。

最终正式 APK 的 instrumentation **通过**（`INSTRUMENTATION_CODE: -1`，结果 `status: passed`，重开 `reopen: passed`）：

- 内置人体与手部模型分别完成真实 CPU 初始化 / 空画面推理；空画面返回缺测，不造关键点。
- 用户原肩外展录像 128 个抽样画面完成实际人体推理，本轮观察 3 次完整往返。录像未转换，结果非 mock；没有人工角度对照，不给准确率。
- 正常计划表单读取该评估，测试将本轮次数减少为 1 次、明确选择一般活动确认，再由“开始下一项训练”进入。训练仅复用同一录像证明流程，不称用户另做了一组训练；实际观测达到该剂量与目标、测试输入无不适后记为完成。此前默认次数测试曾出现同片 4 / 3 次波动，正确保留未完成；不改计次阈值或伪造达标。
- 原深蹲录像 120 个抽样画面成功处理、生成报告，但膝角所需踝点缺测，有效膝角与完整次数均无；**深蹲计次仍未通过实拍验收**，需补拍脚部全程可见的侧面录像。
- 历史 / 身体汇总显示、备份数据校验可用，Activity 关闭后重开，3 条本地活动记录和已完成计划保留。
- 独立 `CameraSmoke` 通过：仅用模拟器生成的前置相机，不访问电脑摄像头；相机流开启、视频画面就绪，暂停后全部轨道释放。没有真人实时计次或红米相机验收。

Android 15 截图实际检查了动作画面、骨架、大字提示和系统栏避让；截图及完整个人结果只在忽略的 `android_offline/build/`。规则 / 画面加载通过不等于所有手机兼容；原生文件选择器、相机录制 App、保存对话框、红米速度 / 温升与全部 53 动作仍需实机。

## 交付边界

这是可安装的独立本地演示工程，不是整个电脑版无差别迁移。双摄 / RTSP、在线分享 / 同步、ASR / OCR、原 Ankang 完整管家 / 周报 / 通知和三维模块尚未迁入。手机运动精度、实时性能、发热、相机 / 文件选择器 / 保存对话框兼容性待实机。附件不包含在 JSON 备份中。具体运行与构建见 [Android 本地说明](../ANDROID_LOCAL.md)。
