# 统一康复与健身动作库 · 2026-10-19

## 范围与实现

用户要求把原先分开的健身分析入口纳入动作库。沿用现有字体、浅底、青柠选中态、双列动作卡和部位横向筛选；不重做首页、Qt界面或现有视频上滑回看。

- 原185项图文卡（63评估、122训练）和656张图保持原内容、ID、来源及剂量。图文资源不自动成为测量绑定。
- 从当前实际`fitnessCatalog`投影8项健身分析；只支持已知、可用、未重复的ID，缺少服务时不显示无效卡。显示总数随实际可用目录变化，完整193项。
- 全部列表先显示8项分析；“全部/评估/训练/健身”分类及原部位筛选、30项分页保留。支持杠铃深蹲/背蹲、杠铃硬拉、杠铃卧推、杠铃划船、肩推、二头肌弯举、中英文及空格归一搜索。
- 健身卡点击进入原`fitnessPage()`，复用原观察侧、拍摄、选片、同意、CPU分析及结果保存。返回清理临时选片、保留原检索和筛选，不写病历、训练计划或完成状态。
- `T-LOW-020→fitness_squat`、`T-LOW-060→fitness_deadlift`为人工明确的图文到分析入口。其他变式不猜绑定；图文原说明和注意事项完整保留。
- 健身直接进入同一目录；原独立康复评估入口、跟练、反馈、历史与计划流程不改。图文加载失败保留原健身分析降级入口；异步加载不能覆盖离开后的页面或新账号。
- 现成动作图仅用于对应健身图示；未有相应照片的四张卡使用项目原哑铃SVG符号。未生成新图片或用不相同的动作照片替代。
