# APK动作图文、登录和云端管家修复

日期：2026-10-15。电脑0.25.6、APK0.5.6/code56；云服务业务版本仍为0.3.5/schema4。本页是本轮实际记录，不替代真实手机的摄像头、BLE或测角验收。

## 原因与修改

- 0.5.4排除了内部候选图片目录，53项评估详情仍显示介绍占位。本轮新增独立的只读公共动作图文库：185卡（63评估／122训练）、656张所选概览与步骤图。按稳定公共动作ID连接文字和图片，不把185卡等同于185个已实现测量算法。
- 动作库支持类型／部位／名称和编号查找、分页、步骤横向浏览和图片放大；保留原文准备、条件、剂量和停止说明。I/Y/T/W、四方向踝动作保留独立图组和原顺序说明。原53项测量、计次、有效性与计划算法未改；其详情直接显示现有起始／动作／回位说明。
- 未将候选图升级为精确左右侧或实时阶段绑定；原预览审核页、映射建议、归档原图不进公开包。动作图解不作为测量参考。656图仍保留原审核状态，未声称全部完成临床姿势审核。
- 原入口封面换为已有常规硬拉的装饰图。随后按用户要求用内置图像编辑工具去背景，再以透明人物和渐变融入按钮。动作库原图字节不改，缩略图通过统一底色与边缘渐变衔接，放大仍查看完整原图。
- 手机卡在“处理中”的根因：`MainActivity.accountRequest`旧白名单不包含`assistantTurn`等新接口，合法请求被静默丢弃。改为与`AccountTransport.supports`共享允许操作；无效请求明确回传错误。同步读取账号身份不再等待整个HTTP请求的对象锁，超时和回执未知仍保留原问题与幂等操作号，不自动重发付费请求。
- Android启动先加载本地登录页：登录／注册只要求普通账号密码，不设复杂度；有效旧会话核验后进入本人独立档案，网络不可用时可选择已有账号离线进入。密码只送原生HTTPS通道，不存页面持久化数据。退出后不能直接回未登录主页。正常未登录提问提示登录；私密／不记录回合仍保留本机处理。
