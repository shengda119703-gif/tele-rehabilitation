# 网页呈现打磨 · 2026-10-07

## 功能冻结与设计目标

目标为正在使用的统一五页网页及 `/capture` 动作页，不涉及 Qt 重构。保留现有绿色、导航与页面结构，减少重复的说明句。长说明按需展开；正文、动作步骤和关键结果不缩小。按钮统一为有明确主次的 48 px 以上点击区域，用轻量 SVG/CSS 图标提示操作。

冻结：所有 API 路径、请求体、数据读写、事件处理、路由、来源选项值、模型、阈值与计划规则。保留原按钮 ID、表单字段与校验、上传同意、停止提醒、缺测和估算标识、家庭共享授权与默认不共享语义。不是删除全部 `.muted` 或 `small`；日期、来源、剂量等真实内容仍显示。用户动作图片与导入脚本不属于本轮。

## 基线与组件选择

在隔离 TEST 服务查看修改前 375 × 812 首页。重复的陪伴式介绍、同步状态、空状态操作说明占用首屏；按钮主次虽有颜色区别，但缺少操作识别。基线图片留在忽略的 `qa-output/ui-polish-2026-10-07/`。

依 UI polish 技能读取设计与交互状态规范，搜索本地 touch/focus 知识，并通过项目发现工具检查 button / segmented control 候选。SpecularButton 依赖 ogl 且采用玻璃 shader；FuseButton 改变长按确认行为；SlingButton 引入拖动发射；VoicePill 默认模拟语音。均不适合本轮功能冻结。RubberSegment 的 `value/onChange/disabled`、选中态和布局可作参考，但 motion/React 依赖与弹性拖动不引入。本轮使用既有原生 HTML/CSS 按钮，保留原事件和语义，图标为装饰性 CSS mask，不复制第三方组件代码或新增依赖。已有导航动效不修改。
