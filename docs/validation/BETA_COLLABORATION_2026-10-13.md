# 医患协作增补：实现与验收

本轮使用隔离 SQLite 数据库与虚构账号；未部署公网服务器、未修改生产数据库、未访问真实患者记录。工作分支为 `codex/rehab-beta-collaboration-20261013`，基于 main `c34bca6`。合入情况以 PR #6 状态为准。

## 实现范围

- 复用现有患者账号、医生权限、授权关系与数据库。正式环境不生成测试患者；登记用户列表与获授权医疗资料分开，未授权不能读取健康记录。生产读取过滤明确标记的合成验收记录。
- 原始 PDF、PNG、JPEG 可以由患者主动分享，每份最多 2 MiB，支持逐份撤销；医生同时需要患者授权和该文件分享权限。没有 OCR，也不把报告图片发送给模型。
- 医患文字聊天沿用持久消息、未读游标及稳定操作编号重试。配置工作日、工作时段和节假日后计算一小时待回复时间，患者补充消息不重置时间；医生明确标记有效人工回复，自动应答不完成回复任务。
- 个人目标、器材、限制条件可保存复用。真实保存的评估与已有动作资料组成候选清单，起始及进阶候选先供医生审核，不直接替代当前方案。候选生成不调用付费模型。
- 医生方案支持阶段日期、每周训练日及逐动作设置。发布后患者确认采用；聊天不修改计划。开始训练前再次核对云端方案、日期、停用状态与本地评估。休息日、停用、离线无法核验及程序不支持的设置都不进入执行。
- 正式绑定云账号的桌面和手机问答通过服务端模型入口，服务端保存供应商返回的 token、缓存命中及未命中量。稳定请求编号避免丢失回执后重复发送；未知或缺失用量不记成零成本。

## 费用口径

服务端配置 `ANKANG_AI_API_KEY`、`ANKANG_AI_MODEL`、`ANKANG_AI_MONTHLY_TOKENS`、`ANKANG_AI_MONTHLY_CALLS`。价格使用 `ANKANG_AI_TARIFF_JSON`，字段为 `version`、`currency`（USD 或 CNY）、`cache_hit`、`cache_miss`、`output`，各价格为每百万 token 的金额。未配置价格显示未计价，不猜测人民币汇率。页面金额为配置价格的估算，不是供应商账单；不自动推算峰谷价格。真实计费 API 尚未调用验收。

数据库新增表采用 schema 3；需要另行备份、迁移及部署验证。本轮没有执行生产迁移。云服务 0.3.0、桌面 0.25.0、Android 源码 0.5.0/versionCode 50。

## 功能边界

只有现有执行契约支持的动作与参数能进入自动训练。附加负重或不支持器材的阶段标为人工执行，不能静默丢弃这些要求。自报分级仅用于资料筛选，不是专业肌力评估。候选审核结论与医生草案仍需要医生明确发布、患者明确采用。旧的未绑定账号个人模型配置不能纳入服务端每用户统计。线下专业初筛、会员和手环本轮不扩展。
