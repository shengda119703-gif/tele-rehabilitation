# Product 黑箱审计 · 2026-10-03

## 结论与置信度

**不能宣称“所有产品路径已验收通过”。** 本轮从公开 Qt 控件执行了软件操作，发现并修复附件返回、家庭绑定确认、私密对话备份及银发错误/忙碌/取消状态问题。可运行软件路径有真实结果；完整真人康复、真人中文语音识别、外部平台及实体健康设备仍未完成验收。此前文档中的按钮合同覆盖或模拟测试不能替代这些实机结果。

- 高置信度：本报告列出的公开控件操作、真实本机业务写入/导出、失败提示、用户隔离与已修复缺陷。
- 中置信度：这些覆盖对更长时间连续使用的稳定性具有支持作用，但没有长期压力、断电或多电脑并发测试。
- 未知：真人测量效果、真人麦克风识别、真实远程身份/送达、iPhone/HealthKit 和实体健康硬件。本轮不据接口存在推断成功。

## 方法与证据范围

1. Qt 公开控件黑箱：正式 `ProductWindow`，通过鼠标/键盘激活真实可见按钮、表单、页签、下拉选项、文件选择和确认框；使用正式 Rehab Runtime、ProductService、SQLite、Python/Node bridge。没有私有回调代替点击、没有替换对话框返回值或直接向业务服务种植数据。
2. 独立 TEST 用户和独立数据目录；所有资料、药物、设备 JSON、PNG/MP4 都是明确的测试输入。临时 APPDATA 在工作区外，不使用真实 API Key。Qt runner 禁用外部模型和语音；其聊天结论仅限当前确定性 Runtime/bridge。
3. Windows 实际 Qt 窗口另做首次建档、对话与 Surface 麦克风开始/取消/结束操作。实际截图为 `rehab_codex_single_camera_v2_1/qa-output/blackbox-native/voice-no-speech.png`。原始相机另经公开 Qt 控件真实打开 Surface Camera Front，取得 1280×720 画面并完成镜像切换/关闭；这不等同真人姿态测量。
4. 既有 Python/Node 自动化回归单列；其中使用模拟对象的测试不归入上述黑箱实机验收。

## 未通过/未执行事项

- 真人摄像头评估、训练完成、组间继续、训练后感受、有测量数据的历史报告/比较/删除、训练回放：本轮没有完整实机证据。单摄原始预览已通过；没有双摄实机、模型推理和动作测量证据。
- Surface 麦克风可实际开始/取消/结束；结束后本机 ASR 显示“未识别到清晰语音，请检查麦克风后重试”，没有假聊天。未提供真人中文讲话，**真人麦克风识别未验收**。
- AI 朗读宿主未接；原银发 Qt TTS 在本轮隔离环境缺 QtTextToSpeech，真实点击提示不可用。两种语音输出不能混为已通过。
- 外部 DeepSeek、可信跨设备同步、iPhone HealthKit、特殊/通用健康设备、webhook/push 真实送达、OCR/多模态识别：接口/状态与不伪成功保护可验证，外部闭环未验收。
- 原康复矩阵仍有未逐项执行的可用控件/分支；详见 165 行缺口 CSV。这是本轮覆盖不足，不能全部归因于硬件。运行中控制、真实远端配对以及有数据报告等不算通过。手机 TEST 演示控制页的 localhost 开启/注入/关闭已通过，不能推断手机收件。正式产品主动隐藏的“一键生成演示计划”没有绕过隐藏控件执行。
- 未发现已执行控件的无反馈行为残留；这句话只限已执行范围，**不保证未执行控件没有问题**。
