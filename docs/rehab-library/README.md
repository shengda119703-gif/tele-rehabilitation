## 本地候选计划

`rehab.plan.draft` 接收目标goal、部位region、器材equipment、限制restrictions、当前任务等级level（0–3）及screeningConfirmed。它不调用LLM，不保存或采用计划，不修改日期或当前计划。

规划器需要经过整理的完整训练卡、结构化候选剂量dose和适用筛选eligibility。当前导入条目都是评估卡且dose=null，所以返回needs_library和明确原因。后续训练资料到齐后应人工整理剂量与适用字段；不能把自然语言剂量自动当作适用于每个人的处方。已实现筛选器的确定性、器材/限制过滤和不自动采用；测试用剂量仅为TEST合成数据，不可入正式库。

## 问答与费用

完整动作卡可直接本地显示。已配置LLM且不是隐私回合时，匹配卡的问答可调用一次模型将资料讲清楚；没有资料不会让模型补造。隐私回合不请求模型。模型失败回退原资料。个人康复记录通过受限只读接口在本地解释；本轮没有新增将个人记录传给模型的许可。

普通聊天不产生健康事件、不撤回业务记录、不共享事实、不调度服药/训练，不导航其他模块。原手动健康、用药、家庭及计划页面保留。旧待操作数据不删除，正式助手不显示或执行。
