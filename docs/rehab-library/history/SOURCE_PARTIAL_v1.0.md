## 0. 本文解决什么问题

本库覆盖髋、膝、踝、足弓、腰骨盆／骶髂区域、腰部、胸部、颈部、肩、肘、前臂与腕。既包含无器械、支撑下活动和日常功能，也包含弹力带、哑铃、壶铃、杠铃、稳固家用支撑上的训练，以及经过适用性筛选的落地、低跳和运动任务。

本库目标是让普通用户、已有力量基础的人和运动员都能找到足够有挑战、又符合当前状态的训练。不要因为用户受伤就把所有部位降到同一低等级，也不要因为用户自称运动员就跳过当前受伤部位的必要筛查。

每张卡都写明目标、设备、开始条件、准备、操作步骤、关键要领、常见错误、候选剂量、退阶、进阶、停止条件、机位、视觉能观察的事实及不能观察的内容。卡片里的动作名称与编号是后续 API 大模型和规则系统的共同词表。

本库默认面向能够理解教学并参与反馈的成人肌肉骨骼康复场景。儿童足弓、明显神经系统功能障碍以及有专门保护要求的术后方案，需要另建适用人群与协议；不能直接继承本库的一般剂量和解释。老年或平衡受限者可使用符合条件的有支撑变式，并记录实际帮助。

**阅读路径：**先读第 1—7 节了解分级、器械与测量含义，再用第 9 节按编号查动作；第 10 节是评估，第 11 节是训练；第 12 节为单人与视觉成果协议，附录 E 为49条见习来源对照，附录 F 为单人适配边界。每张卡都可单独展示，日常训练页只需提炼当前动作的少数关键口令。

**重要定义：**

- “完整”指本库覆盖区域和功能层级有可检索、可执行讲解的动作集合，不意味着收录全部康复技术，也不意味着每个患者适用全部动作。
- “纯视觉”指主要动作观察不依赖穿戴传感器；用户仍需提供疼痛、困难度、已知负重等摄像头无法可靠读取的信息。
- “有效”应理解为目标与渐进负荷有合理依据、适用条件明确。研究支持某类运动或某个特定方案，不代表每一种家用变式都已独立证明疗效。
- “可登记”与“可自动测量上线”分开。全库可以先成为有详细教学的资源；只有完成对应验证的指标才参与自动评分和临床解释。

### 0.1 单人执行与资料使用

本库以单人完成任务、固定摄像头记录动作事实为主要执行方式，再结合本人症状、用力和次日反应追踪。单人表示无须第二人托扶、施力或接抛，可以使用固定扶手、墙与稳固设备；摄像头不能代替人实际托住身体。

适用者须具备理解、反馈和独立摆位能力。青少年、特殊肿瘤切除/假体手术、跟腱重建、ACL取腱等需要相应人群与手术协议，不直接套用一般成人剂量；已知术后限制与专业计划优先。所有动作入口同时遵守第12节及附录F。

资料来源中的见习表采用“01_每日见习记录”序号1–49的有效文字，占位记录不纳入。动作来源与其可观察性、临床疗效和软件验证分别管理，不复制患者身份、导师执照或签名信息。

## 1. 四个维度分别管理

### 1.1 负荷与任务等级

| 等级          | 典型内容                    | 使用方式                         |
| ----------- | ----------------------- | ---------------------------- |
| L0：低负荷与支持   | 有支撑活动、小范围主动运动、轻度等长或辅助任务 | 用于当前需要降低局部需求的任务；不是对全身能力的评价   |
| L1：基础能力     | 自重活动、基本站立、可控的双侧功能和基础耐力  | 先确认能稳定完成，再增加剂量               |
| L2：负重与单侧能力  | 哑铃／壶铃／杠铃／弹力带、单侧任务、较长杠杆  | 要有该动作技能、设备条件和当前局部耐受证据        |
| L3：高要求与运动任务 | 快速发力、落地低跳、连续任务、专项组合     | 需相应恢复阶段与前置能力；不由一次成功或身份标签自动放行 |

L0—L3 是本项目的任务标签，不是临床肌力分级、损伤严重程度，也不是通用临床常模。一个人可以同时是“患侧踝快速落地暂不适用、坐位上肢负重可用、髋部某些训练可用”。

### 1.2 视觉能力

| 模式      | 可做内容                        | 缺测时的行为                |
| ------- | --------------------------- | --------------------- |
| 身体点观察   | 规定机位的次数、时长、明显肢体活动和二维投影指标    | 保留有效片段与已确认完成事实        |
| 局部／标定观察 | Face、Hand、足部近景、尺度或经过验证的三维指标 | 暂停缺失指标，可使用自报或替代指标     |
| 陪练与自报   | 等长发力、短足、细小脊柱活动、不可见的主观症状     | 正常教学、计时与保存；不伪造肌肉发力或角度 |

以上模式与负荷等级独立：高水平选手的重负荷等长练习也可能以陪练为主；一个基础踝角测量反而需要额外足点。

### 1.3 当前能力与既往能力

分别保存受伤前训练量和熟练动作、当前患侧任务表现、当次症状，以及本次负荷后的恢复反应。历史深蹲重量只帮助理解经验，不能替代这次受伤后的负重、平衡或跳跃能力。

### 1.4 临床依据与本项目验证

来源提供临床协议、运动类别或特定研究的依据；本项目还要独立验证机位、点位、计次、动作阶段及目标人群。不能把“研究中的临床测法可靠”标成“当前模型准确率已经达标”。

## 2. 选择动作时先看需求，再看器材

2026 年 ACSM 健康成人抗阻训练立场文件支持渐进抗阻训练改善力量及多种功能；器械类型或动作复杂程度并未一致决定训练结果。其对象为健康成人，不能把其中高负荷建议直接移用到急性损伤。[ROOT-S01]

因此，本库不把杠铃视为必然高于弹力带，也不认为复合动作必然优于简单动作。选择顺序应为：

1. 本次最需要改善的任务与能力是什么？
2. 该动作对患侧、支撑侧、躯干与上肢分别提出什么要求？
3. 当前适用条件和恢复反应是否支持这些要求？
4. 用户会不会做，设备是否稳固可用？
5. 再选择负重、动作幅度、组次、节奏和休息。

必须记录间接负荷：地板推举的上下地过程、划船的支撑、负重行走的踝支撑、哥本哈根的上腿接触、弓步转体的足膝与躯干需求。不能仅凭“主练肩／髋”判定不会影响受伤踝。

## 3. 家庭器械与支撑规则

| 器材        | 进入计划前需要确认                        | 数据记录                         |
| --------- | -------------------------------- | ---------------------------- |
| 哑铃／壶铃     | 能安全拿起和放下、握把完整、周围无碰撞障碍            | 单只重量、数量、握持位置；单手重量与总重量分开      |
| 杠铃        | 既有技术经验、锁扣和配重明确；需要架的动作有合适深蹲架及安全支撑 | 杆重、单侧片重、总重量；不要求无人辅助最大测试      |
| 弹力带       | 无破损、锚点可靠、拉伸方向不朝向脸部、不会脱落          | 品牌／型号／颜色、原长、使用长度可选；无标定时张力为未知 |
| 家用椅／沙发／台阶 | 无轮、无明显摇晃、不滑移、承重和接触面合适；必要时靠墙固定    | 高度、支撑位置、固定方式                 |
| 家庭代用品     | 重量与握持可控，不使用易碎、尖锐或会突然移动的物体        | 重量来源标记为实测、商品标注或估计            |

### 哥本哈根的家庭替代

短杠杆先考虑膝附近的宽软垫支持，长杠杆转为踝／远端支持会显著改变接触和关节要求。支撑高度要让身体能够稳定完成，不能把“越高越好”写进提示。无法确认家用支撑可靠时，改为地面侧卧内收或其他低需求变式。

哥本哈根训练的预防与强化研究主要来自特定足球人群；家庭支撑版属于本库的教学适配，不能据此声称适用于所有腹股沟痛，也不能把长杠杆版本直接分配给刚崴脚的人。[ROOT-S02]

### 壶铃弓箭步转体的拆分

先确认分腿站／分腿蹲和独立小幅转体，再组合为稳定分腿位持轻壶铃靠胸转体，最后才考虑加入跨步。负重离身体越远、旋转越快、动作越连续，要求都会变化。一次只改变一个主要变量，不强迫腰、膝或脚在固定位置承受末端扭转。

## 4. 剂量和进阶：卡片给候选，规则系统给当次计划

卡片中所列组次、保持和休息用于形成试做与训练模板。没有通过适用性筛选和当次试做，不得直接把全库剂量批量发给用户。

### 4.1 初次试做

- 对不熟悉动作，先用无负重或明显可控的轻负重完成少量重复，确认起止、支撑、呼吸和症状。
- 有力量经验者可从符合技能的动作形式开始，但外部负重仍需依据当前受伤部位和任务反应选择。
- 首次任务若太轻，可以调整负重或任务要求；若太难，只退阶相关任务，不把整个用户档案清零。
- 试做不是最大测试。急性疼痛、术后限制或恢复状态未明时，不要求做到力竭、1RM 或反复最大跳。

### 4.2 用力与症状是不同维度

RPE 采用明确的 0—10 主观用力量表；RIR 表示估计还能以相同标准完成几次。二者不能替代疼痛、肿胀、稳定感、活动下降和次日恢复，也不能用固定公式相互精确转换。初学者不理解 RIR 时，问“还可以轻松做几次／已经很吃力”即可。

不存在适用于所有部位、所有伤情的统一允许疼痛值。已有医疗计划的阈值与限制优先；未设阈值时出现新发或明显加重的熟悉症状，先降低幅度／负荷或停止该任务并补问。出现新发明显无力、麻木、失稳、胸痛、晕厥等改变风险的信息时走对应临床分流，不因画面质量差启动同一阻断。

### 4.3 一次改变一个主要变量

可以改变负重、活动范围、杠杆长度、支撑、重复量、保持时间、速度或动作组合。不要同时增加重量、减少支撑、增加旋转和追求速度。是否进阶还取决于练后与次日的症状、肿胀、功能和信心，而不只看训练当时是否做完。

运动员可以需要更高水平的力量、功率、平衡、跳跃和专项准备。踝扭伤后的 PAASS 框架包括疼痛、踝部功能、运动员感知、感觉运动控制、运动／功能表现；它没有提供一个可以自动判定返赛的通用分数线。[ROOT-S03]

## 5. 评估与训练复用动作，但不混用协议

坐站可以是轻松练习、5 次坐站测试或 30 秒坐站测试。动作识别底层可以共用，`protocol_id`、开始／结束条件、是否允许用手、椅高和解释范围必须分别保存。

- 标准测试未完成时如实记录，不用“估计已做完”生成标准分数。
- 可以继续完成一个改良训练任务，记录实际支撑与完成情况；它不覆盖原标准测试的事实。
- 同一个用户复评时，优先重复相同机位、椅高、负重、节奏要求和帮助条件；条件变化时标注，不把变化全归因于康复效果。
- 未标定距离就不输出精确厘米或米／秒；只有近似二维图像角时就保留投影角身份。

## 6. 纯视觉实现与流畅体验规则

1. 先让用户选择或由计划明确本次动作，模型只验证是否符合当前任务，不要求复杂模型每帧猜全库类别。
2. 基本动态动作共用角度／相位／计次状态机；保持、步行、旋转、足部近景和手脸局部分别使用合适的观察模块。
3. 摄像机正面、侧面或斜前方各有用途。适合计次的机位不一定适合某个角度定量；不要给所有动作统一一个机位后宣称全指标可测。
4. 膝／肘角、上臂相对躯干抬举等可以先做规定平面的投影指标。髋角受骨盆和躯干影响；胸腰椎分段、骶髂运动、肩胛动态角和足底压力不得由稀疏身体点直接给数。
5. 足弓用足部近景与症状／负重变化；颈部用 Face 与躯干参考；腕／前臂用 Hand 与前臂信息。COCO17 不具备这些全部点位。[ROOT-S04][ROOT-S05]
6. Face、Hand、Body 的局部 world 坐标不直接拼接成统一公制骨架。图像坐标先统一裁剪／缩放，三维融合必须校验参考系与尺度；颈相对躯干旋转也不是不同坐标系欧拉角简单相减。
7. 短缺测保留任务上下文和已确认进度；长期不可观测时降为陪练或自报。缺测期间不补造转折、保持时间或完整次数。
8. 用户自报“总共做了 10 次”与视觉已确认 6 次不能相加成 16 次。保存两个来源和合并语义。
9. 等长收缩、短足、深层肌激活等动作不能仅凭计时成功标记“发力已验证”。用户仍可正常完成与保存。
10. 动作讲解优先保持 2—3 个关键提示；动作详情随时可查看。同一个纠错不高频复读，旧提示在暂停、换动作或状态改变时取消。

## 7. 力学估计的使用边界

首版先提供任务完成能力、次数、时间、负重记录和节奏。体重与人体测量模型可以估计肢段质量、质心及惯量，但不是实际称量。

规定条件下，缓慢持重的重力力矩可用 `Σ(估计质量 × g × 水平力臂)` 作模型估计；有可靠全身质心与尺度时，起立过程的 `M × g × 质心升高 / 上升时间` 可作为重力势能增加速率。只测髋点时必须命名为髋位移代理，不能称真实全身质心。MediaPipe 身体 world 点以髋中点为原点，不能直接用来读取人体相对地面的整体升高。

动作速度不等于肌力。动态力矩还取决于加速度、惯量、负重和地面／椅子／扶手等外力；净力矩也不等于某块肌肉的最大力量。不得自动转换成 MMT 0—5 级。[ROOT-S06]

2026 年 OpenCap Monocular 提供了单手机结合三维优化和动力学模型的研究路线，但其验证任务、人群、算力与许可范围均有限。本项目可将类似方法作为离线研究能力，不把它放入实时训练必须等待的链路。[ROOT-S07][ROOT-S08]

纯视觉表示主要动作记录不依赖穿戴设备；疼痛、麻木、RPE、负重/器械设置和次日反应保留本人/设备/专业输入。第12节的单人筛选与可观察性约束对全库有效，所有动作均须遵守。

### 8.1 动作出处与证据解释

每卡的“动作出处与对应原文”给出可检索资料和原文动作名称；附录G按卡片编号集中列出对应关系。引用核对日期为2026-10-13，优先采用专业学会资料、政府/公共卫生机构协议、大学医疗中心或公立专科医院说明，并在适用时引用原始研究。

| 来源性质                   | 可以支持                   | 不能据此直接宣称            |

| AAOS等专业学会、大学医院/NHS动作手册 | 有明确描述或官方目录的动作形式与临床使用背景 | 每个患者均适用、每个改良版本已验证疗效 |
| NSCA/ACE技术手册与文章        | 健身动作形式、器材及技术出处         | 急性损伤/术后许可、疾病疗效或医学诊断 |
| 原始训练试验或肌电研究            | 原研究人群、干预、实际测量的结果       | 肌电等于临床疗效，或视频能读取肌肉激活 |

## 10. 评估动作详细卡

### 10.1 综合功能与专项任务

<a id="e-gen-001"></a>

#### E-GEN-001｜家庭短距离自然步行观察

**区域：**综合功能/髋膝踝/步态　 **等级：**L1基础；有规定辅助条件的个体化步行观察

**目标：**观察家庭中自然起步、连续迈步、停步和必要转身的功能表现、辅助需求与症状；无标准4 m路径或无尺度时仍可使用，但不报告标准步速或m/s。

**器材**

- 平整、清理杂物且不打滑的一小段通路
- 日常合适鞋及平时使用的助行器（如需要）
- 手机固定支架；按当前情况安排可协助的陪同者

**开始条件**

- 当前允许相应程度的承重，能在既定辅助条件下安全起步；新近外伤承重资格不明时先澄清，不让用户靠试走排除骨折。
- 有近期反复跌倒、明显站立不稳或既定陪同要求者，不安排独自测试。场地或个人条件不允许安全迈步时使用已有日常活动报告，不强行录像。

**准备与起始位：**选择家中能自然走几步的实际通路，记录长度是否实测、鞋、助行器、扶持和地面条件；不要求凑够4 m。相机固定，尽量包含全身、双脚和通路。无需为观察功能强行完成尺度标定。

**操作步骤**

1. 先在起点站稳，报告此刻症状和所用辅助；陪同者站在方便协助而不挡路的位置。
2. 按平时舒适速度沿通路自然迈步，不为镜头刻意加快或放慢，也不边走边拿手机。
3. 走到预定安全位置后停稳；空间足够且当前允许时，可舒适转身再返回，否则本次只观察单向步行。
4. 结束后记录是否需要临时扶墙、有人扶持、停顿或发生熟悉症状；选择仍有决策价值时才增加一次观察。

**关键要领**

- 用你平时的步伐，先顾好走路，不用追求步数或速度成绩。
- 平时需要的助行器照常使用，不为展示能力撤掉。
- 转身空间不够就停稳，不挤着转或绕开危险家具。
- 感觉需要停下来或扶稳时立即照做，并说明原因。

**常见错误**

- 把无尺度的像素位移除以时间，直接显示为m/s或4 m步行测试分数。
- 短通路中多次起停与转身被当作稳态直线步行，与其他测试协议直接比较。
- 为拍清全身要求用户走入狭窄区域、撤掉助行器，或让陪同者后退拍摄而无法协助。

**试做与候选剂量／评估协议：**本库功能观察方案：通常1趟足够；若第一趟已获可用信息不重复。必要时再观察1趟，两趟之间坐下或扶稳休息30–60秒或更久，直到回到舒适状态。实际长度、次数与休息为任务条件，不是标准4 m步速协议。

**退阶：**缩短为安全范围内的少量自然步行，增加已允许的助行/陪同；若仍不适合，保存用户日常走路、转移困难及辅助需求的报告，或改为另注册的坐站观察。改变辅助或任务后另记协议，不冒充同条件步行通过。

**进阶：**同条件复测可观察个人变化；确有步速评估需求时另启用有实测距离、固定计时边界和适用验证的标准步行协议。需要更复杂转向时另选注册任务，不在本卡直接增加负重或快走。

**停止或调整条件**

- 出现明显失衡、腿软、新发锐痛或当前症状明显恶化时停止并扶稳/坐下。
- 出现胸痛、晕厥或不能用一般用力解释的明显不适时终止测试并按系统分流。

**机位与画面：**优先固定的侧前方或侧面全身视角，视野覆盖实际安全通路；不能同时看清全程时保留可见段，不强迫用户重新摆机位反复走。

**视觉可以观察**

- 可见段中的起步、连续迈步、明显停顿、停步和转身过程。
- 清楚可见时的步数、节律、明显左右动作差异与临时扶持事件；接触边界不清时对应指标标未知。
- 用户自报的症状和困难另存自述证据，不由步态外观自动生成疼痛评分。

**视觉不能直接判定**

- 没有实测距离或可靠地面尺度时不能输出m/s、真实步长或标准4 m步行结果。
- 有限单目短片不能直接确定关节接触力、地面反力、肌力等级或步态异常的病因。
- 看不见的路段、跌倒风险全貌及助行器实际承担的力，不能由模型补造。

**观察不足时：**没有4 m空间、没有尺度或局部出画时仍保留本次功能观察及自述；速度字段置未知，不让用户为得到m/s反复重拍。已有录像可重分析。安全性本身不满足时停止行走任务，改用允许的替代而不是仅降级测量。

**动作出处与对应原文：**[REF-S079]；Walking for health：自然步行；本卡为短距离功能观察。

**证据性质与适用范围：**公共卫生机构活动说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S079]；背景及临床边界：[GEN-S03]。动作形式、背景指南和产品测量证据按第8节分别解释。

**设计与见习追溯：**[GEN-S05]；本库单人设置、阶段规则与候选量用于实施登记，见习经历和项目设计不属于临床疗效证据。

- 有完整安全的3 m通路和明确起点/转向线；路径不足时改用E-GEN-001，不缩短距离后仍标标准TUG。
- 全自动计时需要完整可见的路径、开始信号与坐回边界；也可由现场评估者完整观察并独立用秒表计时，标记人工来源。

**准备与起始位：**椅子固定，地面标记本协议的椅前起始基准与距其3.00 m的转向线，记录距离基准、椅高、扶手、鞋和助行器；用户背靠椅背坐稳，助行器放在惯常可取的位置。固定相机覆盖椅子、整段路、转向线及双脚，不能拍全时先决定使用完整现场人工计时或改为功能观察。

**操作步骤**

1. 先说明并按本地冻结协议熟悉一次完整路线：起立、走到转向线、转身、返回并坐回，不以最快速度完成。
2. 休息后回到同样坐姿；评估者说“开始”时启动计时，而不是等模型识别到髋部上升才计时。
3. 用户从椅上起立，使用其平时需要的辅助，以舒适自然速度走至3 m标记，再转身返回。
4. 回到椅前，按惯常方式转向并坐下；本版本以臀部重新接触椅面完成坐回作为终点，不以到达椅旁、开始下蹲或报告返回为终点。
5. 保存总秒数、计时方式、全部协议条件及功能观察。自然停顿仍包含在总时间；如果因安全原因中断则记未完成，不计算假想完成时间。

**关键要领**

- 用平时舒适、稳妥的速度，不跑，也不需要争取最快成绩。
- 常用助行器照常使用；是否借助扶手起立按协议记录，不强行改为抱胸。
- 到标记处再转身，回来确实坐到椅面才结束。
- 感觉不稳就停下求助；是否完成比追求一个秒数更重要。

**常见错误**

- 从检测到起立才开始，或走回椅旁就停止，造成与口令开始/坐回结束的标准计时不一致。
- 用网络请求接收时间代替本地口令或录像时钟，或对中间停顿自行扣时。
- 改变路径长度、椅高、助行器或速度要求，却与其他测试条件的结果直接比较。
- 关键画面缺失时用预测轨迹补完整秒数；把单一跌倒界值套用于所有用户，或把TUG当竞技回归测试。

**试做与候选剂量／评估协议：**本库冻结施测版本：先1次熟悉，休息约60–120秒或至舒适稳定，再进行1次正式计时；演练和休息安排属于实施协议。已有一次有效结果即可结束，不为取最好成绩反复走。确需其他重复测量方案须使用另一明确版本，保留每次结果与聚合规则。

**退阶：**改用E-GEN-001家庭自然步行或允许条件下的起立/转身功能观察；保留已完成片段和原因，不输出标准3 m TUG总时间。需要增加人的身体扶持时明确改变辅助条件，不能当作独立完成的同类结果。

**进阶：**先以相同椅子、路径、鞋、助行器和计时版本复测；更快速度、双任务或携物TUG应作为独立协议另行判断资格，不在本卡自动进阶或用于宣布可以比赛。

**停止或调整条件**

- 明显失衡、需要突然身体扶持、腿软、新出现眩晕、锐痛或症状明显恶化时停止。
- 通路出现障碍、椅子移动、助行器使用不安全或评估者无法提供预定协助时终止本次，保留未完成记录。

**机位与画面：**固定广角侧前方视野，尽量覆盖完整起立、3 m路径、转身、返回和坐回；手持跟拍与网络延迟不能被无条件视为可靠自动计时输入。

**视觉可以观察**

- 全程与计时基准有效时的总时间，以及可可靠分开的起立、步行、转身和坐回片段。
- 明显停顿、转身策略、步行不稳和临时扶持；人工记录与视觉事件保留各自来源。
- 仅在边界清楚时计算分阶段时间，不因总秒数存在就编出每阶段秒数。

**视觉不能直接判定**

- 丢失开始、转身、坐回或关键路径且无完整独立人工记录时，不能自动补造符合协议的TUG结果。
- TUG秒数不能单独诊断病因，也不能直接量化最大肌力、组织愈合或宣布竞技恢复。
- CDC相关跌倒筛查提示有特定老年人使用背景，不能当作适合所有人群的一条万能界值。

**观察不足时：**若自动视频计时无效但现场人员完整观察了规定路线并完成独立秒表计时，可录入该人工TUG结果，注明来源而不必重拍。若没有完整人工记录，保存功能观察和未完成/测量缺失状态；不输出推算标准秒数。优先复用原视频，不强制重做整套评估。

**动作出处与对应原文：**[REF-S054]；Directions：3m往返、口令开始、坐回结束。

**证据性质与适用范围：**官方标准测试协议。测试动作和出处可追溯；本卡的单人实施、自动计时/角度与评分一致性仍须验证。

#### E-GEN-003｜地面多方向触点动态平衡：非标准化功能观察

**区域：**综合功能/踝膝髋/动态平衡　 **等级：**L1有支撑短距离触点—L2无支撑受控任务；按患侧当前资格选择

**目标：**观察规定支撑条件下向不同方向轻触地面目标并返回的控制、辅助需求与症状；这是本库自定功能任务，不是标准Y-Balance或SEBT，不输出其综合分数、标准化分或回归运动结论。

**器材**

- 平整防滑地面及贴牢、不形成绊脚物的地面标记
- 稳固台面或固定扶手；需要时有陪同者在旁
- 固定手机；不要求购买标准Y-Balance器械

**开始条件**

- 当前允许支撑侧承重并短暂承担主要身体重量；急性伤后限制、术后限制、疼痛和单腿控制条件必须先满足。
- 能完成对应支持条件下的安全站立与小幅重心转移；明显腿软或频繁失衡时不做单脚触点评估。
- 先明确手是否扶稳、辅助程度、哪条腿支撑和哪条腿触点；全程保持相同条件。

**准备与起始位：**一侧为支撑脚，在其前方、斜前方和侧方放置3个舒适可及的平面标记；初始距离由小幅试做确定并记录，不追求最大伸达。触点与支撑条件均为本库协议，不能套成标准Y字或星形测试。相机拍到躯干、骨盆、膝、双脚及标记。

**操作步骤**

1. 站稳并确认症状，选定支撑侧及扶持条件；先向最近的一个方向轻触一次以熟悉任务。
2. 主要重心留在支撑脚，另一只脚缓慢伸向一个标记，用足尖轻触地面，不跳过去，也不靠触点脚大力蹬地。
3. 把触点脚收回起始位置，先恢复稳定再开始下一个方向。
4. 按固定顺序完成另外两个方向；每方向记录是否够到、是否需要额外扶持、支撑脚是否移动及是否出现症状。
5. 休息后按资格选择是否观察另一侧，并记录两侧实际标记距离与支撑条件；不同条件不计算伪造的左右标准分。

**关键要领**

- 目标是稳稳伸出再收回，不是尽量够得远。
- 扶手按事先选择的方式使用，不为成绩临时松手。
- 每次回来先站稳；需要把脚落下或抓紧扶手就照做并记录。
- 支撑膝保持可控，不刻意锁死；不要憋气或用猛甩身体增加距离。

**常见错误**

- 触点脚明显承重或蹬地、支撑脚移位后仍被记为同一条件的成功触点。
- 用跳跃、快速甩腿或大幅失衡去追逐远处目标。
- 将自定的三个方向、扶持版本或自选距离冒充标准Y-Balance/SEBT，并计算其标准化综合分。

**试做与候选剂量／评估协议：**本库候选观察协议：每侧先1次近距离熟悉，再按3个方向各做1次；只有需要判断重复性且仍舒适时才每方向加1次。方向间可把两脚落地休息，侧间至少30–60秒或至稳定舒适。剂量属于设计方案，不是标准Y-Balance/SEBT施测次数。

见习34仅记录Y-Balance前向触及且尝试数不一致、无腿长，不输出标准化/综合分数。见习28的“单腿下蹲伸膝距离”缺正式协议及单位，不擅自视为Y-Balance。原始数据只作为当次记录；本卡仍是非标准化触点任务。

**退阶：**缩短标记距离、减少到一个方向或增加已允许的手扶；若仍不适合单侧支撑，另记为双脚着地的小幅重心转移观察。退阶结果只评价新条件，不视为原任务达标。

**进阶：**先在相同标记距离、顺序和支撑条件下提高完成稳定性；目标需要且当前允许时，一次只增加一个方向或少量距离，或减少一档扶持。快速触点、闭眼、不稳垫和跳跃不在本卡自动添加。正式Y-Balance/SEBT须另建准确协议并具备适当评估条件。

**停止或调整条件**

- 支撑腿打软、需要急抓扶手或陪同者身体保护、出现新发锐痛/眩晕或明显症状恶化时停止。
- 标记松动、地面打滑、无法受控收回触点脚或当前负重限制被触及时停止该方向。

**机位与画面：**固定侧前方全身视角，地面标记和两只脚清楚；地面尺度未标定时只记录触点类别与完成，不输出实际伸达厘米数。

**视觉可以观察**

- 清楚可见时的方向顺序、足部伸出和返回、支撑脚明显移位及额外落地。
- 明显躯干摆动或扶持变化；足尖触地边界不清时相应事件标未知。
- 有实际距离记录时可保留各标记距离与是否完成，作为本任务结果而非标准化测试分数。

**视觉不能直接判定**

- 脚底压力、触点脚实际承担多少体重、手扶力、关节稳定性和本体感觉，不能由普通RGB直接测得。
- 无可靠尺度不能输出厘米；即便有尺度也不能生成标准Y-Balance/SEBT分数。
- 成功完成或左右接近，均不能独立证明韧带愈合、不存在运动风险或可恢复竞技。

**观察不足时：**足尖/标记被遮挡时，可由陪同者或用户确认各方向是否完成及是否额外扶持，保存为自述/人工观察；自动指标缺失不计失败。可复用视频，必要时只补有决策价值的一个方向；不要求全套重拍，也不为获得完整分数强制加大伸达。

**动作出处与对应原文：**[REF-S004]；Star excursion：地面触点单腿伸及；本卡不采用SEBT标准计分。

**证据性质与适用范围：**专科医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S004]；背景及临床边界：[GEN-S03]。动作形式、背景指南和产品测量证据按第8节分别解释。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

#### E-LOW-017｜4米常速步行

**区域：**综合下肢、步态　 **等级：**L1基础

**目标：**记录固定路径常速行走能力。

**器材：**4米实测通道、起终点贴条、平整地面；允许原有助行器

**开始条件：**能安全通过通道，无需相机跟随而制造绊倒风险。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**记录4米静止起步协议，起止标记与完整路段尽量入镜。

**操作步骤**

1. 用卷尺确认路径并清除障碍。
2. 从起线站稳，按平时速度走，使用需要的助行器。
3. 越过终线后继续几步再停。
4. 休息后按同法完成第二次并记录症状。

**关键要领**

- 按日常速度，不比赛。
- 看前方，不盯相机。
- 按平时需要使用助行器。

**常见错误**

- 未实测距离却输出精确米每秒。
- 把转弯时间混入直线速度。

**试做与候选剂量／评估协议：**协议：通常2次，记录每次时间和所用助行器；起点按足开始移动、终点按足完整越线的选定规则。场地缩短需另设协议。

**退阶：**改较短真实距离的家庭观察，或只记录安全步行片段。

**进阶：**需要耐力评价时另开合适协议，不由4米成绩自动准许跑步。

**停止或调整条件：**明显眩晕、胸部不适、新发腿软、失稳或症状显著加重时停。

**机位与画面：**侧面或斜侧广角，起终点明确，无需追拍。

**视觉可以观察：**在标定/时钟可靠时的通过时长、速度和粗步频。

**视觉不能直接判定：**精确地反力、每步关节力矩、仅踝点下准确着地时刻。

**观察不足时：**起止难识别则用原录像人工/用户计时；无尺度仅输出完成情况。

### 10.2 髋、膝与下肢控制

#### E-LOW-001｜扶稳站姿主动屈髋

**区域：**髋　 **等级：**L0低负荷支持—L1基础

**目标：**比较抬膝活动表现、症状及躯干代偿，不输出独立髋关节诊断。

**器材：**无轮稳固椅背或固定台面

**开始条件：**能安全站立并按许可单腿短暂承重。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧身面对相机，一手轻扶；明确左右侧和可接受的自选幅度。

**操作步骤**

1. 双脚落地站稳，先记录自然站姿。
2. 保持躯干舒适直立，缓慢抬一侧膝。
3. 达到主动舒适终点后短暂停留，不用手抱拉。
4. 缓慢放回；休息后以同样方式测另一侧。

**关键要领**

- 轻扶用于平衡，不大力拉起身体。
- 膝向前抬，身体不要刻意后仰。
- 出现熟悉症状时说出位置和变化。

**常见错误**

- 后仰腰部来增加表面抬腿角。
- 跳起或用手提腿，被当成主动活动。

**试做与候选剂量／评估协议：**候选评估协议：每侧先熟悉1次，再做2次缓慢主动运动；间歇至站稳。保留最佳可观察次和重复差异，不能用一次失误判异常。

**退阶：**改坐位抬膝并标记体位改变。

**进阶：**仅在目标需要时补仰卧屈髋或有固定骨盆条件的精测。

**停止或调整条件：**新出现锐痛、明显夹卡、腿软或失衡即停止该方向；不为追求角度继续。

**机位与画面：**侧面全身，髋与膝无遮挡。

**视觉可以观察：**抬膝次数、躯干—大腿投影角、侧别和明显后仰。

**视觉不能直接判定：**骨盆真实旋转、独立髋ROM、关节内病变和实际支撑力。

**观察不足时：**看不清时保存完成情况与症状；改用自述可达位置，不要求整套重做。

**动作出处与对应原文：**[REF-S086]；Standing heel peel：扶稳站姿屈髋；抬膝高度按本卡许可限制。

**证据性质与适用范围：**专科医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

#### E-LOW-002｜扶稳站姿主动髋后伸

**区域：**髋　 **等级：**L0低负荷支持—L1基础

**目标：**观察向后抬腿能力及腰骨盆共同代偿。

**器材：**固定台面或稳固椅背

**准备与起始位：**侧面机位；双手或单手轻扶，足尖朝自然方向。

**操作步骤**

1. 站稳并记录自然体位。
2. 让一侧腿缓慢向后移动，膝保持自选轻微屈曲或接近伸直。
3. 在躯干无需继续前倾或腰部无需明显后仰的位置停留。
4. 放回后休息，再完成另一侧。

**关键要领**

- 动作幅度小也有效。
- 骨盆和胸口不要同时转走。

**常见错误**

- 腰部后仰替代髋后伸。
- 支撑身体整体前倾后声称髋活动大幅增加。

**试做与候选剂量／评估协议：**候选评估协议：每侧1次熟悉加2次记录，统一膝姿势和扶手条件；只在同一协议内比较。

**退阶：**改站姿小步后移或有治疗师安排的卧姿动作。

**进阶：**必要时由专业人员固定骨盆后测真实髋后伸。

**停止或调整条件：**出现前髋明显牵痛、腰部新锐痛、麻木或站立不稳时结束。

**机位与画面：**侧面，可见肩、髋、膝、踝。

**视觉可以观察：**后移范围、节奏、躯干倾斜与明显膝屈曲。

**视觉不能直接判定：**骨盆和腰椎各自贡献、髋关节囊限制及肌力等级。

**观察不足时：**输出后移完成度及症状，不勉强输出独立髋角。

**动作出处与对应原文：**[REF-S001]；Leg extension（站姿后伸）、Sideways leg lift（外展及回收）。

#### E-LOW-003｜扶稳髋外展与小幅内收

**区域：**髋　 **等级：**L0低负荷支持—L1基础

**目标：**观察侧向移动范围、侧差及控制能力。

**器材：**稳固扶手

**开始条件：**允许站立负重，且髋内收未被术后限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**正面机位；支撑腿站稳，测试腿前后均有空间。

**操作步骤**

1. 从自然站姿缓慢把一侧腿移向外侧。
2. 达到舒适终点后回到起点。
3. 若允许内收，再让测试腿轻轻向中线靠近或小幅越过中线。
4. 另一侧以相同扶手和幅度规则重复。

**关键要领**

- 足尖尽量维持自然向前。
- 身体不要向相反方向甩动。
- 外展与内收分别记录，不合成一个角。

**常见错误**

- 抬高骨盆来制造外展幅度。
- 交叉腿过远引起站立失衡。

**试做与候选剂量／评估协议：**候选协议：每侧每方向1次熟悉、2次记录；内收受限者只做外展，缺项不是失败。

**退阶：**坐位小幅滑动腿，或只完成许可方向。

**进阶：**需要精准髋角时补骨盆定位和专门测量。

**停止或调整条件：**明显腹股沟疼痛、术区牵拉、交叉腿不稳或禁忌方向出现时停止。

**机位与画面：**正面全身，双髋和双膝可见。

**视觉可以观察：**二维大腿侧向运动、躯干侧倾、次数。

**视觉不能直接判定：**真实骨盆定位、深层组织牵拉、独立内收肌力。

**观察不足时：**保留已完成方向；其他方向记未测，不要求补齐才出结果。

#### E-LOW-004｜坐姿髋内旋与外旋

**区域：**髋　 **等级：**L1基础

**目标：**观察旋转活动表现与左右差异。

**器材：**足够高的稳固椅、可选大腿位置标记

**开始条件：**能稳定坐位；髋旋转没有术后或急伤方向限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**正面拍摄；大腿大致水平，膝屈曲，小腿能自由摆动。

2. 大腿尽量不动，让一侧小腿向外摆，观察髋内旋方向。
3. 回到起点，再让小腿向内摆，观察外旋方向。
4. 两方向各记录后换侧。

**关键要领**

- 看小腿摆动，不只看脚尖。
- 膝位置尽量不横向移动。
- 舒适终点即可，不用手推压。

**常见错误**

- 整个骨盆转向一边。
- 膝大幅移动或脚仅作踝内外翻。

**试做与候选剂量／评估协议：**候选协议：每方向2次缓慢主动运动，必要时先熟悉1次；记录椅高和膝姿势，条件不同不直接比角度。

**退阶：**只做小幅旋转并记录症状；无法悬腿时改专业人员评估。

**停止或调整条件：**腹股沟卡住、明显疼痛、术区不适或动作不稳即停止。

**机位与画面：**正面腿部近中景，兼顾骨盆和双膝。

**视觉可以观察：**小腿摆角、膝位变化、左右侧表现。

**视觉不能直接判定：**准确股骨旋转角、股骨形态或撞击诊断。

**观察不足时：**只报告方向和受限感；识别失败不要求再拍全身录像。

**动作出处与对应原文：**[REF-S068]；Seated examination：屈髋90°主动内外旋。

#### E-LOW-005｜仰卧主动直腿抬高功能观察

**区域：**髋、膝、下肢后侧　 **等级：**L0低负荷支持—L1基础

**目标：**观察主动抬腿和保持膝位的综合表现；不作为神经根病诱发诊断。

4. 恢复舒适后换侧，描述牵拉或疼痛位置。

**停止或调整条件：**新发放射痛、麻木、明显无力、腰痛显著加重时停止。

**机位与画面：**侧面低机位，髋膝踝可见。

**视觉可以观察：**主动抬起角、膝位、次数和保持。

**视觉不能直接判定：**神经根张力、肌腱结构、骨盆细小运动及MMT等级。

#### E-LOW-006｜仰卧滑跟屈膝活动观察

**区域：**膝、髋　 **等级：**L0低负荷支持

**目标：**记录主动膝屈曲表现以及活动终点症状。

**器材：**硬床或防滑垫、光滑小毛巾

**开始条件：**已知可活动范围；术后按许可屈曲上限执行。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面近中景，脚跟能平顺滑动；不使用弹力带强拉。

**操作步骤**

1. 在舒适伸腿位开始，脚跟接触床面或地面。
2. 慢慢把脚跟向臀部滑近。
3. 到许可或舒适终点停留，报告症状。

#### E-LOW-008｜坐姿踝背屈与跖屈

**区域：**踝　 **等级：**L0低负荷支持

**目标：**观察踝上下运动与左右差异。

**器材：**稳固椅、可选足跟与前足贴点

**开始条件：**坐位安全，踝活动符合急伤或术后限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面足部近景，足悬空或小腿被支持，说明体位。

**操作步骤**

1. 保持小腿位置，放松脚趾。
2. 慢慢把前足向小腿方向抬起。
3. 回到中间，再把前足向下移动。
4. 两方向记录后换脚。

**关键要领**

- 让踝运动，不只翘脚趾。
- 动作缓慢且不向极限甩动。
- 小腿尽量不一起摆。

**常见错误**

- 仅脚趾活动却算作踝背屈。
- 用膝踝两个COCO点凭空组成踝角。

**试做与候选剂量／评估协议：**候选协议：每方向2次，疼痛和方向分别记录；角度仅在跟/前足标志可靠且同平面时输出。

**退阶：**改有支撑的小幅活动或只记录可完成方向。

**进阶：**增加足部关键点或由专业人员补测，不增加外力。

**停止或调整条件：**明显疼痛、卡锁、术区牵拉或麻木增多时停止。

**机位与画面：**侧面足部近景，包含膝或足够长小腿参考。

**视觉可以观察：**有足点时的踝运动投影、次数和范围趋势。

**视觉不能直接判定：**没有足点时的踝角、距下关节分量、肌力及关节结构。

**观察不足时：**保持教学和症状记录；未定位到足点时关闭角度，不要求反复拍。

**动作出处与对应原文：**[REF-S002]；Ankle stretch：主动背屈/跖屈。

**证据性质与适用范围：**公共卫生机构动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

#### E-LOW-009｜坐姿踝内翻与外翻方向观察

**区域：**踝、足　 **等级：**L0低负荷支持—L1基础

**目标：**记录主动侧向足部运动和症状，避免用作韧带应力测试。

**准备与起始位：**足悬空，小腿被支持；正面或足背近景，冻结机位。

**操作步骤**

1. 让脚回到自选中间位置。
2. 小幅使足底朝内转，随后回中间。
3. 小幅使足底朝外转，再回中间。
4. 换侧记录可完成方向及症状。

**关键要领**

- 不要用手掰脚。
- 不要用整条腿旋转替代。
- 仅做允许方向，幅度小也可记录。

**常见错误**

- 髋旋转被误当成踝外翻。
- 急性外侧踝伤自动反复做末端内翻。

**试做与候选剂量／评估协议：**候选协议：每个许可方向2次，不用统一正常角度判定；方向被限制则记未安排。

**退阶：**减少范围，或暂改无痛的背屈/跖屈。

**进阶：**需要细分后足运动时转专业测量。

**停止或调整条件：**出现牵扯性锐痛、失稳感、麻木或肿胀加重时停止。

**机位与画面：**足局部正面，兼顾小腿方向。

**视觉可以观察：**足局部明显方向变化和次数，需额外足模型。

**视觉不能直接判定：**韧带松弛、真实距下角度、踝肌最大力量。

**观察不足时：**以方向完成情况和症状记录为主，不可靠角度直接省略。
