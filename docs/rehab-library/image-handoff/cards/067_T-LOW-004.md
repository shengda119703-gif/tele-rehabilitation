# 067 T-LOW-004｜仰卧直腿抬高

**区域：**髋、膝　 **等级：**L0低负荷支持—L1基础

**目标：**练习保持膝位同时抬腿的控制。

**器材：**垫或硬床

**开始条件：**能维持当前膝位且动作在许可范围；有明确伸膝失控者先降级。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**非测试腿可屈膝支撑，测试腿舒适伸展。

**操作步骤**

1. 先轻收紧测试侧大腿前侧。
2. 保持原膝位，把腿缓慢抬起小幅度。
3. 短停后缓慢落下。
4. 完全放松后重复并换侧。

**关键要领**

- 高度以能保持膝位为准。
- 保持自然呼吸。
- 落下时不砸向床面。

**常见错误**

- 膝弯曲越来越多仍继续加高度。
- 用腰部猛抬或屏气。

**试做与候选剂量／评估协议：**候选模板：首轮3次小幅；一般1—3组×5—10次，不以最大高度或力竭为目标。

**退阶：**改股四头肌等长或屈膝抬腿，按专业目标选择。

**进阶：**先增加稳定重复，再考虑明确允许的轻负荷。

**停止或调整条件：**腰或腹股沟锐痛、放射麻木、膝位明显失控时停。

**机位与画面：**侧面低机位。

**视觉可以观察：**抬起次数、膝位和回落节奏。

**视觉不能直接判定：**肌肉选择性激活、神经病变和MMT等级。

**观察不足时：**无法看清时减少自动评分，保留陪练和症状记录。

**动作出处与对应原文：**[REF-S010]；Early-stage Static Quads / Heel Slides / Straight Leg Raise。

**证据性质与适用范围：**大学医院分阶段动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
