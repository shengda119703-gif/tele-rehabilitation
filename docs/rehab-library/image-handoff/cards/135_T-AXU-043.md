# 135 T-AXU-043｜四点支撑膝微离地保持

**区域：**肩、腕、膝、躯干　 **等级：**L1–L2

**目标：**在稳定地面增加躯干与四肢支撑需求；为记录中未命名膝接近地面练习的候选适配，不声称动作完全相同。

**器材：**防滑垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**四点支撑可耐受，腕肩和膝允许；上下地安全。

**准备与起始位：**手膝支撑，脚趾落稳，膝在髋下附近。

**操作步骤**

1. 先四点支撑平稳呼吸。
2. 脚趾辅助，让双膝仅轻离地，躯干保持自然。
3. 短停后双膝缓慢落垫，充分休息。

**关键要领：**低高度；不憋气；落回有余量。

**常见错误：**抬臀很高；强撑到手腕疼；自行在腘窝绑牵引带。

**试做与候选剂量／评估协议：**首轮2次×3秒；候选1–3组×3–5次、每次3–8秒，组间45–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**膝保持落地或 T-AXU-016单肢伸展。

**进阶：**同高度延长少量保持；爬行或抗阻需另立协议。

**停止或调整条件：**肩腕痛、膝痛或身体突然下坠。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面看双膝与地面间隙，接触确认需局部画面。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**膝离地事件、可见保持、粗躯干位置。

**视觉不能直接判定：**四支点压力、腹压、真实深层肌收缩。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**分开记录任务用时、可见悬膝时间及本人用力。 统一保存当次、练后和次日反应，长期判断按第12.5节。
