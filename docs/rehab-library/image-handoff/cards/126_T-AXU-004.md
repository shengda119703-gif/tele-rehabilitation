# 126 T-AXU-004｜仰卧屈膝小幅左右摆膝

**区域：**腰部/胸腰与骨盆整体　 **等级：**L0

**目标：**在支撑位练习舒适的躯干旋转活动。

**器材**

- 垫或稳定床面

**开始条件**

- 能安全仰卧，当前允许屈膝和小幅旋转；不要求术后限制者扭转。

**准备与起始位：**仰卧屈膝，双脚踩稳并靠近，双手自然打开，肩背放松。

**操作步骤**

1. 保持双膝大致并拢，呼吸恢复平稳。
2. 让双膝缓慢向一侧倾斜一小段，脚可随之自然滚动。
3. 控制双膝回到中间，再向另一侧。
4. 若一侧不适，缩小该侧范围并记录，不强行压到床面。

**关键要领**

- 肩部自然接触床面，不用手把膝拉下去。
- 脚跟不猛蹬，速度保持均匀。
- 动作是整体活动，不追求腰部某节发响。

**常见错误**

- 把膝压到底或利用惯性扭动。
- 把摆膝的可见角度称为腰椎真实旋转角。

**试做与候选剂量／评估协议：**首轮每侧3次；候选模板1–2组×每侧5–8次，组间30秒；由计划决定是否使用。

**退阶：**减少倾斜幅度，在膝下加支撑限制范围。

**进阶：**增加可控舒适范围；抗旋转负重能力另用Pallof，不靠更猛摆膝获得。

**停止或调整条件**

- 新的下肢放射痛、麻木或腰部锐痛。
- 症状在回到中间后仍持续加重。

**机位与画面：**斜上方或床侧全身；注意不因床沿遮挡强求测角。

**视觉可以观察**

- 双膝左右移动、回中间、节奏和完成次数。

**视觉不能直接判定**

- 腰椎分节旋转、骶髂复位或椎间受力。

**观察不足时：**可按节奏陪练并询问感觉；不计算无法区分的局部旋转角。
