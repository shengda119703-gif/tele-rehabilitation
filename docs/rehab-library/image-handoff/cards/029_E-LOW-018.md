# 029 E-LOW-018｜窄基底与串联站立

**区域：**踝、髋、平衡　 **等级：**L0低负荷支持—L1基础

**目标：**观察缩小支持面的静态稳定能力。

**器材：**固定台面、必要时陪同人员

**开始条件：**可站立，事先筛查近期跌倒、眩晕和协助需求。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**睁眼，扶手在一臂可及范围；由并足到半串联，非强制全部阶段。

**操作步骤**

1. 选择当前能安全摆出的脚位并站稳。
2. 必要时轻扶定位，再按协议减少扶手。
3. 保持到约定时长或需要触扶为止。
4. 记录保持时间、触扶/移步与症状。

**关键要领**

- 眼睛保持睁开。
- 失衡就扶，不硬撑。
- 用同一脚位复测。

**常见错误**

- 无人保护下突然闭眼。
- 身体摆动直接当成足底压力中心轨迹。

**试做与候选剂量／评估协议：**候选协议：各许可脚位试1次，最多记录10秒的基础观察；触扶即记录，不将扶稳时间伪装成无支撑成绩。

**退阶：**增大脚间距、全程扶稳或改坐姿任务。

**进阶：**稳定后再选单脚站；高要求平衡需另外筛查。

**停止或调整条件：**头晕、明显恐惧、反复跨步救险或近跌倒即结束。

**机位与画面：**正面全身，双足与支撑可见。

**视觉可以观察：**保持时间、触扶、移步、躯干大幅摆动。

**视觉不能直接判定：**前庭诊断、真实重心/压力中心和感觉通路缺陷。

**观察不足时：**保持计时及用户触扶确认，遮挡时省略摆动评分。

**动作出处与对应原文：**[REF-S057]；Gait speed（4m）/ Balance tests（窄基底与串联）。

**证据性质与适用范围：**官方标准测试协议。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
