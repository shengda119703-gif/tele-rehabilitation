# 099 T-LOW-024｜侧弓步：徒手至杯式负荷

**区域：**髋内收/外展、膝、踝　 **等级：**L2负重能力

**目标：**练习侧向移动及髋内侧组织的渐进负重耐受。

**器材：**空旷防滑地面、固定扶手；可选哑铃或壶铃

**开始条件：**普通侧移和下蹲可控，内收肌/腹股沟没有禁止侧向伸长负荷的急伤限制。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**先用较小侧步；脚尖自然朝向，地面无滑动小垫。

**操作步骤**

1. 站稳后向侧方迈一小步。
2. 落脚稳定后屈髋屈膝，把重心移向该侧。
3. 在舒适范围停住，另一腿不强锁膝。
4. 受控回到起点，再换侧。

**关键要领**

- 步幅由当前耐受决定。
- 先稳定脚再下移。
- 不要追求内侧最大拉伸。

**常见错误**

- 步幅过大牵拉腹股沟。
- 膝向内塌且失稳仍继续加重。

**试做与候选剂量／评估协议：**候选模板：首轮徒手每侧3次小幅；一般1—3组×5—8次，能受控返回后再加轻负荷，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**扶稳侧向重心转移，或原地宽站小幅屈膝。

**进阶：**先增控制范围，再加少量负荷；侧向速度最后考虑。

**停止或调整条件：**腹股沟锐痛、膝踝失稳、明显牵拉加剧或落脚打滑时停。

**机位与画面：**正面或斜前方全身。

**视觉可以观察：**侧步、屈膝深度、躯干位移和次数。

**视觉不能直接判定：**内收肌张力、韧带负荷、真实髋侧向力矩。

**观察不足时：**记录侧向完成与症状；脚点缺失不强行判膝足轨迹。

**动作出处与对应原文：**[REF-S038]；Lateral Lunge。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
