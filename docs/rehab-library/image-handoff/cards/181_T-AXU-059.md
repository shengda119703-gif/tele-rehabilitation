# 181 T-AXU-059｜哑铃锤式弯举

**区域：**肘、前臂与握持　 **等级：**L1–L2

**目标：**练习中立握持下肘屈伸与负荷控制。

**器材：**轻哑铃、可选稳固坐椅。

**单人适用：**条件独立；须能自行摆位、完成及安全卸重；需要他人保护者按第12节分流。

**开始条件：**肘屈伸与握持负荷获准，能独立拿放器材；无进行性手麻或急性未评估损伤。

**准备与起始位：**首选站稳小分腿，掌心向身体、腕自然、上臂靠近体侧；坐姿应单独登记。

**操作步骤：**

1. 中立握持慢慢屈肘抬起哑铃，上臂保持近体侧。
2. 到获准范围后控制停留，不转成掌心向上的弯举。
3. 缓慢伸肘落回；交替臂或双臂同步选择一种并记录。

**关键要领：**掌心向内；上臂不前甩；自然呼吸。

**常见错误：**耸肩摆腰；腕弯曲；锤式和普通弯举数据混在一起。

**试做与候选剂量／评估协议：**首轮每侧3次；候选1–3组×8–12次，组间45–90秒。 所有数值为项目候选模板，不是原资料统一处方或进阶阈值。

**退阶：**徒手屈伸或减轻哑铃。

**进阶：**同握法增加可控回合后，再小步增加重量。

**停止或调整条件：**肘腕锐痛、手麻、握不住或明显摆腰。 同时遵守第4节与第12节。

**机位与画面：**正侧或斜侧上身，双肘腕及哑铃完整入镜。；固定相机，必要支点和器材入镜。

**视觉模块：**身体点；器材、锚点和接触需物体识别或本人确认，自动测量仍须验证。

**视觉可以观察：**肘屈伸回合、阶段时间、明显摆动和耸肩。

**视觉不能直接判定：**最大屈肘力量、握力、肌肉分配及哑铃真实重量。

**观察不足时：**只保存已确认阶段，缺失信息记unknown；不补造有效回合、负荷或力量。

**复评与训练成果：**固定握法、重量、侧别与节奏，比较有效回合与自报费力。 保存当次、练后及次日反应。

**动作出处与对应原文：**[REF-S049]；Hammer Curl：掌心朝向身体的中立握持。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
