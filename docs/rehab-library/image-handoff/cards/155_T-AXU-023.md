# 155 T-AXU-023｜弹力带肩外旋

**区域：**肩/肩袖负荷能力　 **等级：**L1

**目标：**在可控范围内练习外旋抗阻及回程控制。

**器材**

- 轻弹力带
- 可靠锚点；或按计划双手持带

**开始条件**

- 肩外旋抗阻获准；带与锚点完好，肘腕可握持。

**准备与起始位：**肘屈约90°贴身，可夹薄毛巾作位置提示；带线大致对应前臂动作方向。

**操作步骤**

1. 选择轻阻力，从舒适中间位开始。
2. 保持上臂靠身，呼气缓慢向外转动前臂。
3. 在可控范围短暂停顿，再吸气慢慢回到起点。
4. 每组后记录肩部感觉、实际带设置和费力。

**关键要领**

- 肘位置尽量稳定，不能靠向后拉肘完成。
- 手腕中立，不用腕侧偏替代肩转动。
- 肩不耸起，回程不能被带突然拉回。

**常见错误**

- 带太紧而躯干转向对侧。
- 把腕点横移换算成真实肩旋转角或实际带力。

**试做与候选剂量／评估协议：**首轮轻带5次；候选模板2–3组×8–12次、组间60秒。阻力和范围由计划确认，保留可控制余力。

**退阶：**减轻张力、缩短范围；可改获准的轻等长并自报用力。

**进阶：**先稳定全程控制，再逐渐增加阻力或其他上臂位置；90°外展位不作为默认进阶。

**停止或调整条件**

- 肩前方滑脱感、锐痛、麻木。
- 必须明显代偿或不能控制回程。

**机位与画面：**前上方/斜前方看清肘和前臂；二维以计次和轨迹代理为主。

**视觉可以观察**

- 外转回收次数、肘离身、躯干随转和节奏。

**视觉不能直接判定**

- 真实外旋力矩、肩袖单肌激活与精确轴向ROM。

**观察不足时：**角度不可靠时按节奏与完成记录；不要求更大转动以迎合检测。
