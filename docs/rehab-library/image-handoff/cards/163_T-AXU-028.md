# 163 T-AXU-028｜地雷杆斜向推举

**区域：**肩/肘/躯干　 **等级：**L2

**目标：**用固定器械弧线练习斜向推力，适配力量训练者。

**器材**

- 杠铃
- 厂家设计的地雷杆底座或可靠专用锚固装置
- 适合的配重与锁片

**开始条件**

- 器械支点稳定且可按说明使用；没有设备时替换动作。
- 肩抬举、腕握持及所选站/跪姿可耐受。

**准备与起始位：**首选稳定站姿或分腿站姿，杠端在肩前；不得把杠铃临时抵墙角替代专用支点。

**操作步骤**

1. 从空杆或明显可控的轻负荷开始，确认支点不移动。
2. 握住杠端，在肩前建立稳定肘腕位置。
3. 呼气沿器械弧线向前上方推，躯干不明显后仰。
4. 吸气控制回到肩前，结束后按器械方式安全放下。

**关键要领**

- 跟随杠铃弧线，不把它硬掰成垂直直线。
- 手腕尽量自然，肩不强耸。
- 肋骨与骨盆保持可控关系，允许正常肩胛运动。

**常见错误**

- 无底座时把杠端临时塞墙角，支点可能滑脱。
- 靠后仰或猛伸腿甩起本应上肢控制的负荷。

**试做与候选剂量／评估协议：**首轮每侧3–5次轻负荷；候选模板2–3组×每侧6–10次、组间90秒。记录杠长、握点和片重，不把片重等同手端负荷。

**退阶：**减重、缩短范围；无可靠设备改墙滑或哑铃可耐受推举。

**进阶：**先稳定弧线与回程，再小幅加片；跪姿、单臂和较高速度各是额外变量。

**停止或调整条件**

- 支点位移、锁片松动或无法控制杠端。
- 肩腕锐痛、新腰痛或站跪姿失稳。

**机位与画面：**侧前方全身与杠端可见；避免把相机放在杠铃运动路径中。

**视觉可以观察**

- 推回次数、杠端轨迹、明显躯干后仰和下肢借力。

**视觉不能直接判定**

- 手端实际力矩、肩组织负荷或精确最大推力。

**观察不足时：**杠端遮挡关节时减少角度项，保存负荷设置与自报完成；支点不可靠则换动作。
