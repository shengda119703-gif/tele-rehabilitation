# 009 E-LOW-004｜坐姿髋内旋与外旋

**区域：**髋　 **等级：**L1基础

**目标：**观察旋转活动表现与左右差异。

**器材：**足够高的稳固椅、可选大腿位置标记

**开始条件：**能稳定坐位；髋旋转没有术后或急伤方向限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**正面拍摄；大腿大致水平，膝屈曲，小腿能自由摆动。

**操作步骤**

1. 坐稳并让双膝保持既定间距。
2. 大腿尽量不动，让一侧小腿向外摆，观察髋内旋方向。
3. 回到起点，再让小腿向内摆，观察外旋方向。
4. 两方向各记录后换侧。

**关键要领**

- 看小腿摆动，不只看脚尖。
- 膝位置尽量不横向移动。
- 舒适终点即可，不用手推压。

**常见错误**

- 整个骨盆转向一边。
- 膝大幅移动或脚仅作踝内外翻。

**试做与候选剂量／评估协议：**候选协议：每方向2次缓慢主动运动，必要时先熟悉1次；记录椅高和膝姿势，条件不同不直接比角度。

**退阶：**只做小幅旋转并记录症状；无法悬腿时改专业人员评估。

**进阶：**补固定骨盆/大腿的临床测量，而非增加自我推压力。

**停止或调整条件：**腹股沟卡住、明显疼痛、术区不适或动作不稳即停止。

**机位与画面：**正面腿部近中景，兼顾骨盆和双膝。

**视觉可以观察：**小腿摆角、膝位变化、左右侧表现。

**视觉不能直接判定：**准确股骨旋转角、股骨形态或撞击诊断。

**观察不足时：**只报告方向和受限感；识别失败不要求再拍全身录像。

**动作出处与对应原文：**[REF-S068]；Seated examination：屈髋90°主动内外旋。

**证据性质与适用范围：**期刊临床技术说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
