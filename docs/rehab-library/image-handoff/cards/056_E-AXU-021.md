# 056 E-AXU-021｜墙面小幅推撑负荷耐受筛查

**区域：**肩/肘/腕　 **等级：**L1

**目标：**观察低负荷上肢闭链任务是否可完成及何处出现症状。

**器材**

- 坚实平整墙面

**开始条件**

- 肩肘腕允许承重，能稳定站立；不使用滑动门或松动表面。

**准备与起始位：**双手置墙约肩高略宽于肩，双脚离墙适当距离；侧面拍到全身。

**操作步骤**

1. 先直臂轻靠墙，确认手腕、肩和下肢可耐受。
2. 屈肘让身体小幅靠近墙，躯干保持整体移动。
3. 呼气平稳推回起点，不猛锁肘。
4. 完成后报告肩、肘、腕疼痛和主观费力。

**关键要领**

- 先近距离，只有稳定才稍远离墙。
- 手掌接触稳定，肩不耸到耳边。
- 身体整体前后移动，避免腰单独塌下。

**常见错误**

- 把墙距不同的结果直接作力量提升百分比。
- 用完成快慢推断实际推力或组织耐受上限。

**试做与候选剂量／评估协议：**先1次试做，再最多3次小幅观察；之后休息30–60秒。非最大次数试验。

**退阶：**站得更近、缩小屈肘幅度，必要时只记录静态轻靠。

**进阶：**稳定无明显反应后再考虑更大范围或台面版本，使用独立负荷条件记录。

**停止或调整条件**

- 手腕锐痛、肩不稳或肘突然打软。
- 头晕、脚滑或无法控制接近墙的速度。

**机位与画面：**侧面全身，肩肘腕髋和脚可见。

**视觉可以观察**

- 推撑次数、肘屈伸、身体直线性与速度。

**视觉不能直接判定**

- 手上反作用力、实际肌力和组织内部负荷。

**观察不足时：**手被身体挡住时记录次数和自报症状，腕角不强行评分。
