# 011 E-LOW-027｜仰卧屈髋位主动伸膝范围观察

**区域：**膝活动、下肢后侧活动耐受　 **等级：**L0–L1

**目标：**记录固定大腿位置时的主动伸膝范围；不是被动腘绳肌长度或Slump诊断测试。

**器材：**垫、可选大腿下支撑

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**屈髋和伸膝许可，能够自行托住大腿；有麻木/放射症状先经专业人员筛选。

**准备与起始位：**仰卧，一侧大腿由本人双手托住在可耐受屈髋位；足踝自然，不叠加颈屈。

**操作步骤**

1. 固定大腿，先让膝舒适弯曲。
2. 主动缓慢伸膝，达到舒适牵拉或计划范围即停。
3. 屈膝返回；同体位观察另一侧。

**关键要领：**只改变膝位；不强推膝；不为了角度叠加神经牵拉。

**常见错误：**大腿随伸膝下降；另一人压腿；把牵拉感认定为肌肉短缩。

**试做与候选剂量／评估协议：**每侧3次舒适尝试；保存选定有效尝试，不取疼痛中的最大值。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**减小屈髋角或 E-LOW-007坐姿伸膝。

**进阶：**固定大腿位置、踝位与机位复评。

**停止或调整条件：**电击样痛、麻木、放射痛或症状延续。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**测试腿正侧面，髋膝踝可见；大腿角超出协议则只保留任务记录。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**膝二维投影伸展范围、维持大腿位置、回程及完成次数。

**视觉不能直接判定：**被动终末感、神经机械敏感性诊断、特定肌肉真实长度。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**比较相同大腿与踝位下的主动膝角代理和症状；不与临床被动90/90测试常模混用。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S018]；Hamstrings (1)：固定屈髋位主动伸膝。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S018]。动作形式、背景指南和产品测量证据按第8节分别解释。
