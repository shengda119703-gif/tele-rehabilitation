# 169 T-AXU-031｜胸前下拉：器械或弹力带

**区域：**肩带/肘/上背　 **等级：**L2

**目标：**练习从较高位置向胸前拉的能力与回程控制。

**器材**

- 维护良好的下拉器械；或完好带和可靠高位锚点

**开始条件**

- 高位抬臂与拉力训练获准，手能稳握；高位锚点可靠。

**准备与起始位：**坐稳或按计划稳定站位，握距舒适；手柄从胸前上方而不是颈后运动。

**操作步骤**

1. 选择可控轻负荷，先进入允许的起始抬臂范围。
2. 呼气屈肘，将手柄向胸前上方区域拉近。
3. 到舒适位置停止，不强把肘拉到躯干后方。
4. 吸气控制上回，保持可控范围，不任由重量/带把肩拉到末端。

**关键要领**

- 胸口自然，不用大幅后仰变成划船。
- 拉动时肩不耸起硬撑。
- 头保持自然，不把杠拉到颈后。

**常见错误**

- 靠全身摆动甩动重量。
- 高位锚点不稳或让弹力带直冲面部。

**试做与候选剂量／评估协议：**首轮5次轻负荷；候选模板2–3组×8–12次、组间60–90秒。记录器械及带条件，不把不同滑轮配重直接等同手端力。

**退阶：**减阻力或缩小高位范围，改坐位划船等已耐受动作。

**进阶：**先恢复可控行程再加重；引体向上需要另外确认悬吊和握持能力。

**停止或调整条件**

- 肩锐痛、不稳、新手麻或控制回程失败。
- 锚点/器械异常或带有损伤。

**机位与画面：**侧前方，肩肘腕、躯干和手柄路径可见。

**视觉可以观察**

- 拉放次数、节奏、明显后仰和左右差异。

**视觉不能直接判定**

- 真实拉力、肩胛分量或背部肌肉选择性激活。

**观察不足时：**手柄遮挡腕点时以完整回合和自报负荷记录，不锁住整组。
