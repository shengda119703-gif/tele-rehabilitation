# 108 T-LOW-052｜半跪位踝背屈活动：不用牵引带

**区域：**踝、膝、下肢　 **等级：**L0–L1

**目标：**提供见习中半跪位向前移膝的单人活动版本。

**器材：**膝垫、固定扶手

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**前脚负重背屈及后膝接触获准，能安全半跪。

**准备与起始位：**一膝在软垫，另一足完整踩地；手扶稳。

**操作步骤**

1. 固定前脚朝前、脚跟接地。
2. 前膝沿脚方向缓慢前移。
3. 到舒适范围短停后退回，不撞墙或强压。

**关键要领：**跟不离地；膝沿脚方向；不压夹痛。

**常见错误：**自行给距骨/舟骨绑牵引带；猛推膝求距离。

**试做与候选剂量／评估协议：**首轮3次；候选1–2组×5–10次、短停1–2秒，组间30–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**T-LOW-032站位膝顶墙或坐姿踝活动。

**进阶：**增加可控范围；与站位测试分开记录。

**停止或调整条件：**后膝接触痛、前踝锐痛或失衡。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**前脚正侧近景含足跟和前膝；全身体位另可确认。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**足部近景；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**前移回程、跟抬起可见事实、胫骨倾角代理。

**视觉不能直接判定：**距骨滑动、足舟骨活动、受限病因。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**用 E-LOW-010站位测试追踪另一个协议的功能，不混入半跪距离。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S019]；Ankle dorsiflexion：半跪前膝前移、足跟留地。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
