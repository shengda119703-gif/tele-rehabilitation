# 098 T-LOW-023｜后脚抬高分腿蹲：徒手至哑铃

**区域：**髋、膝、踝　 **等级：**L2负重能力—L3高要求返运动

**目标：**在适合者中提高分腿负重要求，训练前侧腿的受控工作能力。

**器材：**无轮无摇晃、承重足够且固定靠墙的低长凳；固定扶手；可选哑铃

**开始条件：**熟练普通分腿蹲，前后踝均能耐受抬高接触，允许此类负荷；不能仅凭既往力量自动分配。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**后脚抬高取低起点，可用脚背或前足按个人舒适姿势接触软垫；不得挤压受伤踝。

**操作步骤**

1. 先扶稳，把后脚放在不会移动的低支撑上。
2. 前脚位置调整到上下都能稳定。
3. 缓慢屈膝下降至许可范围。
4. 控制站回，组末先扶稳再把后脚落地。

**关键要领**

- 后脚接触不能疼。
- 保留左右站距，不走钢丝。
- 需要时一直扶稳。

**常见错误**

- 使用会滑动的轻椅或过高桌面。
- 前脚站距不合适仍硬压到底。

**试做与候选剂量／评估协议：**候选模板：首轮徒手每侧2—3次；一般1—3组×5—8次，动作平稳后才试轻负荷，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**普通扶稳分腿蹲；后脚近期扭伤者优先不用抬高版本。

**进阶：**先提高同条件控制，再小幅加重；凳高不是必须升级的变量。

**停止或调整条件：**后踝痛、凳移动、膝软、髋锐痛或失衡时停止。

**机位与画面：**斜侧全身，后脚接触点和支撑可见。

**视觉可以观察：**次数、深度、前后位移及明显支撑移动。

**视觉不能直接判定：**前腿承重百分比、后踝压力、真实肌力和关节力矩。

**观察不足时：**不可靠时只记录组次和负荷自报；不要求带重量补拍。

**动作出处与对应原文：**[REF-S037]；Bulgarian Split Squat。
