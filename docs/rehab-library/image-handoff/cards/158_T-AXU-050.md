# 158 T-AXU-050｜俯卧I/Y/T/W分路线抬臂

**区域：**肩带、肩、上背　 **等级：**L1–L2

**目标：**增加可控上肢路线与肩带负荷能力；侧方T与臂在体侧后伸也可按计划单独登记变式。

**器材：**垫、额头软垫；后期可选轻哑铃

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**俯卧耐受、所选肩路线允许；Y高位不获准则仅选较低路线。

**准备与起始位：**胸腹落垫、额头支撑，每次选一条路线：I双臂沿体侧、Y前外上方、T侧方、W屈肘外开；角度以当前许可为限。

**操作步骤：**

1. 空手摆好选定路线，不把肩强拉到末端。
2. 缓慢轻抬双臂，头颈及躯干留在支撑面。
3. 短停后受控落回；各路线分别记录，轻负重逐条获准。

**关键要领：**低幅即可；不耸肩强夹；正常呼吸。

**常见错误：**颈后伸和抬胸借力；把所有路线一次性负重。

**试做与候选剂量／评估协议：**首轮每路线3次；候选选1–2路线，各1–2组×6–10次、短停1–2秒，组间45–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**站姿/桌面支持路线或 T-AXU-022。

**进阶：**先同路线增控制，再单路线轻负重。

**停止或调整条件：**肩锐痛、颈痛、手麻。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面看离垫与代偿；手臂形状需斜上方/上方另拍。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**路线、起落、明显抬头/抬胸与周期。

**视觉不能直接判定：**各肌选择性激活、肩胛上回旋角及组织状态。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**关联 E-AXU-028，不把I/Y/T/W合成一个临床分数。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S025]；Table Stretch/Wall Climbers、Resisted Open Can、Prone I/W/T/Y、Wall Angels、Push Up Plus Variations。

**证据性质与适用范围：**大学医疗中心公开示范目录。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
