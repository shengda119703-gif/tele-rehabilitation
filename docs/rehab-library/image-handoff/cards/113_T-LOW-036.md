# 113 T-LOW-036｜扶稳单脚/负重提踵

**区域：**踝、小腿　 **等级：**L2负重能力

**目标：**渐进训练单腿跖屈能力和耐力。

**器材：**固定扶手；可选单只哑铃、壶铃或稳妥负重背心

**开始条件：**双脚提踵可控，当前允许单脚及额外负荷；跟腱、前足和踝状态可耐受。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**平地先做，扶手在一手可及处；不要初次就用台阶增加离心深度。

**操作步骤**

1. 先无负荷单脚站稳。
2. 抬跟到可控高度，再缓慢落下。
3. 完成少量试做后，必要时加入可控外重。
4. 组末先放稳器械，充分休息后换侧。

**关键要领**

- 保持同样高度。
- 膝不反复屈伸借力。
- 扶稳不拉起身体。

**常见错误**

- 单脚刚会做就加重并站台阶。
- 高度越来越低却继续加次数。

**试做与候选剂量／评估协议：**候选模板：首轮每侧3次无外重；一般1—3组×5—12次，当前量可控后再小幅加重，非最大负荷/力竭测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**双脚提踵、坐位版本或移除外重。

**进阶：**先加少量次数或负荷；台阶末端深度仅在对应病情允许时另加。

斜板提踵（见习1/13/15/27）属于改变足部接触与末端范围的条件变式；首选平地。记录板角、接触、上升/下降终点，不能默认跟降至前足以下；跟腱/足底术后及急性新伤先遵专门计划。

**停止或调整条件：**跟腱局部锐痛、前足痛、踝软、握持松脱或回程失控时停。

**机位与画面：**侧面含足，负荷与扶手可见。

**视觉可以观察：**次数、节奏、逐次高度趋势。

**视觉不能直接判定：**最大力量、跟腱力、足底压力与实际扶手力。

**观察不足时：**负荷手动记录，视觉丢点期间只陪练，完成数允许用户确认总量。

**动作出处与对应原文：**[REF-S007]；直膝/屈膝Heel Cord Stretch、双脚/单脚Calf Raises。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
