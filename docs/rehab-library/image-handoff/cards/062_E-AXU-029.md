# 062 E-AXU-029｜已知轻物握持与提放功能观察

**区域：**手、腕、前臂、肘　 **等级：**L0–L1

**目标：**观察日常提物任务是否可控，并记录本人疼痛；不代替握力计。

**器材：**握把舒适且不易碎的已知轻物、桌

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**允许握持及轻物负重，能安全放下；任务重量由计划选择。

**准备与起始位：**坐稳，前臂/肘可按需支持；物体置于桌面易取处，腕自然位。

**操作步骤**

1. 先空手开合，确认手指活动耐受。
2. 握物轻抬离桌，短时保持，再缓慢放下。
3. 记录出现不适的阶段及是否需要另一手帮助。

**关键要领：**重量明确；腕不强扭；疼痛或失控前放回。

**常见错误：**靠肩耸起代替手部任务；根据持物秒数换算握力。

**试做与候选剂量／评估协议：**3次×约5秒；非最大负重测试，物体质量和握把固定。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**轻物、双手辅助或无负重握持自报。

**进阶：**同物体和手柄复评；增加质量另存条件。

**停止或调整条件：**手麻、锐痛、明显无力或物体滑脱。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**斜侧近景含肩肘腕手和桌；手/物体被遮挡不推断已握紧。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点＋Hand/物体近景；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**取起、短时保持、放下及明显腕姿变化；抓握接触需近景确认。

**视觉不能直接判定：**握力牛顿值、肌腱负荷、外侧肘病因及神经卡压。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同物体完成情况＋疼痛与次日工作耐受；视觉成功不等于无痛。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S040]；Farmer’s Carry：握持负荷形式；轻物提放不是标准握力测量。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S040]；背景及临床边界：[AXU-S05]。动作形式、背景指南和产品测量证据按第8节分别解释。
