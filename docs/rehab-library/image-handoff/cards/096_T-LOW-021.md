# 096 T-LOW-021｜扶稳分腿蹲：徒手至哑铃

**区域：**髋、膝、踝　 **等级：**L1基础—L2负重能力

**目标：**练习前后分腿姿势下的受控负重。

**器材：**固定扶手；可选单侧或双侧哑铃

**开始条件：**允许分腿负重，前后脚均能耐受，能安全起止。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**前后站距以稳定和舒适为准，保留侧向宽度而非走钢丝。

见习38的前后脚外旋位下蹲和后腿外旋点地保留为专业确认后变式；不按原笔记45°/90°统一设置。双脚方向与膝方向须可控，不能借固定足位扭膝。

**操作步骤**

1. 先扶稳摆好前后脚。
2. 身体受控下降，双膝自然屈曲。
3. 到许可深度后站回。
4. 完成一侧后双脚并回，再换侧。

**关键要领**

- 下降方向平稳。
- 前脚整掌稳定。
- 后脚只承担可耐受任务。

**常见错误**

- 双脚几乎同一直线导致失衡。
- 把前膝是否过脚尖作为唯一合格标准。

**试做与候选剂量／评估协议：**候选模板：首轮徒手每侧3次；一般1—3组×5—10次，负荷从能保持稳定回程的水平开始，非最大测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**扶手增加、减小深度或改分腿重心转移。

**进阶：**先提高重复控制，再增加轻负荷；减少扶手另行安排。

**停止或调整条件：**髋膝锐痛、后脚踝牵扯、腿软或失衡时停。

**机位与画面：**侧面或斜侧全身。

**视觉可以观察：**次数、深度、躯干策略和触扶。

**视觉不能直接判定：**前后脚真实分担、单侧关节力矩和肌力。

**观察不足时：**无法判断足部时只反馈节奏与完成数，用户可继续扶稳。
