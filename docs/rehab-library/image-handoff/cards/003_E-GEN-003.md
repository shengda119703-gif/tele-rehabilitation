# 003 E-GEN-003｜地面多方向触点动态平衡：非标准化功能观察

**区域：**综合功能/踝膝髋/动态平衡　 **等级：**L1有支撑短距离触点—L2无支撑受控任务；按患侧当前资格选择

**目标：**观察规定支撑条件下向不同方向轻触地面目标并返回的控制、辅助需求与症状；这是本库自定功能任务，不是标准Y-Balance或SEBT，不输出其综合分数、标准化分或回归运动结论。

**器材**

- 平整防滑地面及贴牢、不形成绊脚物的地面标记
- 稳固台面或固定扶手；需要时有陪同者在旁
- 固定手机；不要求购买标准Y-Balance器械

**开始条件**

- 当前允许支撑侧承重并短暂承担主要身体重量；急性伤后限制、术后限制、疼痛和单腿控制条件必须先满足。
- 能完成对应支持条件下的安全站立与小幅重心转移；明显腿软或频繁失衡时不做单脚触点评估。
- 先明确手是否扶稳、辅助程度、哪条腿支撑和哪条腿触点；全程保持相同条件。

**准备与起始位：**一侧为支撑脚，在其前方、斜前方和侧方放置3个舒适可及的平面标记；初始距离由小幅试做确定并记录，不追求最大伸达。触点与支撑条件均为本库协议，不能套成标准Y字或星形测试。相机拍到躯干、骨盆、膝、双脚及标记。

**操作步骤**

1. 站稳并确认症状，选定支撑侧及扶持条件；先向最近的一个方向轻触一次以熟悉任务。
2. 主要重心留在支撑脚，另一只脚缓慢伸向一个标记，用足尖轻触地面，不跳过去，也不靠触点脚大力蹬地。
3. 把触点脚收回起始位置，先恢复稳定再开始下一个方向。
4. 按固定顺序完成另外两个方向；每方向记录是否够到、是否需要额外扶持、支撑脚是否移动及是否出现症状。
5. 休息后按资格选择是否观察另一侧，并记录两侧实际标记距离与支撑条件；不同条件不计算伪造的左右标准分。

**关键要领**

- 目标是稳稳伸出再收回，不是尽量够得远。
- 扶手按事先选择的方式使用，不为成绩临时松手。
- 每次回来先站稳；需要把脚落下或抓紧扶手就照做并记录。
- 支撑膝保持可控，不刻意锁死；不要憋气或用猛甩身体增加距离。

**常见错误**

- 触点脚明显承重或蹬地、支撑脚移位后仍被记为同一条件的成功触点。
- 用跳跃、快速甩腿或大幅失衡去追逐远处目标。
- 将自定的三个方向、扶持版本或自选距离冒充标准Y-Balance/SEBT，并计算其标准化综合分。

**试做与候选剂量／评估协议：**本库候选观察协议：每侧先1次近距离熟悉，再按3个方向各做1次；只有需要判断重复性且仍舒适时才每方向加1次。方向间可把两脚落地休息，侧间至少30–60秒或至稳定舒适。剂量属于设计方案，不是标准Y-Balance/SEBT施测次数。

见习34仅记录Y-Balance前向触及且尝试数不一致、无腿长，不输出标准化/综合分数。见习28的“单腿下蹲伸膝距离”缺正式协议及单位，不擅自视为Y-Balance。原始数据只作为当次记录；本卡仍是非标准化触点任务。

**退阶：**缩短标记距离、减少到一个方向或增加已允许的手扶；若仍不适合单侧支撑，另记为双脚着地的小幅重心转移观察。退阶结果只评价新条件，不视为原任务达标。

**进阶：**先在相同标记距离、顺序和支撑条件下提高完成稳定性；目标需要且当前允许时，一次只增加一个方向或少量距离，或减少一档扶持。快速触点、闭眼、不稳垫和跳跃不在本卡自动添加。正式Y-Balance/SEBT须另建准确协议并具备适当评估条件。

**停止或调整条件**

- 支撑腿打软、需要急抓扶手或陪同者身体保护、出现新发锐痛/眩晕或明显症状恶化时停止。
- 标记松动、地面打滑、无法受控收回触点脚或当前负重限制被触及时停止该方向。

**机位与画面：**固定侧前方全身视角，地面标记和两只脚清楚；地面尺度未标定时只记录触点类别与完成，不输出实际伸达厘米数。

**视觉可以观察**

- 清楚可见时的方向顺序、足部伸出和返回、支撑脚明显移位及额外落地。
- 明显躯干摆动或扶持变化；足尖触地边界不清时相应事件标未知。
- 有实际距离记录时可保留各标记距离与是否完成，作为本任务结果而非标准化测试分数。

**视觉不能直接判定**

- 脚底压力、触点脚实际承担多少体重、手扶力、关节稳定性和本体感觉，不能由普通RGB直接测得。
- 无可靠尺度不能输出厘米；即便有尺度也不能生成标准Y-Balance/SEBT分数。
- 成功完成或左右接近，均不能独立证明韧带愈合、不存在运动风险或可恢复竞技。

**观察不足时：**足尖/标记被遮挡时，可由陪同者或用户确认各方向是否完成及是否额外扶持，保存为自述/人工观察；自动指标缺失不计失败。可复用视频，必要时只补有决策价值的一个方向；不要求全套重拍，也不为获得完整分数强制加大伸达。
