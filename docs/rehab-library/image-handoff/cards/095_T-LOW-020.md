# 095 T-LOW-020｜杠铃背蹲：已有技术者的受控版本

**区域：**髋、膝、踝、躯干　 **等级：**L2负重能力—L3高要求返运动

**目标：**为具备既往技术和安全设备者恢复渐进负重下蹲。

**器材：**合格深蹲架、安全杠、标准杠铃与卡扣；合适场地，必要时有经验保护者

**开始条件：**已有杠铃背蹲经验，当前允许轴向负重和下蹲；具备安全取杠、回架和保护杆设置能力。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**安全杠在可安全结束的位置；杆放上背合适接触处而非颈椎；先检查架体稳定。

**操作步骤**

1. 先空杆或更轻替代物确认当日动作和深度。
2. 取下可控负荷，少量步伐站稳。
3. 缓慢下蹲至许可深度，再受控站起。
4. 完成后确认挂钩位置，稳妥回架再松手。

**关键要领**

- 安全杆必须就位。
- 不追求历史工作重量。
- 不在无法稳定回架时继续。

**常见错误**

- 没有安全架却尝试高要求背蹲。
- 把以前能蹲的重量当成当前负重许可。

**试做与候选剂量／评估协议：**候选模板：空杆3—5次、轻负荷3次；一般2—3组×5—8次，不做1RM、力竭或最大速度测试；处于保护期时不分配。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**杯式蹲、徒手蹲或更浅的有支撑版本。

**进阶：**当前量稳定且后续反应可接受时一次小幅增加一个变量。

**停止或调整条件：**胸部不适、眩晕、锐痛、杆位滑移或无法控制回程时停止并依安全方案落架。

**机位与画面：**斜侧全身，架体、杆和双足尽量可见。

**视觉可以观察：**次数、深度、节奏、杆路径和明显偏移。

**视觉不能直接判定：**椎间/关节内部负荷、真实负荷和力量上限。

**观察不足时：**视觉受杆遮挡时改记录模式；不让用户为补视频再完成负重组。

**动作出处与对应原文：**[REF-S035]；Back Squat。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
