# 093 T-LOW-018｜扶稳浅蹲/椅前目标蹲

**区域：**髋、膝、踝　 **等级：**L0低负荷支持—L1基础

**目标：**练习个人允许范围内的负重屈伸。

**器材：**固定扶手、可选稳定椅作目标

**开始条件：**允许双脚负重，明确深度和扶手方案。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**双脚自然分开，椅子仅作为深度提示或需要时坐下。

**操作步骤**

1. 站稳轻扶，选定本次浅蹲目标。
2. 缓慢屈髋屈膝下降。
3. 在个人目标范围内停一下。
4. 控制起身，站稳后重复。

**关键要领**

- 足掌保持稳定。
- 膝随足的自然方向。
- 不必追求深蹲。

**常见错误**

- 为了碰椅而向后跌坐。
- 膝疼仍按照固定健身深度硬蹲。

**试做与候选剂量／评估协议：**候选模板：首轮3次小幅；一般1—3组×5—12次，以可控动作及近期症状决定幅度与总量。

**退阶：**减少深度、增加扶手或改高椅坐站。

**进阶：**先增加舒适幅度/重复，再考虑杯式轻负荷。

**停止或调整条件：**新锐痛、卡锁、腿软、踝失稳或持续症状升级时停。

**机位与画面：**侧面优先，正面可选。

**视觉可以观察：**次数、深度趋势、膝投影角和躯干策略。

**视觉不能直接判定：**关节接触力、足底压力和结构损伤。

**观察不足时：**辅助点缺失仅取消相关反馈，维持陪练和进度。

**动作出处与对应原文：**[REF-S001]；Sit-to-stand / Mini-squats。

**证据性质与适用范围：**公共卫生机构动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
