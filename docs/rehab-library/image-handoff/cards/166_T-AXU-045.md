# 166 T-AXU-045｜高位俯卧撑支撑交替抬手

**区域：**肩带、腕、躯干　 **等级：**L2

**目标：**训练稳定台面上的单手短时支撑与抗旋转任务。

**器材：**不会移动的固定台面

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**双手高位推撑可控；允许单手短时承重，腕肩无相关禁忌。

**准备与起始位：**双手撑台，双脚稍分开以稳定；先只做支撑不做俯卧撑。

**操作步骤**

1. 轻移重心，保持双脚稳定。
2. 一手轻离台面后立即放回；熟练后可轻触对侧肩。
3. 重置后换手；推撑与抬手的组合另建版本。

**关键要领：**离台幅度小；胸口朝台；慢换手。

**常见错误：**身体大幅旋转；低台和快换手同时增加。

**试做与候选剂量／评估协议：**首轮每侧2次；候选1–2组×每侧4–6次，休息60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**双手保持、墙面轻抬手或 T-AXU-029。

**进阶：**同台面增加回合，再另行降低支撑高度。

**停止或调整条件：**肩腕锐痛、扶台松动或身体失控。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**斜前方全身含两手接触；侧面另看躯干线。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**手离台/落回、交替顺序、明显转开与下沉。

**视觉不能直接判定：**真实抗旋转力矩、单手承重力及肩关节结构稳定。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同台高、足距下记录可见回合和躯干随动。 统一保存当次、练后和次日反应，长期判断按第12.5节。
