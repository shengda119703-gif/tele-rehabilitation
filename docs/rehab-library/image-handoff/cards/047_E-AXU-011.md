# 047 E-AXU-011｜颈部主动左右旋转筛查

**区域：**颈部　 **等级：**L0–L1

**目标：**记录转头功能和近似左右差异，区分躯干一起转。

**器材**

- 稳定椅

**开始条件**

- 没有需先评估的近期创伤或新神经症状。

**准备与起始位：**正面上半身近景，双脚落地、胸口朝前；校准自然平视的头姿。

**操作步骤**

1. 缓慢向一侧转头到舒适范围。
2. 停留短暂后回正，确认肩胸没有明显随转。
3. 询问颈、肩、臂症状和头晕。
4. 换侧重复，不为让相机看到脸而扭转躯干。

**关键要领**

- 下巴保持自然高度，避免边抬头边转。
- 身体朝前，转动以颈部舒适度为准。
- 到终点即返回，不需长时间保持。

**常见错误**

- 整个胸口随头一起转，制造较大相机角。
- 脸转走丢点后由模型预测补成最大旋转ROM。

**试做与候选剂量／评估协议：**每侧1次熟悉、1–2次观察；间隔15–20秒。仅在共同坐标与校准有效时显示近似相对转角。

**退阶：**减小范围或只报告能否看向侧方的生活能力。

**进阶：**保持坐姿、光线和镜头复测；不以增加次数追求更大值。

**停止或调整条件**

- 出现眩晕、视物异常、恶心或新上肢麻木无力。
- 出现异常剧烈头颈痛。

**机位与画面：**正面近景；Face估计头姿，Body只用于可见躯干稳定代理。

**视觉可以观察**

- 头转方向、可见转角趋势、明显躯干随转。

**视觉不能直接判定**

- COCO17下可靠的全程轴向颈旋转ROM。
- 血管或神经通畅情况。

**观察不足时：**末端Face失跟时报告可见范围＋自报完成，不要求反复补拍末端。

**动作出处与对应原文：**[REF-S012]；Side flexion / Rotation：主动舒适范围。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
