# 021 E-LOW-016｜低台阶上落功能观察

**区域：**髋、膝、踝　 **等级：**L2负重能力

**目标：**观察上台阶与控制下台阶的任务能力。

**器材：**已知高度的稳固低台阶、固定扶手

**开始条件：**平地行走、坐站可控，允许单腿负重；台阶不松动。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**先从低高度开始，记录高度、领先腿与扶手。

**操作步骤**

1. 站在台阶前，整只测试脚放上。
2. 受控上台阶，必要时轻扶。
3. 按选定方式慢慢下台阶。
4. 完成少量重复后换领先腿。

**关键要领**

- 脚掌充分落在台面。
- 下降主动控制，不直接掉落。
- 扶手使用保持一致。

**常见错误**

- 借非测试腿强蹬却称测试腿独立完成。
- 台阶高度或扶手改变但结果直接比较。

**试做与候选剂量／评估协议：**候选改良协议：每侧先熟悉1次，再观察3次；不是OARSI整段楼梯标准测试，不套原常模。

**退阶：**减低台阶，增加扶手或回坐站。

**进阶：**稳定后按目标考虑更高台阶或更多次数，而非立即跳下。

**停止或调整条件：**疼痛升级、反复膝软、踝失稳、绊脚或台阶移动时停止。

**机位与画面：**斜侧主机位，台阶上下边缘和双足可见。

**视觉可以观察：**上落次数、任务时间、躯干策略及明显扶手。

**视觉不能直接判定：**精确单腿力量、支撑腿负荷、关节接触力。

**观察不足时：**保留能否完成、实际扶手和症状；脚被遮挡时取消细节评分。

**动作出处与对应原文：**[REF-S004]；Step-up / Eccentric step down：低台阶上落。

**证据性质与适用范围：**专科医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
