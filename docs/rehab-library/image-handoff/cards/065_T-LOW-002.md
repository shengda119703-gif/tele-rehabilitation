# 065 T-LOW-002｜滑跟屈膝

**区域：**膝、髋　 **等级：**L0低负荷支持

**目标：**在许可范围内反复练习屈膝和回程。

**器材：**硬床或垫、脚跟下滑布

**开始条件：**遵守当前屈曲上限，可安全仰卧。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**脚跟有滑动条件；侧面机位不妨碍通道。

**操作步骤**

1. 从舒适伸腿位开始。
2. 脚跟贴面缓慢滑向臀部。
3. 到个人规定上限或舒适终点停片刻。
4. 缓慢滑回，放松后重复。

**关键要领**

- 滑动均匀，不猛拉。
- 不越过术后上限。
- 小范围重复也算训练。

**常见错误**

- 手把膝强行拉到胸前。
- 疼痛逐次增加仍追求角度。

**试做与候选剂量／评估协议：**候选模板：首轮3次慢滑；一般1—3组×5—12次，按活动许可决定幅度与停留，不把模板当所有术后处方。

**退阶：**缩小范围或改坐位脚后滑。

**进阶：**先改善同范围控制，再按许可增加幅度；无需每次同时加量。

**停止或调整条件：**明显锐痛、关节卡住、术区异常或肿胀反应加重时停。

**机位与画面：**侧面低机位，膝和脚跟可见。

**视觉可以观察：**屈伸次数、膝投影角和节奏。

**视觉不能直接判定：**关节积液、组织愈合、被动阻力。

**观察不足时：**缺点时保留节拍陪练与自主完成数，不反复要求重新录。

**动作出处与对应原文：**[REF-S010]；Early-stage Static Quads / Heel Slides / Straight Leg Raise。

**证据性质与适用范围：**大学医院分阶段动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
