# 178 T-AXU-037｜腕尺偏/桡偏轻负荷控制

**区域：**腕/前臂　 **等级：**L1

**目标：**练习腕侧向活动和轻外载控制，按任务选择方向。

**器材**

- 桌面
- 可选极轻短握杆/小哑铃；或合适轻带

**开始条件**

- 尺桡偏方向可耐受，未评估的尺侧/桡侧急性腕痛先处理。

**准备与起始位：**首轮空手，前臂支撑、拇指大致向上，腕伸出桌边；若用杆，靠近重心短握以缩小杠杆。

**操作步骤**

1. 保持前臂稳定，先做舒适小幅桡偏与尺偏。
2. 获准后持很轻、短杠杆物体，缓慢完成同样路线。
3. 每次控制返回中立，不让重量把腕拖向一侧。
4. 放下负荷休息，分别报告尺侧和桡侧感觉。

**关键要领**

- 动作小而清楚，不靠前臂旋转。
- 杠杆先短，负荷不是越长越好。
- 手腕避免同时大幅掌屈/背伸。

**常见错误**

- 从一开始就握长柄末端造成很大杠杆。
- 用旋前旋后代替侧偏，或认为两个方向重力负荷相同。

**试做与候选剂量／评估协议：**首轮空手每方向3–5次；候选模板1–2组×每方向6–10次、组间45秒。外载方向和物体握点由计划确定。

**退阶：**空手、减小范围或把手更多放回支撑面。

**进阶：**先增加可控范围，之后按需要改变轻带方向或稍加负荷；重量和握点不可同时大增。

**停止或调整条件**

- 尖锐尺侧/桡侧腕痛、卡住或麻木。
- 负荷即将失控或前臂必须明显旋转才能继续。

**机位与画面：**近景正对手腕侧偏平面，前臂和Hand掌部轴可见。

**视觉可以观察**

- 侧偏方向、回中立、次数与前臂明显代偿。

**视觉不能直接判定**

- 腕骨间稳定、实际肌腱力或每方向相同的阻力。

**观察不足时：**握物遮挡时保留训练方向、负荷和自报次数，不追精确角。

**动作出处与对应原文：**[REF-S069]；Weighted radial deviation / Weighted ulnar deviation。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
