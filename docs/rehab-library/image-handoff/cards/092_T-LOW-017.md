# 092 T-LOW-017｜分级坐站训练

**区域：**髋、膝、综合下肢　 **等级：**L0低负荷支持—L2负重能力

**目标：**把起立这一日常任务练到顺畅可重复。

**器材：**无轮稳固椅；必要时扶手；可选轻哑铃/壶铃

**开始条件：**椅面承重可靠；依当前能力选择高度和扶手，而非为了标准测试拒绝支撑。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**椅子防滑并必要时靠墙；脚位舒适，起身通道清空。

**操作步骤**

1. 坐到能安全起身的位置。
2. 身体适当前移，按需要用扶手站起。
3. 站稳后受控坐回。
4. 恢复平稳呼吸再重复。

**关键要领**

- 站起后先稳住。
- 下降不要跌坐。
- 扶手使用可以保留。

**常见错误**

- 只因为借手就把整组判无效。
- 过低椅面导致反复失败。

**试做与候选剂量／评估协议：**候选模板：首轮3次；一般1—3组×5—10次，或分散短组。能轻松完成基础版且获许可者才加入可控轻负荷，非最大测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**升高椅面、使用扶手、减少次数。

**进阶：**一次只改变椅高、扶手、次数或负荷中的一个。

**停止或调整条件：**明显疼痛增长、腿软、头晕、胸部不适或跌坐风险时停。

**机位与画面：**侧面全身与椅面可见。

**视觉可以观察：**组次、循环、节奏和明显借手。

**视觉不能直接判定：**真实腿部力量、左右承重、手臂帮助量。

**观察不足时：**保留已完成数量；可由用户确认本组总数，不与自动数重复相加。

**动作出处与对应原文：**[REF-S001]；Sit-to-stand / Mini-squats。

**证据性质与适用范围：**公共卫生机构动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
