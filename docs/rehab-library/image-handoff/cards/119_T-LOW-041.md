# 119 T-LOW-041｜支撑旁单腿触点平衡

**区域：**髋、膝、踝、平衡　 **等级：**L1基础—L2负重能力

**目标：**练习单腿支撑中可控的小范围多方向移动。

**器材：**固定扶手、地面近距离点位贴条

**开始条件：**基础站立和单腿负重安全；可持续使用扶手，高跌倒风险者须有合适陪同。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**先设置前方和侧方很近的点，不采用标准Y-balance距离或分数。

**操作步骤**

1. 扶稳并将重心转到测试腿。
2. 另一脚向选定近点轻触地面。
3. 慢慢收回，在支撑腿上重新站稳。
4. 按当前能力增加另一个方向，再换侧。

**关键要领**

- 轻触即可，不追远。
- 可以随时扶或落脚。
- 一次移动后先站稳。

**常见错误**

- 为了够远而扭膝或快跌倒。
- 把家用触点结果套标准动态平衡常模。

**试做与候选剂量／评估协议：**候选模板：首轮每方向2次；一般1—3组×每方向3—5次，方向数量按需要选择，质量和安全优先。

**退阶：**双脚重心转移、半串联或扶稳单脚静止。

**进阶：**先增加稳定性，再小幅增加距离或减少扶手；不同时加速度。

见习中的滑垫多方向单腿任务先采用稳定地面近点轻触；足踩滑片增加滑移风险，需独立设备/能力确认。BOSU单脚与突然扰动不作为无人保护默认进阶。

**停止或调整条件：**近跌倒、踝失稳、膝软、明显恐惧或疼痛升级即停。

**机位与画面：**正面或斜前方全身，点位和扶手清楚。

**视觉可以观察：**触点方向、次数、明显落脚和支撑。

**视觉不能直接判定：**真实本体感觉、压力中心、返运动资格。

**观察不足时：**按口令完成即可，识别不到点位就只记录方向和用户完成数。
