# 129 T-AXU-007｜坐位上躯干侧屈活动

**区域：**胸部/胸腰整体　 **等级：**L0

**目标：**练习侧方胸廓与躯干舒适活动；减少骨盆随动。

**器材**

- 稳定椅

**开始条件**

- 可坐稳；肩不舒服时双手保持低位。

**准备与起始位：**双脚踩地，双手放在大腿；若肩允许，上侧手可轻放头旁但不牵拉。

**操作步骤**

1. 坐到自然中立位，确认两侧坐骨贴椅面。
2. 呼气向一侧轻缓侧屈，保留另一侧坐骨接触。
3. 自然吸气后回正，再换侧。
4. 记录肋部、肩及背部反应，必要时减小范围。

**关键要领**

- 胸口朝前，不同时扭身。
- 不抬臀、不用手压头。
- 上举手只是可选变式，不是完成标准。

**常见错误**

- 为更深侧屈而一侧臀部离椅。
- 肩受限仍强行把上侧手举过头。

**试做与候选剂量／评估协议：**首轮每侧3次；候选模板1–2组×每侧5次，组间30秒；由当前计划决定。

**退阶：**双手放腿，小幅侧倾并保留靠背支撑。

**进阶：**先提高可控范围；如肩允许，再增加轻上举手的杠杆。

**停止或调整条件**

- 锐痛、异常胸闷气促或头晕。
- 侧屈引起新的上肢或下肢放射症状。

**机位与画面：**正面坐位，肩髋和脚入镜。

**视觉可以观察**

- 整体侧倾、明显抬臀和回正次数。

**视觉不能直接判定**

- 独立胸椎侧屈角、肋骨活动或局部组织长度。

**观察不足时：**保留动作与症状，细分胸腰不可见时不给局部分数。
