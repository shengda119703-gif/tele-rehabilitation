# 150 T-AXU-012｜颈部主动左右转头

**区域：**颈部　 **等级：**L0

**目标：**恢复日常观察两侧所需的转头能力。

**器材**

- 稳定椅

**开始条件**

- 转头方向可耐受；创伤或新神经症状已先评估。

**准备与起始位：**胸口朝前坐稳，双脚落地，手机正面头肩近景。

**操作步骤**

1. 从自然平视位开始，缓慢向一侧转头。
2. 到舒适范围即控制回正，不需眼睛看向身后。
3. 回正后再转另一侧。
4. 完成少量次数后询问头晕及颈肩臂症状。

**关键要领**

- 下巴高度自然，不先仰头。
- 身体尽量朝前，不用扭胸补角度。
- 两次之间先回稳中立位。

**常见错误**

- 快甩头或反复冲末端。
- 为了让相机继续看到脸而改变整个动作姿势。

**试做与候选剂量／评估协议：**首轮每侧3次；候选模板1–2组×每侧5–8次，组间30秒；由计划限定范围。

**退阶：**减小范围，靠背支撑。

**进阶：**逐渐恢复生活所需范围，之后再结合安全环境中的视线转移任务。

**停止或调整条件**

- 眩晕、恶心、视觉异常或新上肢症状。
- 异常突发头颈痛。

**机位与画面：**正面头肩近景，保留Face置信度与可见范围。

**视觉可以观察**

- 转头方向、回正、近似范围与躯干明显随动。

**视觉不能直接判定**

- 全程精确颈旋转、血管和神经情况。

**观察不足时：**看不到侧脸末端也可保留练习时长和自报次数，不补算末端。
