# 014 E-LOW-026｜仰卧单腿桥式控制观察

**区域：**髋伸展、躯干控制　 **等级：**L2

**目标：**观察单足支撑时骨盆抬起与受控落回，不用于骶髂位置判断。

**器材：**防滑垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**双脚桥式可控、单脚支撑允许；能自行上下地。

**准备与起始位：**先双脚屈膝仰卧，再让一脚轻离地；记录支撑膝起始角和足位。

**操作步骤**

1. 先完成一遍双脚桥式。
2. 换成单脚支撑，缓慢抬髋到可控高度。
3. 短停后缓慢落回；放下另一脚再换侧。

**关键要领：**两侧目标高度相近；头颈放松；不过度顶腰。

**常见错误：**屏气硬撑；支撑脚滑动；非支撑腿挥动借力。

**试做与候选剂量／评估协议：**每侧3次，顶部约2秒；不是最大保持测试。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**双脚桥式 T-LOW-011 或仅短幅抬起。

**进阶：**固定足位和高度复评，不自动增加单腿保持到力竭。

**停止或调整条件：**持续抽筋、髋/腰锐痛或放射症状。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面计起落；脚端略斜机位可观察明显左右高度变化，不能定量骨盆旋转。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**起落、可见髋高度代理、保持时明显下沉、非支撑足触地。

**视觉不能直接判定：**臀肌/腘绳肌激活比例、真实骶髂活动及左右支撑力。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**在相同足位、高度和时长下比较有效回合、下沉事件和自报难度。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S082]；Single leg bridge：单足支持桥式；本卡为观察改编。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S082]。动作形式、背景指南和产品测量证据按第8节分别解释。
