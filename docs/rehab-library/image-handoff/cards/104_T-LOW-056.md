# 104 T-LOW-056｜坐站结合扶稳提踵：分段版

**区域：**髋、膝、踝、躯干与功能步序　 **等级：**L1–L2

**目标：**练习坐站和提踵的顺序协调；两阶段分别记录，不作为单腿复杂组合的等效测试。

**器材：**靠墙稳固椅、可触及固定扶手；首轮无外负重。

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**坐站、双脚提踵均已获准且能独立完成，能安全坐回；需要旁人防跌者不进入独处版本。

**准备与起始位：**坐在固定椅前半部、双脚稳固落地；扶手在站起后可及位置，记录椅高、脚位与扶持。

**操作步骤：**

1. 按已掌握的坐站方式受控站起。
2. 站稳并扶住固定支撑后，双脚提踵到舒适高度。
3. 受控落下足跟，确认稳定后缓慢坐回；完整循环再重复。

**关键要领：**站稳再提踵；足跟落稳再坐下；不用弹跳衔接。

**常见错误：**站起即抢着提踵；足跟未落稳便向后坐；坐站次数当作完整组合次数。

**试做与候选剂量／评估协议：**首轮3个完整循环；候选1–2组×5–8个循环，组间60–90秒；按计划调整。

**退阶：**分开执行 T-LOW-017 坐站与 T-LOW-035 双脚提踵。

**进阶：**先固定支撑增加少量可控循环，再改变单一条件；不自动改成单脚或快速连续版。

**停止或调整条件：**近跌倒、足踝失稳、膝或跟腱锐痛、不能控制坐回。

**机位与画面：**侧面含椅、扶手和全身双足；提踵高度另用足部近景，不拼接为同步三维。

**视觉模块：**身体点＋足部近景/足点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**坐站、站稳、提踵与落跟事件，完整循环和中断；脚跟可见时才记录提踵趋势。

**视觉不能直接判定：**双脚受力比例、最大肌力、心肺能力或单腿运动准备程度。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同椅高、脚位、扶持比较完整循环、阶段时间与自报反应；子动作次数与组合次数分开保存。
