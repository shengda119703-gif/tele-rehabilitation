# 100 T-LOW-025｜小幅弓步转体

**区域：**髋、膝、踝、胸廓　 **等级：**L2负重能力

**目标：**在稳定分腿支撑上练习徒手小幅躯干转动与下肢协同。

**器材：**防滑地面、固定扶手；徒手

**开始条件：**分腿蹲与躯干小幅转动均可耐受；当前无禁止腰髋旋转或膝踝扭转载荷的限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**采用原地浅分腿位而非跳步；双手在胸前或一手扶稳，膝足方向保持可控。

**操作步骤**

1. 先徒手进入稳定浅弓步并停住。
2. 保持下肢可控，胸廓向前腿一侧缓慢小幅转动。
3. 转回中间后再站起或收步。
4. 每次重新站稳，完成后换侧。

**关键要领**

- 先稳弓步，再转体。
- 转幅小于会扭动膝踝的范围。
- 不猛甩手臂制造旋转。

**常见错误**

- 脚固定而膝被强扭。
- 下降、转体和加重一次全部加速。

**试做与候选剂量／评估协议：**候选模板：首轮徒手每侧2—3次；一般1—3组×4—8次，先原地分腿小转体，不做最大转幅或速度挑战。

**退阶：**坐姿小幅转体或静止分腿站，不叠加转动。

**进阶：**稳定且当前许可时增加流畅度；如有负重目标，再单独选择并试做负重转体卡。不是急性膝踝伤默认动作。 需要加入壶铃或动态跨步时，转入独立的T-AXU-021并重新校验，不能静默改变本卡徒手版本。

**停止或调整条件：**腰部放射痛、膝/踝扭痛、髋夹痛、头晕或失稳时停。

**机位与画面：**斜前方全身；旋转定量需专门胸廓/骨盆信息。

**视觉可以观察：**动作次序、次数、明显身体转动及失衡。

**视觉不能直接判定：**独立胸椎/腰椎角度、膝扭矩、足底受力。

**观察不足时：**只提供阶段口令和完成记录；测不到分节角度不强行重拍。

**动作出处与对应原文：**[REF-S039]；Reverse Lunge with Rotation：小范围、徒手为实施退阶。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
