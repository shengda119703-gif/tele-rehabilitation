# 142 T-AXU-020｜双侧农夫行走

**区域：**全身携物/肩带/躯干　 **等级：**L2

**目标：**恢复双侧携物与中等负荷步行能力。

**器材**

- 两只质量明确且易握持的哑铃或壶铃
- 安全短直线路径

**开始条件**

- 步行、下肢承重与双手握持可耐受；无当前限制携重的方案。

**准备与起始位：**两器械尽量同重并置于安全提起高度；路径无滑物、门槛和急转角。

**操作步骤**

1. 先用轻负荷双手提起并站稳，确认能自由呼吸。
2. 以平稳步速沿直线前行，器械靠近身体两侧而不撞腿。
3. 转向前减速，以小步转向，不急刹甩动重量。
4. 到终点控制放下，记录质量、时长、症状与费力。

**关键要领**

- 目视前方，肩带自然，不耸肩硬憋。
- 步长适中，脚落地稳定。
- 物体保持可控，不能靠前后摆荡帮助走路。

**常见错误**

- 过重导致屏气、碎步失衡或器械打腿。
- 认为同重量走得更快一定表示组织耐受改善。

**试做与候选剂量／评估协议：**首轮1趟10–15秒轻负荷；候选模板2–4趟×15–30秒、趟间60–90秒。是否加重由计划和症状反应决定。

**退阶：**减重、缩短距离或先短时站持。

**进阶：**先增加稳定时间/距离，再小幅加重；高要求运动者可另设任务速度，不与康复默认合并。

**停止或调整条件**

- 握力即将失控、头晕、胸部异常不适。
- 腰、膝、踝疼痛持续升高或步态明显失稳。

**机位与画面：**全身正/侧面，短路径与器械入镜。

**视觉可以观察**

- 步行和转身完成、明显晃动、器械摆动和时长。

**视觉不能直接判定**

- 握力、躯干内部负荷、实际足底压力。

**观察不足时：**局部出画保留任务时间和自报完成，丢点不让用户重走已完成路段。
