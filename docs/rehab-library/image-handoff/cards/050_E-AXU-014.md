# 050 E-AXU-014｜肘靠身的肩主动内旋/外旋筛查

**区域：**肩　 **等级：**L0–L1

**目标：**观察旋转动作完成与症状；易用机位优先提供轨迹代理。

**器材**

- 可选薄毛巾夹在肘与躯干之间

**开始条件**

- 当前允许肩内外旋；术后或不稳者按明确的角度限制执行。

**准备与起始位：**坐或站稳，肘屈约90°并贴近身侧；手机前上方能看清前臂水平扫动。

**操作步骤**

1. 肘靠身，前臂从舒适中间位置开始。
2. 保持肘位置大致不变，缓慢向外转动前臂。
3. 回到中间，再在允许范围内向腹部方向内转。
4. 分别记录两个方向的可见活动和疼痛；不靠另一手推末端。

**关键要领**

- 上臂不要张开或向后甩。
- 身体不要随前臂一起转。
- 肘弯角尽量不变，保持自然呼吸。

**常见错误**

- 用伸肘、外展上臂代替肩旋转。
- 将正面腕点横移量直接换算成解剖旋转角。

**试做与候选剂量／评估协议：**每方向1–2次；方向间15–20秒。无验证机位/三维方案时只报完成、轨迹和粗略范围。

**退阶：**仅做较小范围，坐位支撑肘部但不强压肩。

**进阶：**相同机位与姿势复测；精确旋转ROM需专门量测协议。

**停止或调整条件**

- 出现前方滑脱感、尖锐疼痛或新麻木。
- 需要身体大幅代偿才能继续。

**机位与画面：**前上方或其他使前臂运动尽量可见的固定机位；准确测角需单独验证。

**视觉可以观察**

- 前臂扫动、肘是否明显离身、躯干是否随转。

**视觉不能直接判定**

- 普通正面二维的准确肩轴向旋转角。
- 肩袖各肌肉激活或关节囊紧张程度。

**观察不足时：**改为完成＋症状，角度不可见时不强迫额外摆机位。

**动作出处与对应原文：**[REF-S025] [REF-S085] [REF-S009]；Stanford External Rotation / AAOS Internal Rotation：肘靠身主动旋转。

**证据性质与适用范围：**大学医疗中心公开示范目录、大学医学院临床技术说明、专业学会患者训练手册。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
