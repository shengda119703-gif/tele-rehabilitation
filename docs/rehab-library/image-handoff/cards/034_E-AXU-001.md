# 034 E-AXU-001｜仰卧主动直腿抬高：腰骨盆功能代理

**区域：**骶髂/腰骨盆/髋　 **等级：**L0–L1

**目标：**比较主动抬腿的困难度和症状；不定位骶髂疼痛来源。

**器材**

- 硬度适中的床或垫

**开始条件**

- 能安全仰卧和上下床；当前没有禁止主动抬腿的术后限制。
- 这是主动任务，不加入治疗师被动牵拉或神经张力试验。

**准备与起始位：**仰卧，两腿伸直，双手放身侧；手机放在被测侧，拍到肩、髋、膝和踝。

**操作步骤**

1. 先报告腰、臀或腹股沟当前症状及左右侧。
2. 一侧膝保持自然伸直，主动把脚跟抬离支撑面一个舒适小距离。
3. 停留约2秒，平稳落回；报告抬起是否沉重、困难或重现熟悉疼痛。
4. 休息后换另一侧，保持床面和抬高目标相同。

**关键要领**

- 抬到可控位置即可，不追求脚举得高。
- 正常呼吸，不靠猛憋气甩腿。
- 另一条腿和骨盆尽量保持自然稳定。

**常见错误**

- 屈膝或甩腿把任务变成另一种动作。
- 把左右困难差异直接解释为骶髂错位。

**试做与候选剂量／评估协议：**每侧先1次熟悉，再最多2次可耐受观察；侧间休息20–30秒。记录自报困难度和症状，不套用诊断阈值。

**退阶：**改成屈膝小幅抬脚或由用户描述翻身、穿裤等生活任务；不强迫重复。

**进阶：**复测相同高度和停留条件；如需负重能力评价，另选合适负荷任务。

**停止或调整条件**

- 出现新的放射痛、麻木或明显加重的腰臀痛。
- 无法平稳落腿，或上下床本身不安全。

**机位与画面：**单侧全身侧面，保持相同床高和距离。

**视觉可以观察**

- 脚离开床面的过程、可见高度和保持时间。
- 膝是否明显弯曲，另一侧肢体是否明显移动。

**视觉不能直接判定**

- 骶髂关节真实位移、复位或骨盆韧带稳定性。
- 深层肌激活、实际抬腿力量及疼痛。

**观察不足时：**看不清脚离床时记录用户完成与困难度，保留已有视频；不要求整段重做。
