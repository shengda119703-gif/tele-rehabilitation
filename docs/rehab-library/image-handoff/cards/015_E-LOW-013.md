# 015 E-LOW-013｜五次坐站：固定坐回终点版

**区域：**髋、膝、综合下肢　 **等级：**L1基础

**目标：**量化完成五个坐站循环的转移能力。

**器材：**有靠背的稳定硬椅、计时；参考椅高43—45厘米，记录实际椅高和扶手

**开始条件：**可安全独立完成坐站；需要扶手者使用单独改良协议。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**参考无手支撑版：双臂交叉胸前、背靠椅起始；从开始指令计时到第5次坐回接触椅面结束。SRALab主页面采用独立放置椅；家庭靠墙固定、不同椅高或使用扶手均标modified，不直接套其常模。

**操作步骤**

1. 坐稳，背轻靠椅背，脚自然落地；无手支撑参考版双臂交叉胸前。
2. 先练习1次，确认站直和坐回的要求。
3. 发出开始指令后，在每次完整站起且能够受控坐回的前提下，尽快连续完成5个站起—坐回循环；若采用舒适自选速度，另记为modified协议，不套用参考常模。
4. 第5次坐回结束计时并询问症状。

**关键要领**

- 每次都站到可识别的直立位。
- 坐回要受控，不跌坐。
- 用手或需要帮助必须如实记录。

**常见错误**

- 第5次站起就结束，却和坐回版本比较。
- 椅高或扶手变了仍直接解释为力量改善。

**试做与候选剂量／评估协议：**协议：熟悉1次后测1轮，必要时充分休息再测；冻结椅高、起止和手位。无法完成保存未完成及原因，不记作0秒的优秀结果；影像缺测记未评分。家庭固定椅等改良条件用独立协议版本。

**退阶：**采用扶手/高椅改良版，仅作本人同条件比较。

**进阶：**稳定后再选适用参考版；不用哑铃加重来产生标准测试结果。

**停止或调整条件：**眩晕、胸部不适、明显新痛、腿软或跌坐风险时停止。

**机位与画面：**侧面全身与椅子边缘可见。

**视觉可以观察：**动作循环、总时长、站起/下降时长和明显用手。

**视觉不能直接判定：**股四头肌独立最大力量、真实扶手力和心肺病因。

**观察不足时：**自动漏识别时保留录像及用户确认完成数；必要时人工计时原录像，优先复用不重拍。

**动作出处与对应原文：**[REF-S056]；第1页：第五次坐回终点。

**证据性质与适用范围：**医院公开测试协议。测试动作和出处可追溯；本卡的单人实施、自动计时/角度与评分一致性仍须验证。
