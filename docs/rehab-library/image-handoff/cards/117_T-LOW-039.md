# 117 T-LOW-039｜短足练习：坐位至站位

**区域：**足弓　 **等级：**L0低负荷支持—L1基础

**目标：**练习足内在肌控制和足部负重配合，适用于经过选择的柔韧性低足弓/功能问题。

**器材：**稳固椅、可选镜子；站位需固定扶手

**开始条件：**能理解脚趾不蜷曲；不把高足弓、僵硬足弓或急痛都自动分配此动作。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**赤足，跟、第一和第五跖骨头附近轻贴地；先坐位。

**操作步骤**

1. 放松脚趾，让脚自然接地。
2. 尝试把前脚掌轻轻向脚跟方向收近，使足弓出现小幅收拢感。
3. 脚趾保持较放松，维持短时间。
4. 充分放松后重复；坐位熟悉且可负重时才站位。

**关键要领**

- 不是抓地或蜷脚趾。
- 力量轻，变化可以很小。
- 足外侧不要翻起来。

**常见错误**

- 蜷趾抓地制造足弓外观。
- 对骨性高弓足继续要求抬高足弓。

**试做与候选剂量／评估协议：**候选模板：首轮3次、每次3—5秒；一般1—3组×5—10次短保持，重点理解和控制，不承诺改变骨性结构。

**退阶：**仅练足三点轻接触与放松，或由专业人员示范。

**进阶：**先坐位稳定，再站位或加入轻重心转移；不靠提高足弓照片分数升级。

**停止或调整条件：**足底抽筋反复、前足痛、内踝锐痛或负重症状增加时停。

**机位与画面：**足内侧近景；无需全身镜头才能开始。

**视觉可以观察：**近景可见蜷趾/明显翻足；足弓细变需专门模型和验证。

**视觉不能直接判定：**内在肌实际激活、足底压力或结构矫正幅度。

**观察不足时：**主要用教学、计时和用户感觉确认；普通COCO17不判短足是否正确。

**证据性质与适用范围：**随机对照试验。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
