# 160 T-AXU-026｜支撑单臂哑铃/壶铃划船

**区域：**肩带/肘/上背　 **等级：**L2

**目标：**练习单侧水平拉力及躯干控制，适配器械训练者。

**器材**

- 哑铃或壶铃
- 可靠长凳/固定台面

**开始条件**

- 俯身、腰部静态控制和握持可耐受；支撑物牢固。
- 采用站姿时，当前双脚承重和患侧踝的支撑须可耐受；不因目标为上肢而绕过下肢限制。坐位带划船须另登记清楚变式、固定方式和步骤后才可作为替代。

**准备与起始位：**一手扶稳定支撑，双脚站稳并髋部后移，躯干前倾到可维持位置；器械自然垂下。

**操作步骤**

1. 先建立舒适躯干位置和支撑，不悬空憋气。
2. 呼气让负重侧肘朝躯干旁后方移动，器械靠近身体。
3. 到舒适位置停止，不必把肘拉到身后很远。
4. 吸气控制伸肘放回，再换侧；取放器械不急扭腰。

**关键要领**

- 想象肘沿身侧滑，不耸肩硬拉。
- 胸口和骨盆大致稳定，允许自然肩胛运动。
- 手腕自然，回程不要突然坠落。

**常见错误**

- 用腰旋转或身体起伏甩起重量。
- 强行把肩胛夹死、把肘拉到极端后伸。

**试做与候选剂量／评估协议：**首轮每侧5次轻负荷；候选模板2–3组×每侧6–12次、组间60–90秒。重量与范围须按计划并保留余力。

**退阶：**减重、提高支撑使躯干更直，或改坐位弹力带划船。

**进阶：**先提高稳定范围，再加重；减少支撑属于新的躯干需求，不与加重同时做。

**停止或调整条件**

- 肩前方锐痛、手麻或握持失控。
- 腰部症状增加、支撑台移动或站立不稳。

**机位与画面：**斜侧方，全上肢、躯干和支撑点可见。

**视觉可以观察**

- 拉回次数、肘轨迹、明显躯干旋转和节奏。

**视觉不能直接判定**

- 肩胛精确运动、背阔肌激活和腰椎内部负荷。

**观察不足时：**器械遮住腕点时保留计次和自报负荷，减少角度评分。
