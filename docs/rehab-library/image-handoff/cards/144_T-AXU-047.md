# 144 T-AXU-047｜仰卧屈膝呼吸控制

**区域：**呼吸协调、躯干与舒适体位　 **等级：**L0–L1

**目标：**在放松体位练习自然节律呼吸，并记录本人呼吸舒适度；不以视频判定膈肌力量或腹压。

**器材：**垫或稳固床面、头枕、可选膝下枕。

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**能独立进入和退出仰卧体位，当前计划允许；无新发未处理的胸痛或明显呼吸困难。

**准备与起始位：**仰卧屈膝或膝下垫枕，头颈舒适；一手轻放胸前、一手腹部，不用手压迫。

**操作步骤：**

1. 先放松肩颈与下颌，正常呼吸。
2. 按自身舒适节律轻柔吸气、呼气；不刻意加快或增加吸气量。
3. 保持自然节律，结束后休息并反馈有无不适；不做屏气挑战。

**关键要领：**自然、小幅、放松；出现头晕就结束；不用力压腹或追求手位起伏。

**常见错误：**连续强吸气；长时间憋气；把腹部起伏作为膈肌功能评分。

**试做与候选剂量／评估协议：**先试做30–60秒；耐受时按计划延长至1–2分钟；时长为候选实施模板。

**退阶：**采用本人已确认舒适的坐位或侧卧体位，单独登记；症状不适则停止。

**进阶：**先在同体位保持自然节律；其他体位或结合肢体动作须另建任务。

**停止或调整条件：**头晕、新发胸痛、明显气短、手足麻或其他异常不适。

**机位与画面：**侧面含头、躯干和双膝；避免被衣物和手部遮挡的腹部起伏被当作精确测量。

**视觉模块：**体位观察＋陪练/本人反馈；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**体位、明显屏气相关动作线索和可见任务时间；呼吸次数只在专门验证的清晰画面中候选记录。

**视觉不能直接判定：**膈肌力量、肺容量、血氧、腹压、换气效率或深层肌激活。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同体位比较本人呼吸舒适度、任务完成与症状；只记录时长不能说明呼吸功能提高。
