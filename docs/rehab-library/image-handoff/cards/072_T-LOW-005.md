# 072 T-LOW-005｜扶稳站姿交替抬膝

**区域：**髋、站立控制　 **等级：**L0低负荷支持—L1基础

**目标：**练习屈髋和站立转移，不要求高抬腿。

**器材：**固定台面或无轮稳固椅

**开始条件：**可安全双脚站立并短暂转移重心。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**两手或一手扶稳，脚下无障碍。

**操作步骤**

1. 站稳并轻轻转移重心。
2. 一侧膝缓慢抬至个人舒适范围。
3. 脚轻放回地面。
4. 确认站稳后换侧。

**关键要领**

- 躯干不后仰。
- 先站稳再换腿。
- 扶手始终可用。

**常见错误**

- 追求速度导致左右摇摆。
- 手拉身体而非主动抬腿。

**试做与候选剂量／评估协议：**候选模板：首轮每侧3次；一般1—3组×每侧5—10次，或短时间交替练习，按站立耐受安排休息。

**退阶：**坐姿抬膝或更小幅度。

**进阶：**先减少借手与提高控制，再按目标增加时间；负荷另行评估。

**停止或调整条件：**失衡、腿软、髋锐痛、眩晕或呼吸异常时停止。

**机位与画面：**侧面或斜前方全身。

**视觉可以观察：**抬膝次数、节奏、明显躯干代偿。

**视觉不能直接判定：**独立屈髋肌力、实际承重比例。

**观察不足时：**保持语音节拍和用户计次，缺测不清零。
