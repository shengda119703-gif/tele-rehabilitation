# 179 T-AXU-038｜前臂旋前/旋后：空手到短杠杆

**区域：**前臂/肘/腕　 **等级：**L1

**目标：**练习前臂旋转及逐步增加的外载控制。

**器材**

- 桌面
- 可选轻短棒/短握小锤，须按计划选择

**开始条件**

- 尺桡关节旋转和轻握持获准；腕尺侧痛或不稳需先确认适用性。

**准备与起始位：**肘屈约90°并有支撑，上臂靠身；先空手，负重版靠近物体重心握持。

**操作步骤**

1. 从拇指向上的中立位开始。
2. 缓慢旋到掌心向上的舒适范围，再控制回中立。
3. 再旋到掌心向下并回中立，前臂不从支撑上甩开。
4. 空手稳定且反应合适后，才用轻短杠杆重复。

**关键要领**

- 肘不向外张，肩不跟着转。
- 手腕大致中立，不靠侧偏凑范围。
- 物体转动速度慢，避免长柄惯性带腕走。

**常见错误**

- 一开始拿重长柄锤并握在末端。
- 腕痛仍大幅旋转，或用肩旋转冒充前臂动作。

**试做与候选剂量／评估协议：**首轮空手每方向3–5次；候选模板1–3组×每方向6–10次、组间45–60秒。质量、握点与范围由计划确认。

**退阶：**取消外载、缩小旋转范围或增加前臂支撑。

**进阶：**先稳定范围和回程，再略增加质量或杠杆之一；不同时加速。

**停止或调整条件**

- 腕尺侧/肘部锐痛、卡顿或新麻木。
- 长柄将失控或无法稳定回中立。

**机位与画面：**前方斜近景，肘腕及Hand掌面可见；共同图像坐标而非直接拼world。

**视觉可以观察**

- 掌面转向、重复、肘离位和节奏。

**视觉不能直接判定**

- 真实尺桡力矩、DRUJ/TFCC稳定性或精确深度旋转角。

**观察不足时：**掌部被柄遮住时按口令与用户确认记录；不把低置信度猜测当完整ROM。
