# 077 T-LOW-010｜坐姿髋内外旋控制

**区域：**髋　 **等级：**L0低负荷支持—L1基础

**目标：**在有支撑体位反复练习许可的旋转范围。

**器材：**足够高的稳定椅

**开始条件：**髋旋转允许，可悬腿或小腿被可靠支持。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**大腿稳定，膝与髋在舒适角度；固定椅高。

**操作步骤**

1. 放松坐稳，选一侧腿。
2. 让小腿缓慢向外摆后回中间。
3. 再向内摆后回中间。
4. 分别完成允许方向并换侧。

**关键要领**

- 膝尽量不横移。
- 骨盆不转走。
- 不使用另一只脚强推。

**常见错误**

- 踝内外翻代替髋旋转。
- 强行打开到疼痛终点。

**试做与候选剂量／评估协议：**候选模板：首轮每个允许方向3次；一般1—2组×5—10次，重点可控活动而非最大范围。

**退阶：**减少幅度或只做一个许可方向。

**进阶：**经评估后再增加阻力或功能转体，不能自动升级。

**停止或调整条件：**腹股沟卡痛、术区牵扯或明显症状增长时停止方向练习。

**机位与画面：**正面下半身，双膝骨盆可见。

**视觉可以观察：**方向、次数和粗小腿摆幅。

**视觉不能直接判定：**独立髋旋转力矩及骨性限制。

**观察不足时：**保留方向完成和症状记录，省略精确角度。

**动作出处与对应原文：**[REF-S068]；Seated examination：坐姿主动内外旋；重复活动为训练改编。

**证据性质与适用范围：**期刊临床技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
