# 032 E-LOW-021｜已确认标志点的足弓高度变化

**区域：**足弓　 **等级：**L1基础

**目标：**在定位和尺度条件满足时追踪同人足弓形态变化。

**器材：**专业人员确认的舟骨等标志点、贴点、同平面标尺、稳固椅

**开始条件：**仅限标志点可靠、能安全坐站者；不要求普通用户凭感觉找舟骨。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**足内侧近景；相机位置固定，标尺与足处于相近测量平面。

**操作步骤**

1. 核对标志点身份并记录坐位放松高度。
2. 脚不挪位，站起后按统一双脚站姿记录。
3. 回坐位复核标记未移动。
4. 保存两体位高度及测量条件，不单凭差值诊断。

**关键要领**

- 不要用一个随机凸起代替舟骨。
- 尺度和脚保持同平面。
- 站位与鞋履条件要一致。

**常见错误**

- 把MediaPipe足尖当成舟骨。
- 默认每只脚恰好承担一半体重。

**试做与候选剂量／评估协议：**候选协议：每体位2次静态读数，标点或负重条件不可靠则不出毫米值；静态改良协议不继承动态研究常模。

**退阶：**回足弓外观和症状筛查，无需自行加标点。

**进阶：**需要更可靠临床结论时补规范体检。

**停止或调整条件：**站立不适、头晕、足部明显疼痛或无法保持安全姿态即停。

**机位与画面：**足内侧水平近景，避免广角近距离畸变。

**视觉可以观察：**可信标记之间距离变化和有条件的尺度值。

**视觉不能直接判定：**足底负重比例、骨性畸形分期和病因。

**观察不足时：**只存图像与条件，不伪造数值；允许人工后处理原图。

**动作出处与对应原文：**[REF-S060]；Methods / Navicular drop：坐位与站位标志点高度。

**证据性质与适用范围：**原始测量研究。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
