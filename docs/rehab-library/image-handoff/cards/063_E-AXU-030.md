# 063 E-AXU-030｜墙面手掌承重的腕背伸观察

**区域：**腕、前臂、上肢承重　 **等级：**L0–L1

**目标：**观察低负荷墙面版本的腕背伸耐受，不以此诊断腕管或腕骨问题。

**器材：**墙、手位标记

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**手掌接触与轻承重获准；无未明确的急性腕伤或承重禁忌。

**准备与起始位：**面墙站稳，手在获准高度，手指自然；先贴掌不压，记录站距。

**操作步骤**

1. 手掌舒适贴墙，肘留小幅可控弯曲。
2. 身体缓慢靠近一点改变腕姿，再退回。
3. 按同路径重复，保存本人疼痛与麻木反馈。

**关键要领：**不猛压掌根；不自加关节牵引带；改站距和手高须另记。

**常见错误：**手腕远景却报精确角；把可承重判断为韧带正常。

**试做与候选剂量／评估协议：**3次舒适往返；不追最大腕背伸。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**仅手掌贴墙不前移，或 E-AXU-019非承重活动。

**进阶：**相同手高、肘位、站距复评；桌面/地面承重另建协议。

**停止或调整条件：**腕痛、手麻或肘打软。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**腕的正侧近景含肘、腕、手背中指掌骨方向；手掌不可见则只保留体位。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**Hand＋前臂统一图像坐标；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**近景可靠时腕投影角、往返及肘位变化。

**视觉不能直接判定：**手掌实际压力、腕骨松动、神经受压或完整三维腕角。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同体位比较可见活动范围和症状；Hand缺测不补角。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S001]；Wall press-up的手掌墙面接触；本卡为低负荷腕耐受观察。

**证据性质与适用范围：**公共卫生机构动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
