# 039 E-AXU-006｜坐位屈背/伸胸功能筛查

**区域：**胸部/胸腰整体　 **等级：**L0–L1

**目标：**观察坐位向前屈背和向后伸胸的舒适程度；不测真实胸椎后凸角。

**器材**

- 稳定椅

**开始条件**

- 已知脊柱骨折、近期术后或活动限制者须先获得对应方向许可。

**准备与起始位：**侧面对镜头坐稳，双脚落地，手轻放大腿，椅背不遮住全部肩髋。

**操作步骤**

1. 坐到自然位置，记录背部及胸前症状。
2. 呼气时轻轻让上背向前屈，范围以舒适为限。
3. 回中间后轻轻向上、向后伸胸，避免强行抬下巴。
4. 分别记录两个方向的困难或症状，必要时只完成获准的方向。

**关键要领**

- 骨盆稳定坐在椅上，不靠滑到椅前完成动作。
- 活动要小而慢，不把腰部最大后仰当成伸胸。
- 呼吸自然，肩放松。

**常见错误**

- 大幅抬头或腰后仰代替上背活动。
- 从肩髋两点计算胸椎分节屈伸角。

**试做与候选剂量／评估协议：**每方向1–2次，之间回正休息；这是低负荷筛查，不作反复末端诱发。

**退阶：**有靠背支撑的小幅动作，或记录呼吸、久坐和转身的主诉。

**进阶：**条件一致复测；需局部脊柱测量时转专业量测，不能仅升级为更大动作。

**停止或调整条件**

- 胸痛伴气促、冷汗或其他非熟悉症状。
- 新发尖锐背痛、眩晕或无法保持坐稳。

**机位与画面：**侧面坐位全躯干，头和骨盆均入镜。

**视觉可以观察**

- 躯干整体姿态改变、头部明显跟随及动作完成。

**视觉不能直接判定**

- 胸椎后凸角、分节活动及肋椎关节活动。
- 局部疼痛来源或胸廓真实容量。

**观察不足时：**只记录舒适范围内完成情况与主诉；不以胸腰不可分为由强制重拍。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
