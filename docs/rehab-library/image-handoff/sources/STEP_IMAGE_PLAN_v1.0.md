## 4. 图组顺序、命名、复用与验收

### 4.1 如何阅读每个动作

- “首轮示范图”是该条目当前选定图组的总画面数。
- 表中“图号01—08”只在本动作内部编号。独立方向／路线会写入每行，如“I路线准备”“Y路线抬臂”；这些分组之间不表示一次动作的连续步骤。
- 每一行必须按体位、活动肢体、支撑接触和运动方向一起核对。镜头能看见姿势，不代表已证明肌肉发力、真实负荷或测试有效性。
- “扩展版本（不计入首轮）”是另外一套图片；只有明确选做该版本时增加，保持同一组内器材和难度设置一致。

### 4.2 保存建议

保留现有单图及现有进度JSON。新步骤图建议另存到以下子目录：

```text
E:/git冲突问题/rehab image/assess/steps/
E:/git冲突问题/rehab image/train/steps/
```

文件名采用`序号_动作ID_s图号.png`，例如`006_E-LOW-001_s01.png`和`006_E-LOW-001_s02.png`。扩展版本增加版本后缀，例如`153_T-AXU-022_wall_s01.png`。055、116、158号首轮仍连续编号s01—s08，但制作清单中保留四个独立图组标签。首次制作不覆盖现有文件；不同尝试或修订另加`_v2`等后缀。

### 4.3 每张图的完成条件

逐张记录拟定文件名、实际保存位置、是否复用及对应原图、动作与比例检查结果。合格后再登记为完成：人物身份、服装、背景和光线一致；姿势与本行相符；支撑与器材接触正确；人体比例自然；关键关节及完整手脚可见；独立方向和版本标签明确。生成成功或文件存在本身不等于画面验收完成。
