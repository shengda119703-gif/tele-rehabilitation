# 040 E-AXU-007｜坐位上躯干左右侧屈筛查

**区域：**胸部/胸腰整体　 **等级：**L0–L1

**目标：**在较少下肢移动的条件下比较左右侧屈表现。

**器材**

- 稳定椅

**开始条件**

- 能独立坐稳或有必要扶持；无禁止侧屈的限制。

**准备与起始位：**正面坐位，双脚踩地、双手可沿椅边自然下垂，椅子不转动。

**操作步骤**

1. 先坐正，记录起始症状。
2. 向一侧轻缓侧倾，保持两侧坐骨与椅面接触。
3. 回中间停顿，询问背部或肋部感觉。
4. 另一侧以相同方式完成。

**关键要领**

- 胸口朝前，不把转身混入侧屈。
- 不用手抓椅腿向下牵拉。
- 两脚不蹬地把臀部抬起。

**常见错误**

- 一侧臀部离开椅面增加表观角度。
- 把整体侧倾定名为独立胸椎侧屈ROM。

**试做与候选剂量／评估协议：**每侧1–2次，侧间休息15秒；只在相同坐姿下比较。

**退阶：**减小范围并允许一手轻扶椅面。

**进阶：**复测时保持椅高和脚位；不通过手持重量扩大评估范围。

**停止或调整条件**

- 出现尖锐肋部/背部痛或呼吸明显不适。
- 有失去坐位平衡的趋势。

**机位与画面：**正面，肩髋及双脚可见。

**视觉可以观察**

- 整体侧倾、明显抬臀/抬肩及回正。

**视觉不能直接判定**

- 胸椎与腰椎各自贡献比例。
- 肋骨错位或特定肌肉紧张程度。

**观察不足时：**椅子遮挡髋点时保留肩躯干动作和症状，不给精确分段角。
