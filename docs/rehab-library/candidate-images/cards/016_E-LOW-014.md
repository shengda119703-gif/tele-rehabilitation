# 016 E-LOW-014｜30秒坐站：标准及扶手改良分轨

**区域：**髋、膝、综合下肢　 **等级：**L1基础

**目标：**记录固定时间内坐站次数及功能耐受。

**器材：**有直靠背的稳定无扶手椅、计时；CDC参考座高17英寸，约43.2厘米，记录实际椅高

**开始条件：**能安全尝试坐站；需要帮助者不可冒充标准评分。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**标准版双臂交叉胸前、手置对侧肩、双脚平放、背保持直；椅子防滑固定。椅高或手位改变则单列modified版本。

**操作步骤**

1. 示范并试做1—2次，确认足位、手位和站直要求。
2. 听到开始后在30秒内连续站起并坐回。
3. 记录完整站起；计时结束时若末次已站起超过一半，按CDC规则计1次，否则不计该次。
4. 结束后坐稳，记录症状、是否借手和实际完成时长。

**关键要领**

- 每次充分站起再坐回。
- 安全比抢次数优先。
- 需要扶手即可使用，但结果转改良版。

**常见错误**

- 把半蹲起身均算完整次。
- 扶手改良次数套用标准老年常模。

**试做与候选剂量／评估协议：**协议：熟悉后通常1轮30秒。若必须使用手臂，结束标准测试并按CDC记标准0分；仍可把扶手完成记录保存在独立改良轨。影像缺测、未开始或无法确定末次半站时保持未评分/待复核，不能冒充标准0分。

**退阶：**用高椅、扶手或缩短观察时间并更改协议名。

**进阶：**仅在条件允许时改标准版；两种轨迹分别追踪。

**停止或调整条件：**出现头晕、胸部不适、呼吸异常、明显疼痛升级或失稳即停。

**机位与画面：**侧面全身，椅面可见。

**视觉可以观察：**次数、时间、后半程节奏变化及明显扶手。

**视觉不能直接判定：**最大腿力、左右承重以及疲劳的确切原因。

**观察不足时：**保留已确认次数和实际时长，允许用户补充总数；不要求完整重测。

**动作出处与对应原文：**[REF-S055]；标准30秒计数与使用手臂的停止规则；扶手轨另记。

**证据性质与适用范围：**官方标准测试协议。测试动作和出处可追溯；本卡的单人实施、自动计时/角度与评分一致性仍须验证。
