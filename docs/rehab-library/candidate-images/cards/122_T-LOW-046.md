# 122 T-LOW-046｜坐姿踝主动背屈与跖屈：无外阻

**区域：**踝　 **等级：**L0低负荷支持

**目标：**在当前许可范围内练习轻量主动踝上下运动；不自动加入内翻或外翻。

**器材：**无轮稳固椅或硬床；可选软垫支撑小腿

**开始条件：**已完成急伤风险分流且允许轻主动踝活动；疑似骨折、需先检查的异常或医嘱制动者不靠此动作绕过限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**小腿有舒适支持，脚能小幅自由活动；不使用弹力带、不手掰、不负重压踝。

**操作步骤**

1. 稳定坐好，放松脚趾，选定本次允许的上下范围。
2. 缓慢把前足向小腿方向抬起一点，回到中间。
3. 再把前足轻轻向下移动一点，回到中间。
4. 完成少量重复后休息，记录当次与稍后疼痛、肿胀变化。

**关键要领**

- 是踝上下动，不只动脚趾。
- 小范围、慢速度即可。
- 不绕圈，不自动加入内翻/外翻。

**常见错误**

- 用手强掰到最大角度。
- 把轻主动活动直接升级成带阻四方向。

**试做与候选剂量／评估协议：**候选而非统一急伤处方：首轮每个允许方向3次；一般可选1—3组×5—10次轻活动，按当前限制与反应调整范围和总量，不做最大幅度挑战。

**退阶：**只做一个明确允许方向、更小范围或更少重复；暂不允许活动则保留教育与后续复评。

**进阶：**活动稳定且当前阶段明确允许后，才另选带阻或负重动作；不能仅因视频幅度变大就自动升级。

**停止或调整条件：**锐痛、新麻木、明显无力、活动后肿胀或疼痛持续加重时停止并复核；出现新的急伤异常转相应评估。

**机位与画面：**坐位足侧面近景可选，能看见小腿参考和前足；没有相机也可执行。

**视觉可以观察：**有足部点时可看方向与重复；普通COCO17只提供有限体位信息。

**视觉不能直接判定：**真实韧带状态、关节内损伤、肿胀量、肌力等级及无足点时的踝角。

**观察不足时：**直接使用语音节拍、计时和用户确认；缺模型点不阻止按许可做轻活动，不要求重拍。
