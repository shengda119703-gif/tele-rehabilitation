# 049 E-AXU-013｜肩主动外展/回收内收筛查

**区域：**肩　 **等级：**L0–L1

**目标：**观察侧方抬臂及控制回收，记录整体抬举范围和症状。

**器材**

- 无

**开始条件**

- 主动外展在当前治疗/术后限制内；没有明显新发肩不稳。

**准备与起始位：**正面对镜头，双脚稳定；可单侧先测，手臂和上半身全程留在画面内。

**操作步骤**

1. 从手臂下垂开始，手自然朝向舒适位置。
2. 缓慢向侧方抬臂到可耐受高度，不必须到头顶。
3. 沿原路线平稳回到身侧，完成回收内收阶段。
4. 报告疼痛出现、缓解的阶段，再按需要测另一侧。

**关键要领**

- 胸口朝前，减少向对侧歪身。
- 肘保持自然伸直，不耸肩硬顶。
- 回落也保持控制，不任由手臂突然掉下。

**常见错误**

- 靠躯干侧倾制造更大的投影角。
- 把外展疼痛或回落困难直接确诊为肩袖撕裂。

**试做与候选剂量／评估协议：**每侧1次熟悉、1–2次观察；间隔20秒。这里测侧方抬举与回收，不把回到身侧等同完整跨中线内收ROM。

**退阶：**缩小抬举范围或以桌面/对侧手提供获准的助力。

**进阶：**同镜头复测；需要水平内收时另做水平开合筛查。

**停止或调整条件**

- 出现突然失去控制、肩部滑脱感或新麻木。
- 锐痛持续增加，或无法平稳放回手臂。

**机位与画面：**正面上半身，肩肘腕髋可见。

**视觉可以观察**

- 上臂相对躯干的投影抬举角和回收阶段。
- 明显屈肘、躯干侧倾与左右范围差异。

**视觉不能直接判定**

- 肩胛与盂肱各自贡献、肌腱病变。
- 疼痛及真实肌力等级。

见习44/46中的主动外展受限或疼痛阶段需由本人报告；摄像头只关联该时刻的投影姿态。主动、主动辅助、被动ROM分栏，不能把墙面滑手等同于被动ROM；不自动诊断关节囊/肩袖病变。

**观察不足时：**末端遮挡时保留已见范围、次数和主诉，不要求为补一个角重做。

**动作出处与对应原文：**[REF-S025] [REF-S085]；Shoulder ROM、Wall Climbers及主动抬举路线；具体平面另参Stanford肩检查。

**证据性质与适用范围：**大学医疗中心公开示范目录、大学医学院临床技术说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
