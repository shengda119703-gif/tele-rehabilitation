# 130 T-AXU-008｜侧卧开书式转胸

**区域：**胸部/胸腰整体/肩　 **等级：**L0

**目标：**在支撑位练习可耐受转胸和肩部开合。

**器材**

- 垫
- 头部枕垫；可选膝间枕

**开始条件**

- 侧卧舒适，肩外展/水平开合与躯干旋转均在获准范围内。

**准备与起始位：**侧卧，髋膝适度弯曲并叠放，头有支撑，两臂在胸前伸出、双手相合。

见习18他人/重物固定骨盆的版本改为双膝叠放、轻夹枕或膝靠稳定支撑；无人在侧时不在骨盆/腰部压重物。保留小范围并允许上侧手不碰地。

**操作步骤**

1. 下侧手保持在原位，上侧手缓慢向身后打开。
2. 眼睛可跟随手，但不强迫颈部旋到极限。
3. 膝尽量保持叠放，在舒适位置做一次自然呼吸。
4. 控制上侧手返回，完成后再决定是否换侧。

**关键要领**

- 转动以胸口缓慢打开为主，膝不要大幅掀起。
- 上侧手不必碰地，肩前方不应被强拉。
- 不借手臂惯性把腰扭过去。

**常见错误**

- 为了手碰地把膝和骨盆一起翻开。
- 肩痛仍强压手背到地面。

**试做与候选剂量／评估协议：**首轮每侧3次；候选模板1–2组×每侧5–8次，组间30秒；范围与方向需按计划。

**退阶：**上侧手放胸前，只作较小转胸；肩不适可改坐位转胸。

**进阶：**增加可控舒适范围与短暂停留；不手持重物追末端。

**停止或调整条件**

- 肩锐痛、腰腿放射痛或明显颈部不适。
- 出现新的手麻或不能控制回合。

**机位与画面：**斜前上方，双膝、肩和上侧手可见。

**视觉可以观察**

- 开合次数、可见手臂轨迹、明显膝/骨盆随动。

**视觉不能直接判定**

- 真实胸椎独立旋转角与肩胛运动。
- 手臂重量如何分配到局部椎节。

**观察不足时：**开到背后遮挡时可按节奏与自报完成，不能补造精确末端。
