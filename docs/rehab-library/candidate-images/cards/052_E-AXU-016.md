# 052 E-AXU-016｜梳头/够后腰功能够取

**区域：**肩/肘　 **等级：**L0–L1

**目标：**用生活任务评估够取能力；不把复合动作当孤立肩内旋测量。

**器材**

- 无

**开始条件**

- 没有禁止手臂后伸、内旋或头上够取的限制。

**准备与起始位：**保持自然站或坐位；梳头用正面或侧面，后腰用斜后方；不要求为了背后腕点反复重拍。

**操作步骤**

1. 先选实际困难的任务：摸头顶或把手送到后腰。
2. 自然完成到舒适可达区域，不用另一手牵拉。
3. 停约1秒后平稳回到身侧。
4. 报告能否用于真实生活、疼痛位置及是否依赖躯干代偿。

**关键要领**

- 先求舒服完成，不求摸到某个椎体高度。
- 手去够目标，不把头或腰猛移来迎手。
- 后腰任务不得由另一手把患侧腕往上拽。

**常见错误**

- 把到达某个后背高度等同精确肩内旋角。
- 通过衣服遮挡猜测手所触及的椎体节段。

**试做与候选剂量／评估协议：**每个相关任务1–2次，间隔20秒；记录可达区域和自报困难，不给统一通过高度。

**退阶：**把目标降低，例如摸侧头、臀侧或腰带旁；只评估获准任务。

**进阶：**用同样目标复测；再根据生活要求增加可达区域。

**停止或调整条件**

- 出现肩部不稳、尖锐疼痛或麻木。
- 需要强力扭腰或拉腕才能达到目标。

**机位与画面：**正/侧面用于摸头，斜后方用于后腰；功能观察优先。

**视觉可以观察**

- 复合够取完成、可见目标区域、明显躯干代偿。

**视觉不能直接判定**

- 孤立肩内外旋ROM、准确后背椎体高度。
- 手触目标的压力和组织损伤。

**观察不足时：**手被身体遮住时询问到达区域，标为自报，不重复整套拍摄。

**动作出处与对应原文：**[REF-S025] [REF-S085] [REF-S088]；Shoulder internal/external rotation：头后和背后功能够取；主动观察分轨。

**证据性质与适用范围：**大学医疗中心公开示范目录、大学医学院临床技术说明、医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S025] [REF-S085] [REF-S088]；背景及临床边界：[AXU-S03] [AXU-S09]。动作形式、背景指南和产品测量证据按第8节分别解释。
