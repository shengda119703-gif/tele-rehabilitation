# 048 E-AXU-012｜肩主动前举/后伸活动筛查

**区域：**肩　 **等级：**L0–L1

**目标：**记录上臂相对躯干的前后活动及代偿；前举和后伸单独存结果。

**器材**

- 无；必要时稳定椅

**开始条件**

- 没有禁止主动肩运动或限制后伸的术后/脱位方案；有则按批准方向执行。

**准备与起始位：**被测侧朝镜头，手臂自然下垂，躯干直立；全上肢入镜。

**操作步骤**

1. 肘自然伸直，将手臂缓慢向前抬到舒适位置。
2. 平稳放回身侧，报告出现症状的阶段。
3. 若允许，把手臂小幅向后伸，身体不同时前倾。
4. 回起始位，分别记录两个方向的范围与感觉。

**关键要领**

- 避免耸肩或后仰去追更高的手。
- 手臂自然转向舒适位置，不锁死肘。
- 后伸尤其保持小而慢，不借弹力冲末端。

**常见错误**

- 肘大幅弯曲改变上臂抬举任务。
- 将整体肩复合体抬举角写成孤立盂肱ROM。

**试做与候选剂量／评估协议：**每个允许方向1–2次；方向间休息20秒。疼痛出现时记录而不反复寻找痛点。

**退阶：**坐位或桌面助力前滑；后伸不适可跳过并记录。

**进阶：**同机位复测；负荷耐受另用负重任务评估。

**停止或调整条件**

- 出现突然无力、明显不稳或新的麻木。
- 肩前方锐痛、动作后持续加重或无法控制放下。

**机位与画面：**正侧面，肩、肘、腕和髋可见；运动尽量在成像平面。

**视觉可以观察**

- 上臂与躯干的投影角、肘屈曲、明显躯干代偿。

**视觉不能直接判定**

- 独立肩胛上回旋、盂肱活动及肌腱状态。
- 疼痛弧与实际抗重力力量。

见习44出现主动外展约90°、被动约140°，提示需要进一步专业评估；本卡只自动观察主动动作。被动范围保留clinician_entered来源，不让用户强拉到临床被动角度；墙面/木棒辅助范围另立协议。

**观察不足时：**手越过画面时保留已见角度及自报终点，缺一个末端不抹掉整个评估。

**动作出处与对应原文：**[REF-S025] [REF-S085]；Shoulder ROM、Wall Climbers及主动抬举路线；具体平面另参Stanford肩检查。

**证据性质与适用范围：**大学医疗中心公开示范目录、大学医学院临床技术说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
