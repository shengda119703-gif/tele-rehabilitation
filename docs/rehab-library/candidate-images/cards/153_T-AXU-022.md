# 153 T-AXU-022｜肩桌面滑手到墙面滑手

**区域：**肩　 **等级：**L0

**目标：**借助支撑逐步恢复抬举活动与主动控制。

**器材**

- 稳定桌面或平整墙面
- 可选毛巾减摩擦

**开始条件**

- 抬举方向和助力程度符合当前计划；术后依照批准范围。

**准备与起始位：**桌面版坐在桌旁，前臂和手放毛巾上；墙面版面对墙，手轻触墙面。

**操作步骤**

1. 桌面版先让手向前滑，躯干可少量前移配合获准助力。
2. 到舒适位置停短暂，控制滑回，不耸肩强顶。
3. 能控制且反应合适后，按计划换墙面向上滑手。
4. 墙面版同样平稳上滑与下滑，结束后报告肩部反应。

**关键要领**

- 支撑用于减负荷，不用另一手强压到末端。
- 肘和手沿舒适路线，肩离耳朵。
- 下滑要控制，躯干不过度后仰。

**常见错误**

- 靠腰部大后仰制造更高抬举。
- 把桌面助力范围与空手主动ROM混成同一指标。

**试做与候选剂量／评估协议：**首轮桌滑3–5次；候选模板1–3组×6–10次、组间30–60秒。桌面/墙面版本与角度由计划决定。

**退阶：**降低桌高/滑动距离，按许可增加支撑。

**进阶：**桌滑→墙滑→离墙短时保持→主动抬臂；不以能摸更高即自动加负荷。

见习3/14/29/44/46中肩胛上回旋辅助需区分墙支持、带辅助、治疗师助力和主动任务；帮助未知时不报力量改善。墙天使 T-AXU-051与斜向轨迹 T-AXU-055，不测肩胛骨真实角。

**停止或调整条件**

- 肩不稳、锐痛或新麻木。
- 不能控制下滑，或练后症状明显持续上升。

**机位与画面：**侧面或斜前方，肩肘腕髋可见。

**视觉可以观察**

- 滑动次数、可见抬举范围、明显躯干与屈肘代偿。

**视觉不能直接判定**

- 手臂实际被支撑的重量、主动/被动贡献、肩袖激活。

**观察不足时：**手在墙上遮挡时保留次数和自报完成，角度只对可见片段评分。
