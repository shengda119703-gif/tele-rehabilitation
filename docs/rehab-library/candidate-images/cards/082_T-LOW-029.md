# 082 T-LOW-029｜侧卧下侧腿内收抬起

**区域：**髋内收　 **等级：**L1基础

**目标：**建立动态内收训练的基础控制。

**器材：**防滑垫、小枕头

**开始条件：**侧卧舒适，内收训练获许可，腹股沟无未评估急伤。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**测试腿在下伸展，上侧腿屈膝置于前方稳固支撑，避免压住测试腿。

**操作步骤**

1. 调整侧卧位并让上侧脚站稳。
2. 下侧腿向上缓慢抬起小幅度。
3. 短停后受控放回。
4. 放松后重复，再换侧。

**关键要领**

- 骨盆尽量不滚动。
- 抬起幅度以可控为准。
- 上侧脚只是稳住姿势。

**常见错误**

- 上半身晃动带动下腿。
- 腹股沟牵痛仍追求抬高。

**试做与候选剂量／评估协议：**候选模板：首轮每侧3次；一般1—3组×5—10次，先不加外重，按近期反应调整。

**退阶：**仰卧轻夹垫或更小幅度。

**进阶：**完成稳定且允许后，选择短杠杆哥本哈根试做。

**停止或调整条件：**腹股沟锐痛、侧卧压痛、抽筋或新麻木时停。

**机位与画面：**面对身体正侧中景，测试腿能看清。

**视觉可以观察：**内收抬起次数、范围和明显骨盆滚动。

**视觉不能直接判定：**内收最大力、肌腱张力及受伤组织。

**观察不足时：**卧姿识别不足时继续计时口令和自主计次，不强迫反复重拍。

**动作出处与对应原文：**[REF-S005]；Hip Abduction / Internal Hip Rotation（蚌式）/ Hip Adduction。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
