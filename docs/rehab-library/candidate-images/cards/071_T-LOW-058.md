# 071 T-LOW-058｜短幅反向北欧挺：专业确认后启用

**区域：**股四头肌、膝、髋躯干　 **等级：**L2–L3

**目标：**登记见习中的Reverse Nordic，以小幅、可返回版本管理膝伸肌离心任务。

**器材：**厚膝垫；仅在专业教学确认后可选可靠前方低位辅助带

**单人适用：**条件独立；非默认，须已完成专业教学；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**治疗师已确认膝屈范围、跪膝接触、膝伸负荷和术后限制；已学会受控返回；不作为平台默认首练。

**准备与起始位：**稳定地面高跪位，躯干与大腿大致同线；首轮小幅且保留回正余量。

**操作步骤**

1. 高跪位自然呼吸。
2. 整体小幅后倾，髋不折回；仍能返回的范围即止。
3. 受控回正，充分休息；辅助带版本另保存锚点和帮助方式。

**关键要领：**范围小；不做到失控；膝接触舒适。

**常见错误：**后倾到回不来；为完成次数腰折叠；自行以治疗师旧用量10次默认发给术后患者。

**试做与候选剂量／评估协议：**教学试做2–3次；获准候选1–2组×3–5次、下降约2–3秒，组间60–90秒，按个体计划。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**更小幅，或 T-LOW-018浅蹲/计划许可的膝伸训练。

**进阶：**仅当范围和次日反应稳定时再增加一项；不能自动力竭。

**停止或调整条件：**膝前痛、跪位接触痛、失控或回正困难。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正侧面含肩髋膝和地面；辅助带接触必须可见。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**后倾/回正、粗躯干大腿线与周期。

**视觉不能直接判定：**髌腱应力、膝伸真实力或术后组织安全。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同范围、辅助和节奏记录回合与反应；完成不等于自动解除保护。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S064]；Reverse Nordic exercise：跪位整段后倾与回正。

**证据性质与适用范围：**原始训练与肌肉结构研究。原始研究观察股直肌结构变化；短幅退阶属于实施变式，不能外推所有患者、术后阶段或疾病疗效。
