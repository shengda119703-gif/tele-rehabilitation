# 085 T-LOW-044｜弹力带侧向行走

**区域：**髋外展、膝踝协同　 **等级：**L2负重能力

**目标：**练习持续侧向跨步和髋周阻力耐受。

**器材：**完整弹力带、平坦空间、旁侧固定扶手

**开始条件：**徒手侧移安全，当前允许侧向负重；带位置不会压迫受伤踝或膝。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**先把带放膝上近大腿处，选择轻张力；只有确认足踝可耐受时才改更远端位置。 检查带体和锚点；记录品牌型号、固定长度和设置，不由颜色直接推张力。

**操作步骤**

1. 站稳并保持舒适浅屈膝。
2. 一侧脚缓慢向旁跨小步。
3. 另一脚受控跟进，避免带突然松弹。
4. 完成短距离后站稳，反方向返回。

**关键要领**

- 步幅小而一致。
- 躯干不左右甩。
- 脚不交叉。

**常见错误**

- 带太紧只能拖脚。
- 踝刚受伤却自动把带套踝增加杠杆。

**试做与候选剂量／评估协议：**候选模板：首轮每方向3—5小步；一般1—3组×每方向5—10步，采用可控非最大阻力，不做力竭侧走。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**无带侧移、带放更近端或扶稳站姿外展。

**进阶：**先提高平稳步数，再小幅增阻；带位置改变视为新负荷试做。

**停止或调整条件：**支撑踝失稳、腹股沟锐痛、膝痛加重、带滑脱或步伐失控时停。

**机位与画面：**正面或斜前方全身。

**视觉可以观察：**侧步次数、脚交叉、躯干大幅晃动。

**视觉不能直接判定：**弹力带实际张力、髋肌激活和膝内外翻力矩。

**观察不足时：**识别不到带仍可计步；记录品牌与设置，不识别颜色估牛顿。

**动作出处与对应原文：**[REF-S046]；Lateral Band Walks / Isometric Single-leg Wall Lean。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
