# 143 T-AXU-021｜壶铃分腿位转胸：静态到弓步转体

**区域：**胸腰/髋膝踝协同/返运动　 **等级：**L2—L3（依静态、跨步及任务要求分别判断）

**目标：**分阶段练习分腿支撑下的轻负荷转胸和方向控制。

**器材**

- 可稳握的轻壶铃；首轮可空手
- 平整防滑地面

**开始条件**

- 当前踝、膝、腰症状及承重反应已筛查，能先无负荷保持分腿位。
- 任何一脚为受伤脚时，不默认放前/后都安全：前脚屈膝承重和后脚前掌支撑均须分别获准。
- 有近期踝扭伤、膝旋转限制或腰部旋转不耐受时不自动安排动态版本。
- 可用T-LOW-025的徒手基础版本作为已有证据之一，仍需检查本次负重和跨步变式的额外需求。

**准备与起始位：**双脚前后分开并保留左右宽度，先站稳而不深蹲；轻壶铃双手靠近胸口，不伸到身外。

**操作步骤**

1. 空手建立稳定分腿位，前后脚支撑均舒适，再尝试双手持轻壶铃。
2. 保持浅分腿屈膝或站立位不变，呼气让胸口小幅转向一侧。
3. 控制回正后才转另一侧，骨盆大致稳定，膝随脚方向，不追旋转极限。
4. 首轮完成静态版本即可；经计划确认后另试后撤步、站稳、再小幅转胸。
5. 只有上述步骤稳定且当次/次日反应合适，才进入连续跨步转体，并先减轻重量。

**关键要领**

- 壶铃靠胸以缩短杠杆，不持重伸臂猛甩。
- 先站稳再转，再回正后迈步。
- 脚与膝不能被钉住后强行猛扭，胸腰只作舒适小幅运动。
- 受伤脚支撑反应比“看起来做对了”更优先。

**常见错误**

- 跨步落地尚未稳定就持重旋转。
- 把膝固定而身体大幅扭到极限，或壶铃离胸过远。
- 当前踝膝痛仍自动增加深度、速度和重量。

**试做与候选剂量／评估协议：**首轮空手每侧2–3次静态转胸；候选模板轻负荷2组×每侧4–6次、组间60–90秒。动态版本是独立后续进阶，须由计划/教练确认。

**退阶：**双脚平行站位空手小幅转胸；或保留静态分腿站立、不做转体。

**进阶：**稳定支撑→轻壶铃靠胸小幅转→后撤步停稳再转→最后才连续跨步；一次仅提升一个变量，不能凭RPE低自动进阶。

见习25斜板弓步持壶铃转体上举先拆为稳定平地分腿转体与独立推举；斜板、头固定、负重远离身体等额外条件分开确认。组合优先分段，不能一并撤支撑加重。

**停止或调整条件**

- 受伤踝痛/不稳、膝内外侧或关节内锐痛、打软。
- 腰腿放射症状、旋转痛、落地失衡或握持失控。

**机位与画面：**正面偏斜全身，双脚、膝、骨盆、肩和壶铃可见。

**视觉可以观察**

- 是否先站稳后转、步序、明显膝/躯干偏移、负荷是否靠胸。

**视觉不能直接判定**

- 膝旋转力矩、足底压力、真实胸腰分节旋转或组织耐受。

**观察不足时：**只记录可见动作阶段和用户主诉，轴向角度不可靠不要求重做；当前任务资格仍满足时保留已确认版本的陪练。只有支撑、症状或必要条件不满足时，才改静态或徒手替代；不把缺测直接当作能力不足。
