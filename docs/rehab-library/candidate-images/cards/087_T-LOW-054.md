# 087 T-LOW-054｜扶稳半跪位髋前侧温和牵伸

**区域：**髋前侧、腰骨盆　 **等级：**L0–L1

**目标：**为髋前侧牵伸提供单人稳定体位；不是Modified Thomas或Ober试验。

**器材：**膝垫、固定扶手

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**跪膝、髋伸及前脚承重允许，无强制术后髋保护范围冲突。

**准备与起始位：**一膝落软垫，另一足在前；身体大致直立，双手扶稳。

**操作步骤**

1. 先建立稳定半跪位。
2. 躯干不明显后仰，骨盆连同身体小幅前移。
3. 出现温和前侧牵伸便停，缓慢退回。

**关键要领：**前移很小；正常呼吸；不后弯腰。

**常见错误：**大幅拱腰；按骨盆高低指令强旋转；跪膝痛仍坚持。

**试做与候选剂量／评估协议：**首轮每侧约10秒；候选1–2轮×10–20秒，间歇30秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**站姿小分腿扶稳或取消牵伸改获准主动髋伸。

**进阶：**先舒适范围；不加过头负重或外部压迫。

**停止或调整条件：**髋夹痛、膝接触痛、腰腿放射痛。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面含躯干髋膝和扶手。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**体位与整体前移、明显后仰及任务保持。

**视觉不能直接判定：**髂腰肌孤立长度、前髋痛病因。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**比较同体位症状和获准主动动作，不给肌肉缩短诊断。 统一保存当次、练后和次日反应，长期判断按第12.5节。
