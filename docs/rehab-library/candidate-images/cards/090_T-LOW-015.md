# 090 T-LOW-015｜杠铃罗马尼亚硬拉

**区域：**髋、下肢后侧、躯干　 **等级：**L2负重能力—L3高要求返运动

**目标：**为已有杠铃经历且当前适合者建立渐进后侧链负重能力。

**器材：**标准杠铃、卡扣、匹配杠片、稳定训练区和可用支架

**开始条件：**已有杠铃RDL技术并能受控提放；当前腰髋膝踝状态允许，不因历史力量强跳过急伤限制。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**从合适高度取杠；双手握持稳定，杠靠近腿，周围无人和障碍。

**操作步骤**

1. 先空杆或更轻替代物复习轨迹。
2. 持可控负荷站稳，膝微屈。
3. 髋向后折，杠沿腿下降到个人可控范围。
4. 受控站回；组末把杠稳妥放回支架或合适台面。

**关键要领**

- 杠保持贴近身体。
- 回程不猛甩躯干。
- 先保证能安全结束一组。

**常见错误**

- 把既往工作重量当作伤后起点。
- 接近力竭时继续牺牲轨迹。

**试做与候选剂量／评估协议：**候选模板：轻杆先3—5次；一般2—3组×5—8次，保留明显控制余量，不做最大负荷或速度推算1RM测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**改DB/KB RDL、缩短范围或徒手髋铰链。

**进阶：**稳定完成且近期症状与功能无恶化后小幅增加一个变量。

**停止或调整条件：**放射症状、新锐痛、握力滑脱、呼吸异常或无法可控回程时停。

**机位与画面：**正侧面或斜侧全身，杠两端最好入镜。

**视觉可以观察：**次数、杆路径、屈髋/屈膝粗模式和节奏。

**视觉不能直接判定：**真实外负荷数值、椎间受力、左右出力或组织愈合。

**观察不足时：**使用用户确认负荷和完成量；遮挡时关闭角度评分，不要求重新负重拍摄。

**动作出处与对应原文：**[REF-S029]；Romanian Deadlift：从站姿开始的受控髋铰链。

**证据性质与适用范围：**专业学会训练技术手册摘录。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
