# 020 E-LOW-025｜单腿髋铰链够取与回正观察

**区域：**髋、躯干、踝、平衡　 **等级：**L2

**目标：**观察单腿俯身够取和回正能力；可作为单腿触地起身的较低目标需求版本。

**器材：**固定扶手、稳固高台目标

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**单腿承重允许，双腿髋铰链可控，能安全扶稳回正。

**准备与起始位：**目标从膝部附近高度起，非支撑腿后伸，记录目标高度和手侧。

**操作步骤**

1. 一手扶稳，先确认目标能轻触。
2. 支撑膝微屈，从髋部俯身，另一手够目标。
3. 轻触后控制站回，非支撑脚可落地重置。

**关键要领：**目标不必是地面；先髋后移；转身和失衡前结束。

**常见错误：**为触地突然弯腰；扭骨盆找距离；一次降低目标又撤扶手。

**试做与候选剂量／评估协议：**徒手每侧3次，间歇充分恢复平衡；不追最大伸距。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**先按 T-LOW-013教学完成双脚髋铰链，再观察相同任务。

**进阶：**同目标复评；降低目标与减少扶持分别调整。

**停止或调整条件：**支撑踝松软、腰腿放射痛或近跌倒。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面含全身、目标及扶手；斜前方只能作可见转开事件。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**够取成功、回正、触地补偿、周期时间、整体躯干俯倾。

**视觉不能直接判定：**真实髋力矩、深层稳定肌出力及精确骨盆轴向旋转角。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同目标和扶持下比较可控完成率、重置次数与症状；不把触地更深等同于更强。 统一保存当次、练后和次日反应，长期判断按第12.5节。
