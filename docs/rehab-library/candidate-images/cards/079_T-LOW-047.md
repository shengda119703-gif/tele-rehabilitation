# 079 T-LOW-047｜单腿臀桥：双侧过渡到单侧

**区域：**髋、后侧链、躯干　 **等级：**L1–L2

**目标：**增加单侧髋伸任务需求，不用于骨盆复位。

**器材：**防滑垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**双脚桥式可控、单侧支撑获准；足部接触及上下地安全。

**准备与起始位：**双脚桥式起始，先一脚更多承重，另一脚仍轻接地；再按计划轻离地。

**操作步骤**

1. 建立可控的双脚桥式。
2. 减少另一脚支撑，再慢抬髋至无需顶腰的高度。
3. 顶部短停、受控落回；放下另一脚后再换侧。

**关键要领：**目标高度适中；头颈放松；脚稳。

**常见错误：**非支撑腿踢起借力；腰猛后伸。

**试做与候选剂量／评估协议：**首轮每侧3次；候选1–3组×5–8次、顶部2–3秒，组间45–90秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**T-LOW-011双脚桥式，必要时减高度。

**进阶：**先同高度增少量回合，再考虑支撑变化；不同时加重与滑动。

**停止或调整条件：**持续抽筋或髋腰锐痛。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面全身含双足；另选斜脚端机位看明显高低变化。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**起落、保持、髋高度趋势与另一足触地。

**视觉不能直接判定：**臀肌选择性激活、真实骨盆旋转角、左右支撑力。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**关联 E-LOW-026；固定足位和目标高度追踪回合与症状。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S082]；Single leg glute bridge：单侧支持起落。
