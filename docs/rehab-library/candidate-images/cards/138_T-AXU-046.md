# 138 T-AXU-046｜侧桥结合上侧髋外展

**区域：**躯干侧向、髋外展、肩　 **等级：**L2

**目标：**在侧桥任务中增加髋外展需求，独立登记以反映额外肩/下侧腿负荷。

**器材：**垫，可选大腿上方弹力环

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**短杠杆侧桥及侧卧髋外展各自可控，支撑肩/肘和下侧腿获准。

**准备与起始位：**先屈膝侧桥，下侧前臂支地，上侧腿准备小幅外展。

**操作步骤**

1. 建立低幅侧桥并自然呼吸。
2. 上侧腿轻向上打开后受控回落。
3. 做少量回合后骨盆缓慢落地；换侧。

**关键要领：**先稳侧桥；抬腿无需很高；肩肘舒适。

**常见错误：**抬腿时腰明显坠下；借躯干滚动完成外展。

**试做与候选剂量／评估协议：**首轮每侧2–3次；候选1–2组×每侧4–8次，组间60–90秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**分别做 T-AXU-017侧桥和 T-LOW-008髋外展。

**进阶：**先增少量回合，再加弹力环或改长杠杆；一次一项。

**停止或调整条件：**肩压痛、腰锐痛、下侧膝/踝接触痛。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**面对身体侧面，全身含上下两腿和支撑肘。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**上侧腿开合、侧桥保持、明显骨盆下沉。

**视觉不能直接判定：**臀中肌选择性激活、肩支撑力和腰椎负荷。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同杠杆与支撑条件比较开合回合及保持连续性。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S066]；屈膝侧桥加上侧髋外展的肌电研究动作。

**证据性质与适用范围：**原始肌电研究。原始研究为肌电研究，支持该动作形式；不等同于疼痛改善试验，也不能由视频推断肌肉激活。
