# 102 T-LOW-027｜低台阶控制下落点地

**区域：**髋、膝、踝　 **等级：**L2负重能力

**目标：**练习支撑腿受控下降和下楼能力。

**器材：**稳固低台阶、固定扶手；后续可选轻哑铃

**开始条件：**上台阶可控，允许单腿偏心负重；高度符合当日能力。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**测试腿站台阶上，另一脚悬在台阶前或侧的选定方向。

**操作步骤**

1. 轻扶站稳并确认地面落点。
2. 测试膝缓慢屈曲，让另一脚跟轻触地面。
3. 触地后受控站回台阶。
4. 每次站稳，再完成同侧或换侧。

**关键要领**

- 点地轻，不直接坠落。
- 支撑脚掌稳定。
- 深度跟台阶高度一起控制。

**常见错误**

- 靠触地脚强蹬回来。
- 为触到过低地面而失控内移。

**试做与候选剂量／评估协议：**候选模板：首轮每侧2—3次；一般1—3组×4—8次，初期不加外重，后续仅在控制足够时加轻负荷，非最大测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**更低台阶、更多扶手或小范围下降不触地。

**进阶：**先改善下降节奏，再少量加次数/高度；外重另行试做。

**停止或调整条件：**膝锐痛、腿软、踝失稳、反复失控下落或支撑移动时停。

**机位与画面：**斜前/侧面全身，足落点可见。

**视觉可以观察：**下降时间、次数、粗膝躯干轨迹。

**视觉不能直接判定：**偏心最大力量、真实膝外翻力矩、地反力。

**观察不足时：**保留可见次数和用户完成感受，不强求每次触地都自动识别。

**动作出处与对应原文：**[REF-S004]；Step-up / Eccentric step down / Alternate leg step。

**证据性质与适用范围：**专科医院动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
