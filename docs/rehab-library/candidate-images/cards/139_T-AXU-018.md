# 139 T-AXU-018｜Pallof胸前推：抗旋转训练

**区域：**胸腰/躯干/肩　 **等级：**L2

**目标：**在侧向外载下练习躯干方向控制与呼吸。

**器材**

- 完好弹力带或绳索器械
- 可靠固定锚点

**开始条件**

- 站立、肩腕及腰部可耐受；锚点经检查。
- 无可靠锚点时换动作，不临时拉不确定牢固的家具。

**准备与起始位：**身体侧对胸高锚点，双脚髋宽或稳定分腿，双手把带柄握在胸前。

**操作步骤**

1. 选择明显可控的轻张力，先保持胸口正向。
2. 呼气把双手缓慢向前推出，增加手臂杠杆。
3. 短暂停留且继续呼吸，再吸气控制收回胸前。
4. 完成一侧后转身换方向，记录带长、站位和反应。

**关键要领**

- 胸口和骨盆大致同向，不被拉着转。
- 手腕中立、肩放松，不锁肘。
- 先控制杠杆，再考虑更大阻力。

**常见错误**

- 弹力带快速弹回或站位靠不稳锚点。
- 把带颜色和主观很累等同确定力矩或组织承载能力。

**试做与候选剂量／评估协议：**首轮每侧3–5次轻阻力；候选模板2–3组×每侧6–10次、前伸停2–3秒，组间60秒。负荷与剂量需计划确认。

**退阶：**更轻带/更小初始伸长、缩短前伸距离或用坐位。

**进阶：**一次只增加前伸杠杆、张力或姿势需求之一；结合当次及次日症状，不只看RPE。

**停止或调整条件**

- 锚点移动、带损伤或回弹风险。
- 腰腿放射症状、肩腕锐痛或站立失稳。

**机位与画面：**正面或斜前方全躯干，双手、肩髋脚可见。

**视觉可以观察**

- 推回次数、手臂伸距、明显躯干随转和保持。

**视觉不能直接判定**

- 真实张力、抗旋转力矩、深层肌激活。

**观察不足时：**按动作和自报完成记录；等长保持不需视觉确认发力。
