# 175 T-AXU-034｜弹力带/绳索肘伸下压

**区域：**肘/肩　 **等级：**L1

**目标：**练习可控伸肘负荷，避免不必要的过头姿势。

**器材**

- 绳索器械或完好带
- 可靠高位锚点

**开始条件**

- 肘伸抗阻可耐受，肩可稳定放身侧；高位锚点安全。

**准备与起始位：**站稳，肘弯曲并靠身，手柄在胸腹前；选明显可控轻阻力。

**操作步骤**

1. 先建立稳定上臂位置和自然手腕。
2. 呼气伸肘把手柄向下推到舒适位置。
3. 肘接近伸直即止，不猛锁或推到疼痛后伸。
4. 吸气控制屈肘回原位，不让肩跟着前后摆。

**关键要领**

- 动前臂，上臂尽量稳定。
- 躯干自然，不用全身压下重量。
- 肩不耸，回程也要受控。

**常见错误**

- 靠腰前倾、肩下压甩动负荷。
- 快速弹回到过大屈肘位或猛锁肘。

**试做与候选剂量／评估协议：**首轮5次轻阻力；候选模板2–3组×8–12次、组间60秒。阻力与行程由计划确认。

**退阶：**更轻阻力或小范围伸肘；无安全锚点改空手/合适哑铃变式。

**进阶：**增加控制和少量负荷；过头臂屈伸有额外肩ROM要求，需另行确认。

**停止或调整条件**

- 肘后方锐痛、不稳、麻木。
- 带/锚点异常或回弹不可控。

**机位与画面：**侧面，肩肘腕和躯干可见。

**视觉可以观察**

- 肘屈伸次数、上臂移动和身体借力。

**视觉不能直接判定**

- 肱三头肌真实力、关节压缩力和最大肌力。

**观察不足时：**局部点遮挡时只记录回合和负荷条件，不强制追加次数。
