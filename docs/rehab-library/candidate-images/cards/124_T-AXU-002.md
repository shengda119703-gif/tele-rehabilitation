# 124 T-AXU-002｜扶持站位的小幅躯干后伸

**区域：**腰部/胸腰整体　 **等级：**L1

**目标：**练习当前被允许且症状反应合适的后伸方向。

**器材**

- 可选稳定台面

**开始条件**

- 已评估后伸方向可耐受；不是所有腰痛者的默认动作。
- 能站稳且没有禁止脊柱后伸的已知限制。

**准备与起始位：**双脚舒适分开，手轻扶骨盆或固定台面，膝自然微松。

**操作步骤**

1. 先站稳，记录当前腰腿症状。
2. 缓慢让上身小幅向后移动，保持脚掌贴地。
3. 到舒适限度即回正，不在末端用手猛推。
4. 停顿确认症状，再决定是否继续下一次。

**关键要领**

- 范围小而可控，不追求后弯很深。
- 颈部随躯干自然移动，避免把全部动作变成抬头。
- 呼吸顺畅，回正前不要迈步。

**常见错误**

- 锁膝、猛推腰或突然向后甩。
- 后伸诱发腿部症状仍反复追求更大角度。

**试做与候选剂量／评估协议：**首轮试做2–3次；候选模板1–2组×5次，组间30–60秒；不自动套用高频方向性治疗处方。

**退阶：**缩小范围并使用扶手；不耐受时跳过该方向。

**进阶：**优先增加控制与可耐受活动，不用额外负重放大末端。

**停止或调整条件**

- 新的放射痛、麻木、腿软或明显头晕。
- 局部锐痛或回正后症状继续上升。

**机位与画面：**侧面全身，拍到脚、髋和肩。

**视觉可以观察**

- 整体后倾、回正和明显屈膝/抬头代偿。

**视觉不能直接判定**

- 局部腰椎伸展角或椎管变化。
- 方向性治疗是否适合，须结合症状反馈。

**观察不足时：**停用角度提示，保留试做反应；不因没达到角度要求用户再后弯。
