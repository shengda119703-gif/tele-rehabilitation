# 159 T-AXU-055｜单臂斜向抬举：徒手至轻哑铃

**区域：**肩、上肢、躯干　 **等级：**L1–L2

**目标：**练习明确的单臂对角线抬举与回落；手臂轨迹不代表肩胛骨X形运动。

**器材：**首轮徒手，获准后使用可独立取放的轻哑铃。

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**所选肩活动方向获准、主动小幅抬举可控，能独立握持及放回器材。

**准备与起始位：**站稳，动作手放在对侧大腿前方；另一手自然放置，躯干朝前。

**操作步骤：**

1. 动作手从对侧大腿前方，沿对角线移向同侧前外上方。
2. 到获准高度（不超过该版本肩高）短暂停留。
3. 沿原路线受控落回；站稳后再重复，左右侧分别执行。

**关键要领：**躯干不跟着扭；不耸肩找高度；路线与终点每次一致。

**常见错误：**把动作手的X轨迹当肩胛骨运动；甩动哑铃；超过获准肩高。

**试做与候选剂量／评估协议：**首轮徒手每侧3次；候选1–2组×6–10次，组间45–60秒；轻负荷由计划确认。

**退阶：**缩小同一对角线路径，或 T-AXU-022 支持滑手。

**进阶：**固定路线和高度后增加少量重复，再考虑轻哑铃；不把两个斜向路线混为同一任务。

**停止或调整条件：**肩锐痛、手麻或路线失控。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正面或斜前方含双肩、肘、腕与髋，动作全程不出画面。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**手轨迹、完成回合、明显躯干随动和肩高变化。

**视觉不能直接判定：**肩胛骨真实对角线运动、肩袖激活与治疗师助力大小。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**固定侧别、路线、终点和重量，比较完整回合、节奏与自报反应；不输出肩胛控制总分。

**动作出处与对应原文：**[REF-S052]；Diagonal Raise：对侧大腿前方到同侧肩高。
