# 184 T-AXU-040｜双手壶铃摆动：后期熟练者项目

**区域：**髋-躯干动力传递/肩握持/返运动　 **等级：**L3

**目标：**为已具备技术与负荷基础者练习髋驱动和反复动力输出；不是初学康复默认动作。

**器材**

- 合适壶铃
- 充足无障碍空间和防滑地面

**开始条件**

- 已由合格教练/治疗师确认熟悉髋铰链、安全提放和壶铃摆动。
- 当前腰、髋、膝、踝与肩腕症状稳定，已通过相应力量/承重进阶；近期伤脚未获动态负荷许可者不做。
- 首次不由视觉模型独立判定技术合格或自动开课。

**准备与起始位：**使用已掌握的双手至胸前高度版本，脚距适合髋铰链；镜头和他人均不在器械飞出路径。

**操作步骤**

1. 按已掌握方式把壶铃安全带入摆动，先少量重复。
2. 壶铃向后时髋后移、膝自然弯曲，以既有技术吸收回摆。
3. 用髋伸展带动壶铃前摆，手臂主要传递负荷，不主动猛提肩。
4. 上端身体稳定，不向后折腰，也不追求过头高度。
5. 在控制尚好时按已学方式停铃并放回，再休息和评估反应。

**关键要领**

- 髋驱动而非用肩硬举，幅度服从已掌握技术。
- 顶部站稳，不用过度后仰制造动力。
- 组短、留余力，技术下降前结束。
- 手始终握稳，空间安全比相机能否全程计次优先。

**常见错误**

- 初学者把深蹲、耸肩和甩腰混在一起，仍自动加速加重。
- 疲劳后继续摆动或试图把失控壶铃拉回。
- 仅凭速度高、RPE低就推断组织能够承受更大冲击。

**试做与候选剂量／评估协议：**首轮仅熟练且获准者试1组5次轻于常规训练的负荷；候选模板3–5组×5–10次、组间60–120秒。由教练/治疗师确认，不自动处方。

**退阶：**停止摆动，回到下肢库已获准的髋铰链/提放和非弹道力量训练。

**进阶：**先确认稳定技术及当次/次日反应，再改变次数、重量或密度之一；过头摆动不在默认进阶。

**停止或调整条件**

- 任何握持失控、腰腿锐痛、膝踝不稳或新神经症状。
- 技术明显崩坏、异常胸闷头晕或环境不再安全。

**机位与画面：**安全侧面全身，器械完整轨迹尽量可见；高速度时减少精细评分。

**视觉可以观察**

- 大致回合数、髋铰链/顶部姿势代理、明显过度后仰和轨迹变化。

**视觉不能直接判定**

- 真实地面反力、腰椎剪切/压缩、髋部功率与组织耐受。
- 普通低帧率RGB不能据速度独立证明力量或技术安全。

**观察不足时：**追踪丢失时不发过时纠正；由已获准的用户完成短组并自报，若关键安全条件无法满足则改非弹道动作。
