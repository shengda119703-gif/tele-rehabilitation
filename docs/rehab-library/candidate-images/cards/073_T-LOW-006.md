# 073 T-LOW-006｜扶稳站姿髋外展：徒手至弹力带

**区域：**髋　 **等级：**L1基础—L2负重能力

**目标：**训练侧向抬腿控制和髋外展负重能力。

**器材：**固定扶手；可选弹力带

**开始条件：**能安全单侧短暂负重，带阻力不迫使身体侧甩。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**正面站稳；带可放膝上或按既定锚点设置，避免未经评估的踝部压力。 检查带体和锚点；记录品牌型号、固定长度和设置，不由颜色直接推张力。

**操作步骤**

1. 先无带向外侧小幅抬腿试做。
2. 保持躯干稳定，把测试腿缓慢移向外侧。
3. 在可控终点停片刻。
4. 慢慢回到起点，完成后换侧。

**关键要领**

- 骨盆不要提起。
- 足尖维持自然朝向。
- 回程控制带子的回拉。

**常见错误**

- 躯干侧倾代替外展。
- 带一回弹就让脚撞回。

**试做与候选剂量／评估协议：**候选模板：首轮徒手每侧3次；一般1—3组×6—12次，选全程可控阻力，带长和位置固定后再比较。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**移除带、减幅或双手扶稳。

**进阶：**先稳定躯干，再少量加阻力或减少扶手，不同时改变所有条件。

**停止或调整条件：**髋外侧/腹股沟锐痛、支撑踝失稳、带滑脱时停。

**机位与画面：**正面全身。

**视觉可以观察：**侧向次数、幅度、骨盆/躯干明显移动。

**视觉不能直接判定：**臀中肌激活比例、带张力和单侧地反力。

**观察不足时：**只计次和记录自觉用力，缺辅助点时停止代偿评分。
