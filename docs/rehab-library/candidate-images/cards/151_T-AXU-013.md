# 151 T-AXU-013｜轻柔下巴回收与点头控制

**区域：**颈部　 **等级：**L0

**目标：**练习头颈中立位控制；不声称从视频识别深颈屈肌。

**器材**

- 稳定椅；或薄枕与垫

**开始条件**

- 该小幅动作可耐受；不得用力压颈后或屏气。

**准备与起始位：**先用靠背坐位，耳部自然位于肩上方附近；也可按计划用仰卧轻点头版本。

**操作步骤**

1. 自然平视并放松下颌。
2. 轻轻把头整体向后收一点，像做很小的双下巴。
3. 维持短暂并正常呼吸，不向下压头。
4. 完全放松回自然位，重新准备下一次。

**关键要领**

- 力度轻，牙齿不咬紧。
- 眼睛保持大致水平，避免明显低头。
- 肩膀放松，不把后脑使劲顶墙或枕头。

**常见错误**

- 强力后仰或压低下巴。
- 用很大力量和憋气代替细小控制。

**试做与候选剂量／评估协议：**首轮3次、每次约2秒；候选模板1–2组×5–8次、每次3–5秒，组间30秒；由计划选择坐位或仰卧版本。

**退阶：**更小的点头意图或仅练放松的中立坐姿。

**进阶：**先增加舒适保持和坐位任务结合，再讨论颈部耐力，不能因镜头看不出就要求用更大力。

**停止或调整条件**

- 出现眩晕、放射症状或异常头痛。
- 颈部紧张明显加剧且放松后不缓解。

**机位与画面：**侧面头肩近景；小动作可仅陪练。

**视觉可以观察**

- 明显头前后移、低头/后仰代偿以及自报保持时间。

**视觉不能直接判定**

- 深颈屈肌选择性激活、肌肉收缩大小。

**观察不足时：**采用口令和用户确认，不要求视觉达到细微位移阈值才累计。
