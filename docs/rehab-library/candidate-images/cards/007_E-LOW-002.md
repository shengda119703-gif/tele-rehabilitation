# 007 E-LOW-002｜扶稳站姿主动髋后伸

**区域：**髋　 **等级：**L0低负荷支持—L1基础

**目标：**观察向后抬腿能力及腰骨盆共同代偿。

**器材：**固定台面或稳固椅背

**开始条件：**站立和平衡足够，无被禁止的髋后伸方向。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面机位；双手或单手轻扶，足尖朝自然方向。

**操作步骤**

1. 站稳并记录自然体位。
2. 让一侧腿缓慢向后移动，膝保持自选轻微屈曲或接近伸直。
3. 在躯干无需继续前倾或腰部无需明显后仰的位置停留。
4. 放回后休息，再完成另一侧。

**关键要领**

- 动作幅度小也有效。
- 骨盆和胸口不要同时转走。
- 保持呼吸并报告前髋或腰部症状。

**常见错误**

- 腰部后仰替代髋后伸。
- 支撑身体整体前倾后声称髋活动大幅增加。

**试做与候选剂量／评估协议：**候选评估协议：每侧1次熟悉加2次记录，统一膝姿势和扶手条件；只在同一协议内比较。

**退阶：**改站姿小步后移或有治疗师安排的卧姿动作。

**进阶：**必要时由专业人员固定骨盆后测真实髋后伸。

**停止或调整条件：**出现前髋明显牵痛、腰部新锐痛、麻木或站立不稳时结束。

**机位与画面：**侧面，可见肩、髋、膝、踝。

**视觉可以观察：**后移范围、节奏、躯干倾斜与明显膝屈曲。

**视觉不能直接判定：**骨盆和腰椎各自贡献、髋关节囊限制及肌力等级。

**观察不足时：**输出后移完成度及症状，不勉强输出独立髋角。

**动作出处与对应原文：**[REF-S001]；Leg extension（站姿后伸）、Sideways leg lift（外展及回收）。

**证据性质与适用范围：**公共卫生机构动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S001]；背景及临床边界：[LOW-S08] [LOW-S21]。动作形式、背景指南和产品测量证据按第8节分别解释。
