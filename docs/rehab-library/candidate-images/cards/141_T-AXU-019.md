# 141 T-AXU-019｜单侧手提箱行走

**区域：**躯干/肩带/握持与步行　 **等级：**L2

**目标：**练习单侧携物时的全身控制和实际搬运能力。

**器材**

- 哑铃或壶铃
- 平整无障碍短直线路径

**开始条件**

- 当前步行与下肢承重可耐受，能握稳负荷。
- 肩腕及腰部允许单侧携重；高跌倒风险者不自动派发。

**准备与起始位：**器械放在方便安全提起的高度；单手提于身侧，另一手空着，规划回放路径。

**操作步骤**

1. 用已掌握的安全提物方式拿起轻负荷，先静止站稳。
2. 保持自然躯干与呼吸，以平常小步直线行走。
3. 需要转向时先减速，用数个小步改变方向，不固定脚猛扭。
4. 回到放置位置控制放下，再休息换手。

**关键要领**

- 肩不刻意强耸或强压，手腕保持自然。
- 身体不明显倒向负荷，也不强行僵直过度纠正。
- 行走比重量优先，步幅自然。

**常见错误**

- 重量过大导致握持滑脱或大幅侧倒。
- 转弯时单脚钉地，身体带着重量急扭。

**试做与候选剂量／评估协议：**首轮每侧1趟约10–15秒轻负荷；候选模板每侧2–3趟×15–30秒、趟间60秒。质量、路程与症状由计划确认。

**退阶：**减轻负荷，先做短时静态站持；下肢不耐受则换非站立动作。

**进阶：**先增加稳定距离，再增加少量质量；不同时提高速度、距离和重量。

**停止或调整条件**

- 握持将滑脱、明显失衡或足踝膝痛增加。
- 新腰腿放射痛、肩臂麻木或头晕。

**机位与画面：**可看清全身的正/侧面短路径；不要求用户走出镜头仍持续精确评分。

**视觉可以观察**

- 行走完成、明显侧倾、步态中断、携物时长。

**视觉不能直接判定**

- 实际地面反力、脊柱力矩、握力或组织耐受阈值。

**观察不足时：**出画期间不评分，但用自报距离/时长保留本趟；无需整趟重走。
