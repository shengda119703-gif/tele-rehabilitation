# 036 E-AXU-003｜站立躯干主动前屈/后伸筛查

**区域：**腰部/胸腰整体　 **等级：**L1

**目标：**记录两个方向的可见活动和症状反应，供后续选择方向；不测分节腰椎ROM。

**器材**

- 必要时固定扶手

**开始条件**

- 能安全站立；没有已知禁止脊柱屈伸的限制。
- 前屈和后伸可只选其中一个方向；不默认必须连续反复。

**准备与起始位：**双脚舒适分开，膝自然；镜头在侧面腰髋高度，拍到头、肩、髋、膝和脚。

**操作步骤**

1. 自然站立，记录起始症状和姿势。
2. 选择前屈时缓慢向前弯到舒适限度，双手可沿大腿滑下。
3. 平稳回中立位；若计划允许，再双手轻扶骨盆做小幅后伸并回正。
4. 每个方向结束后报告局部及远端症状变化，不立即反复追求更大幅度。

**关键要领**

- 范围由当下耐受决定，不比赛摸地。
- 膝保持自然，不锁死也不故意深蹲。
- 每次先回稳中立位再做下一方向。

**常见错误**

- 用快速弹振或手推腰部强行增大范围。
- 把肩髋轴投影倾角标成真实腰椎活动度。

**试做与候选剂量／评估协议：**每方向1次熟悉、1–2次观察；方向间休息20–30秒。方向选择和重复次数由评估计划限定。

**退阶：**坐位有支撑的小幅屈伸，或只收集日常弯腰症状。

**进阶：**复测原相机和起始姿势；只有症状允许才增加舒适范围。

**停止或调整条件**

- 疼痛向腿部扩散，出现新的麻木、无力或眩晕。
- 出现尖锐疼痛、无法平稳回正或症状持续明显上升。

**机位与画面：**侧面全身，相机固定；左右侧复测保持一致。

**视觉可以观察**

- 躯干整体投影倾角变化。
- 髋屈曲、膝弯曲和回正过程的可见代理。

**视觉不能直接判定**

- 各腰椎节段角度或椎间盘压力。
- 是否存在椎间盘突出、关节阻挡或疼痛中央化；后者须询问分布。

**观察不足时：**肩髋短时缺点时保留动作及症状记录，仅隐藏角度；不令用户重做全套。
