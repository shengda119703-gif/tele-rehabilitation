# 026 E-LOW-012｜扶稳单脚提踵耐力表现

**区域：**踝、小腿　 **等级：**L2负重能力

**目标：**评估单侧重复推起的功能耐力，不能等同最大肌力。

**器材：**固定支撑、可选跟部贴点

**开始条件：**双脚提踵可控、能安全单脚负重；疼痛和现阶段限制允许。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**平地同鞋履；测试脚承担体重，手轻扶，另一脚不蹬地。

**操作步骤**

1. 完成少量双脚热身并选择测试侧。
2. 单脚缓慢抬跟到约定可控高度，再放下。
3. 按统一节奏连续完成，出现约定终止条件即停。
4. 休息至恢复后换侧，并记录终止原因。

**关键要领**

- 每次尽量达到一致高度。
- 手只保平衡，不拉身体。
- 不以疼痛换次数。

**常见错误**

- 后半程高度明显降低仍无区别累计。
- 把次数换算成MMT五级或最大肌力百分比。

**试做与候选剂量／评估协议：**候选协议：首次先做每侧3次熟悉；正式可用预设次上限的亚最大观察，或经允许的标准耐力协议。两种结果必须分开，组间休息至恢复。

见习48的单脚提踵保持差异与重复提踵次数是不同协议；保持观察使用 E-LOW-029，不能把秒数和次数混为肌力或跟腱断裂结论。

**退阶：**改双脚或坐位提踵。

**进阶：**在无不良反应下使用同协议复测；加负荷属于训练而非本次评估。

**停止或调整条件：**疼痛明显升级、反复踝失稳、无法维持高度或借手明显时结束并记录原因。

**机位与画面：**侧面含足，必要时跟部标记。

**视觉可以观察：**有效次数、逐次高度趋势、节奏和停止时刻。

**视觉不能直接判定：**最大力、跟腱张力、地反力和疲劳的唯一病因。

**观察不足时：**自动只确认可见次数；其余让用户补总数并标记，不相加重复。

**动作出处与对应原文：**[REF-S007] [REF-S062]；Calf Raises：单脚版；本卡为扶稳/封顶功能观察。

**证据性质与适用范围：**专业学会患者训练手册、原始测量研究。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
