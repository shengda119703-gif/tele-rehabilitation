# 183 T-AXU-056｜下蹲—站稳—轻负重推举的分段组合

**区域：**髋膝踝、肩、全身协调　 **等级：**L2–L3

**目标：**在单独蹲起与推举均可控后练习动作衔接；不是抓举/挺举自动教学。

**器材：**先空手；可控轻哑铃或壶铃

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**蹲起和允许肩推举分别通过试做；具备安全取放器械技能，患侧全链负荷获准。

**准备与起始位：**双脚稳站，器械靠近胸前；先分段不转体。

**操作步骤**

1. 受控浅蹲并站起。
2. 站稳后再作获准范围推举。
3. 先收回器械至胸前，再做下一次；侧别、转体或从地拾物需另立版本。

**关键要领：**先蹲后站稳再举；重量轻；一步一段。

**常见错误：**蹲未站稳便甩上举；同时加旋转、拾物和重负荷。

**试做与候选剂量／评估协议：**首轮空手3个链；候选1–2组×4–6链，休息60–90秒；链数与子动作数分开。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**分别 T-LOW-018/019与 T-AXU-030；肩不适只练蹲。

**进阶：**先衔接稳定再少量加负重；动态挺举/抓举另经专项教学。

**停止或调整条件：**肩腰痛、下肢失稳、握持或回程失控。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面全身及负重轨迹；方向变化不能用同一平面精测。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**三个阶段、链完成数、子动作数、明显躯干后仰。

**视觉不能直接判定：**真实功率、各关节净力矩、肌力或运动回归资格。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同负重、深度和肩终点比较衔接与症状；链完整才计整链。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S053]；Squat to Overhead Press；站稳再推为慢速分段实施。
