# 172 T-AXU-060｜单臂绳索或弹力带侧平举

**区域：**肩、肩带与躯干　 **等级：**L1–L2

**目标：**练习单侧肩外展负荷控制；与肩胛平面抬举分开登记。

**器材：**腰高可靠绳索滑轮或同方向固定锚点弹力带。

**单人适用：**条件独立；须能自行摆位、完成及安全卸重；需要他人保护者按第12节分流。

**开始条件：**肩外展与所选范围获准，锚点可靠且可独立摆位；弹力带完好，拉力方向不朝脸。

**准备与起始位：**侧身面对锚点，远侧手握把，拉索从身前通过；双脚站稳、胸口朝前，记录锚点高度和阻力设置。

**操作步骤：**

1. 慢慢将动作臂抬向同侧侧方。
2. 到获准高度，不超过肩高，短停并避免明显耸肩。
3. 受控落回，不松手弹回；另一侧重新布置相同条件。

**关键要领：**小阻力、慢起落；胸口和髋不跟着转。

**常见错误：**用摆动拉起；锚点过低却沿用腰高协议；以带颜色推断牛顿值。

**试做与候选剂量／评估协议：**首轮每侧3次；候选1–2组×6–10次，组间45–60秒。 所有数值为项目候选模板，不是原资料统一处方或进阶阈值。

**退阶：**徒手小范围外展或降低同方向阻力。

**进阶：**固定锚点、站距和范围后增加回合，再小步调整阻力。

**停止或调整条件：**肩锐痛、手麻、带锚点松动或不能受控回程。 同时遵守第4节与第12节。

**机位与画面：**正面含双肩、肘腕、髋与锚点；侧面另拍躯干改变。；固定相机，必要支点和器材入镜。

**视觉模块：**身体点；器材、锚点和接触需物体识别或本人确认，自动测量仍须验证。

**视觉可以观察：**手臂抬落、投影高度、完成回合、明显耸肩或转身。

**视觉不能直接判定：**肩胛骨精确旋转、三角肌激活、弹力带实际张力。

**观察不足时：**只保存已确认阶段，缺失信息记unknown；不补造有效回合、负荷或力量。

**复评与训练成果：**固定侧别、锚点、带型号/长度或器械设置，比较同范围回合和本人费力。 保存当次、练后及次日反应。

**动作出处与对应原文：**[REF-S050] [REF-S042]；Single-arm Lateral Raise：腰高锚点；弹力带同方向改编。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
