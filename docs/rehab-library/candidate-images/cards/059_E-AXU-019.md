# 059 E-AXU-019｜腕主动掌屈/背伸ROM筛查

**区域：**腕　 **等级：**L0–L1

**目标：**测统一成像平面中的手相对前臂投影活动。

**器材**

- 桌面

**开始条件**

- 腕活动在当前限制内；无未评估的急性创伤或明显肿胀。

**准备与起始位：**前臂放稳在桌面，手腕伸出桌边，手保持轻松张开；手机拍腕的侧面近景并包含肘。

**操作步骤**

1. 前臂稳定，从手与前臂自然相接的中立位开始。
2. 缓慢掌屈，让手向掌侧落下，再回中立。
3. 缓慢背伸，让手向手背方向抬起，再回中立。
4. 分别记录症状和可见范围，手指不需参加测试。

**关键要领**

- 前臂不要离开桌面。
- 手指保持轻松，避免用大幅屈指改变手部方向。
- 只主动移动，不用另一手掰腕。

**常见错误**

- 整条前臂抬起制造腕角。
- 仅用肘与腕两个点计算手腕屈伸。

**试做与候选剂量／评估协议：**每方向1–2次，间隔10–15秒；保存前臂姿势、镜头和是否有支撑。

**退阶：**缩小范围或仅记录可完成的方向。

**进阶：**同支撑与机位复测；负荷能力需另外测试。

**停止或调整条件**

- 局部锐痛、明显卡住或新手麻。
- 腕肿痛显著增加或无法控制回到中立。

**机位与画面：**腕侧面近景；使用统一图像坐标的前臂轴和掌部轴。

**视觉可以观察**

- 规定视角的腕投影屈伸范围与次数。
- 前臂是否明显抬离支撑。

**视觉不能直接判定**

- 腕骨间运动、韧带稳定性或握力。
- 独立Hand与Body world未经配准的公制关节角。

**观察不足时：**手边缘导致Hand失跟时保留主诉及已见范围；可陪同完成而不打分。

**动作出处与对应原文：**[REF-S016]；主动旋前/旋后、腕掌屈/背伸、桡偏/尺偏。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
