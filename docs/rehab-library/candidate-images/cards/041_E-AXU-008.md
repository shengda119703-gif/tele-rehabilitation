# 041 E-AXU-008｜坐位抱胸转胸筛查

**区域：**胸部/胸腰整体　 **等级：**L0–L1

**目标：**观察胸部旋转相关的生活功能，尽量减少髋与骨盆随动。

**器材**

- 稳定无脚轮的椅子

**开始条件**

- 肩部可舒适抱胸；若不行可双手放大腿。

**准备与起始位：**脚踩稳，髋膝大致朝前，手机斜前方；起始姿势和镜头存档供复测。

**操作步骤**

1. 抱胸坐稳，记录起始症状。
2. 缓慢向一侧转动胸口，头自然跟随。
3. 在舒适范围停顿，再回正并报告症状。
4. 换侧重复，不借手拉椅背。

**关键要领**

- 坐骨不离椅，膝盖保持大致朝前。
- 动作从躯干发生，不能只有头转过去。
- 不要憋气追求末端。

**常见错误**

- 整个骨盆和椅子一起转。
- 把上肢或头部到达方向等同胸椎ROM。

**试做与候选剂量／评估协议：**每侧1–2次、间隔15–20秒；无经过验证的三维输入时不显示精准旋转度数。

**退阶：**缩小范围，双手放大腿以避免肩痛干扰。

**进阶：**同条件复测；局部胸椎ROM需求交专业量测。

**停止或调整条件**

- 出现新的放射性症状、眩晕或胸痛。
- 转动引起明显锐痛并在回正后仍不缓解。

**机位与画面：**正面或斜前方；肩、骨盆和膝均可见。

**视觉可以观察**

- 转动方向、回正和明显骨盆随动。

**视觉不能直接判定**

- 真实分节胸椎旋转角和韧带稳定性。
- 肩关节因素对抱胸姿势的全部影响。

**观察不足时：**只保存完成与症状，身体三维点不稳时不开精确角度评分。

**动作出处与对应原文：**[REF-S014]；动作4：坐位抱胸转体。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
