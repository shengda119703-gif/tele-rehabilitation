# 057 E-AXU-017｜肘主动屈曲/伸展ROM筛查

**区域：**肘　 **等级：**L0–L1

**目标：**测规定视角下的肘屈伸投影范围和动作症状。

**器材**

- 稳定椅；可选上臂支撑

**开始条件**

- 肘主动活动在当前限制内，无近期未处理创伤。

**准备与起始位：**被测臂靠近镜头，肩放松，上臂稳定；镜头正对肘屈伸平面。

**操作步骤**

1. 从舒适伸肘位开始，不强锁或过伸。
2. 缓慢弯肘让手靠近肩，再停约1秒。
3. 平稳伸回可耐受位置，肩不前后摆动。
4. 报告屈伸哪个阶段困难、是否疼痛或卡顿。

**关键要领**

- 保持上臂位置，主要转动前臂。
- 前臂保持同一舒适旋转位置以便比较。
- 不借甩臂增加范围。

**常见错误**

- 肩前举或躯干前倾把手带到肩旁。
- 把腕点丢失时的预测当真实肘末端。

**试做与候选剂量／评估协议：**1次熟悉后2次观察；如需双侧比较，侧间休息20秒。保存前臂旋转位置和镜头。

**退阶：**前臂放桌面上辅助滑动，记录为主动助力任务而非原协议。

**进阶：**原条件复测；肌耐力与负荷另做轻负重任务。

**停止或调整条件**

- 尖锐肘痛、明显机械卡住或新手麻。
- 无法控制伸回，或关节明显不稳。

**机位与画面：**正对上臂-前臂运动平面，肩肘腕都可见。

**视觉可以观察**

- 肘的二维投影屈伸角、速度和次数。
- 肩或躯干明显代偿。

**视觉不能直接判定**

- 关节内部阻挡、韧带稳定性、肌力等级。
- 疼痛或被动末端感。

**观察不足时：**部分末端不可见时报告已见范围；保留完整次数与用户反应。

**动作出处与对应原文：**[REF-S009]；Elbow Flexion / Extension：不加负重的主动屈伸观察。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
