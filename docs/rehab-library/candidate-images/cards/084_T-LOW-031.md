# 084 T-LOW-031｜长杠杆哥本哈根内收支撑

**区域：**髋内收、躯干、踝部支撑　 **等级：**L3高要求返运动

**目标：**为已有适应且获许可者提高内收支撑要求。

**器材：**无轮无摇晃、合适承重且固定靠墙的低长凳/牢固桌椅；防滑软垫；地垫

**开始条件：**短杠杆已稳定耐受，且肩、肘、髋、膝、踝均允许承重；近期崴脚者不得自动分配。家庭家具不可靠则不用。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**上侧腿伸展，踝部/远端小腿内侧置于软垫支撑，避开直接压迫疼痛骨突；这是踝承重接触动作。

**操作步骤**

1. 先确认家具、软垫和脚踝接触均安全。
2. 前臂支地，下腿先支地辅助，上腿放在长杠杆位置。
3. 缓慢抬骨盆，保持舒适侧向支撑。
4. 受控落下；稳定后才减少下腿辅助，不急着加动态起落。

**关键要领**

- 踝部压力必须可耐受。
- 先学会缓慢落地。
- 不靠耸肩或腰侧折硬撑。

**常见错误**

- 认为练内收肌就与受伤踝无关。
- 从短杠杆直接跳到长时悬空力竭。

**试做与候选剂量／评估协议：**候选模板：首轮每侧1—2次、每次约3—5秒，充分休息；一般1—3组×2—5次短保持，按反应选择。非最大负荷或最长时间挑战。

**退阶：**回短杠杆哥本哈根或侧卧内收；踝接触不适直接回避踝支撑。

**进阶：**先稳定短保持，再增加少量时间或起落次数；额外负荷不是默认升级。

**停止或调整条件：**踝痛/失稳、腹股沟锐痛、膝不适、家具滑动或无法安全下落时停止。

**机位与画面：**身体正侧，全身、家具、踝接触点可见。

**视觉可以观察：**杠杆位置、保持时间、明显骨盆下降和次数。

**视觉不能直接判定：**踝/内收肌真实负荷、最大内收力及组织恢复状态。

**观察不足时：**拍不清时保留用户完成自述与已有可靠片段，不为补评分再撑一次；当前任务条件仍满足时可继续已确认版本的陪练。只有支撑、踝接触或其他必要资格不能确认，或出现不适时，才考虑短杠杆或基础替代；单纯测量缺失不等于能力下降。
