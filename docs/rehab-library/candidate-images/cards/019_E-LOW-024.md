# 019 E-LOW-024｜椅前目标单腿浅蹲观察

**区域：**髋、膝、踝、单腿控制　 **等级：**L2

**目标：**在固定目标和扶持条件下观察单腿蹲起；不把记录28的未知测试重命名为标准测试。

**器材：**固定扶手、靠墙稳固椅或可见深度目标

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**能够安全单腿支撑及小幅屈膝；无单腿负重禁忌。

**准备与起始位：**支撑足固定，另一足轻离地，目标椅位于身后；有扶手但不靠椅坐下。

**操作步骤**

1. 先双脚浅蹲确认目标安全。
2. 扶稳后单腿缓慢下降到当次目标，另一脚需要时立即落地。
3. 受控起身，站稳再重复；对侧用相同设置。

**关键要领：**起落都可控；目标浅一些；保留扶稳和随时落另一脚的余量。

**常见错误：**非支撑脚偷偷蹬地；坐下反弹；以膝内扣单一画面定位病因。

**试做与候选剂量／评估协议：**每侧熟悉1次后记录3次，非最大深度/最大次数测试。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**E-LOW-023 或 E-LOW-015。

**进阶：**先保持同目标复评；减少扶持或增深另存新条件。

**停止或调整条件：**打软腿、近跌倒、关节锐痛。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面全身含椅和双足；正面侧偏观察作为另一次拍摄。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**完整回合、脚落地帮助、扶持事件、投影深度及明显躯干偏移。

**视觉不能直接判定：**臀中肌真实力量、ACL完整性、真实膝关节三维对位。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**记录独立完成数与扶持/触地次数；支撑条件改变时不直接判定改善。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S004]；Single leg squat：单腿浅蹲；椅前目标为观察设置。

**证据性质与适用范围：**专科医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S004]。动作形式、背景指南和产品测量证据按第8节分别解释。
