# 070 T-LOW-053｜仰卧带辅助温和后侧链牵伸

**区域：**髋、膝、下肢后侧　 **等级：**L0–L1

**目标：**提供可单人操作的温和后侧链牵伸，避免他人压腿。

**器材：**垫、非弹性拉伸带或毛巾

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**该方向牵伸已获准，无新发神经症状；麻木/放射痛者先按专业计划筛选。

**准备与起始位：**仰卧，带绕前足但不勒趾，一侧腿抬到舒适髋位，膝允许弯曲，足踝自然。

**操作步骤**

1. 本人握带，仅提供可控助力。
2. 缓慢调整膝/髋到温和牵伸，保持自然呼吸。
3. 卸力、腿落回再换侧；不叠加颈屈或强踝背屈。

**关键要领：**温和牵伸；膝可屈；不靠带猛拉。

**常见错误：**出现麻痛仍加幅度；把紧张感当神经测试阳性。

**试做与候选剂量／评估协议：**首轮每侧约10秒；候选1–2轮×每侧10–20秒，休息约30秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**屈膝更明显或主动小幅伸膝。

**进阶：**优先舒适范围和主动控制；不以最长保持或最大角为目标。

**停止或调整条件：**麻木、电击样痛、放射痛或持续疼痛。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面含髋膝踝和握带；助力大小靠本人反馈。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**体位、粗范围与任务计时。

**视觉不能直接判定：**组织长度、带力及是否牵到某条神经。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**用 E-LOW-027同协议主动范围＋本人症状复测，不以被牵更远当作力量改善。 统一保存当次、练后和次日反应，长期判断按第12.5节。
