# 101 T-LOW-026｜低台阶上台阶：扶稳至持哑铃

**区域：**髋、膝、踝　 **等级：**L1基础—L2负重能力

**目标：**训练上楼所需的台阶负重能力。

**器材：**已知高度的稳固低台阶、固定扶手；可选单只哑铃或壶铃

**开始条件：**平地坐站可控且台阶任务获许可；单手持物时仍保留可用扶手。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**台阶无滑动，整只前脚能放上；后方安全退下空间足够。

**操作步骤**

1. 先徒手把测试脚完整放上台阶。
2. 缓慢站上去，按需要扶稳。
3. 另一脚轻触台面，确认稳定。
4. 按预定方式受控下去再重复。

**关键要领**

- 脚掌充分放上。
- 不要用地面腿猛烈弹起。
- 每次站稳再下。

**常见错误**

- 前脚只踩台阶边缘。
- 同时加高台阶、去扶手和加重。

**试做与候选剂量／评估协议：**候选模板：首轮每侧3次；一般1—3组×5—10次，先选低高度，再考虑可控负荷，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**减台阶高度、全程扶稳或改坐站。

**进阶：**只增加高度、次数或负荷中的一个，观察后续症状。

**停止或调整条件：**绊脚、膝软、踝失稳、锐痛或台阶移动时停。

**机位与画面：**斜侧全身，台阶与双脚可见。

**视觉可以观察：**组次、时间、明显代偿和触扶。

**视觉不能直接判定：**真实前腿出力、关节负荷或持物重量。

**观察不足时：**只记录完成量和扶手，遮挡时关闭足部纠错。
