# 180 T-AXU-039｜桌面到四点跪的手掌承重转移

**区域：**腕/肘/肩　 **等级：**L1

**目标：**逐步恢复手掌承重耐受和身体重心控制。

**器材**

- 固定高台/桌面
- 后期可用垫或稳定握把

**开始条件**

- 腕伸展与轴向承重获准；急性创伤、术后限制或明显不稳先按专门方案。

**准备与起始位：**首选双手撑固定高台，手指自然分开，双脚稳；保持较直身体以降低初始负荷。

见习31墙掌腕背伸不默认加尺桡骨远端关节牵引带；先做墙面低负荷姿态往返，评估用 E-AXU-030。墙→桌→地面逐项确认，不在疼痛加重时追更大角。

**操作步骤**

1. 先轻放手掌，确认接触本身和手腕角度可耐受。
2. 缓慢把身体重心向手侧移一点，让负荷逐渐增加。
3. 在舒适范围内控制移回，不猛压手掌。
4. 稳定且反应合适后，另次训练才考虑更低台或四点跪小幅前后移。

**关键要领**

- 重量慢慢交给手，不弹压手腕。
- 手掌接触稳定，肘不要突然打软。
- 呼吸自然，肩不耸起；手腕角度可按获准握把调整。

**常见错误**

- 直接从无负荷跳到地面全体重。
- 手掌压得越痛越认为能撑开活动度。

**试做与候选剂量／评估协议：**首轮高台3–5次小幅移重；候选模板1–3组×6–10次或短时轻靠，组间45–60秒。台高、腕角与剂量由计划决定。

**退阶：**提高支撑、减小身体前移；获准时用稳定握把减少腕背伸。

**进阶：**逐级降台→四点跪→更大移重→再到俯卧撑；一次改一个变量，观察当次和次日症状。

**停止或调整条件**

- 腕锐痛、卡住、肿痛明显增加或手麻。
- 支撑面移动、肘肩不稳或身体失衡。

**机位与画面：**侧面近全身，手腕、肘、肩及支撑面可见。

**视觉可以观察**

- 重心移动代理、次数、腕投影姿态与明显肘打软。

**视觉不能直接判定**

- 手掌实际压力、左右承重分配及腕骨稳定性。

**观察不足时：**腕点遮挡时只保留任务条件、时间与自报耐受，不要求机器测到力。
