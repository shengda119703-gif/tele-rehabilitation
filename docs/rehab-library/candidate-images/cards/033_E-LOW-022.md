# 033 E-LOW-022｜许可后的低跳与落地能力观察

**区域：**髋、膝、踝、返运动　 **等级：**L3高要求返运动

**目标：**观察基本跳落地完成度和信心，仅作为返运动评估的一部分。

**器材：**平整防滑地面、充足空间；初始不用高台

**开始条件：**已有跑跳经历、当前获得冲击活动许可；单腿负重与基础下蹲可控。原本强壮不能跳过急伤限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**先双脚原地极低跳，旁边有安全空区；不做距离最大化。

**操作步骤**

1. 先做1—2次无腾空的下蹲制动熟悉。
2. 双脚小幅离地后落回原位。
3. 每次落地站稳再做下一次。
4. 记录症状、稳定感和随后24小时反应。

**关键要领**

- 高度以能轻松控制为准。
- 落地后先稳住。
- 不追逐最大高度或距离。

**常见错误**

- 一次视频看着平稳就准许返赛。
- 按跳高、体重推导精确地反力峰值。

**试做与候选剂量／评估协议：**候选协议：首轮3次单独低跳，充分休息；必要时再做1小组。不是最大跳跃或跳远测试，不生成通用通过阈值。

**退阶：**取消腾空，改小幅下蹲制动或双脚提踵。

**进阶：**结合PAASS各领域和专业计划逐步增加连续性，再考虑方向或单脚。

**停止或调整条件：**疼痛升级、踝失稳、膝软、落地恐惧、肿胀增加或不受控落地即停。

**机位与画面：**斜侧全身，落地点清楚；正面仅补二维观察。

**视觉可以观察：**可见起落次数、稳定落地、明显代偿和任务完成。

**视觉不能直接判定：**真实地反力、关节负荷、组织愈合和完整返运动资格。

**观察不足时：**识别不足时保留录像、已确认事实和用户反馈，关闭缺乏依据的自动评分；当前许可、任务能力及症状条件仍满足时，不因画面质量自动降阶。只有当前能力或症状条件不满足，或执行所需关键资格事实尚未确认时，才选低阶替代；不强迫为补评分重跳。
