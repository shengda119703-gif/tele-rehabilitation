# 064 T-LOW-001｜股四头肌等长收缩

**区域：**膝　 **等级：**L0低负荷支持

**目标：**练习许可范围内主动收紧大腿前侧，适合低负荷教学和保持记录。

**器材：**床垫或瑜伽垫、可选小毛巾

**开始条件：**已知膝伸展姿势和术后限制；能理解主动收缩与放松。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**仰卧或长坐，膝下可放薄毛巾，保持舒适伸展位。

**操作步骤**

1. 先放松腿并自然呼吸。
2. 轻轻收紧大腿前侧，想象让膝后方接近毛巾。
3. 维持短时间后充分放松。
4. 按试做次数重复，记录是否能感到收缩和症状。

**关键要领**

- 不需要把膝压得疼。
- 收紧时继续呼吸。
- 臀部和脚趾无需用力代偿。

**常见错误**

- 屏气全身绷紧。
- 把视频中的静止姿势当成肌肉已经有效收缩。

**试做与候选剂量／评估协议：**候选而非统一处方：首轮3次、每次保持3—5秒，间歇充分放松；一般可选1—3组×5—10次，按当前组织限制调整。

**退阶：**更轻收缩、更短保持或先练习放松识别。

**进阶：**可控且允许后接短弧/坐姿伸膝，再增加合适外阻。

**停止或调整条件：**新锐痛、术区不适、抽筋或收缩后症状持续升级时停止。

**机位与画面：**侧面膝部即可，画面不应决定是否继续。

**视觉可以观察：**保持计时、体位、明显膝或躯干移动。

**视觉不能直接判定：**收缩是否充分、肌电强度、关节内压力或真实力量。

**观察不足时：**采用语音计时和用户确认，始终不声称视觉确认激活强度。

**动作出处与对应原文：**[REF-S010]；Early-stage Static Quads / Heel Slides / Straight Leg Raise。

**证据性质与适用范围：**大学医院分阶段动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
