# 069 T-LOW-048｜臀桥位腘绳肌滑动：双腿到单腿离心

**区域：**腘绳肌、髋、膝、躯干　 **等级：**L2–L3

**目标：**训练髋伸位下屈膝/伸膝的受控后侧链负荷。

**器材：**适合地面的滑片或小毛巾、防滑垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**桥式可控且获准腘绳肌抗阻/离心；ACL腘绳肌取腱、急性拉伤等须按专门计划。

**准备与起始位：**肩背在垫上，脚跟置滑片；地面其余区域不滑，起始膝角舒适。

**操作步骤**

1. 先双脚短幅桥式并确认可控。
2. 保持低幅髋伸，让足跟缓慢向前滑一小段。
3. 可控时双脚滑回；困难时先落臀卸重再收脚，此为离心主导版本。
4. 单腿版仅在计划许可后选择：另一脚离地，滑出后落臀、双脚收回重置。

**关键要领：**短距离开始；回程版本写清；先主动落臀再失控。

**常见错误：**硬撑全伸膝；不受控滑出；把不同回程版本合并。

**试做与候选剂量／评估协议：**首轮双腿3次；候选1–2组×4–8次、滑出约3秒、组间60–90秒；单腿另定较低起始量。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**双脚桥式或 T-LOW-045屈膝。

**进阶：**先增可控滑程，再换单腿；不同时提速加负重。

**停止或调整条件：**后侧锐痛、反复痉挛、膝痛或滑片失控。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面肩髋膝踝与滑片全入镜。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**滑出/回程事件、膝投影角、髋下沉、离心阶段时间。

**视觉不能直接判定：**腘绳肌真实离心力量、肌纤维长度及肌腱应力。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同滑程和回程版本比较可控回合、滑出时间与次日反应。 统一保存当次、练后和次日反应，长期判断按第12.5节。
