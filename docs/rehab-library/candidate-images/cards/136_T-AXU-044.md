# 136 T-AXU-044｜高位/地面平板支撑交替抬腿

**区域：**躯干、肩、髋　 **等级：**L2

**目标：**在固定高台或地面支撑中加入单侧髋伸控制。

**器材：**固定高台或垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**基本平板支撑可控，腕/肩与单侧足部支撑允许。

**准备与起始位：**首轮双手撑固定台面、双脚分开；前臂地面版作为独立体位参数。

**操作步骤**

1. 先短时保持基础支撑。
2. 一脚轻离地，向后小幅伸出，不抬高到顶腰。
3. 足落回、重置，再换侧。

**关键要领：**先稳定再抬脚；小幅；躯干不大幅转开。

**常见错误：**抬腿很高；两脚同时离地；把站姿误当平板。

**试做与候选剂量／评估协议：**首轮每侧2次；候选1–2组×每侧4–6次、短停1–2秒，组间60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**保持双脚支撑或 T-AXU-016鸟狗。

**进阶：**先少量增回合，再降低台面；地面手掌与前臂版分开。

**停止或调整条件：**肩腕痛、腰锐痛、足部不稳。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面全身及高台；转开事件需斜前机位另看。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**交替抬脚顺序、起落、明显下沉、单次可见保持。

**视觉不能直接判定：**脊柱内部负荷、深层肌激活或足底力。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**相同支撑高度下比较回合和明显姿态下降事件。 统一保存当次、练后和次日反应，长期判断按第12.5节。
