# 078 T-LOW-011｜双脚桥式

**区域：**髋、躯干　 **等级：**L0低负荷支持—L1基础

**目标：**练习髋伸展和躯干协同控制，不作骶髂复位。

**器材：**防滑垫或硬床

**开始条件：**仰卧和双脚支撑可耐受，允许髋伸展。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**屈膝双脚落稳，间距舒适；头颈平放。

**操作步骤**

1. 先轻收紧臀部并自然呼吸。
2. 脚掌稳定，缓慢把骨盆抬起。
3. 到腰不需明显后仰的位置短停。
4. 一节整体受控落回并放松。

**关键要领**

- 不用头和颈顶地。
- 脚掌保持稳定。
- 抬起高度由控制决定。

**常见错误**

- 腰过度后仰凑高度。
- 双脚滑移或屏气硬撑。

**试做与候选剂量／评估协议：**候选模板：首轮3次、每次短停2—3秒；一般1—3组×6—12次，或短时保持方案，按任务目标择一。

**退阶：**降低高度或只做臀部等长收紧。

**进阶：**先延长可控保持，再选择髋推或分腿支撑；不直接跳单腿。

可选变式包括桥式夹轻软垫、大腿弹力环和短暂停留（见习7/13/18/33）；一次选择一项，夹力/带力不自动测。单腿臀桥使用独立 T-LOW-047，滑片版本使用 T-LOW-048。

**停止或调整条件：**腰/髋锐痛、腿抽筋反复、麻木或不适持续上升时停。

**机位与画面：**侧面中景，肩髋膝踝可见。

**视觉可以观察：**起落次数、保持时间、粗躯干大腿位置。

**视觉不能直接判定：**左右承重、骶髂活动、腹压和肌肉激活比例。

**观察不足时：**看不清腰骨盆时只计时/计次，不宣称姿态完美。

**动作出处与对应原文：**[REF-S008]；Hip Bridge。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
