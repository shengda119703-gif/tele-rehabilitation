# 149 T-AXU-011｜颈部主动左右侧屈

**区域：**颈部　 **等级：**L0

**目标：**练习舒适的侧向活动与抬肩控制。

**器材**

- 稳定椅

**开始条件**

- 主动侧屈可耐受；无需先处理的创伤或新神经症状。

**准备与起始位：**正面坐稳，眼睛平视，双肩自然下垂。

**操作步骤**

1. 缓慢让一侧耳朵靠近同侧肩的方向。
2. 在舒适位置停短暂，肩不迎向耳朵。
3. 回中立位，再换另一侧。
4. 每轮后报告是否只是轻牵拉，或出现熟悉/新的症状。

**关键要领**

- 鼻尖尽量朝前，避免边转头边侧屈。
- 不使用手拉头。
- 侧屈和回正都缓慢，呼吸不中断。

**常见错误**

- 耸肩换取更短耳肩距离。
- 把拉得越痛当作越有效。

**试做与候选剂量／评估协议：**首轮每侧3次；候选模板1–2组×每侧5次，组间30秒；范围由计划决定。

**退阶：**缩小范围，靠背坐稳。

**进阶：**增加可耐受活动或短暂控制，不加手压。

**停止或调整条件**

- 眩晕、异常头痛或新手麻无力。
- 局部锐痛或回正后仍持续加重。

**机位与画面：**正面头肩近景。

**视觉可以观察**

- 近似头部侧倾、肩线变化和次数。

**视觉不能直接判定**

- 局部颈肌长度、神经压迫与真实节段ROM。

**观察不足时：**只做节奏指导及症状收集，不让头姿丢失触发重做。
