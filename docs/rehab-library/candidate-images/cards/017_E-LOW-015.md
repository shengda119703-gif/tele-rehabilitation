# 017 E-LOW-015｜自选深度康复下蹲

**区域：**髋、膝、踝、躯干　 **等级：**L1基础

**目标：**观察下蹲活动、负重耐受和运动策略。

**器材：**可选稳固扶手或作为深度目标的椅子

**开始条件：**可双脚负重，明确个人允许深度和是否需支撑。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面先测；双脚自然宽度，不强制足尖完全平行。

**操作步骤**

1. 站稳，确认本次目标为浅蹲或坐椅目标。
2. 缓慢屈髋屈膝下降至许可范围。
3. 停稳后起身，不反弹追求深度。
4. 完成约定次数后报告疼痛位置与变化。

**关键要领**

- 膝随前足自然方向。
- 重心保持可控，呼吸连续。
- 达到个人目标即可。

**常见错误**

- 所有用户必须蹲到大腿平行地面。
- 把正面膝内移直接诊断为臀肌无力或膝病。

**试做与候选剂量／评估协议：**候选协议：熟悉1次、记录3次，固定扶手、深度和鞋履；评估不加最大负荷。正面补充为可选，不因缺正面而全套无效。

**退阶：**改扶稳浅蹲或高椅坐站。

**进阶：**需要更高功能时再做台阶或单腿任务，先通过限制检查。

**停止或调整条件：**明显关节卡锁、腿软、锐痛或失衡时停止。

**机位与画面：**侧面主机位，正面可另选一次补充。

**视觉可以观察：**膝投影角、躯干前倾、次数、深度与节奏。

**视觉不能直接判定：**膝关节力矩、左右地反力、结构性损伤或准确髋ROM。

见习1/13/33中的双膝高度/身体偏移可作为规定机位的外部事实；不能由髋点侧移认定真实承重比例，也不能由下蹲视频确诊骨盆错位。分腿/单腿任务分别用 E-LOW-023/002。

**观察不足时：**缺辅助点则只输出计次和自述深度；保留已完成记录。

**动作出处与对应原文：**[REF-S001]；Mini-squats：自选许可深度观察。

**证据性质与适用范围：**公共卫生机构动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
