# 131 T-AXU-041｜四点跪位后坐髋屈活动

**区域：**髋、膝、胸腰整体　 **等级：**L0–L1

**目标：**在低平衡需求下练习髋后坐；默认去掉治疗师所用大腿近端牵引带。

**器材：**垫、膝部软垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**手膝接触获准；能自行上下地。

**准备与起始位：**四点跪位、支点稳固，双脚自然。

**操作步骤**

1. 慢慢后移臀部，保持手膝支撑。
2. 到获准舒适范围短停。
3. 受控回起点，不强坐足跟。

**关键要领：**慢移慢回；小范围；正常呼吸。

**常见错误：**弹力带绑股根自行关节牵引；腰代偿越来越大。

**试做与候选剂量／评估协议：**首轮3次；候选1–2组×6–10次，组间30–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**桌面支持后坐或 T-LOW-013扶稳髋铰链。

**进阶：**增加可控范围；牵引带只按另行专业协议，不自动进阶。

**停止或调整条件：**膝/腕接触痛、髋夹痛或放射症状。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面含四支点。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**后坐回合、髋躯干夹角代理和明显背形变化。

**视觉不能直接判定：**髋囊松动、真实关节滑动或脊柱分节活动。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**关联 E-AXU-025，按相同支点复测。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S008]；Bird Dog / Modified Side Plank / Kneeling Back Extension后坐。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
