# 025 E-LOW-011｜扶稳双脚提踵功能观察

**区域：**踝、小腿　 **等级：**L1基础

**目标：**观察双脚推起能力、节奏和症状。

**器材：**固定台面或无轮稳固椅

**开始条件：**能双脚负重；无跟腱或前足禁止负荷限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面全身与足部可见，手只用于维持平衡。

**操作步骤**

1. 双脚自然站稳并轻扶。
2. 缓慢抬起双跟到自选可控高度。
3. 短暂停住，再控制落地。
4. 按约定次数完成并报告哪侧不适或更费力。

**关键要领**

- 不要弹跳借惯性。
- 膝不要反复深蹲来代偿。
- 手保持轻扶。

**常见错误**

- 用手把身体拉上去。
- 身体上下晃动被误记为真实提踵。

**试做与候选剂量／评估协议：**候选协议：先试2次，再记录5次可控动作；这是功能观察，不是最大耐力常模测试。记录支撑及鞋履。

**退阶：**坐位提踵或减小高度。

**进阶：**适合者再测扶稳单脚提踵，不按双脚次数直接晋级。

**停止或调整条件：**后跟/前足新锐痛、腿软、失衡或动作持续失控时停止。

**机位与画面：**侧面，足跟前足尽量清楚。

**视觉可以观察：**次数、节奏；有足点时跟位移趋势。

**视觉不能直接判定：**左右实际承重、跟腱力及最大跖屈肌力。

**观察不足时：**缺足点保留用户确认次数与症状，标记自动计次有限。

**动作出处与对应原文：**[REF-S007]；Calf Raises (Two-Legged or One-Legged)：双脚版。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
