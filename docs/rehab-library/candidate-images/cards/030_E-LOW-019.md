# 030 E-LOW-019｜支撑旁睁眼单脚站立

**区域：**髋、踝、平衡　 **等级：**L1基础—L2负重能力

**目标：**观察单腿静态站立能力和本人稳定感。

**器材：**固定扶手、平整防滑地面

**开始条件：**并足/串联或双脚站安全，允许单腿负重；跌倒高风险不独自尝试。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**正面；支撑随手可用，抬脚高度只需离地。

**操作步骤**

1. 先轻扶并把重心转到测试腿。
2. 另一脚稍离地后，按能力减少扶手。
3. 保持至设定时限或重新触地。
4. 记录触地、触扶、信心和症状，再换侧。

**关键要领**

- 眼睛看固定目标。
- 随时允许落脚或扶稳。
- 身体不需要完全不晃。

**常见错误**

- 追求长时间而拒绝扶手。
- 骨盆偏移被直接判为某一肌肉损伤。

**试做与候选剂量／评估协议：**候选协议：每侧2次，每次最多10—20秒的初步观察；上限与支撑条件要保存，不套所有年龄统一阈值。

**退阶：**改半串联、轻扶单腿或双脚重心转移。

**进阶：**之后可考虑触点平衡，不根据这一项单独批准运动。

**停止或调整条件：**失稳、疼痛升级、眩晕或明显不安全感即停止。

**机位与画面：**正面全身，双足、骨盆、扶手可见。

**视觉可以观察：**时间、落脚、明显扶手、躯干和骨盆运动。

**视觉不能直接判定：**独立髋肌力量、压力中心、韧带稳定度。

**观察不足时：**保留时间及触扶自述；看不见脚时不自动判失败。

**动作出处与对应原文：**[REF-S003]；One-leg stand：支撑旁睁眼站立。

**证据性质与适用范围：**公共卫生机构动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
