# 042 E-AXU-025｜四点跪位后坐活动观察

**区域：**髋屈曲、胸腰整体控制　 **等级：**L0–L1

**目标：**观察支撑位髋后坐的可控范围和症状。

**器材：**垫、膝部软垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**允许手腕、肩与膝接触承重；可以自行进入退出四点跪位。

**准备与起始位：**双手膝落稳，大腿与躯干自然位置；不加关节牵引带。

**操作步骤**

1. 保持四个支点，缓慢把臀部向后移。
2. 达到舒适范围便停止，不强坐到足跟。
3. 受控回到起始位。

**关键要领：**慢移慢回；头颈自然；范围由髋膝与症状决定。

**常见错误：**手掌滑动；为后坐猛拱腰；将外观判为关节囊卡住。

**试做与候选剂量／评估协议：**记录3个回合；非最大髋屈测试。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**更浅范围、桌面扶持后坐；膝不耐受者改站姿扶稳髋铰链。

**进阶：**原支点和目标距离复评。

**停止或调整条件：**膝术区接触痛、腕痛或腰腿症状加重。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正侧面，肩肘腕髋膝踝及支撑面可见。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**后坐回合、躯干大腿夹角代理、明显整体背形变化。

**视觉不能直接判定：**独立髋关节ROM、髋关节囊状态、腰椎分节屈曲。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**比较同支点的后坐幅度代理及症状，范围更大但代偿增多时分别报告。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S008]；Kneeling Back Extension：后坐阶段。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
