# 091 T-LOW-016｜扶稳单腿罗马尼亚硬拉

**区域：**髋、踝、平衡　 **等级：**L2负重能力

**目标：**训练单腿髋铰链与平衡控制，可选轻哑铃负荷。

**器材：**固定扶手、可选轻哑铃或壶铃

**开始条件：**双腿RDL可控、单脚负重获许可；支撑踝稳定，当前无单腿限制。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**一手扶固定台面；另一手持负荷时保证不妨碍扶稳。

见习11/22/37单腿触地起身先用稳固高目标；不强求够地。前脚垫高版本（39）需额外足部/支撑资格，非默认家庭进阶；转为 E-LOW-025时使用独立评估协议。

**操作步骤**

1. 站稳并把重心转到测试腿。
2. 测试膝轻屈，髋向后折，另一腿自然向后伸。
3. 到骨盆能保持大致朝前的位置停住。
4. 控制站回并落另一脚；每次站稳再继续。

**关键要领**

- 先平衡再增加幅度。
- 骨盆不大幅转开。
- 扶手可以一直使用。

**常见错误**

- 为了抬后腿而过度拱腰。
- 移除支撑和加重同时进行。

**试做与候选剂量／评估协议：**候选模板：首轮徒手每侧3次；一般1—3组×5—8次，轻负荷只在动作和踝稳定后加入，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**双脚/分腿支撑髋铰链，或增加扶手、缩小范围。

**进阶：**先增加稳定范围，再小幅加重；减少支撑单独安排。

**停止或调整条件：**支撑踝失稳、腿软、髋腰锐痛或近跌倒时停。

**机位与画面：**斜侧全身，扶手和双足可见。

**视觉可以观察：**次数、骨盆明显旋转、触地、髋铰链表现。

**视觉不能直接判定：**单腿地反力、髋稳定肌实际出力、韧带状态。

**观察不足时：**平衡优先，识别不到后腿仍可陪练并记录自主完成。

**动作出处与对应原文：**[REF-S026]；Single Leg RDL：单腿髋铰链。

**证据性质与适用范围：**大学医疗中心公开示范目录。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
