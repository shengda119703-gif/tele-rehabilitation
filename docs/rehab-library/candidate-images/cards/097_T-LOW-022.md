# 097 T-LOW-022｜反向弓步：徒手至哑铃

**区域：**髋、膝、踝　 **等级：**L2负重能力

**目标：**练习后退落脚、下降与回位的动态控制。

**器材：**清空的防滑区域、旁侧固定扶手；可选哑铃

**开始条件：**分腿蹲和后退一步可控，当前允许动态单腿负重。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**先确定后方空间，站距保留左右宽度。

**操作步骤**

1. 站稳后把一脚缓慢向后迈。
2. 后脚落稳再屈膝下降。
3. 在许可深度控制回升。
4. 后脚收回并重新站稳，换侧或完成同侧。

**关键要领**

- 先落稳再下降。
- 不要跨到身体正后方交叉。
- 回位不急跳。

**常见错误**

- 跨步太大造成踝髋牵扯。
- 后退未站稳就猛蹲。

**试做与候选剂量／评估协议：**候选模板：首轮徒手每侧3次；一般1—3组×5—8次，负重只在步伐稳定后加入，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**固定分腿蹲或扶稳后退点地。

**进阶：**先增加连续流畅性，再小幅加重或增加范围。

**停止或调整条件：**踩空、踝失稳、膝软、锐痛或明显恐惧时停止。

**机位与画面：**斜侧全身，后方足落点清楚。

**视觉可以观察：**步次、落脚后下降顺序、节奏和明显失衡。

**视觉不能直接判定：**地面冲击力、前后腿力矩和最大力量。

**观察不足时：**足被遮挡就省略足部评分，保留可确认次数，避免要求再走一遍。

**动作出处与对应原文：**[REF-S036]；Reverse Lunge。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
