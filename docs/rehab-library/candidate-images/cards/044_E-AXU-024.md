# 044 E-AXU-024｜低负荷侧向支撑耐受筛查

**区域：**胸腰/肩　 **等级：**L0–L1

**目标：**以短时非极限支撑观察侧方躯干与肩部任务耐受。

**器材**

- 坚实墙面；经许可可用垫做屈膝侧撑

**开始条件**

- 肩能轻度侧向承重、站立稳定；不以疼痛肩直接挑战地面侧桥。

**准备与起始位：**首选侧身靠墙，前臂接触墙，肘约肩下；脚靠近墙以控制负荷，正斜面拍全身。

**操作步骤**

1. 先轻靠墙建立稳定前臂支撑。
2. 身体保持整体直线，轻轻离开完全放松位置。
3. 在允许的短时内正常呼吸，然后平稳退出。
4. 换侧比较疼痛、困难和是否能保持，不追求最长时间。

**关键要领**

- 肩离耳朵，不用耸肩硬撑。
- 腰不向墙折，双脚踩稳。
- 结束时先移回重心再放开手臂。

**常见错误**

- 一个方向用墙，另一个方向用地面却直接比较时间。
- 把短时保持等同核心肌力正常。

**试做与候选剂量／评估协议：**每侧试1次，候选保持5–10秒；侧间休息30–60秒。疼痛或技术下降先结束。

**退阶：**站得更近或只做轻靠；肩不能承重时选择其他躯干任务。

**进阶：**在相同支撑条件复测；地面屈膝侧桥另建负荷条件。

**停止或调整条件**

- 肩不稳、锐痛、手臂打软或脚滑。
- 新的腰痛、眩晕或明显屏气不适。

**机位与画面：**斜前方全身，侧向躯干线和支撑臂可见。

**视觉可以观察**

- 短时保持、明显下沉或侧折、退出过程。

**视觉不能直接判定**

- 支撑力、侧腹肌力量、肌肉收缩与组织负荷。

**观察不足时：**姿势不能可靠自动评分时保留用户实际保持和症状，机器计时不当发力证明。
