# 107 T-LOW-032｜膝顶墙背屈活动训练

**区域：**踝　 **等级：**L1基础

**目标：**在负重许可下练习向前移膝的背屈活动。

**器材：**墙、固定扶手、可选地面位置贴条

**开始条件：**允许负重背屈；前踝夹痛或急伤限制需要先调整方案。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**从容易完成的位置开始，脚朝墙，跟稳定。

半跪位训练见 T-LOW-052；站位负重背屈评估仍用 E-LOW-010。关节牵引带及距骨/舟骨自我松动须另行专业协议，不能因运动画面“卡”自动启动。

**操作步骤**

1. 轻扶墙并站稳。
2. 脚跟不离地，膝缓慢向墙靠近。
3. 到舒适位置短停。
4. 退回起点，按节拍重复。

**关键要领**

- 膝沿前足方向。
- 跟保持接触。
- 不弹震和强压。

**常见错误**

- 膝每次冲击墙面。
- 足跟抬起却继续加远距离。

**试做与候选剂量／评估协议：**候选模板：首轮3—5次；一般1—3组×5—10次，终点可短停2—3秒，活动范围依许可和症状选择。

**退阶：**减趾墙距离，双手扶稳或坐姿背屈。

**进阶：**先稳定控制，再小幅后移脚；距离不是越大越好。

**停止或调整条件：**前踝锐痛、跟腱牵痛明显、踝失稳或症状逐次增加时停。

**机位与画面：**侧面足近景或全身兼顾。

**视觉可以观察：**次数、小腿向前倾；足点可靠时跟抬起。

**视觉不能直接判定：**关节病因、距骨滑动或真实足底负荷。

**观察不足时：**无需每次测厘米，识别失败仍可陪练并记录位置。

**动作出处与对应原文：**[REF-S058]；负重背屈弓步；本库作舒适活动训练。

**证据性质与适用范围：**原始测量信度研究。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
