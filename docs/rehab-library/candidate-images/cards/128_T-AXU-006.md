# 128 T-AXU-006｜椅背支持的坐位伸胸

**区域：**胸部/胸腰整体　 **等级：**L0

**目标：**在可控支撑下练习胸部伸展活动。

**器材**

- 结实椅背；可选薄毛巾缓冲

**开始条件**

- 没有未获许可的脊柱骨折、近期术后或伸展限制。
- 椅背高度和硬度适合，不压颈部。

**准备与起始位：**坐稳，椅背上缘位于舒适的中上背支撑区，双脚踩地；手可交叉放胸前。

**操作步骤**

1. 吸气向上坐长，臀部不向前滑。
2. 呼气时让上背在椅背支持下小幅向后展开。
3. 颈部保持舒适，不强行仰头；自然吸气一次。
4. 用躯干控制回到中间，确认反应后再重复。

**关键要领**

- 支撑是帮助控制，不是硬顶某节椎骨。
- 腰部避免明显向前顶、脚不蹬地。
- 手不拉头，伸展幅度宁小。

**常见错误**

- 把腰后仰和抬下巴当作全部伸胸动作。
- 使用不稳椅或让椅背直接顶颈部。

**试做与候选剂量／评估协议：**首轮2–3次；候选模板1–2组×5–6次，组间30–60秒；不自动规定所有胸背痛用户必做。

**退阶：**不靠椅背，仅坐位轻柔伸胸或有靠背呼吸。

**进阶：**先提升舒适范围及呼吸，再衔接转胸；不通过加重物压末端。

**停止或调整条件**

- 锐痛、异常胸痛、呼吸困难或头晕。
- 椅子晃动或后伸后症状持续增加。

**机位与画面：**侧面坐位，头、肩、髋及椅背可见。

**视觉可以观察**

- 伸胸尝试、回正和明显腰部/头部代偿。

**视觉不能直接判定**

- 真实胸椎伸展角、节段活动或椅背压力。

**观察不足时：**只作节奏陪练和反应记录，不对局部胸椎角度评分。
