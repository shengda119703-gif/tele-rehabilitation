# 031 E-LOW-020｜足弓外观与负重变化初筛

**区域：**足弓、后足　 **等级：**L0低负荷支持—L1基础

**目标：**区分外观描述与病因判断，观察柔韧性线索。

**器材：**稳固椅、固定扶手、可拍清足内侧和后方的相机

**开始条件：**能安全坐站；单脚提踵不是每人必做项目。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**赤足或露出足部；先内侧近景，尽量保持机位与脚位置。

**操作步骤**

1. 坐位放松拍足内侧外观。
2. 双脚站立后记录外观变化及疼痛。
3. 适合者扶稳做一次双脚提踵，观察足弓是否改变。
4. 可选补后方外观，询问出现时间、单双侧和近期变化。

**关键要领**

- 正常放松站，不刻意抓地造足弓。
- 左右采用相同条件。
- 症状和外观分开记录。

**常见错误**

- 一张照片直接诊断扁平足分期或高弓病因。
- 无症状低足弓自动生成矫正治疗。

**试做与候选剂量／评估协议：**候选协议：每种可安全体位1段短记录即可；后方或提踵缺失可输出部分筛查。新发、进行性或神经症状走专业评估。

**退阶：**只做坐位照片和病史，保留未评估的负重信息。

**进阶：**如临床需要再补准确标点、体检或影像，不强求拍更多张。

**停止或调整条件：**负重疼痛明显、提踵不能安全完成、足下垂或进行性无力出现时停止动作并升级评估。

**机位与画面：**足内侧近景为主，后方为可选补充。

**视觉可以观察：**专门足模型/人工标点支持的外观及体位变化。

**视觉不能直接判定：**病因、骨性结构、肌腱是否断裂、真实足底压力；COCO17本身无足弓点。

**观察不足时：**保留照片给人工复核，标“外观初筛”；不反复要求用户改变姿势重拍。

**动作出处与对应原文：**[REF-S059]；Examination：站立足弓、后足外观；不直接诊断。

**证据性质与适用范围：**专业学会临床观察说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
