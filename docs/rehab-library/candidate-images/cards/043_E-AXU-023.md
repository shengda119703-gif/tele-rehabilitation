# 043 E-AXU-023｜轻阻力Pallof抗旋转任务筛查

**区域：**胸腰/躯干　 **等级：**L1–L2

**目标：**观察规定轻阻力下保持身体方向的任务控制及症状。

**器材**

- 牢固专用锚点和完好的弹力带

**开始条件**

- 站立稳定；肩、腕及腰部可耐受；锚点与弹力带已检查。

**准备与起始位：**身体侧对锚点，双脚稳定，带位于胸高；输入带型号和初始距离，但不把颜色当力值。

**操作步骤**

1. 双手把带柄放胸前，先感受轻张力。
2. 呼气把手缓慢推出少量距离，胸口尽量保持原方向。
3. 短暂停留后控制收回，不让带突然拉回。
4. 换另一侧，以相同带长和脚位完成并报告症状。

**关键要领**

- 手往前走，躯干不被带拉着转。
- 膝不锁死，脚保持踩稳。
- 负荷先轻，正常呼吸比僵硬憋气重要。

**常见错误**

- 不同初始伸长量仍按相同负荷比较。
- 把外观不动当作已测得抗旋转力矩。

**试做与候选剂量／评估协议：**每侧先1次试做，最多2次各停2–3秒；休息30秒。记录条件与表现，不测极限。

**退阶：**缩短前伸距离、靠近锚点降低张力，或无阻力练习。

**进阶：**同条件复测；无明显反应后才考虑扩大手臂杠杆或增加阻力。

**停止或调整条件**

- 锚点移动、弹力带损坏或回弹危险。
- 出现新的腰痛、肩腕锐痛或失去站稳。

**机位与画面：**正面或斜前方，胸骨方向代理、双手和骨盆可见。

**视觉可以观察**

- 推回次数、手臂杠杆变化、明显躯干转动。

**视觉不能直接判定**

- 真实带张力、躯干抗旋转力矩和深层肌激活。

**观察不足时：**保持难以自动识别时使用自报完成与计时，不要求机器确认等长收缩。
