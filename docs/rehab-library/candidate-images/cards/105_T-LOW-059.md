# 105 T-LOW-059｜扶稳直线弓步走：分段版

**区域：**髋膝踝、步序、躯干　 **等级：**L2–L3

**目标：**在直线路线中练习弓步迈步、受控下降和站稳衔接；不作为变向或返赛测试。

**器材：**平整防滑短直线路径、可靠长扶栏或连续可及固定支撑；首轮徒手。

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**分腿蹲、迈步和回位分别可控，已获准弓步负重；可独立退出且整条路径支撑可及。

**准备与起始位：**预设短直线，记录步距、深度与扶持方式；路径不含急转向或交叉脚。

**操作步骤：**

1. 前迈一脚并站稳，在获准范围做浅弓步。
2. 受控起身，将后脚向前收拢，确认稳定。
3. 另一脚沿直线迈向下一落点；行程结束站稳，休息后重新开始。

**关键要领：**先稳再动；步距舒适；不用连续反弹。

**常见错误：**连续抢速度；支撑不可及仍前进；固定足位猛扭膝转向。

**试做与候选剂量／评估协议：**首轮4步；候选1–2组×4–8步，组间60–90秒。有效步需包含受控下降和起身。

**退阶：**T-LOW-021 原地分腿蹲或 T-LOW-022 原地反向弓步。

**进阶：**先固定路线增加可控步数，再单独调整深度或轻负荷；变向须另有专项协议与出处。

**停止或调整条件：**膝/踝失稳、熟悉痛加重或近跌倒。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**全身及所有落点可见；超出视野只记录可见片段。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**步序、完整弓步、站稳重置、扶持和明显失稳；越出画面不计完整步。

**视觉不能直接判定：**切入峰值力、韧带负荷、真实跑跳准备程度。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同路线、步距、深度和支撑比较有效步数、阶段时间与本人反应；不与点地变向数据合并。

**动作出处与对应原文：**[REF-S076]；Kettlebell Walking Lunge：直线弓步走；不含点地变向。

**证据性质与适用范围：**专业机构研究与技术手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
