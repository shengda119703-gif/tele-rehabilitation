# 132 T-AXU-042｜四点跪位猫式与舒适伸展

**区域：**胸腰整体、运动控制　 **等级：**L0–L1

**目标：**练习躯干舒适屈伸与呼吸协调。

**器材：**垫、膝垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**手膝支撑及躯干屈伸获准。

**准备与起始位：**四点跪位，头颈自然，手在肩下附近、膝在髋下附近。

**操作步骤**

1. 呼气时背部轻圆起，头顺势轻低。
2. 吸气回中立；计划允许时再小幅展开上背。
3. 受控回中立，不追求极限凹腰或仰头。

**关键要领：**幅度舒适；呼吸不憋；动作平缓。

**常见错误：**头后仰压颈；腰腹过度下坠；把拱背高度当分节ROM。

**试做与候选剂量／评估协议：**首轮3个周期；候选1–2组×5–8周期，休息30–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**仅中立位自然呼吸或坐位小幅屈背。

**进阶：**增加协调与少量回合；不增加足部弹力带牵拉作自动进阶。

**停止或调整条件：**腕膝痛、头晕或腰腿放射症状。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正侧面含肩髋与支点；局部背形需轮廓模块。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点/轮廓；细节以陪练为主；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**粗屈伸周期、整体躯干变化；身体点不足时只陪练计时。

**视觉不能直接判定：**椎节活动、椎间盘压力、深层肌激活。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**追踪舒适完成和症状；不设置全人群标准弧度。 统一保存当次、练后和次日反应，长期判断按第12.5节。
