# 134 T-AXU-016｜鸟狗式：单肢到对侧手脚

**区域：**胸腰/肩/髋控制　 **等级：**L1

**目标：**在四点支撑及肢体伸展时练习整体控制与耐力。

**器材**

- 垫；可选稳定高台作降阶

**开始条件**

- 可安全跪位，腕、膝、肩承重可耐受；必要时选高台或前臂替代版本。

**准备与起始位：**四点跪，手大致在肩下、膝在髋下，头自然延续躯干。

**操作步骤**

1. 先在四点支撑位正常呼吸并站稳支点。
2. 先单独伸出一只手或沿地面后滑一条腿，找可控范围。
3. 基础稳定后才同时伸出对侧手与腿，不要求抬过躯干高度。
4. 短暂停留后控制放回，再换侧。

**关键要领**

- 向远处伸长，不向上猛抬。
- 骨盆大致朝地，避免明显翻开。
- 支撑肩不塌，眼睛看垫面而非抬头看屏幕。

**常见错误**

- 抬腿过高使腰明显后仰。
- 快速换手脚或支撑点不稳时继续加难度。

**试做与候选剂量／评估协议：**首轮每侧3次单肢；候选模板2组×每侧5–8次、每次停2–5秒，组间45–60秒；版本按计划。

**退阶：**只滑手或滑脚不离地；手撑固定高台以减小腕膝负担。

**进阶：**先从单肢到对侧，再增加短暂停留；额外阻力需稳定控制与症状反应支持。

**停止或调整条件**

- 肩腕膝锐痛或新腰腿放射症状。
- 支撑打软、明显失衡或无法控制放回。

**机位与画面：**斜侧方，四肢及躯干完整入镜。

**视觉可以观察**

- 支撑/抬起事件、对侧配对、保持、明显躯干翻转或下沉。

**视觉不能直接判定**

- 局部椎节稳定、支撑力或深层肌激活。

**观察不足时：**手脚遮挡时保留自报次数与计时，暂停细项评分，不重置整组。
