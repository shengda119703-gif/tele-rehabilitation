# 112 T-LOW-050｜扶稳屈膝站姿提踵

**区域：**踝、小腿、膝　 **等级：**L1–L2

**目标：**补充坐位与直膝之间的屈膝负重提踵，关注可控起落。

**器材：**平地、固定扶手

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**站立、膝小幅屈曲及提踵获准。

**准备与起始位：**双脚先做，膝舒适轻屈；单腿版另查当前资格。

**操作步骤**

1. 扶稳并建立屈膝起点。
2. 保持膝大致原角度，缓慢抬起脚跟。
3. 受控落回平地，不弹跳。

**关键要领：**屈膝幅度固定；慢落；跟落平地。

**常见错误：**反复伸膝借力；未查跟腱阶段就用斜板大幅下落。

**试做与候选剂量／评估协议：**首轮5次；候选1–3组×6–12次，组间45–90秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**T-LOW-037坐位提踵。

**进阶：**先增加回合，再单腿或轻负重；快提踵仅后期另定协议。

**停止或调整条件：**膝、前足、跟腱痛加重或失稳。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面足部近景含膝。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**足部近景＋膝点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**跟起落、膝角代理、下降时间与高度趋势。

**视觉不能直接判定：**比目鱼肌孤立出力、肌腱应力。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**关联 E-LOW-028；同膝角/扶持下复评。 统一保存当次、练后和次日反应，长期判断按第12.5节。
