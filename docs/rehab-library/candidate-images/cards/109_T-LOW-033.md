# 109 T-LOW-033｜直膝小腿牵伸

**区域：**踝、小腿　 **等级：**L0低负荷支持—L1基础

**目标：**针对当前存在的小腿后侧活动限制提供温和牵伸。

**器材：**墙或固定台面

**开始条件：**后跟可负重，膝伸位和踝背屈符合限制；不对急性撕裂强牵伸。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**前后分腿，后腿为牵伸侧；足尖自然朝前，后膝舒适接近伸直。

**操作步骤**

1. 双手扶稳并摆好前后脚。
2. 后脚跟接触地面。
3. 身体轻向前移，感到小腿后侧温和牵伸即可。
4. 保持自然呼吸，缓慢退出。

**关键要领**

- 后膝不硬锁。
- 跟不抬起。
- 牵伸不追求疼痛。

**常见错误**

- 脚外转太多绕过原动作。
- 持续弹震压踝。

**试做与候选剂量／评估协议：**候选模板：先试10秒1次；一般2—4次×15—30秒，休息后再做。保持时长是候选，按症状与限制调整。

**退阶：**减小前移，或改坐姿温和牵伸。

**进阶：**先提升舒适保持，再按需要改变站距；不增加外人推压。

**停止或调整条件：**锐痛、足麻、跟腱局部明显痛或痉挛时停。

**机位与画面：**侧面含双腿和足。

**视觉可以观察：**姿势、保持时间；可靠足点下的跟抬起。

**视觉不能直接判定：**组织实际牵伸力、跟腱状态及肌束长度。

**观察不足时：**用计时和感受确认；不以角度不足不断催用户前压。

**动作出处与对应原文：**[REF-S007]；直膝/屈膝Heel Cord Stretch、双脚/单脚Calf Raises。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
