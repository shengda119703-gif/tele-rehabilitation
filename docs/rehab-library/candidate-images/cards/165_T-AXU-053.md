# 165 T-AXU-053｜Push-up Plus：墙面到固定高台

**区域：**肩带、上肢推撑、躯干　 **等级：**L1–L2

**目标：**在直臂支持末端加入可控肩带前推；不以背部拱起替代任务。

**器材：**墙或固定高台

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**普通墙面/高位推撑可控，肩肘腕承重获准。

**准备与起始位：**先双手墙面或高台直臂支持，肘不猛锁，足距舒适。

**操作步骤**

1. 先保持可控直臂支持。
2. 不明显屈肘，把胸廓轻轻远离支持面，让肩带自然前移。
3. 控制回到初始位置；获准后才与一次推撑组合。

**关键要领：**轻推轻回；颈部自然；少量前移即可。

**常见错误：**仅圆背低头；把肘屈伸误计为Plus；憋气。

**试做与候选剂量／评估协议：**首轮3次；候选1–2组×6–10次，组间45–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**更直立墙面支持或 T-AXU-029基本推撑。

**进阶：**同支撑高度增回合，再逐步降低台面；地面版另建协议。

**停止或调整条件：**腕肩痛或躯干失控。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面含上臂、肘、躯干和支撑面；小幅动作需要近景/轮廓。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点＋上躯干近景；小幅时陪练；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**直臂是否保持、明显胸廓往返；识别不足只陪练不补次数。

**视觉不能直接判定：**前锯肌选择性激活、肩胛精确角、翼状肩胛病因。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同支撑条件复评；Plus与普通俯卧撑分别计次。 统一保存当次、练后和次日反应，长期判断按第12.5节。
