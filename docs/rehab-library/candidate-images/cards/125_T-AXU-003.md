# 125 T-AXU-003｜扶持躯干左右侧屈活动

**区域：**腰部/胸腰整体　 **等级：**L0

**目标：**恢复舒适范围的侧屈活动与两侧控制。

**器材**

- 稳定椅或台面

**开始条件**

- 当前允许侧屈，能坐稳或扶持站稳。

**准备与起始位：**首选坐位或扶持站位，胸口朝前，双脚稳定；双手可沿大腿滑动。

**操作步骤**

1. 回到自然中立位，放松肩膀。
2. 呼气时向一侧缓慢侧屈，手沿同侧大腿下滑。
3. 控制回到中间，再换另一侧。
4. 每轮结束检查腰背与下肢反应。

**关键要领**

- 不同时转身，不抬起一侧臀部。
- 侧屈幅度以呼吸不受阻为宜。
- 每侧都从中间开始，避免连续甩动。

**常见错误**

- 用骨盆横移替代躯干侧屈。
- 一手持重强行把身体拉向更深范围。

**试做与候选剂量／评估协议：**首轮每侧3次；候选模板1–2组×每侧5–8次，组间30秒，选择和范围须按计划。

**退阶：**有靠背的小幅坐位侧倾。

**进阶：**先改善活动和回正控制；负重侧方能力用侧桥或手提箱行走单独训练。

**停止或调整条件**

- 出现放射痛、持续锐痛或头晕。
- 坐位/站位平衡不能保持。

**机位与画面：**正面全身或坐位上半身。

**视觉可以观察**

- 整体侧倾、回正、次数及明显抬臀。

**视觉不能直接判定**

- 独立腰椎ROM、腰方肌长度或椎间负荷。

**观察不足时：**只指导轻柔左右活动，不对不可见的局部脊柱曲度打分。
