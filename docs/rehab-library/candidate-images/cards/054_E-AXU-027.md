# 054 E-AXU-027｜墙面持球小圈控制观察

**区域：**肩带、上肢闭链控制　 **等级：**L1

**目标：**观察可控手部圆形轨迹，不根据轨迹诊断肩胛功能障碍。

**器材：**墙、轻软球或折叠毛巾

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**能舒适低位扶墙承重；自行取放球。

**准备与起始位：**手在肩前下方或获准高度抵球，另一手可辅助摆位；站姿稳定。

**操作步骤**

1. 先轻抵墙停住。
2. 按小范围顺时针画圈，再停止。
3. 同幅度逆时针，卸力放下。

**关键要领：**小圈慢做；不夹肩憋气；不为了稳球猛压墙。

**常见错误：**球滚走仍追着移动；把手轨迹稳定解释成关节已经稳定。

**试做与候选剂量／评估协议：**每方向3圈；球、手高和站距固定。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**毛巾擦小圈、双手辅助或 E-AXU-021墙面轻推。

**进阶：**同条件复评；增圈径或增高分别记录。

**停止或调整条件：**肩/腕痛、球反复失控。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正面看手轨迹和侧偏；侧面看身体前移；墙面平面需校准才测厘米。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点＋手/球近景；接触需额外确认；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**圈数、方向、手轨迹闭合与停顿；球/接触需物体模块或人工确认。

**视觉不能直接判定：**墙面压力、肩胛角、真实闭链稳定性。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同范围下比较完整圈数、失控事件与症状；无球识别时只报告手轨迹。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S015]；Ball circles：墙面持球小圈。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
