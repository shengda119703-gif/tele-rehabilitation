# 075 T-LOW-008｜侧卧髋外展

**区域：**髋　 **等级：**L1基础

**目标：**在卧位练习侧向抬腿控制。

**器材：**防滑垫、小枕头；可选轻踝部负重

**开始条件：**能安全侧卧，髋外侧压迫可耐受，抬腿方向允许。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**测试腿在上，底腿屈曲支撑；头颈有支撑。

**操作步骤**

1. 把骨盆和躯干放在舒适侧卧位。
2. 上侧腿缓慢抬起，不追求高幅度。
3. 停片刻后受控放下。
4. 休息后换侧。

**关键要领**

- 脚尖不刻意翻向天花板。
- 骨盆避免向后滚。
- 抬起和放下都慢。

**常见错误**

- 身体滚后使动作变成屈髋。
- 靠脚甩动完成次数。

**试做与候选剂量／评估协议：**候选模板：首轮每侧3次；一般1—3组×6—12次，首次不加外负荷；增加负荷前确认压迫耐受。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**站姿扶稳外展或缩短范围。

**进阶：**动作稳定后才选小负荷，或进阶站姿功能动作。

**停止或调整条件：**髋外侧压痛明显、腹股沟锐痛、腰痛或感觉异常时停。

**机位与画面：**面对身体正侧的中景，躯干骨盆腿可见。

**视觉可以观察：**抬腿次数和明显滚动，卧姿模型需单独验证。

**视觉不能直接判定：**真实外展力、臀肌与阔筋膜张肌各自贡献。

**观察不足时：**卧姿点不可靠时用节拍和自主记录，不无限要求换机位。

**动作出处与对应原文：**[REF-S005]；Hip Abduction / Internal Hip Rotation（蚌式）/ Hip Adduction。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
