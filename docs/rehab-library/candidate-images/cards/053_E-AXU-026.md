# 053 E-AXU-026｜墙面滑手的抬举与代偿观察

**区域：**肩、上肢、胸腰整体　 **等级：**L0–L1

**目标：**观察固定墙面支持下抬手和回程；只报告上肢轨迹与粗代偿。

**器材：**墙、毛巾

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**肩抬举获准；手或前臂贴墙可耐受。

**准备与起始位：**面向墙自然站立，记录用手或前臂、距墙与起始高度。

**操作步骤**

1. 记录起始症状，低位先试滑动。
2. 缓慢上滑到获准高度，避免为碰高点后仰。
3. 平稳下滑，报告熟悉痛出现的大致阶段。

**关键要领：**不强迫手一直贴墙；肩胛允许自然移动；舒适终点即回。

**常见错误：**把手离墙视为疾病；用腰后仰凑高度；把助力角当被动ROM。

**试做与候选剂量／评估协议：**3次；原主动肩 E-AXU-012/013可在同日另测，分别保存。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**桌面滑手 T-AXU-022。

**进阶：**同墙支持方式复评；主动无支持抬举另建协议。

**停止或调整条件：**肩锐痛、手麻或明显失控。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面看抬举及后仰；正面另看左右高度，不能兼得全部精测。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**抬举投影范围、周期、明显肘屈曲/整体后仰及手离墙事件。

**视觉不能直接判定：**精确肩胛上回旋、盂肱角、肩袖完整性及主动/被动贡献。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**比较固定支持下的轨迹和症状；辅助完成更多不能当作主动能力自动提高。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S025]；Wall Climbers / Table Stretch Flexion & Abduction：抬举与回落。

**证据性质与适用范围：**大学医疗中心公开示范目录。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
