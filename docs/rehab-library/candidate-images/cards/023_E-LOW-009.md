# 023 E-LOW-009｜坐姿踝内翻与外翻方向观察

**区域：**踝、足　 **等级：**L0低负荷支持—L1基础

**目标：**记录主动侧向足部运动和症状，避免用作韧带应力测试。

**器材：**稳固椅、可选足部标记

**开始条件：**没有禁止内翻/外翻的急伤或术后限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**足悬空，小腿被支持；正面或足背近景，冻结机位。

**操作步骤**

1. 让脚回到自选中间位置。
2. 小幅使足底朝内转，随后回中间。
3. 小幅使足底朝外转，再回中间。
4. 换侧记录可完成方向及症状。

**关键要领**

- 不要用手掰脚。
- 不要用整条腿旋转替代。
- 仅做允许方向，幅度小也可记录。

**常见错误**

- 髋旋转被误当成踝外翻。
- 急性外侧踝伤自动反复做末端内翻。

**试做与候选剂量／评估协议：**候选协议：每个许可方向2次，不用统一正常角度判定；方向被限制则记未安排。

**退阶：**减少范围，或暂改无痛的背屈/跖屈。

**进阶：**需要细分后足运动时转专业测量。

**停止或调整条件：**出现牵扯性锐痛、失稳感、麻木或肿胀加重时停止。

**机位与画面：**足局部正面，兼顾小腿方向。

**视觉可以观察：**足局部明显方向变化和次数，需额外足模型。

**视觉不能直接判定：**韧带松弛、真实距下角度、踝肌最大力量。

**观察不足时：**以方向完成情况和症状记录为主，不可靠角度直接省略。

**动作出处与对应原文：**[REF-S070]；Inversion/eversion：内外翻主动方向。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S070]；背景及临床边界：[LOW-S10] [LOW-S06] [LOW-S21]。动作形式、背景指南和产品测量证据按第8节分别解释。
