# 004 E-GEN-004｜前向弓步分段控制观察

**区域：**综合下肢功能与动态步序　 **等级：**L2

**目标：**以确定的前向弓步任务观察迈步、下降和回正控制；这是功能观察，不是运动项目回归测验。

**器材：**平整防滑地面、足位贴条、可触及固定扶手。

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**已获准前向迈步及双下肢负重，扶稳分腿蹲可控；无打软腿或需要人在旁扶住的情况。

**准备与起始位：**站稳，标记舒适近距离前向落点；首轮徒手，记录前脚侧、步距和扶持方式。

**操作步骤：**

1. 前迈一脚到预设落点并站稳。
2. 在当次许可范围屈髋屈膝下降，不要求后膝触地。
3. 受控起身并将前脚收回，重新站稳后再重复；换侧使用相同设置。

**关键要领：**先站稳再下降；双脚沿预设方向；范围以获准控制为限。

**常见错误：**连续抢速度；一次改变步距、深度和扶持；凭一次表现给出专项回归结论。

**试做与候选剂量／评估协议：**每侧熟悉1次后观察3次，侧间休息30–60秒；非最大速度或最大深度测试。

**退阶：**固定分腿蹲 E-LOW-023 或双脚浅蹲 E-LOW-015。

**进阶：**先同设置复评；减少扶持、增加步距或深度分别建立新协议。

**停止或调整条件：**打软腿、近跌倒、关节锐痛或不能控制收脚。

**机位与画面：**侧面全身含双脚、落点和扶手；正面另拍观察侧偏。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**迈步、起落、收脚、扶持或触地事件、完整回合和阶段时间。

**视觉不能直接判定：**真实双脚负荷、韧带应力、运动专项准备程度或组织愈合。

**观察不足时：**只保存可见片段；缺少落点或回正证据时不补成完整回合。

**复评与训练成果：**保存同任务的视觉事实＋症状/信心自报；即刻变化只称当次任务变化。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S077]；Forward Lunge：前迈、下降、回正；本卡为分段观察。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**复评与训练成果：**同步距、深度、扶持和机位比较可控回合、阶段时间及本人反应；专项回归仍需独立协议。

**依据：**[REF-S077]。动作形式、背景指南和产品测量证据按第8节分别解释。
