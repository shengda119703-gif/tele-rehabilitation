# 121 T-LOW-043｜受控落地到原地低跳进阶

**区域：**髋、膝、踝、返运动　 **等级：**L3高要求返运动

**目标：**在冲击许可后逐渐训练制动与低水平跳落地。

**器材：**防滑平地、充足空间；初期无外负荷和高台

**开始条件：**有相应运动经历且当前允许冲击；基础下蹲、单腿承重和本人信心足够，急伤保护优先。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**先用双脚、小幅度、每次站稳的版本；不得默认连续跳或单腿最大跳。

**操作步骤**

1. 从无腾空的小幅下蹲制动开始，练习稳定停住。
2. 允许后做一次极低双脚跳，落地后保持稳定。
3. 每次充分站稳、确认症状再做下一次。
4. 记录当次及随后24小时反应，再决定下次是否增加。

**关键要领**

- 先稳定，再谈高度。
- 落地后给自己停住的时间。
- 不要边失稳边追次数。

**常见错误**

- 一次看似稳定就自动升级返赛。
- 用视频高度与体重计算真实地反力峰值。

**试做与候选剂量／评估协议：**候选模板：首轮3次单独低跳，休息后最多再1小组；一般可选1—3组×3—5次，非最大高度/距离或力竭测试。

**退阶：**无腾空制动、浅蹲或提踵；无法安全落地则取消跳跃。

**进阶：**多次稳定且反应可接受后，按专业计划依次考虑连续、方向变化、单脚；不是自动通过。

**停止或调整条件：**疼痛升级、膝软、踝失稳、明显恐惧、肿胀增加或连续失控落地时停。

**机位与画面：**斜侧全身，落地点清晰，足部无需特写到丢失身体。

**视觉可以观察：**起落次数、明显失衡、停稳和任务节奏。

**视觉不能直接判定：**真实GRF、关节冲击峰值、组织愈合和完整返运动决定。

**观察不足时：**看不清时保留已确认片段、完成自述和当次感受，关闭不能支持的自动指标，不为验证追加跳跃。若当前许可、能力和环境仍符合该任务，测量缺失不自动改变等级；必要资格未确认、失稳或症状不合适时才换低阶任务。

**动作出处与对应原文：**[REF-S010]；Late-stage：跳跃/落地任务；低幅及分阶段是实施变式。
