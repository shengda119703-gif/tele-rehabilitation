# 182 T-AXU-061｜单臂轻哑铃过头肘伸

**区域：**肘伸肌群、肩与躯干　 **等级：**L2

**目标：**在获准过头位置练习肘伸负荷；不把过头持臂能力视为肩病治愈。

**器材：**可独立拿放的轻哑铃。

**单人适用：**条件独立；须能自行摆位、完成及安全卸重；需要他人保护者按第12节分流。

**开始条件：**能主动到获准过头位置且肘伸负荷允许；可用自己的另一手稳定上臂并安全放回重量。

**准备与起始位：**站稳，动作臂抬到获准过头位、屈肘使哑铃在头后；另一手轻支持上臂，头颈自然。

**操作步骤：**

1. 保持上臂大致位置，缓慢伸肘把重量举到获准终点。
2. 短停，避免仰腰或屏气。
3. 受控屈肘将哑铃落回头后舒适范围；结束时按已学会方法卸重。

**关键要领：**另一手是本人支持；小重量；不要求极限屈肘。

**常见错误：**肘外甩；哑铃碰头；无法独立卸重仍加重。

**试做与候选剂量／评估协议：**首轮每侧3次；候选1–2组×6–10次，组间60–90秒。 所有数值为项目候选模板，不是原资料统一处方或进阶阈值。

**退阶：**T-AXU-034 胸前下压，或徒手肘伸。

**进阶：**固定过头位和范围后增加可控回合，再按计划加少量重量。

**停止或调整条件：**肩肘锐痛、手麻、哑铃失控或不能独立卸重。 同时遵守第4节与第12节。

**机位与画面：**正侧或斜侧含头、肩、肘腕和哑铃；避免头部遮住动作肘。；固定相机，必要支点和器材入镜。

**视觉模块：**身体点；器材、锚点和接触需物体识别或本人确认，自动测量仍须验证。

**视觉可以观察：**肘屈伸回合、阶段时间、明显上臂移位或仰腰。

**视觉不能直接判定：**三头肌真实力量、肩关节稳定性、准确外负荷或支撑手的力。

**观察不足时：**只保存已确认阶段，缺失信息记unknown；不补造有效回合、负荷或力量。

**复评与训练成果：**固定重量、过头臂位和本人支持方式，比较有效回合与自报反应。 保存当次、练后及次日反应。

**动作出处与对应原文：**[REF-S009]；动作11 Elbow Extension：自己另一手支持上臂的过头肘伸。
