# 123 T-AXU-001｜坐位支持下的小幅躯干前屈

**区域：**腰部/胸腰整体　 **等级：**L0

**目标：**恢复已被评估为可耐受的前屈方向活动与生活弯腰信心。

**器材**

- 稳定椅

**开始条件**

- 当前计划允许前屈，试做没有让下肢症状扩散。
- 已知骨折或术后方向限制者须先得到许可。

**准备与起始位：**坐在稳定椅前部，双脚踩稳，双手放大腿；范围从小开始。

**操作步骤**

1. 吸气坐到自然位置，不刻意把腰挺到极限。
2. 呼气时双手沿大腿缓慢下滑，让躯干小幅前屈。
3. 在舒适位置停短暂后，用腿和躯干共同控制回坐直。
4. 回正后检查症状，确认恢复再做下一次。

**关键要领**

- 可用大腿提供支撑，不要求摸地。
- 动作连续平稳，不在末端弹振。
- 前屈后先坐稳，避免连续快速起落。

**常见错误**

- 为了达到统一角度继续忍受向腿放射的症状。
- 用颈部低头代替全部躯干活动或猛甩上身。

**试做与候选剂量／评估协议：**首轮试做3次；候选模板1–2组×5–8次，组间30–60秒，范围及频次须由当前计划确认。

**退阶：**减小前屈范围，靠背坐稳后只作轻微姿态变化。

**进阶：**先增加可耐受范围与生活够取，再考虑站立弯腰任务；不直接加负重。

**停止或调整条件**

- 疼痛向远端扩散、新麻木无力。
- 回正后症状仍明显升高或出现头晕。

**机位与画面：**侧面坐位，肩髋膝入镜。

**视觉可以观察**

- 整体前屈与回正次数、节奏、可见范围。

**视觉不能直接判定**

- 真实腰椎分节屈曲与椎间盘压力。
- 疼痛中央化或深层肌肉松紧。

**观察不足时：**仅按节奏陪练并收集反应；角度缺失不影响已完成次数保存。
