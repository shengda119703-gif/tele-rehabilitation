# 157 T-AXU-025｜肩胛平面抬举：空手到哑铃

**区域：**肩　 **等级：**L1

**目标：**在身体前外侧平面练习抬臂控制与渐进负荷。

**器材**

- 无或轻哑铃

**开始条件**

- 肩抬举获准，可握持所选负荷，当前无显著不稳。

**准备与起始位：**站稳或坐稳，手臂位于正侧方稍偏前的舒适平面，拇指自然偏上。

**操作步骤**

1. 先空手沿前外侧路线抬起手臂，确认舒适范围。
2. 有计划许可时持轻哑铃，以同路线平稳抬起。
3. 到目标高度短暂停顿，再慢慢放回身侧。
4. 每组后检查肩部和颈部反应。

**关键要领**

- 先在肩高以下找到控制，不强制过头。
- 肩不耸向耳朵，躯干不后仰。
- 肘自然微松，左右可分开练。

**常见错误**

- 重量太大，靠身体摆动和耸肩抬起。
- 把任何拍摄角度的投影值当作真实抬举角。

**试做与候选剂量／评估协议：**首轮空手或极轻负荷5次；候选模板2–3组×6–12次、组间60–90秒。负荷、目标高度和数量由计划确认。

**退阶：**减重、降低高度或改桌面滑手。

**进阶：**先增加可耐受范围，再小幅加重；过头范围与更高速度分别评价。

**停止或调整条件**

- 突然无力、滑脱感、锐痛或新麻木。
- 无法控制下放或练后症状持续升高。

**机位与画面：**让相机尽量正对实际运动平面；用固定机位比较投影变化。

**视觉可以观察**

- 次数、节奏、投影范围和明显屈肘/躯干代偿。

**视觉不能直接判定**

- 独立肩胛上回旋、肌腱负荷或肩袖单肌力量。

**观察不足时：**抬举平面偏离时仅计次，不要求用户反复调整才能完成一组。
