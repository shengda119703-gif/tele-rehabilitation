# 037 E-AXU-004｜站立躯干左右侧屈筛查

**区域：**腰部/胸腰整体　 **等级：**L1

**目标：**比较左右整体侧屈功能和症状，区分侧倾与明显骨盆平移。

**器材**

- 可选稳固扶手

**开始条件**

- 能稳定站立，侧屈方向没有已知禁忌。

**准备与起始位：**正面对镜头，双脚位置固定，双臂自然下垂；留出两侧空间。

**操作步骤**

1. 自然站立，记录肩髋起始位置。
2. 一侧手沿大腿向下滑，躯干缓慢向同侧侧屈到舒适位置。
3. 回到中间并短暂停顿，询问症状。
4. 另一侧重复，保持同样脚距和膝位置。

**关键要领**

- 胸口尽量朝前，减少同时转身。
- 不要故意把骨盆甩到对侧增加手的下移。
- 平稳呼吸，回中立后再换侧。

**常见错误**

- 用抬肩或屈膝代替躯干侧屈。
- 把腕点下降距离当成纯腰椎ROM或筋膜长度。

**试做与候选剂量／评估协议：**每侧最多2次观察；两侧间停10–20秒。比较须注明起始姿势一致性。

**退阶：**坐在稳定椅上作小幅侧倾，脚不离地。

**进阶：**保持条件一致复测，不用负重来增加评估末端范围。

**停止或调整条件**

- 出现新放射痛、明显头晕或站立不稳。
- 侧屈引起持续加重的局部锐痛。

**机位与画面：**正面全身，避免广角贴得过近。

**视觉可以观察**

- 肩中点到髋中点轴的投影侧倾。
- 骨盆明显平移、膝弯曲和两侧动作范围差异。

**视觉不能直接判定**

- 独立腰椎侧屈角与椎间关节运动。
- 哪条肌肉短缩或具体组织损伤。

**观察不足时：**部分点遮挡时只保留可见侧倾和主诉，不输出左右精确百分比。
