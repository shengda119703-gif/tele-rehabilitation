# 164 T-AXU-029｜推撑阶梯：墙面→固定台面→地面俯卧撑

**区域：**肩/肘/腕/躯干　 **等级：**L1—L2（依支撑高度与任务版本）

**目标：**按支撑高度渐进恢复上肢推力与全身控制。

**器材**

- 坚实墙面或固定台面
- 地面垫；可选稳定握把

**开始条件**

- 所选版本的肩肘腕和足部承重可耐受；支撑面不滑不动。
- 手腕伸展受限者的握把须稳定且获准，不临时用易滚哑铃。
- 地面版本须单独确认肩腕及前足支撑许可；墙面版本完成良好不自动表示可进入地面版本。

**准备与起始位：**从高支撑面开始，双手位置舒适、略宽于肩；脚踩稳，躯干保持可控整体线。

**操作步骤**

1. 先直臂支撑试耐受，确认腕肩和下肢没有明显不适。
2. 吸气屈肘让身体整体靠近支撑面，肘走舒适斜向路线。
3. 呼气推回，肘接近伸直但不猛锁，肩胛允许自然移动。
4. 当前高度稳定且反应合适后，另一次训练才逐级降低支撑面。

**关键要领**

- 头、胸、骨盆大致一起移动，不先探头。
- 手掌/握把稳定，肩不耸起。
- 下降和推回都可控，不在底部弹起。

**常见错误**

- 台面晃动、脚滑还继续。
- 降低高度同时大量加次数，导致腰塌或手腕疼痛。

**试做与候选剂量／评估协议：**首轮当前高度3–5次；候选模板2–3组×6–12次、组间60–90秒。支撑高度、幅度和剂量由计划确认。

**退阶：**提高支撑面、减小幅度；必要时只做短时轻支撑。

**进阶：**墙→高固定台→低台→合适地面版本；稳定后才增加次数或外载，不能只因RPE低而跳级。

高位交替抬手见 T-AXU-045，Push-up Plus见 T-AXU-053；二者改变任务阶段或单侧支撑，不和普通俯卧撑混计。

**停止或调整条件**

- 肩不稳、肘打软、腕锐痛或新麻木。
- 脚滑、支撑面移动或无法控制下降。

**机位与画面：**侧面全身，正面可补观察明显左右差异；不要求两视角才能完成。

**视觉可以观察**

- 次数、肘屈伸、整体线和节奏、明显侧偏。

**视觉不能直接判定**

- 双手实际受力、胸肩肌激活或组织耐受极限。

**观察不足时：**局部遮挡仅停对应评分；自报次数和版本仍可保存，不清空整组。
