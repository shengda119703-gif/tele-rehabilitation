# 156 T-AXU-024｜弹力带肩内旋

**区域：**肩/肩袖负荷能力　 **等级：**L1

**目标：**练习可控的内旋抗阻与外回程控制。

**器材**

- 轻弹力带
- 可靠固定锚点

**开始条件**

- 肩内旋抗阻在当前许可内；带与锚点安全。

**准备与起始位：**被测侧靠近锚点，肘屈约90°并靠身，前臂从舒适位置开始。

**操作步骤**

1. 用轻张力试握，保持身体朝前。
2. 呼气把前臂向腹前方向内转，肘位置基本不动。
3. 在舒适范围停短暂，再控制向外回到起点。
4. 完成后记录肩、肘和腕部反应，休息再重复。

**关键要领**

- 不是把肘往身后拉，也不靠转腰。
- 手腕和前臂保持自然对齐。
- 带线不摩擦颈部或身体尖锐边缘。

**常见错误**

- 用胸腰旋转把手带到腹前。
- 初始外旋过大或回程被带强拉到末端。

**试做与候选剂量／评估协议：**首轮5次轻张力；候选模板2–3组×8–12次、组间60秒。初始角、阻力及组数由计划确认。

**退阶：**减小初始伸长和动作范围，必要时采用获准轻等长。

**进阶：**先增加稳定范围，再增加阻力；换上臂角度需重新确认耐受。

**停止或调整条件**

- 肩部锐痛、不稳或上肢麻木。
- 锚点松动或带回弹不可控。

**机位与画面：**前上方/斜前方，肘腕和躯干可见。

**视觉可以观察**

- 回合次数、肘离身、明显躯干转动与速度。

**视觉不能直接判定**

- 真实内旋力矩或肩胛下肌激活。
- 二维轨迹不等于完整解剖旋转角。

**观察不足时：**仅记录可见计次和自报负荷，不因看不清轴向角阻断训练。
