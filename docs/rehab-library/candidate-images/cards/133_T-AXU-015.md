# 133 T-AXU-015｜死虫式：脚跟滑动到对侧伸展

**区域：**胸腰/躯干控制　 **等级：**L1

**目标：**在四肢活动中维持可耐受的躯干控制与呼吸。

**器材**

- 垫

**开始条件**

- 仰卧舒适，腰部与髋屈曲可耐受；选择能控制的版本。

**准备与起始位：**仰卧屈膝，双脚踩垫、双臂自然放置；首轮从单侧脚跟滑动开始。

**操作步骤**

1. 找到自然舒适的腰背位置，先正常呼吸。
2. 呼气时让一侧脚跟沿垫缓慢向远处滑动，距离以躯干可控为限。
3. 吸气控制滑回，再换侧。
4. 基础版稳定后，才按计划改为双髋膝屈起、对侧手脚小幅伸远。

**关键要领**

- 不要为追脚伸直而让腰明显拱起。
- 动作范围服从呼吸与控制，不强压腰到疼痛。
- 一次只移动计划要求的肢体。

**常见错误**

- 腿伸得太远，腰部被拉成明显后仰。
- 屏气僵住或把腹部发紧当作必须达到的机器指标。

**试做与候选剂量／评估协议：**首轮每侧3次脚跟滑动；候选模板2组×每侧5–8次，组间45–60秒。具体版本、范围和组数由计划确认。

**退阶：**缩短滑动距离，双脚始终留在地面；必要时只练支撑位呼吸。

**进阶：**先延长杠杆，再引入离地交替点地、对侧手脚伸展；不一次增加多个难度。

增加单手持轻带、另一侧肢体舒适移动的变式（见习30）；锚点可靠、方向不朝脸，先做单肢任务。视觉只看次序与明显代偿，不确认腹压/深层激活。

**停止或调整条件**

- 腰腿症状扩散或出现锐痛。
- 明显失控、屏气且无法调节，或仰卧不适。

**机位与画面：**侧面或斜前方，肩髋膝踝可见。

**视觉可以观察**

- 四肢运动次序、节奏、明显躯干姿态变化。

**视觉不能直接判定**

- 腰背压垫压力、腹横肌激活或脊柱分节稳定。

**观察不足时：**细微躯干变化不可见时按节奏陪练、自报控制感；不需机器确认肌肉收缩。
