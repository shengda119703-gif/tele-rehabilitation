# 152 T-AXU-014｜低强度多方向颈部等长

**区域：**颈部　 **等级：**L1

**目标：**在头部大致不动时练习可耐受的颈部用力与耐力。

**器材**

- 自己的手掌；无需弹力带

**开始条件**

- 颈部等长已获当前计划允许，无急性未评估创伤。
- 用户理解只需轻抵，不是最大用力测试。

**准备与起始位：**坐稳，头中立；选择额头或头侧一个获准方向，手掌轻贴。

**操作步骤**

1. 先放松呼吸，建立很轻的手头接触。
2. 逐渐轻抵手掌，让头保持大致原位而不是明显推动。
3. 保持短暂、持续呼吸，然后逐渐卸力。
4. 充分放松后再重复；换方向前重新确认症状。

**关键要领**

- 力量慢慢上来、慢慢下去。
- 手和头互相轻抵，不用全力比赛。
- 牙关和肩部尽量放松，避免屏气。

**常见错误**

- 突然发力或用手把头扳向末端。
- 机器计时完成就认为真实用力已被检测。

**试做与候选剂量／评估协议：**首轮每个选定方向2次×3秒；候选模板每方向3–5次×5秒、次间休息10–20秒；方向与力度由计划确认。

**退阶：**减小自报用力或只保持自然头位。

**进阶：**先延长少量可耐受保持，再增加重复；不通过摄像机自动升级成最大阻力。

**停止或调整条件**

- 异常头痛、眩晕或新上肢麻木无力。
- 用力时明显不适、屏气或症状持续升高。

**机位与画面：**正面或侧面头肩近景，主要检查明显位移。

**视觉可以观察**

- 头是否明显离开中立、肩耸起、保持计时。

**视觉不能直接判定**

- 真实施力、肌肉收缩、关节压缩或最大力量。

**观察不足时：**用户按开始/结束并自报轻中重用力，明确force_observed=false，不因静止而判未训练。
