# 038 E-AXU-005｜坐位骨盆相对稳定的躯干旋转筛查

**区域：**腰部/胸腰整体　 **等级：**L0–L1

**目标：**观察转身能力及症状；用功能代理区分明显骨盆随动。

**器材**

- 稳定无脚轮的椅子

**开始条件**

- 能稳定坐位，不需要通过外力强扭到终末位。

**准备与起始位：**椅子不转动，双脚落地，髋膝舒适；双手放胸前，正面或斜前方拍摄。

**操作步骤**

1. 坐稳并记录当前腰背症状。
2. 缓慢向一侧转动胸口，双膝仍大致朝前。
3. 在舒适终点停约1秒，然后回正。
4. 换侧并询问疼痛位置与是否出现下肢症状。

**关键要领**

- 想象转胸口，坐骨保持接触椅面。
- 头可自然跟随，不单靠转头完成。
- 不要用手拉椅背加力。

**常见错误**

- 整张椅子转动或脚跨出去造成假性大范围。
- 把二维肩线角当成三维轴向旋转角。

**试做与候选剂量／评估协议：**每侧1–2次；侧间休息15–20秒。无已验证三维方案时只报完成度和粗略差异。

**退阶：**减小范围，一手轻放对侧大腿作位置提示而不牵拉。

**进阶：**使用同样椅高与坐姿复测；经验证的三维方案才增加相对旋转测量。

**停止或调整条件**

- 出现锐痛、症状向下肢扩散或头晕。
- 用户感到身体被卡住而需要借手强扭。

**机位与画面：**正面或斜前方中近景，肩髋膝可见；二维只作代理。

**视觉可以观察**

- 转动方向、完整回正、明显骨盆随动。
- 可靠三维配准后可研究躯干相对骨盆旋转估计。

**视觉不能直接判定**

- 腰椎或胸椎各自的真实旋转ROM。
- 骨盆固定接触力、关节卡位或韧带松弛。

**观察不足时：**三维或骨盆观察不可靠时改为动作完成＋症状，不让用户为了一个角度反复转身。

**动作出处与对应原文：**[REF-S014]；动作4：坐位抱胸转体。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
