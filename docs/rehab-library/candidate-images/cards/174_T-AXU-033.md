# 174 T-AXU-033｜哑铃/弹力带肘屈曲

**区域：**肘/前臂　 **等级：**L1

**目标：**逐步建立屈肘负荷与下放控制，供生活及力量训练。

**器材**

- 哑铃、水瓶或轻弹力带

**开始条件**

- 屈肘抗阻与握持可耐受；前臂握法按计划选择。

**准备与起始位：**坐稳或站稳，上臂靠近身侧；首选手腕自然、前臂中立或舒适旋后位。

**操作步骤**

1. 先用轻负荷保持起始姿势，不锁死肘。
2. 呼气弯肘，让负荷向肩方向移动。
3. 在可控制范围停止，再吸气缓慢伸肘下放。
4. 每组后记录肘内外侧、腕部症状与费力。

**关键要领**

- 上臂不大幅前后摆，身体不甩。
- 手腕尽量与前臂自然对齐。
- 回程比自由落下慢，保持握稳。

**常见错误**

- 借腰后仰和肩前举抬起过重负荷。
- 前臂握法变化却仍把两次训练当完全同条件。

**试做与候选剂量／评估协议：**首轮轻负荷5次；候选模板2–3组×8–12次、组间60–90秒。实际重量、握法和幅度须按计划。

**退阶：**减重、缩短范围或空手屈伸。

**进阶：**先增加稳定重复再加少量负荷；锤式与旋后握法分别记录，不能盲目切换。

**停止或调整条件**

- 肘或腕锐痛、麻木、握持失稳。
- 无法控制下放或代偿明显且减量后仍无法完成。

**机位与画面：**侧面正对屈伸平面，肩肘腕与躯干可见。

**视觉可以观察**

- 屈伸角代理、次数、节奏与明显肩躯干代偿。

**视觉不能直接判定**

- 真实最大肌力、肌腱载荷和MMT等级。

**观察不足时：**器械遮挡手腕时保留次数和自报负荷；不以速度下降自动判组织损伤。
