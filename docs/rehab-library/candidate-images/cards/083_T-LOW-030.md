# 083 T-LOW-030｜短杠杆哥本哈根内收支撑

**区域：**髋内收、躯干侧向控制　 **等级：**L2负重能力

**目标：**在许可人群中渐进训练内收支撑能力；不承诺治疗全部腹股沟痛。

**器材：**无轮无摇晃、合适承重、固定靠墙的低长凳或牢固桌椅；防滑软垫；地垫

**开始条件：**已经能耐受内收基础训练及侧向支撑；肩肘腕、髋膝接触处允许承重。家庭支撑无法核验稳定承重时不分配。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**前臂支地；上侧膝周/近端小腿屈曲放软垫上承托，避开疼痛关节线和术区；下侧腿先留地辅助。

**操作步骤**

1. 徒手测试家具各方向不移动，软垫不滑。
2. 摆好短杠杆上腿和前臂，下腿支地帮助。
3. 缓慢抬起骨盆到可控位置。
4. 短时保持后受控落地；可耐受时才减少下腿帮助。

**关键要领**

- 上腿为膝周/近端小腿支撑，不把脚踝硬压家具。
- 肩在肘上方附近舒适承重。
- 每次保留安全落地余量。

**常见错误**

- 用有轮、会摇、承重未知的餐椅或折叠桌。
- 直接悬空下腿并长时间硬撑。

**试做与候选剂量／评估协议：**候选模板：首轮每侧2—3次、每次约3—5秒；一般1—3组×3—6次短保持或受控起落。为亚最大训练，不做最大保持/最大负荷测试。

**退阶：**侧卧内收、轻夹垫，或下腿更多支地帮助。

单人版本保留固定家具支持，禁止依赖他人托腿；无法独立摆位/安全落回者改 T-LOW-028/029。不把此项目设为所有用户默认候选。

**进阶：**先减少下腿帮助或延长少量保持；是否改长杠杆须重新检查髋、膝、踝与当前伤情。

**停止或调整条件：**家具/软垫移动、腹股沟锐痛、肩肘痛、膝接触痛或无法缓慢落地时立即停。

**机位与画面：**面对身体正侧，全身及支撑接触点可见。

**视觉可以观察：**保持时间、骨盆明显下降、上腿接触位置与完成次数。

**视觉不能直接判定：**真实内收力、家具承重余量、肌腱应力和左右肌力比。

**观察不足时：**不可靠画面改计时和用户确认；不能辨认家具安全时改基础内收动作，不能用模型猜承重。
