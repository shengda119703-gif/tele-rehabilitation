# 058 E-AXU-018｜前臂主动旋前/旋后筛查

**区域：**肘/前臂　 **等级：**L0–L1

**目标：**记录掌面转向和粗略旋转能力，避免用COCO腕点假测长轴旋转。

**器材**

- 稳定椅或桌面

**开始条件**

- 当前允许前臂旋转；近期骨折或尺桡关节术后按批准范围。

**准备与起始位：**肘屈约90°靠身，前臂水平，手掌张开但不绷紧；近景可见肘腕和手掌。

**操作步骤**

1. 从拇指朝上的舒适中立位开始。
2. 缓慢转到掌心向上的舒适位置，再回中立。
3. 缓慢转到掌心向下的舒适位置，再回中立。
4. 报告腕或肘是否疼痛、卡顿；两方向分别保存。

**关键要领**

- 上臂不随手掌向外张开。
- 肘位置和弯曲角尽量稳定。
- 手腕保持自然，不用尺桡偏替代旋转。

**常见错误**

- 肩内外旋代替前臂旋转。
- 把Hand和Body各自world坐标直接拼接计算角度。

**试做与候选剂量／评估协议：**每方向1–2次，间隔15秒；未验证三维测量时仅报告掌面转向、完成和粗略范围。

**退阶：**前臂支撑桌面边缘，只做舒适小范围。

**进阶：**同姿势复测；负重旋转是训练进阶，不是首轮ROM必需项。

**停止或调整条件**

- 出现腕尺侧或肘部尖锐痛、明显卡住。
- 新的麻木或无法控制手中物体。

**机位与画面：**前方或斜前方近景；同一图像坐标定位肘腕，Hand提供掌部方向。

**视觉可以观察**

- 掌面转向、肘/上臂明显移动和完成次数。

**视觉不能直接判定**

- 未经验证的精确尺桡关节旋转角。
- 远端尺桡关节稳定性和TFCC状态。

**观察不足时：**掌面失跟时记录用户能否转向目标，不由遮挡预测补成完整旋转。

**动作出处与对应原文：**[REF-S016]；主动旋前/旋后、腕掌屈/背伸、桡偏/尺偏。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
