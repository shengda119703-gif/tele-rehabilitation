# 055 E-AXU-028｜俯卧I/Y/T/W上肢控制观察

**区域：**肩带、肩、上背　 **等级：**L1

**目标：**观察各手臂路线能否主动抬起与回落；不输出选择性肌肉激活。

**器材：**垫、额头软垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**俯卧及肩相应路线允许，能自行上下地；过顶Y路线不获准则不测。

**准备与起始位：**额头支撑、胸腹落垫；每次选一条路线：I双臂沿体侧、Y前外上方、T侧方、W屈肘外开。记录臂位和获准幅度。

**操作步骤：**

1. 空手摆好一条获准路线；I、Y、T、W分开观察。
2. 轻抬手臂，头颈与躯干留在支撑面。
3. 受控落回，再重新摆位；不要求连续完成四条路线。

**关键要领：**低高度即可；不抬头顶腰；路线分开保存。

**常见错误：**凭Y完成就视为W外旋正常；胸部抬起凑高度。

**试做与候选剂量／评估协议：**每个选定路线3次，顶部约2秒；首轮可只选1–2条路线。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**站姿低位手臂路线或桌面支持抬举。

**进阶：**同路线无负重复评；负重观察另建协议。

**停止或调整条件：**肩前锐痛、颈部不适或手麻。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面/斜上方含额头、躯干、肘腕；上方手臂轨迹与离地高度应分机位观察。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**手臂路线、起落、明显抬头/顶腰、不同路线完成情况。

**视觉不能直接判定：**肩胛精确旋转、冈上肌/下斜方肌出力及肌力等级。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同路线和幅度比较可控回合、保持和自报反应，不能比较不同字母的总分。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S025]；Prone I’s, W’s, T’s, Y’s：四条俯卧路线分别登记。

**证据性质与适用范围：**大学医疗中心公开示范目录。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S025]；背景及临床边界：[OBS-S04] [OBS-S07]。动作形式、背景指南和产品测量证据按第8节分别解释。
