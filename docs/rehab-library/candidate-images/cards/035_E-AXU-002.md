# 035 E-AXU-002｜扶持重心转移与小幅原地抬脚

**区域：**骶髂/腰骨盆　 **等级：**L0–L1

**目标：**观察左右承重转换的任务耐受，收集站立和转移时的熟悉症状。

**器材**

- 固定台面或稳固扶手

**开始条件**

- 能在扶持下站立；足踝和膝可承受当前站立负荷。
- 不把此任务作为平衡极限挑战或骶髂诱发试验。

**准备与起始位：**面对固定台面，双脚约髋宽，双手可随时扶稳；正面拍到躯干和双脚。

**操作步骤**

1. 先双脚站稳，报告当前腰臀及下肢症状。
2. 扶着台面把重心缓慢移向一侧，另一脚仅轻轻减重。
3. 若舒适且稳定，轻抬非承重侧脚后立即放回，不追求单腿久站。
4. 换侧重复，并比较是否出现熟悉疼痛、恐惧或明显困难。

**关键要领**

- 移动缓慢，双手保留支撑。
- 躯干自然直立，不靠突然侧倒完成转移。
- 抬脚之前先确认承重侧膝踝稳定。

**常见错误**

- 把扶手松开进行未经安排的单腿平衡。
- 从肩髋高低或摇晃直接诊断SIJ异常。

**试做与候选剂量／评估协议：**每侧先1次；必要时各补1次，间歇20秒。只记录任务条件、完成和症状。

**退阶：**双脚始终接触地面，仅做轻微重心转移。

**进阶：**在同一扶持条件复测；独立平衡测试由下肢动作库另行选择。

**停止或调整条件**

- 出现腿打软、明显头晕或接近失去平衡。
- 承重引起新的尖锐膝踝痛或持续加重的腰臀痛。

**机位与画面：**正面全身，扶手不能遮住全部髋膝。

**视觉可以观察**

- 转移方向、抬脚事件、明显躯干偏移。
- 是否一直使用扶手及完成次数。

**视觉不能直接判定**

- 足底左右受力百分比。
- 骶髂关节疼痛来源或骨盆是否需要复位。

**观察不足时：**扶手遮挡时保留用户对完成和症状的报告，不追求精确不对称评分。
