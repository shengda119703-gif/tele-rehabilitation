# 089 T-LOW-014｜哑铃/壶铃罗马尼亚硬拉

**区域：**髋、下肢后侧、躯干　 **等级：**L2负重能力

**目标：**在可控负荷下训练髋铰链和后侧链负重能力。

**器材：**一只壶铃或两只哑铃、平整防滑地面、合适放置架

**开始条件：**已掌握徒手髋铰链，能安全提放器械；当前允许后侧链负荷。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**负荷贴近身体，脚距舒适；不要求器械触地。

**操作步骤**

1. 先轻负荷站稳，膝微屈。
2. 臀部后移，让器械沿腿前缓慢下降。
3. 到仍能控制且后侧舒适牵伸的位置停止下降。
4. 脚掌稳定，用受控髋伸展站回，再安全放置器械。

**关键要领**

- 负荷靠近腿。
- 膝维持轻屈，不锁死。
- 每次在可控终点回程。

**常见错误**

- 为触地继续弯腰。
- 器械离身太远或突然甩起。

**试做与候选剂量／评估协议：**候选模板：首轮轻负荷3—5次；一般2—3组×6—10次，组间恢复到能保持同样轨迹，明确不是最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**徒手触墙或减少下降范围，必要时把器械放高便于拿取。

**进阶：**先保持同范围重复，再小幅增加重量；不同时加深和加重。

**停止或调整条件：**锐痛、向腿放射、握持松脱或回程明显失控时结束。

**机位与画面：**侧面全身，器械和双足可见。

**视觉可以观察：**次数、髋铰链范围、膝位和器械路径。

**视觉不能直接判定：**真实髋/腰力矩、椎间负荷、肌腱力及最大力量。

**观察不足时：**重量由用户确认；只保存可见计次和主观用力，不用视频估算1RM。

**动作出处与对应原文：**[REF-S029]；Romanian Deadlift：从站姿开始的受控髋铰链。

**证据性质与适用范围：**专业学会训练技术手册摘录。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
