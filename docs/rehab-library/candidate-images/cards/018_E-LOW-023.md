# 018 E-LOW-023｜扶稳分腿蹲控制观察

**区域：**髋、膝、踝、躯干　 **等级：**L1–L2

**目标：**观察前后脚负重姿势中的下降、起身及明显侧偏；这是项目功能观察，不是韧带检查。

**器材：**固定扶手、足位贴条、可选深度目标

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**获准双下肢承重，基础浅蹲可控；无近期打软腿。

**准备与起始位：**平地前后脚分开，双脚不交叉；记录足距、前脚侧和扶持方式。

**操作步骤**

1. 扶稳并先完成一次小幅熟悉动作。
2. 以舒适速度屈髋屈膝下降到预定目标，前脚跟留地。
3. 受控站回，重新站稳；同条件观察另一侧。

**关键要领：**先站稳再蹲；膝沿脚方向；范围以当次许可为限。

**常见错误：**足距每次改变；后脚抬高却沿用原协议；为了更低而大幅转身。

**试做与候选剂量／评估协议：**候选观察：每侧3次；默认不加外负重，侧间休息30–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**双脚浅蹲 E-LOW-015 或增加双手支撑。

**进阶：**固定深度后复评；后脚抬高应另建协议，不能直接合并。

**停止或调整条件：**膝/踝失稳、熟悉痛持续上升或不能受控起身。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面看起落和深度代理；正面另拍看侧偏，两个机位分别报告。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**完整回合、下降/上升时间、规定平面的膝角代理、明显躯干侧倾。

**视觉不能直接判定：**双脚负荷比例、膝内旋力矩、足旋前程度及疼痛来源。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同足位、支撑和深度下比较完成回合、节奏、侧偏事件及自报症状。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S004]；Static lunge：扶稳分腿下降与回正。

**证据性质与适用范围：**专科医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
