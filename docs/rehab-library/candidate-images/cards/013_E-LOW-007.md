# 013 E-LOW-007｜坐姿主动伸膝活动观察

**区域：**膝　 **等级：**L0低负荷支持

**目标：**记录主动伸膝终点和维持能力。

**器材：**稳固椅

**开始条件：**坐位安全；开放链伸膝符合现阶段限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面，坐到大腿受支持而小腿可摆动的位置。

**操作步骤**

1. 双脚自然落地，保持坐稳。
2. 缓慢把一侧膝伸至主动舒适终点。
3. 短暂停留后缓慢放下。
4. 另一侧同样完成并记录前膝或后膝症状。

**关键要领**

- 不把大腿整段抬离椅面。
- 不要快速踢腿。
- 终点不必强锁膝。

**常见错误**

- 后仰身体甩起小腿。
- 缺少被动参考却把未伸直诊断为伸膝迟滞。

**试做与候选剂量／评估协议：**候选协议：每侧2次，终点短停1—2秒用于观察，非耐力到力竭测试；记录椅高和大腿姿势。

**退阶：**缩小角度或改仰卧支垫短弧伸膝。

**进阶：**如需区别被动受限与主动控制不足，由专业人员补参考。

**停止或调整条件：**新锐痛、卡锁、明显弹响伴痛或无法安全落脚时停止。

**机位与画面：**侧面可见髋膝踝。

**视觉可以观察：**膝投影角、终点波动、动作时间。

**视觉不能直接判定：**股四头肌最大力量、韧带稳定性及独立迟滞诊断。

**观察不足时：**记录能否主动伸到指定位置与症状，不输出不可靠角度。

**动作出处与对应原文：**[REF-S006]；Leg Extensions：坐姿主动伸膝。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S006]；背景及临床边界：[LOW-S09] [LOW-S21]。动作形式、背景指南和产品测量证据按第8节分别解释。
