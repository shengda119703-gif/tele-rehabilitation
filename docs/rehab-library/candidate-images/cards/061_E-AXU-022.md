# 061 E-AXU-022｜已知轻负荷弯举功能任务

**区域：**肘/上肢　 **等级：**L1–L2

**目标：**记录在指定外载、动作范围和节奏下的功能表现；不替代MMT。

**器材**

- 质量已知且握持牢固的小哑铃或水瓶

**开始条件**

- 当前允许轻负荷屈肘；能握稳物体且无急性肘腕痛。

**准备与起始位：**坐稳或站稳，上臂靠身；输入物体实际或标称质量及是否为估计值，侧面拍摄。

**操作步骤**

1. 先空手弯举确认范围，再选择明显轻于极限的负荷。
2. 按自然平稳节奏屈肘，将物体送近肩。
3. 控制下放至允许范围，保持肩和躯干基本稳定。
4. 按预定少量次数结束，报告费力、疼痛及剩余余力。

**关键要领**

- 不甩腰、不用另一手帮助。
- 手腕大致中立，物体握稳。
- 呼气抬起、吸气放下，避免憋气冲刺。

**常见错误**

- 把未知水量或物体体积当精确质量。
- 由动作较慢直接断言肌力低或组织无法耐受。

**试做与候选剂量／评估协议：**空手1–2次后，候选观察为3–5次轻负荷；休息60秒。不是做到力竭，不输出MMT等级或1RM。

**退阶：**减轻重量、缩小范围或改为空手任务。

**进阶：**复测须同重量、姿势和范围；增加重量后建立新条件记录。

**停止或调整条件**

- 握持失稳、锐痛或新的麻木。
- 躯干必须明显摆动，或无法控制下放。

**机位与画面：**正对屈伸平面，肩肘腕、躯干和物体可见。

**视觉可以观察**

- 可见范围、次数、速度、下放控制和明显代偿。

**视觉不能直接判定**

- 真实最大自主力量、疼痛抑制程度和组织耐受阈值。
- 仅凭重量与速度无法唯一确定肌肉力量。

**观察不足时：**计时/点位不可靠时保留负荷、完成次数自报和症状，不转换为虚假力量评分。

**动作出处与对应原文：**[REF-S009]；Elbow Flexion：已知轻负荷弯举。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
