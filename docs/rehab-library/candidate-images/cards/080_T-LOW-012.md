# 080 T-LOW-012｜稳定长凳髋推：徒手至哑铃/杠铃

**区域：**髋　 **等级：**L2负重能力—L3高要求返运动

**目标：**在足够能力和设备条件下增加髋伸展负荷。

**器材：**承重足够、无轮无晃动并固定靠墙的长凳；防滑垫；可选哑铃、壶铃或带护垫杠铃

**开始条件：**已熟练桥式/髋推，能安全放置及卸下负荷；肩背和骨盆接触处可耐受。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**上背受凳支持而非颈部；足稳定；杠铃装片有卡扣并设可安全结束的位置。

**操作步骤**

1. 先徒手确认长凳稳定和上下路径。
2. 把可控负荷稳妥置于髋前并用手防滚，不压腹部。
3. 双脚支撑，缓慢抬髋到躯干舒适位置。
4. 控制下落，组末稳妥卸下负荷再起身。

**关键要领**

- 颈部不顶凳。
- 顶端不把腰硬拱。
- 负荷始终防滚。

**常见错误**

- 用轻型家用凳承重并靠摇晃调整。
- 负荷压腹、颈部或术区。

**试做与候选剂量／评估协议：**候选模板：先徒手3次、轻负荷3—5次；一般2—3组×6—10次，保留可控余量，不测试最大髋推。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**地面双脚桥式，或降低高度并移除负荷。

**进阶：**保持相同范围和控制后小幅加重；不能只因原来力量好就直接恢复旧重量。

**停止或调整条件：**凳移动、负荷滚动、接触处疼痛、腰髋锐痛或回程失控时立即结束。

**机位与画面：**侧面全身，支撑凳和负荷可见。

**视觉可以观察：**髋推次数、幅度、节奏与支撑移动。

**视觉不能直接判定：**真实臀肌力、腰椎剪切力、骨盆承重和重量真实性。

**观察不足时：**保留负荷自报与完成次数；视觉不可靠时只陪练，不尝试识别最大力。
