# 177 T-AXU-036｜前臂支撑的负重腕掌屈

**区域：**腕/前臂屈肌　 **等级：**L1

**目标：**建立可耐受的腕屈曲负荷与下降控制。

**器材**

- 桌面
- 轻小哑铃或小水瓶

**开始条件**

- 腕掌屈和握持获准；肘内侧或腕部症状适合当前轻负荷。

**准备与起始位：**掌心向上，前臂放稳，手腕在桌边外；轻物稳握于手掌，不让负荷滚到指尖。

**操作步骤**

1. 先空手掌屈回到中立，确认舒适范围。
2. 持轻负荷缓慢向掌侧弯腕，前臂保持桌面接触。
3. 在可控位置停止，再缓慢放回允许范围。
4. 放下重量休息，记录腕掌侧及肘内侧反应。

**关键要领**

- 不靠肘抬起或身体前倾。
- 手腕不同时明显尺偏/桡偏。
- 握物稳但不必最大抓握，呼吸自然。

**常见错误**

- 让重量滚到指尖，再用抓指代替腕屈。
- 下放被重量突然拉到过伸末端。

**试做与候选剂量／评估协议：**首轮轻负荷5次；候选模板1–3组×8–15次、组间45–60秒。重量与范围按当前计划，不自动套所有肘腕疾病。

**退阶：**空手或减小范围，必要时更多支撑。

**进阶：**先稳定动作与耐受，再小幅加重；延长前臂杠杆/伸肘须独立记录。

**停止或调整条件**

- 腕掌侧锐痛、肘内侧疼痛明显升高或手麻。
- 物体将滑落、回程不能控制。

**机位与画面：**腕侧面近景，前臂和掌部可见。

**视觉可以观察**

- 投影掌屈范围、次数、节奏和前臂抬起。

**视觉不能直接判定**

- 屈肌腱实际负荷、握力或腕管状态。

**观察不足时：**Hand受器械遮挡时计时陪练并自报完成，不给虚假腕角。
