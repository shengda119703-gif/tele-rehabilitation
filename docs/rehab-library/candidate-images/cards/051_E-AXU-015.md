# 051 E-AXU-015｜肩水平内收/水平外展功能筛查

**区域：**肩　 **等级：**L1

**目标：**评估手臂在身前开合与跨胸够取能力。

**器材**

- 可选稳定椅

**开始条件**

- 能舒适抬臂到计划高度；若肩高位置不耐受可降低高度。

**准备与起始位：**坐稳或站稳，一臂在身前抬起，肘可轻弯；手机前上方拍到两肩与手臂。

**操作步骤**

1. 把被测上臂抬到舒适高度，记录起始位置。
2. 缓慢跨向身体对侧，完成水平内收，不用另一手拉。
3. 回到起点后向外打开，到舒适限度即止。
4. 分别记录开合范围、疼痛和是否必须转动躯干。

**关键要领**

- 躯干尽量朝前，肩不强行向后夹。
- 上臂高度尽量一致，避免抬高或掉下。
- 不强追手臂到背后。

**常见错误**

- 躯干跟着大幅转动造成更大开合。
- 从腕点到胸口距离直接推断肩关节囊或胸肌长度。

**试做与候选剂量／评估协议：**每个允许方向1–2次；间隔20秒。高度与肘角须记入结果，二维优先报告功能范围。

**退阶：**降低抬臂高度或仅完成跨胸生活够取。

**进阶：**稳定同高度复测；只有输入有效才研究三维水平活动角。

**停止或调整条件**

- 肩前方锐痛、滑脱感或新麻木。
- 手臂无法保持基本高度而明显失控。

**机位与画面：**前上方或斜前方；二维不强行生成水平面精确ROM。

**视觉可以观察**

- 开合方向、完成、上臂高度变化及明显躯干随转。

**视觉不能直接判定**

- 准确盂肱水平ROM或肩胛胸廓分量。
- 胸肌短缩、撞击或肩锁关节病变确诊。

**观察不足时：**保留可完成的方向和疼痛信息，不因一个方向遮挡删除另一方向结果。

**动作出处与对应原文：**[REF-S025] [REF-S085] [REF-S028]；Shoulder ROM、Wall Climbers及主动抬举路线；具体平面另参Stanford肩检查。

**证据性质与适用范围：**大学医疗中心公开示范目录、大学医学院临床技术说明、大学医疗中心动作手册。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
