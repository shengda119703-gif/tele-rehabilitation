# 086 T-LOW-049｜扶稳单腿站立加对侧髋外展顶墙

**区域：**髋外展、单腿支撑、腰骨盆　 **等级：**L1–L2

**目标：**练习支撑侧稳站和对侧外展轻等长对抗，不换算臀中肌力。

**器材：**墙、软垫、固定扶手

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**单腿支撑和对侧髋外展允许；近跌倒者改双脚版。

**准备与起始位：**靠墙侧腿膝弯曲，外侧大腿/膝周软垫轻触墙；另一腿支撑，手扶固定支撑。

**操作步骤**

1. 先双脚站稳并摆好软垫。
2. 靠墙侧脚轻离地，外侧轻顶墙。
3. 短停后卸力、脚落地重置；换侧。

**关键要领：**轻顶；不侧倒；扶手保留。

**常见错误：**用全身挤墙；屏气；把支撑腿和顶墙腿混为同侧训练。

**试做与候选剂量／评估协议：**首轮每侧2次×3秒；候选1–2组×3–5次、每次5–10秒，休息45–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**双脚站立轻顶墙或 T-LOW-006。

**进阶：**同条件延长少量保持；不自动撤扶手加阻力。

**停止或调整条件：**髋膝痛、支撑踝不稳。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正面含双髋、双膝足和墙；腿墙接触需局部确认。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点＋接触确认/陪练；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**单足离地、粗躯干侧倾、保持及落脚。

**视觉不能直接判定：**墙压、臀中肌等长力量、真实骨盆水平。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**保存支撑腿与顶墙腿两个字段；跟踪同条件保持与症状。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S046]；Lateral Band Walks / Isometric Single-leg Wall Lean。
