# 167 T-AXU-052｜墙面持球小圈与短时支持

**区域：**肩带、上肢闭链　 **等级：**L1–L2

**目标：**训练墙面接触下的手部路线控制，替代需要他人推动的部分肩部扰动任务。

**器材：**墙、轻软球；可用毛巾退阶

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**墙面轻承重允许，肩腕可耐受；球可自行放置和取下。

**准备与起始位：**球在手和墙之间，手高低于或接近肩的获准位置；站距稳定。

**操作步骤**

1. 轻抵球短停，确认不会滑走。
2. 小范围顺时针画圈，停住。
3. 逆时针画圈；结束先卸力再拿下球。

**关键要领：**小圈慢做；不追球；躯干稳定。

**常见错误：**前移身体猛加墙压；使用过大易滚失控的球。

**试做与候选剂量／评估协议：**首轮各方向3圈；候选1–2组×各5–8圈或5–10秒短支持，择一；休息45–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**毛巾小圈或双手墙面轻支持。

**进阶：**先增控制回合，再改变高度/范围中的一项。

**停止或调整条件：**肩腕疼痛、球失控或明显疲劳。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正面手球轨迹；身体承重姿态需侧面另看。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点＋球/手近景；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**圈数、方向、停顿、可见球失控；接触需物体/局部确认。

**视觉不能直接判定：**墙压、肩胛精确运动、肌肉发力是否充分。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**关联 E-AXU-027；同球、手高与站距复评。 统一保存当次、练后和次日反应，长期判断按第12.5节。
