# 028 E-LOW-029｜扶稳提踵短时保持观察

**区域：**踝、小腿、负荷耐受　 **等级：**L1–L2

**目标：**观察特定提踵高度能否短时维持，区分任务时间与力竭耐力。

**器材：**平地、固定扶手

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**获准提踵；能主动抬跟并受控放回；急性跟腱伤尚未明确时不进入。

**准备与起始位：**先双脚，选定可控高度；单脚版需另确认；记录膝位和扶持。

**操作步骤**

1. 缓慢抬跟到本次目标。
2. 按计划短时保持，出现明显下沉或症状时主动落回。
3. 休息后再试；不追求最大维持时间。

**关键要领：**自然呼吸；保持目标一致；有余量结束。

**常见错误：**把抓扶手提起身体当提踵；将可见保持时间当肌肉等长力。

**试做与候选剂量／评估协议：**候选2次×5–10秒，间歇30–60秒；本项目观察，不继承记录48的耐力差值阈值。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**降低高度或双脚/坐位版本。

**进阶：**固定目标复评；延长时间另记，不自动到力竭。

**停止或调整条件：**跟腱锐痛、突然推蹬无力或支撑不稳。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正侧足近景及扶手；高度必须有足跟可见证据。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**足部近景＋计时；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**可见目标范围内保持时长、明显下沉、提前结束。

**视觉不能直接判定：**真实等长出力、肌腱结构及疼痛值。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同时保存计划时长、实际已观察时长、是否提前终止与本人症状；达上限标为封顶。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S021]；Isometric heel raise：提踵保持；本卡不作最大耐力测试。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S021]；背景及临床边界：[LOW-S10]。动作形式、背景指南和产品测量证据按第8节分别解释。

**设计与见习追溯：**[OBS-S01] [OBS-S02]；见习表记录32、48；本库单人设置、阶段规则与候选量用于实施登记，见习经历和项目设计不属于临床疗效证据。
