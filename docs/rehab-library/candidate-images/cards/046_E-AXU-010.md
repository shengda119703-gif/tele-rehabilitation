# 046 E-AXU-010｜颈部主动左右侧屈筛查

**区域：**颈部　 **等级：**L0–L1

**目标：**观察左右头部侧倾与抬肩代偿，收集症状。

**器材**

- 稳定椅

**开始条件**

- 能保持稳定坐位；没有当前需要先处理的颈部创伤或新神经症状。

**准备与起始位：**正面头肩近景，眼睛平视，双肩自然，先记录面部和躯干中立位。

**操作步骤**

1. 缓慢让一侧耳朵朝同侧肩方向移动，不需真正接触。
2. 在舒适范围停约1秒并回正。
3. 报告是否出现局部牵拉、熟悉疼痛或手臂症状。
4. 另一侧以相同速度完成。

**关键要领**

- 鼻尖大致朝前，不同时扭头。
- 肩不主动抬向耳朵。
- 保持呼吸，不用手拉头。

**常见错误**

- 侧屈同时明显转头或抬肩。
- 将左右角度不同直接视为病变证据。

**试做与候选剂量／评估协议：**每侧1–2次；侧间15秒。报告头相对躯干的近似侧倾与症状，不做强拉伸测试。

**退阶：**只做较小范围，靠背坐稳。

**进阶：**同条件复测，不用外加压力扩大角度。

**停止或调整条件**

- 出现眩晕、视觉异常或新的上肢放射症状。
- 颈部突然锐痛或动作后持续恶化。

**机位与画面：**正面近景，双肩与整张脸可见。

**视觉可以观察**

- 面部侧倾、肩线变化、回到中立的过程。

**视觉不能直接判定**

- 独立颈椎节段侧屈与组织长度。
- 是否存在神经根病或肌肉痉挛。

**观察不足时：**局部关键点短缺时只隐藏角度，保留方向、完成和症状。

**动作出处与对应原文：**[REF-S012]；Side flexion / Rotation：主动舒适范围。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
