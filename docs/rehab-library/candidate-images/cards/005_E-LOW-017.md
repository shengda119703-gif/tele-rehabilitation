# 005 E-LOW-017｜4米常速步行

**区域：**综合下肢、步态　 **等级：**L1基础

**目标：**记录固定路径常速行走能力。

**器材：**4米实测通道、起终点贴条、平整地面；允许原有助行器

**开始条件：**能安全通过通道，无需相机跟随而制造绊倒风险。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**记录4米静止起步协议，起止标记与完整路段尽量入镜。

**操作步骤**

1. 用卷尺确认路径并清除障碍。
2. 从起线站稳，按平时速度走，使用需要的助行器。
3. 越过终线后继续几步再停。
4. 休息后按同法完成第二次并记录症状。

**关键要领**

- 按日常速度，不比赛。
- 看前方，不盯相机。
- 按平时需要使用助行器。

**常见错误**

- 未实测距离却输出精确米每秒。
- 把转弯时间混入直线速度。

**试做与候选剂量／评估协议：**协议：通常2次，记录每次时间和所用助行器；起点按足开始移动、终点按足完整越线的选定规则。场地缩短需另设协议。

**退阶：**改较短真实距离的家庭观察，或只记录安全步行片段。

**进阶：**需要耐力评价时另开合适协议，不由4米成绩自动准许跑步。

**停止或调整条件：**明显眩晕、胸部不适、新发腿软、失稳或症状显著加重时停。

**机位与画面：**侧面或斜侧广角，起终点明确，无需追拍。

**视觉可以观察：**在标定/时钟可靠时的通过时长、速度和粗步频。

**视觉不能直接判定：**精确地反力、每步关节力矩、仅踝点下准确着地时刻。

**观察不足时：**起止难识别则用原录像人工/用户计时；无尺度仅输出完成情况。

**动作出处与对应原文：**[REF-S057]；Gait speed（4m）/ Balance tests（窄基底与串联）。

**证据性质与适用范围：**官方标准测试协议。测试动作和出处可追溯；本卡的单人实施、自动计时/角度与评分一致性仍须验证。
