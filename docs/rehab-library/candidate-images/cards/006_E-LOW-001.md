# 006 E-LOW-001｜扶稳站姿主动屈髋

**区域：**髋　 **等级：**L0低负荷支持—L1基础

**目标：**比较抬膝活动表现、症状及躯干代偿，不输出独立髋关节诊断。

**器材：**无轮稳固椅背或固定台面

**开始条件：**能安全站立并按许可单腿短暂承重。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧身面对相机，一手轻扶；明确左右侧和可接受的自选幅度。

**操作步骤**

1. 双脚落地站稳，先记录自然站姿。
2. 保持躯干舒适直立，缓慢抬一侧膝。
3. 达到主动舒适终点后短暂停留，不用手抱拉。
4. 缓慢放回；休息后以同样方式测另一侧。

**关键要领**

- 轻扶用于平衡，不大力拉起身体。
- 膝向前抬，身体不要刻意后仰。
- 出现熟悉症状时说出位置和变化。

**常见错误**

- 后仰腰部来增加表面抬腿角。
- 跳起或用手提腿，被当成主动活动。

**试做与候选剂量／评估协议：**候选评估协议：每侧先熟悉1次，再做2次缓慢主动运动；间歇至站稳。保留最佳可观察次和重复差异，不能用一次失误判异常。

**退阶：**改坐位抬膝并标记体位改变。

**进阶：**仅在目标需要时补仰卧屈髋或有固定骨盆条件的精测。

**停止或调整条件：**新出现锐痛、明显夹卡、腿软或失衡即停止该方向；不为追求角度继续。

**机位与画面：**侧面全身，髋与膝无遮挡。

**视觉可以观察：**抬膝次数、躯干—大腿投影角、侧别和明显后仰。

**视觉不能直接判定：**骨盆真实旋转、独立髋ROM、关节内病变和实际支撑力。

**观察不足时：**看不清时保存完成情况与症状；改用自述可达位置，不要求整套重做。

**动作出处与对应原文：**[REF-S086]；Standing heel peel：扶稳站姿屈髋；抬膝高度按本卡许可限制。

**证据性质与适用范围：**专科医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
