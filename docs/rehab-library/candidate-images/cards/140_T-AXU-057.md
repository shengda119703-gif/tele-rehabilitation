# 140 T-AXU-057｜稳定地面高跪位Pallof抗旋转

**区域：**躯干、肩、膝接触　 **等级：**L1–L2

**目标：**用稳定地面和固定弹力带替代跪在瑜伽球上由他人推扰；不是等效刺激。

**器材：**膝垫、可靠侧方低位锚点、轻弹力带

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**双膝接触和躯干抗旋转允许，跪位可自行退出；锚点可靠。

**准备与起始位：**双膝在地垫，胸口朝前，带从侧方牵引，手在胸前较低位。

**操作步骤**

1. 先轻张力胸前持带，身体自然。
2. 缓慢把手前推一小段，继续呼吸。
3. 控制收回；卸张力后转向换侧。

**关键要领：**稳定地面；轻阻；不憋气。

**常见错误：**瑜伽球跪站；同伴突然推；用带力推算抗旋转力矩。

**试做与候选剂量／评估协议：**首轮每方向3次；候选1–2组×5–8次、短停2秒，组间45–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**坐位或站位 T-AXU-018；膝不适取消跪位。

**进阶：**同跪位增少量杠杆/回合；不自动改不稳定平面。

**停止或调整条件：**跪膝痛、腰腿症状或锚点移动。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正面含双膝、手和躯干；侧面另外看推距。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**推回、明显侧偏/随转、任务时间。

**视觉不能直接判定：**带力、膝接触压力、深层肌激活。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**按相同带设置和体位追踪，不与球上扰动结果合并。 统一保存当次、练后和次日反应，长期判断按第12.5节。
