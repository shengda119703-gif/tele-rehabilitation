# 010 E-LOW-005｜仰卧主动直腿抬高功能观察

**区域：**髋、膝、下肢后侧　 **等级：**L0低负荷支持—L1基础

**目标：**观察主动抬腿和保持膝位的综合表现；不作为神经根病诱发诊断。

**器材：**防滑垫、必要时枕头

**开始条件：**能安全上下地面，或有合适硬床；无需他人压腿。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面低机位，双腿伸展或非测试腿按舒适方式屈曲，并冻结体位。

**操作步骤**

1. 仰卧调整至舒适位，记录非测试腿姿势。
2. 主动抬起测试腿，尽量保持原膝位。
3. 在舒适范围停留后慢慢放下。
4. 恢复舒适后换侧，描述牵拉或疼痛位置。

**关键要领**

- 由自己主动抬，不由助手抬高。
- 不要为了高度屏气或用力压腰。
- 若出现向下放射感觉，立即说明。

**常见错误**

- 膝明显弯曲却仍按直腿结果计算。
- 把单次后侧牵拉直接判为坐骨神经病。

**试做与候选剂量／评估协议：**候选协议：每侧2次，记录主动范围和症状；不反复追求极限，不叠加踝背屈等神经张力动作。

区别主动直腿抬高、带辅助牵伸和治疗师神经动力学检查。足踝/颈位、帮助条件必须保存；屈髋位主动伸膝观察 E-LOW-027不能替代神经查体。

**退阶：**屈膝抬腿或取消地面评估，改坐姿功能观察。

**进阶：**必要时转专业神经/肌力检查，不由用户加压升级。

**停止或调整条件：**新发放射痛、麻木、明显无力、腰痛显著加重时停止。

**机位与画面：**侧面低机位，髋膝踝可见。

**视觉可以观察：**主动抬起角、膝位、次数和保持。

**视觉不能直接判定：**神经根张力、肌腱结构、骨盆细小运动及MMT等级。

**观察不足时：**保留自述牵拉部位与完成能力，省略角度。

**动作出处与对应原文：**[REF-S010]；Early-stage #4 Straight leg raise。

**证据性质与适用范围：**大学医院分阶段动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S010]；背景及临床边界：[LOW-S09] [LOW-S21]。动作形式、背景指南和产品测量证据按第8节分别解释。
