# 111 T-LOW-035｜扶稳双脚提踵

**区域：**踝、小腿　 **等级：**L1基础

**目标：**建立基础跖屈重复负重能力。

**器材：**固定台面或无轮稳固椅

**开始条件：**双脚负重许可，跟腱和前足无禁止负荷要求。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**平地开始，双脚舒适间距，手保持轻扶。

**操作步骤**

1. 站稳并轻扶。
2. 缓慢抬起双脚跟。
3. 到可控高度短停。
4. 控制落地，放松后重复。

**关键要领**

- 上下都受控。
- 不要弹跳。
- 手只用于平衡。

**常见错误**

- 用手把身体拉起。
- 深屈膝再猛伸来代替提踵。

**试做与候选剂量／评估协议：**候选模板：首轮5次；一般1—3组×6—15次，选择保持高度的重复量，不以做到无法下落为目标。

可在平地顶部进行短时保持；当任务是保持时用hold协议，不同时按连续提踵计数。屈膝站位见 T-LOW-050；双上单下见 T-LOW-051。

**退阶：**坐位提踵、降低高度或减次数。

**进阶：**先稳定高度和节奏，再考虑单脚或外加负荷，不必同时升级。

**停止或调整条件：**跟腱/前足锐痛、踝失稳、抽筋持续或肿胀反应明显时停止。

**机位与画面：**侧面含全身及足。

**视觉可以观察：**次数、节奏和粗高度趋势。

**视觉不能直接判定：**左右出力、跟腱张力、最大跖屈肌力。

**观察不足时：**允许用户确认次数，自动无法看清足跟时不判整组无效。

**动作出处与对应原文：**[REF-S007]；直膝/屈膝Heel Cord Stretch、双脚/单脚Calf Raises。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。

**依据：**[REF-S007]；背景及临床边界：[LOW-S10] [LOW-S16]。动作形式、背景指南和产品测量证据按第8节分别解释。
