# 094 T-LOW-019｜哑铃/壶铃杯式深蹲

**区域：**髋、膝、踝、躯干　 **等级：**L2负重能力

**目标：**在可控前置负荷下训练下蹲与起身。

**器材：**单只哑铃或壶铃；可选后方稳定椅作深度目标

**开始条件：**基础蹲可控，握持和肩腕能耐受，允许负重；能安全提放器械。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**器械靠近胸前但不压呼吸，脚位自选舒适，周围无障碍。

壶铃相扑蹲可采用舒适的足距/脚角变式（见习2）：脚位由舒适与个体计划决定，不硬拉到固定外旋角。深蹲接推举为 T-AXU-056，转体/抓举不由杯式蹲自动放行。

**操作步骤**

1. 先徒手确认当日深度。
2. 把可控器械稳妥持在胸前。
3. 屈髋屈膝缓慢下降至个人许可深度。
4. 受控站起，组末先安全放下器械。

**关键要领**

- 负荷靠近身体。
- 深度由当前状态决定。
- 不要屏气硬顶完成次数。

**常见错误**

- 为更深蹲而失去平衡。
- 握持已不稳仍继续。

**试做与候选剂量／评估协议：**候选模板：徒手3次、轻负荷3—5次试做；一般2—3组×6—10次，保留可控余量，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**移除负荷、减少深度或改扶稳蹲。

**进阶：**先维持质量与症状稳定，再小幅加重或加次数。

**停止或调整条件：**膝髋锐痛、明显头晕、负荷滑脱或回程失控时停。

**机位与画面：**侧面全身，器械和双足可见。

**视觉可以观察：**次数、深度、节奏、明显躯干策略。

**视觉不能直接判定：**重量真实性、关节力矩、左右地反力和最大肌力。

**观察不足时：**负荷手动填写；关键点被器械遮挡时保留计次，不重置组。

**动作出处与对应原文：**[REF-S034]；Goblet Squat。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
