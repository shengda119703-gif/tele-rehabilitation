# 171 T-AXU-058｜上斜凳轻哑铃胸推

**区域：**胸、肩、肘与上肢推　 **等级：**L2

**目标：**练习上斜平面的受控推举；健身负荷任务，不据动作成功推断肩部疾病康复。

**器材：**可锁定上斜凳、轻哑铃；凳角45–60°且双足有稳定支持。

**单人适用：**条件独立；须能自行摆位、完成及安全卸重；需要他人保护者按第12节分流。

**开始条件：**肩推举方向和负重获准，能自行坐靠、摆放哑铃及卸重；需要旁人递接器材或保护者使用其他已许可任务。

**准备与起始位：**头、上背与臀靠稳长凳，双足落地；记录凳角、握法、每只哑铃重量和下降终点。

**操作步骤：**

1. 先轻负荷摆到可控起点，确认凳与足部稳定。
2. 受控推起哑铃至获准终点，腕保持自然，不锁死肘。
3. 沿相同路径下降至获准胸前高度，不反弹；结束时按已学习方法安全卸重。

**关键要领：**轻负荷先练；下降可控；不抬臀或仰腰凑高度。

**常见错误：**无法独立卸重仍坚持；下降过深；双臂节奏差异被总次数掩盖。

**试做与候选剂量／评估协议：**首轮轻负荷3次；候选1–3组×6–10次，组间60–120秒。 所有数值为项目候选模板，不是原资料统一处方或进阶阈值。

**退阶：**T-AXU-027 轻负荷地板卧推，或 T-AXU-029 墙面推撑。

**进阶：**固定凳角和范围后增加少量回合，再考虑重量；不得自动追求力竭。

**停止或调整条件：**肩胸锐痛、手麻、哑铃失控、不能安全卸重。 同时遵守第4节与第12节。

**机位与画面：**侧面或斜侧含全身、凳和双哑铃；双臂对称观察另用正前机位。；固定相机，必要支点和器材入镜。

**视觉模块：**身体点；器材、锚点和接触需物体识别或本人确认，自动测量仍须验证。

**视觉可以观察：**推起/下降、规定平面肘角代理、完整回合、明显抬臀或躯干改变。

**视觉不能直接判定：**胸肩肌力、肩袖实际激活、凳上支撑力与未录入重量。

**观察不足时：**只保存已确认阶段，缺失信息记unknown；不补造有效回合、负荷或力量。

**复评与训练成果：**固定凳角、重量、握法和终点，比较有效回合、节奏及本人费力；与平凳/地板版分开。 保存当次、练后及次日反应。

**动作出处与对应原文：**[REF-S048]；Incline Chest Press：凳角45–60°、轻哑铃。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
