# 012 E-LOW-006｜仰卧滑跟屈膝活动观察

**区域：**膝、髋　 **等级：**L0低负荷支持

**目标：**记录主动膝屈曲表现以及活动终点症状。

**器材：**硬床或防滑垫、光滑小毛巾

**开始条件：**已知可活动范围；术后按许可屈曲上限执行。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面近中景，脚跟能平顺滑动；不使用弹力带强拉。

**操作步骤**

1. 在舒适伸腿位开始，脚跟接触床面或地面。
2. 慢慢把脚跟向臀部滑近。
3. 到许可或舒适终点停留，报告症状。
4. 缓慢滑回，休息后重复或换侧。

**关键要领**

- 跟着滑动，不需要抬整条腿。
- 保持自然呼吸。
- 达到规定上限就回程。

**常见错误**

- 借手猛拉膝超过限制。
- 臀部滑动让表观屈膝角失真。

**试做与候选剂量／评估协议：**候选协议：每侧熟悉1次、记录2次；保存目标上限、是否辅助和可观察角度，不能把限制性终点记为能力差。

**退阶：**缩小范围或采用坐位脚后滑。

**进阶：**只有限制调整且症状稳定时增加活动范围。

**停止或调整条件：**新锐痛、明显肿胀感、卡锁或超过已知术后界限时停止。

**机位与画面：**测试侧正侧面，股骨与小腿轮廓清楚。

**视觉可以观察：**髋膝踝投影形成的膝屈曲角和回程。

**视觉不能直接判定：**关节积液、被动ROM、手辅助的力量及组织愈合。

**观察不足时：**让用户记录脚跟可达位置及症状，保留有效次不重做整套。

**动作出处与对应原文：**[REF-S010]；Early-stage #1 Heel slides。

**证据性质与适用范围：**大学医院分阶段动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
