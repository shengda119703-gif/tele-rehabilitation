# 162 T-AXU-027｜哑铃/壶铃地板卧推

**区域：**肩/肘/上肢推力　 **等级：**L2

**目标：**在地面限制上臂后移的条件下练习推举负荷。

**器材**

- 一对轻哑铃；或计划指定的壶铃
- 垫与安全取放空间

**开始条件**

- 仰卧、肩水平运动及推举获准；能够安全取放器械。
- 较重器械需要适当辅助；单侧版本另增加抗旋转需求。
- 当前能够安全上下地，双脚接触、取放器械和必要帮助符合患侧限制；不把仰卧姿势自动视为不需要下肢参与。

**准备与起始位：**仰卧屈膝，手腕大致中立，肘在舒适斜向位置；首轮用可稳定掌握的轻哑铃。

**操作步骤**

1. 安全把器械送到胸旁；底部手腕大致位于肘上方、前臂接近竖直，选择肩部舒适的肘外展角度。
2. 呼气向上推起，肘接近伸直但不猛锁。
3. 吸气缓慢下降，让上臂轻触地面而不是撞地反弹。
4. 组末先控制器械到身侧安全位置，再起身。

**关键要领**

- 握持稳定，手腕不被重量压折。
- 肩不强耸，肘不必完全横张。
- 地面限制行程，不表示可以无条件用大重量。

**常见错误**

- 上臂砸地借反弹，或重量落向面部。
- 用腰大幅桥起/屏气代替合适负荷控制。

**试做与候选剂量／评估协议：**首轮5次轻负荷；候选模板2–3组×6–10次、组间90秒。单/双侧、握法和重量由计划确认。

**退阶：**空手或减轻重量；推力不耐受可改墙面推撑。

**进阶：**先稳定范围与回程，再小幅加重；卧凳增加后伸行程需另评估。

**停止或调整条件**

- 肩不稳、锐痛、上肢麻木或重量控制丢失。
- 无法安全取放、异常胸部不适或头晕。

**机位与画面：**斜上方/侧面，全上肢和躯干可见，不把手机放在重量可能跌落处。

**视觉可以观察**

- 推下次数、肘路径、左右明显差异和节奏。

**视觉不能直接判定**

- 肩关节接触力、胸肌/肩袖贡献及实际最大推力。

**观察不足时：**地面遮挡上臂末端时记录完成和负荷，不强迫增加下放行程。
