# 161 T-AXU-054｜固定锚点弹力带划船

**区域：**肩带、肘、上背　 **等级：**L1–L2

**目标：**补充无哑铃的水平拉力训练，不将划船直接命名为肩胛上回旋训练。

**器材：**弹力带、胸口以下可靠锚点、可选椅

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**锚点和弹力带已核验，肩肘拉力路线允许；拉伸方向不朝眼脸。

**准备与起始位：**坐稳或站稳面向锚点，双手胸前下方持带；单/双手版本分别保存。

**操作步骤**

1. 轻张力起始，手腕自然。
2. 肘缓慢向身体两侧后方移动，手拉至舒适躯干附近。
3. 受控向前回程，允许肩胛自然运动而不强夹。

**关键要领：**带不猛弹；身不后甩；肘不追身后极限。

**常见错误：**把条带颜色当牛顿；挺腰耸肩完成；把未知上拉动作猜成同一划船。

**试做与候选剂量／评估协议：**首轮5次轻阻；候选1–3组×8–12次，组间45–90秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**无带路线或坐位更轻张力。

**进阶：**固定带设置先增可控回合，再少量增加张力。

**停止或调整条件：**肩肘疼痛或锚点松动。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正侧面含锚点、上肢和躯干；带设置由本人补记。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**拉回次数、肘路线、明显后仰与周期。

**视觉不能直接判定：**肩胛分量、真实带力、最大拉力。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**相同型号/带长/站距与症状下追踪回合，未知带力不报kg。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S009]；External Rotation / Internal Rotation / Elbow Flexion / Standing Row。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
