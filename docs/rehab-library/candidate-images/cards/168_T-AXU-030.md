# 168 T-AXU-030｜坐位/站位哑铃过头推举

**区域：**肩/肘/躯干　 **等级：**L2

**目标：**为获准的过头任务建立可控推举负荷。

**器材**

- 可控轻哑铃
- 可选稳定靠背椅

**开始条件**

- 主动抬臂与过头负荷已获准，握持稳定；不作为肩痛者一律默认动作。
- 坐位和站位分别记录，不将减少躯干支撑与加重同时进行。
- 站位版本须满足当前双脚承重与患侧踝稳定需求；坐位版本也检查蹬地、器械拿放和起坐转移，不能默认完全不涉及患踝。

**准备与起始位：**首选稳定坐位或站位，哑铃从肩旁起，肘在舒适前外侧位置，手腕自然。

**操作步骤**

1. 先空手试抬到目标高度，确认范围和症状。
2. 持轻哑铃呼气向上推，允许肩胛自然运动。
3. 到可控制高度即停，不靠腰部后仰把手送得更高。
4. 吸气缓慢回肩旁，组末安全放下。

**关键要领**

- 重量路线保持可控，不向头后硬送。
- 肋骨与骨盆保持舒适控制，呼吸不屏住。
- 手腕在负荷下不明显折弯，肘不猛锁。

**常见错误**

- 用腰大后仰或蹬腿甩起本应控制的重量。
- 强夹肩胛限制正常抬举，或追求所有人同一终点。

**试做与候选剂量／评估协议：**首轮3–5次轻负荷；候选模板2–3组×6–10次、组间90秒。由计划确认坐/站姿、范围和重量。

**退阶：**减重/降低高度，换地雷杆或墙滑等已耐受任务。

**进阶：**先改善控制和舒适行程，再加重；高速度推举、推举借力属于另行返运动项目。

**停止或调整条件**

- 肩滑脱感、锐痛、突然无力或新麻木。
- 重量控制丢失、异常胸闷或头晕。

**机位与画面：**正面偏侧全上肢与躯干，确保过头终点在画面内。

**视觉可以观察**

- 推举次数、投影范围、肘腕路线与明显躯干后仰。

**视觉不能直接判定**

- 肩关节压缩力、局部肌腱应力或真实最大力量。

**观察不足时：**手过头出画时保留已见过程和自报完成，不要求追加重复。
