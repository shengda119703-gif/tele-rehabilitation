# 154 T-AXU-051｜墙天使：舒适范围滑动

**区域：**肩、上背、躯干控制　 **等级：**L0–L1

**目标：**练习靠墙条件下抬臂与回程，不强求贴墙或矫正静态姿势。

**器材：**墙

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**站立及获准肩外展抬举可耐受。

**准备与起始位：**背部轻靠墙、双脚舒适前移，肘弯曲在较低位；头与腰不必强贴墙。

**操作步骤**

1. 选择低位起点并放松呼吸。
2. 双臂缓慢沿舒适路线向上滑动。
3. 到获准范围停、受控回落；手离墙可改小范围。

**关键要领：**舒适范围；腰不猛拱；不强贴头/手。

**常见错误：**肩痛仍硬推手背贴墙；以贴墙程度定义姿势异常。

**试做与候选剂量／评估协议：**首轮3次；候选1–2组×6–10次、组间30–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**面对墙滑手 T-AXU-022 或坐位低抬臂。

**进阶：**同范围改善控制后再少量增高度，不自动强拉末端。

**停止或调整条件：**肩痛明显加重、手麻或颈部不适。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正面看臂路线；侧面另看后仰与墙间距。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**起落、上臂投影范围、明显肘位/躯干变化。

**视觉不能直接判定：**胸椎分节伸展、肩胛前倾角或肌肉长度。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同墙支持与起始位追踪范围、回合与症状。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S025]；Table Stretch/Wall Climbers、Resisted Open Can、Prone I/W/T/Y、Wall Angels、Push Up Plus Variations。

**证据性质与适用范围：**大学医疗中心公开示范目录。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
