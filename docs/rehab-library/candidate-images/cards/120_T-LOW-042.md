# 120 T-LOW-042｜分段渐进步行

**区域：**综合下肢、有氧与日常功能　 **等级：**L0低负荷支持—L2负重能力

**目标：**在可耐受范围内恢复日常步行量和耐受。

**器材：**平坦熟悉路径；按需要使用原助行器和合适鞋履

**开始条件：**能按当前许可步行；对明确心肺或神经限制采用既定计划。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**选可随时休息的短路线；手机不必全程拍摄，注意力放在路面。

**操作步骤**

1. 从容易完成的短段开始，按日常舒适速度走。
2. 到预定点或需要休息时停止并休息。
3. 恢复稳定后再走另一短段。
4. 记录总时间/距离、助行器和当天及随后反应。

**关键要领**

- 先稳定总量再求快。
- 需要助行器就使用。
- 途中不要盯屏幕。

**常见错误**

- 把一天目标一次硬走完。
- 同时增加步速、坡度和时长。

**试做与候选剂量／评估协议：**候选模板：首轮选本人确信能完成的1—3分钟短段，必要时更短；一般采用多个可恢复短段。具体总量根据原有水平和当下症状设定，不统一每日步数。

**退阶：**缩短路段、室内平地或更多坐休。

**进阶：**总量稳定后只增加时长、速度或坡度之一；跑步另设准入。

**停止或调整条件：**胸部不适、异常气促、眩晕、新腿软、明显疼痛或跛行加重时停。

**机位与画面：**仅开始/结束短片可选，无需全程镜头。

**视觉可以观察：**短片中的完成能力；可信距离/计时信息下的时间与路程。

**视觉不能直接判定：**持续心肺状态、完整步态负荷和所有症状。

**观察不足时：**完全允许计时/自主记录模式，摄像头缺失不阻断步行计划。

**动作出处与对应原文：**[REF-S079]；Walking for health：按耐受逐步累积步行。

**证据性质与适用范围：**公共卫生机构活动说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
