# 145 T-AXU-048｜仰卧手抵膝的屈髋等长控制

**区域：**髋屈、腰骨盆、躯干　 **等级：**L0–L1

**目标：**通过本人手膝轻对抗练习髋与躯干协同；不按静态骨盆高低自动安排不对称纠正。

**器材：**垫

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**髋屈位及轻抗阻允许；上肢能轻抵膝，能正常呼吸。

**准备与起始位：**仰卧，一脚落垫，另一髋膝舒适屈起；手放大腿近膝处，避开髌骨术区。

**操作步骤**

1. 用手轻抵大腿，腿轻向手方向抬而不明显移动。
2. 短时维持并继续呼吸。
3. 逐渐卸力、足落回，再换侧或按已确认单侧计划。

**关键要领：**轻对抗；不压膝盖；不追极限用力。

**常见错误：**手膝猛烈角力；根据骨盆照片指定高低侧处方。

**试做与候选剂量／评估协议：**首轮每侧3次×2–3秒；候选1–2组×4–6次、每次3–5秒，组间30–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**仅舒适屈髋或 T-AXU-015脚跟滑动。

**进阶：**延长少量保持，阻力仍由本人自报；不自动测最大力。

**停止或调整条件：**腹股沟夹痛、腰腿放射痛或上肢痛。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面含手、髋膝和躯干。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**体位观察＋陪练/本人反馈；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**体位与明显移动、接触可见时的任务保持。

**视觉不能直接判定：**施力大小、肌肉收缩是否发生、骶髂复位。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**保存尝试时长和本人用力/症状；标为等长陪练。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S024]；Hip Flexor Strengthening：自己手抵膝的屈髋等长。
