# 118 T-LOW-040｜扶稳抬前足

**区域：**踝背屈、小腿前侧　 **等级：**L1基础

**目标：**练习主动前足抬起，服务于踝背屈控制。

**器材：**固定台面或墙旁扶手、防滑地面

**开始条件：**足跟承重可耐受；新出现足下垂或进行性无力先专业评估，不直接按训练解决。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**双脚跟稳定，身体保持容易站稳的位置；不把后背靠墙角度当负荷指标。

**操作步骤**

1. 双脚站稳并轻扶。
2. 保持足跟接触，缓慢把前足抬起。
3. 短停后控制前足落地。
4. 充分放松脚趾后重复。

**关键要领**

- 抬前足而非只抬脚趾。
- 脚跟保持稳定。
- 幅度以不失衡为准。

**常见错误**

- 身体后倒来抬脚。
- 把新出现脚下垂当普通无力继续练。

**试做与候选剂量／评估协议：**候选模板：首轮5次；一般1—3组×6—15次，前足落地要可控，疲劳后改更小量。

**退阶：**坐位背屈或轻带背屈。

**进阶：**先增加可控重复，再按目标使用有标定设置的弹力带。

**停止或调整条件：**新麻木/无力、脚跟痛、眩晕或失衡时停止。

**机位与画面：**侧面足近景，扶手可见。

**视觉可以观察：**有足点时前足起落和次数。

**视觉不能直接判定：**神经病因、肌力等级、脚跟地反力。

**观察不足时：**保留方向练习和自报完成，足点看不清不要求重新站拍。
