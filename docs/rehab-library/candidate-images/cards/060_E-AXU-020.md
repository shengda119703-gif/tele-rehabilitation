# 060 E-AXU-020｜腕主动尺偏/桡偏ROM筛查

**区域：**腕　 **等级：**L0–L1

**目标：**记录手相对前臂的侧向活动与症状。

**器材**

- 桌面

**开始条件**

- 当前允许尺桡偏；无未处理急性腕创伤。

**准备与起始位：**前臂掌心向下平放桌面，手自然伸开，手机从上方拍到前臂和掌部。

**操作步骤**

1. 手与前臂自然成一直线，记录起始位置。
2. 缓慢把手向拇指侧偏移，前臂不转动，再回中间。
3. 缓慢向小指侧偏移，再回中间。
4. 分别报告桡侧或尺侧疼痛、卡顿及困难。

**关键要领**

- 前臂贴桌，肘不左右滑。
- 手背尽量维持同一平面。
- 不把转动整条前臂当作手腕侧偏。

**常见错误**

- 用旋前旋后或肘平移代替尺桡偏。
- 按手指摆动而非掌骨轴判断腕方向。

**试做与候选剂量／评估协议：**每方向1–2次，间隔10–15秒。比较需同样前臂姿势，不以单次左右不同判断疾病。

**退阶：**减小幅度；桌面摩擦不适时轻垫毛巾但保留相同复测条件。

**进阶：**同条件复测，随后如适合再进入轻阻力训练。

**停止或调整条件**

- 新的尖锐尺侧/桡侧腕痛或机械卡住。
- 明显麻木、手无力或症状持续升高。

**机位与画面：**桌面正上方近景，避免透视过斜；Hand与前臂使用同一图像坐标。

**视觉可以观察**

- 腕在规定平面内的投影偏移和回中立。

**视觉不能直接判定**

- TFCC、舟骨、腱鞘或韧带病变。
- 手掌实际压桌力量。

**观察不足时：**无法可靠测角时仅保存方向完成和症状，不要求补拍全部腕动作。

**动作出处与对应原文：**[REF-S016]；主动旋前/旋后、腕掌屈/背伸、桡偏/尺偏。

**证据性质与适用范围：**大学医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S016]；背景及临床边界：[AXU-S11]。动作形式、背景指南和产品测量证据按第8节分别解释。
