# 088 T-LOW-013｜髋铰链触墙练习

**区域：**髋、躯干　 **等级：**L1基础

**目标：**学习髋向后移动、躯干随髋倾斜的基础模式。

**器材：**墙、可选轻木棍作体位提示

**开始条件：**可安全站立和屈髋，动作不违反腰髋限制。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**背对墙站近一些，脚下防滑；不追求身体绝对直线。

**操作步骤**

1. 膝轻屈，先确认背后墙距离。
2. 臀部缓慢向墙方向后移。
3. 躯干随髋自然前倾，轻碰墙后停住。
4. 脚掌稳定，站回起点。

**关键要领**

- 想象臀部向后找墙。
- 膝保持柔和，不蹲到底。
- 呼吸连续，范围舒适。

**常见错误**

- 只弯腰而臀部不后移。
- 离墙太远导致失衡或强拉后腿。

**试做与候选剂量／评估协议：**候选模板：首轮3—5次；一般1—3组×5—10次，动作控制优先于触到更远的墙。

**退阶：**站得更靠墙或轻扶台面。

**进阶：**熟练后再做DB/KB RDL，外负荷需重新试做。

**停止或调整条件：**腰痛放射、髋夹痛、眩晕或失衡时停。

**机位与画面：**侧面全身。

**视觉可以观察：**臀后移、膝屈曲、躯干倾斜与次数。

**视觉不能直接判定：**腰椎逐节姿态、组织负荷和髋伸肌力。

**观察不足时：**用口令陪练，缺腰部细节不要求重新开始。

**动作出处与对应原文：**[REF-S033]；Hip Hinge：髋后移与回正；触墙是定位变式。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
