# 066 T-LOW-003｜坐姿伸膝：徒手至轻负荷

**区域：**膝　 **等级：**L0低负荷支持—L2负重能力

**目标：**练习主动伸膝与受控回落，逐步建立伸肌负重能力。

**器材：**稳固椅；可选已知质量踝部负重或可靠固定弹力带

**开始条件：**开放链伸膝符合目前限制；坐位稳定，能自行撤除负荷。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**大腿受椅面支持，小腿自由活动；负荷不压迫术区。 检查带体和锚点；记录品牌型号、固定长度和设置，不由颜色直接推张力。

**操作步骤**

1. 先做无负荷试举。
2. 缓慢伸膝至许可范围。
3. 短停后控制小腿回落。
4. 确认动作和症状稳定后才使用选定的轻负荷。

**关键要领**

- 大腿不要整段离座。
- 回程同样受控。
- 膝终点不需要强锁。

**常见错误**

- 踢腿甩负荷。
- 依照历史踝部负重直接恢复旧重量。

**试做与候选剂量／评估协议：**候选模板：首轮徒手3—5次；稳定后一般1—3组×6—12次，先定允许角度再定阻力，组间恢复至动作可控。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**无负荷或更小活动范围。

**进阶：**只在当前量耐受后小幅增加一次变量：阻力、次数或范围。

**停止或调整条件：**新锐痛、卡锁、明显震颤失控或随后肿胀加重时停并调整。

**机位与画面：**侧面可见髋膝踝及负荷位置。

**视觉可以观察：**次数、角度、保持与速度趋势。

**视觉不能直接判定：**实际肌力、弹力带张力和膝关节内部负荷。

**观察不足时：**改用计时/用户完成记录；重量由用户填写，视觉不猜数值。

**动作出处与对应原文：**[REF-S006]；Leg Extensions / Hamstring Curls。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
