# 170 T-AXU-032｜弹力带胸前水平展开

**区域：**肩/上背　 **等级：**L1

**目标：**练习水平外展与受控回收，作为肩带能力训练之一。

**器材**

- 完好轻弹力带

**开始条件**

- 当前肩水平开合可耐受；可降低上臂高度，不强制肩高。

**准备与起始位：**坐或站稳，双手在胸前握带，肘自然微屈，带远离面部。

**操作步骤**

1. 把手臂放到可耐受的胸前高度，先保留轻张力。
2. 呼气向两侧缓慢展开，躯干朝前。
3. 到舒适开度停止，不强行把手拉到身体后面。
4. 控制双手回收，避免带突然松脱。

**关键要领**

- 肩自然远离耳朵，不强夹死肩胛。
- 肘角大致稳定，手腕不折。
- 带保持完整，握稳且不对着面部回弹。

**常见错误**

- 通过明显挺腰/抬胸来拉开带。
- 过大阻力使肘弯曲成划船而未记录换动作。

**试做与候选剂量／评估协议：**首轮轻带5次；候选模板2–3组×8–12次、组间60秒。阻力、高度和开度由计划确认。

**退阶：**更轻带、更低手臂或无阻力小幅开合。

**进阶：**先稳定范围和回程，再逐渐增加阻力；不靠硬拉终末位进阶。

**停止或调整条件**

- 肩前方锐痛、不稳或新麻木。
- 带破损、握持失控或不能控制回程。

**机位与画面：**正面/斜前方，手臂和躯干可见；二维用轨迹而非精确水平ROM。

**视觉可以观察**

- 展开回收次数、手臂高度、明显躯干代偿。

**视觉不能直接判定**

- 肩胛精确运动、弹力带实际力和肌肉选择性激活。

**观察不足时：**展开到侧方时角度不清可只计次；不要求为高分加大幅度。
