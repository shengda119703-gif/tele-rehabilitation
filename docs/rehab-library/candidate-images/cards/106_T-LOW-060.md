# 106 T-LOW-060｜轻负荷常规杠铃硬拉：地面起落

**区域：**髋、膝、后侧链与躯干　 **等级：**L2–L3

**目标：**在掌握技术后练习从地面提起并放回负荷；与从站姿开始的RDL分开登记。

**器材：**技术杠或轻杠铃、牢固杠片、防滑地面；首轮不做最大重量。

**单人适用：**条件独立；须能自行摆位、完成及安全卸重；需要他人保护者按第12节分流。

**开始条件：**已掌握髋铰链与受控提放、获准髋膝及躯干负重；有足够握持能力，能安全放回而无需他人接重量。

**准备与起始位：**双脚在杠后，记录足距和杠高；使用已学会的握法，双正握或混合握分别登记；首轮优先可握稳的轻负荷。

**操作步骤：**

1. 屈髋屈膝握稳杠，杠接近小腿，保持当前许可的躯干姿势。
2. 双脚压地并伸髋伸膝站起，让杠沿身体近侧上移。
3. 受控屈髋屈膝把杠放回地面，卸力并重新摆位；不连续反弹。

**关键要领：**先握稳再起拉；站直即可；每次落地后重置。

**常见错误：**杠远离身体；突然猛拽；向后过伸腰；用“做完”证明可加大重量。

**试做与候选剂量／评估协议：**空杆/轻负荷熟悉3次；候选1–3组×5–8次，组间90–120秒，保留能受控完成及卸重的余量。 所有数值为项目候选模板，不是原资料统一处方或进阶阈值。

**退阶：**T-LOW-013 髋铰链；需要抬高杠起点时另存protocol_id与实际高度。

**进阶：**先固定重量和杠高增加控制，再按个体计划小步增加重量；不自动估算1RM。

**停止或调整条件：**握持失控、腰腿放射症状、髋膝锐痛或不能受控落回。 同时遵守第4节与第12节。

**机位与画面：**侧面全身及杠片入镜；正面另拍观察侧偏。；固定相机，必要支点和器材入镜。

**视觉模块：**身体点；器材、锚点和接触需物体识别或本人确认，自动测量仍须验证。

**视觉可以观察：**杠离地/落地、起落阶段、完整回合、躯干整体俯倾和明显侧偏。

**视觉不能直接判定：**地面反力、椎间盘负荷、真实肌力、杠铃准确重量或净关节力矩。

**观察不足时：**只保存已确认阶段，缺失信息记unknown；不补造有效回合、负荷或力量。

**复评与训练成果：**固定杠高、握法、重量、足距和节奏，比较有效回合与自报费力；不同杠高结果分轨。 保存当次、练后及次日反应。
