# 110 T-LOW-034｜屈膝小腿牵伸

**区域：**踝、小腿　 **等级：**L0低负荷支持—L1基础

**目标：**在允许条件下练习屈膝位背屈耐受。

**器材：**固定扶手或墙

**开始条件：**允许膝屈曲与足跟承重；没有禁止背屈的保护要求。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**前后或小弓步站，测试脚跟落稳，膝轻屈。

**操作步骤**

1. 先扶稳并让测试脚全掌接触。
2. 保持测试膝弯曲，身体缓慢向前下方微移。
3. 感到舒适后侧牵伸时保持。
4. 缓慢退回并放松。

**关键要领**

- 跟不要离地。
- 幅度小也可以。
- 膝沿足方向而非扭动。

**常见错误**

- 为增加牵伸而使前踝夹痛。
- 脚跟抬起且继续向前压。

**试做与候选剂量／评估协议：**候选模板：先10秒试做；一般2—4次×15—30秒，按个人反应而非统一疼痛分值决定。

**退阶：**减屈膝/前移幅度或做坐位踝活动。

**进阶：**只在舒适稳定后微调站距，不进行强迫末端压力。

**停止或调整条件：**前踝夹锐痛、跟腱痛、腿软或持续症状增加时停。

**机位与画面：**侧面，膝踝足可见。

**视觉可以观察：**膝姿势、保持时间与粗小腿前倾。

**视觉不能直接判定：**比目鱼肌实际张力、足底压力和韧带负荷。

**观察不足时：**继续计时和用户反馈，缺足点不强行出牵伸角。

**动作出处与对应原文：**[REF-S007]；直膝/屈膝Heel Cord Stretch、双脚/单脚Calf Raises。

**证据性质与适用范围：**专业学会患者训练手册。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
