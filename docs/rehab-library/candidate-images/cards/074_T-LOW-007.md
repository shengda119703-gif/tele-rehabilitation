# 074 T-LOW-007｜扶稳站姿髋后伸：徒手至弹力带

**区域：**髋　 **等级：**L1基础—L2负重能力

**目标：**练习髋向后移动与伸肌负荷耐受。

**器材：**固定扶手、可选可靠锚点弹力带

**开始条件：**允许髋后伸并可安全承重；无急伤方向禁忌。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**侧面，支撑足站稳；带锚点不能滑向脚下。 检查带体和锚点；记录品牌型号、固定长度和设置，不由颜色直接推张力。

**操作步骤**

1. 先无带向后移腿试做。
2. 躯干舒适稳定，测试腿缓慢向后移动。
3. 到不需明显腰后仰的位置停下。
4. 控制回程，换侧重复。

**关键要领**

- 幅度宁小而可控。
- 不要用腰猛顶。
- 呼吸保持自然。

**常见错误**

- 全身前倾或腰后仰凑幅度。
- 把带拉到将身体拖走。

**试做与候选剂量／评估协议：**候选模板：首轮每侧3次；一般1—3组×6—12次，逐次保持可控回程。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**去带、双手扶稳或减小范围。

**进阶：**先增加稳定重复，再小幅增加阻力；不以腰后仰作为进步。

**停止或调整条件：**腰痛放射、髋锐痛、支撑脚不稳或带锚点松动时停。

**机位与画面：**侧面全身。

**视觉可以观察：**次数、后移范围、躯干与膝的明显代偿。

**视觉不能直接判定：**独立髋后伸角、肌肉出力和骨盆细小运动。

**观察不足时：**保留陪练和自述完成量，关闭不可靠角度。

**动作出处与对应原文：**[REF-S001]；Sideways leg lift / Leg extension：站姿外展及后伸。

**证据性质与适用范围：**公共卫生机构动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
