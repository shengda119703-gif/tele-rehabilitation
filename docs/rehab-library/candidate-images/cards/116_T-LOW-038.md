# 116 T-LOW-038｜弹力带踝四方向：按许可单独启用

**区域：**踝　 **等级：**L1基础—L2负重能力

**目标：**对允许的背屈、跖屈、内翻、外翻分别进行受控阻力训练。

**器材：**合适弹力带、稳定锚点、稳固椅或垫

**开始条件：**每个方向单独经过急伤/术后限制检查；不能因为开启本卡便默认四方向全做。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**小腿有支撑，带绕前足安全位置不勒皮肤；把需要的方向逐项设置，防回弹朝脸。 检查带体和锚点；记录品牌型号、固定长度和设置，不由颜色直接推张力。

**操作步骤**

1. 先徒手确认本次允许方向。
2. 背屈：阻力从脚前方牵引，前足向小腿移动后控制回程。
3. 跖屈：带由手稳妥向身体方向牵住，前足向下推后控制回程。
4. 内翻：阻力来自外侧，脚向内移动；外翻则阻力来自内侧，脚向外移动。
5. 每完成一个方向先卸张力再换设置，出现不适的方向跳过并记录。

见习27双足同向/相向内外翻仅可作为坐位无外阻方向协调变式，分别保存左右足方向；标准身体点不足时启用足部近景或陪练。不能把完成称为“神经激活已验证”。

**关键要领**

- 小腿保持稳定。
- 动作来自踝，不只是脚趾。
- 回程不让带突然弹回。

**常见错误**

- 用髋旋转替代踝内外翻。
- 用带颜色直接换算牛顿或自动比较品牌。

**试做与候选剂量／评估协议：**候选模板：每个许可方向先3次轻阻力；一般1—3组×6—12次，先选少量必要方向，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**无带主动运动、更轻张力或更短范围。

**进阶：**保持相同锚点和带长后微调张力/次数；最近崴脚者不自动加入末端内翻。

**停止或调整条件：**踝锐痛、明显失稳感、皮肤勒痛、麻木或锚点松动时停。

**机位与画面：**踝足近景并看见小腿，方向切换时机位可保持。

**视觉可以观察：**额外足点下的次数、方向、范围趋势。

**视觉不能直接判定：**实际带张力、韧带应力、最大踝力矩和肌力等级。

**观察不足时：**用方向提示、计次确认和自报用力；足点缺失时不编造角度。

**动作出处与对应原文：**[REF-S070]；Band exercises：背屈、跖屈、内翻、外翻分别执行。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
