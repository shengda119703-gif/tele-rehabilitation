# 173 T-AXU-062｜站姿绳索或弹力带胸前飞鸟

**区域：**胸、肩与上肢水平内收　 **等级：**L2

**目标：**练习站姿水平内收与受控回程；不同于卧姿飞鸟。

**器材：**两个略高于肩的可靠绳索锚点，或同方向弹力带锚点；轻阻力。

**单人适用：**条件独立；须能自行摆位、完成及安全卸重；需要他人保护者按第12节分流。

**开始条件：**肩水平展开和内收负荷已获准、锚点可靠；能独立站稳、松开张力并放下握把。

**准备与起始位：**双脚站稳，两手各握一端，手臂在获准侧方范围且肘微屈；记录锚点高度、站距和阻力。

**操作步骤：**

1. 保持肘微屈，缓慢将双手移向胸前。
2. 到预设会合位置短停，不挤肩或屏气。
3. 按同一路线缓慢展开回起点；先减小张力再安全放开握把。

**关键要领：**范围舒适；躯干不后仰；回程也有控制。

**常见错误：**展开超过肩当前许可；带突然弹回；肘角变化把动作变成推举。

**试做与候选剂量／评估协议：**首轮3次；候选1–2组×6–10次，组间60–90秒。 所有数值为项目候选模板，不是原资料统一处方或进阶阈值。

**退阶：**减小展开范围与阻力，或 T-AXU-029 墙面推撑。

**进阶：**固定锚点和范围后增加少量回合，再改变一个阻力条件。

**停止或调整条件：**肩胸锐痛、手麻、锚点松动或无法控制回程。 同时遵守第4节与第12节。

**机位与画面：**正面或斜前含双肩肘腕、躯干和可见锚点。；固定相机，必要支点和器材入镜。

**视觉模块：**身体点；器材、锚点和接触需物体识别或本人确认，自动测量仍须验证。

**视觉可以观察：**双手会合/展开、规定平面轨迹、完整回合与明显躯干后仰。

**视觉不能直接判定：**胸肌力量、肩前结构负荷、弹力带张力或锚点承重能力。

**观察不足时：**只保存已确认阶段，缺失信息记unknown；不补造有效回合、负荷或力量。

**复评与训练成果：**固定锚点、阻力、展开终点、站距和肘角，比较回合与本人费力；器材版本分轨。 保存当次、练后及次日反应。

**动作出处与对应原文：**[REF-S051] [REF-S042]；Standing Chest Fly：双侧略高于肩的可靠锚点。

**证据性质与适用范围：**专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
