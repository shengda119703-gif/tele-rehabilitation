# 045 E-AXU-009｜颈部主动屈曲/伸展筛查

**区域：**颈部　 **等级：**L0–L1

**目标：**记录头相对躯干的近似俯仰活动及症状。

**器材**

- 稳定椅

**开始条件**

- 没有尚未评估的近期颈部创伤或新的神经症状。
- 方向须为当前计划允许；不加手压和颈椎加压。

**准备与起始位：**侧面上半身近景，坐稳，肩放松，眼睛自然向前；先记录中立位。

**操作步骤**

1. 保持躯干自然直立，缓慢低头到舒适范围。
2. 回到起始位并停顿，报告颈部及上肢症状。
3. 若允许，缓慢抬头到舒适位置，避免连同胸腰后仰。
4. 再次回正，记录该方向反应。

**关键要领**

- 只是主动转动，不用手压头。
- 肩膀尽量放松，动作慢于平常转头。
- 脸出画或看不清不需要硬保持末端。

**常见错误**

- 整个上身前屈/后仰代替颈部动作。
- 把面部相机姿态直接等于解剖颈椎ROM。

**试做与候选剂量／评估协议：**每方向1次熟悉、1–2次观察；方向间休息15–20秒。不是眩晕或血管筛查试验。

**退阶：**减小范围，靠背坐稳；若不适则仅收集日常抬低头能力。

**进阶：**复测相同镜头及中立位；精准临床ROM须验证并处理躯干相对姿态。

**停止或调整条件**

- 出现眩晕、视物异常、恶心或新的上肢麻木无力。
- 出现突发异常头颈痛。

**机位与画面：**侧面头肩近景，头部全程尽量入镜。

**视觉可以观察**

- 可见头部相对躯干的近似俯仰变化和回正。

**视觉不能直接判定**

- 颈椎各节段ROM、神经压迫或血管情况。
- 疼痛强度及被动活动末端感。

**观察不足时：**Face失跟时保留可见片段和自报完成；不补算看不见的最大角。

**动作出处与对应原文：**[REF-S013]；第2页 Neck flexion / Neck extension。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。

**依据：**[REF-S013]；背景及临床边界：[AXU-S02] [AXU-S10]。动作形式、背景指南和产品测量证据按第8节分别解释。
