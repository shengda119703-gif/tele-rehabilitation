# 068 T-LOW-045｜扶稳站姿屈膝：徒手至弹力带

**区域：**膝、下肢后侧　 **等级：**L1基础—L2负重能力

**目标：**练习主动屈膝和腘绳肌的渐进负荷耐受。

**器材：**固定扶手、可选轻踝部负重或可靠锚点弹力带

**开始条件：**可单侧短暂承重，屈膝和腘绳肌收缩符合当前限制；腘绳肌移植术后遵循既定阶段。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**测试侧大腿尽量保持向下，身旁有支撑；带锚点不进入脚下通道。 检查带体和锚点；记录品牌型号、固定长度和设置，不由颜色直接推张力。

**操作步骤**

1. 先无负荷扶稳站立。
2. 测试膝缓慢弯曲，脚跟向后抬。
3. 到许可范围停片刻。
4. 控制落下，站稳后重复并换侧。

**关键要领**

- 大腿不大幅向前抬。
- 腰不要后仰。
- 回程不让负荷坠落。

**常见错误**

- 甩脚或屈髋代替屈膝。
- 忽略术后腘绳肌负荷限制。

**试做与候选剂量／评估协议：**候选模板：首轮徒手每侧3次；一般1—3组×6—12次，轻负荷只在允许且受控时加入，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**减小范围、无负荷或改允许的卧姿/坐姿版本。

**进阶：**先保持大腿稳定与回程控制，再小幅增阻或次数。

**停止或调整条件：**后膝/后大腿锐痛、抽筋反复、术区牵扯或支撑脚失稳时停。

**机位与画面：**侧面全身。

**视觉可以观察：**屈膝次数、范围、躯干与大腿明显代偿。

**视觉不能直接判定：**腘绳肌最大力、移植物愈合、实际阻力或MMT。

**观察不足时：**保留口令和用户完成量；器械遮挡时省略角度，不重新开始整组。

**证据性质与适用范围：**专业学会患者训练手册、专业机构训练技术说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
