# 024 E-LOW-010｜膝顶墙负重背屈

**区域：**踝　 **等级：**L1基础

**目标：**获得可重复的负重背屈功能指标。

**器材：**墙、地面卷尺或已知尺度贴条、必要时扶手

**开始条件：**可安全负重，急伤/术后允许背屈和弓步。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**测试脚朝墙，膝朝同一脚前方；侧面近景可看足跟。

**操作步骤**

1. 从容易完成的趾墙距离站稳。
2. 脚跟不离地，膝缓慢向墙移动。
3. 能舒适碰墙则小步后移，不能完成则前移。
4. 记录最后可控距离和症状；另一侧同法。

**关键要领**

- 膝沿前足方向移动。
- 跟贴地，不扭脚取巧。
- 找到可控终点即可，不弹震压膝。

**常见错误**

- 足跟抬起仍算有效。
- 相机未标定却仅按身高推厘米。

**试做与候选剂量／评估协议：**候选协议：每侧先熟悉，再取2—3个可重复有效结果；记录趾墙距离或胫骨倾角中的一种主指标，不混用阈值。

见习1/13的13.5 cm等数值仅是特定患者当次结果，不能当通用阈值。分别保存“舒适可达距离”和“首次熟悉痛出现位置”两个独立字段；后者仅在自然出现时本人报告，不要求继续诱发痛。被动终末感、距骨/舟骨滑动由治疗师输入，摄像头不推断。

**退阶：**减小距离并扶稳；无法负重者改坐姿踝活动。

**进阶：**复测采用原尺度与机位；不为追求更远距离增加强压。

**停止或调整条件：**明显前踝夹痛、后跟锐痛、失衡或违反负重限制时停止。

**机位与画面：**测试足内侧近景，墙和地面标尺同时入镜。

**视觉可以观察：**有标定时趾墙距离；可靠足点下跟抬起及小腿倾角。

**视觉不能直接判定：**真实关节受限病因、足底力、无足点时跟接触。

**观察不足时：**允许用户尺量并确认跟不离地，保存为辅助自测结果；不因缺足点阻断。

**动作出处与对应原文：**[REF-S058]；负重背屈弓步测量；固定距离或投影角分轨。

**证据性质与适用范围：**原始测量信度研究。运动形式有公开出处；本卡为项目功能观察，不能解释为已验证标准量表或诊断测试。
