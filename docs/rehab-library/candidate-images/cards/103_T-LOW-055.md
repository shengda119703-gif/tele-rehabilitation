# 103 T-LOW-055｜低台阶交替点踏与受控上落

**区域：**下肢、步序、活动耐受　 **等级：**L1–L2

**目标：**以低速点踏/完整上落分轨练习台阶交换步，避免默认快速跳换脚。

**器材：**低而稳固台阶、固定扶手

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**台阶任务承重获准、基础上落可控；台阶高度按当前能力。

**准备与起始位：**台阶固定，双脚在地，一手可扶稳；记录点踏还是整人上台。

**操作步骤**

1. 先一脚点踏台面后放回，另一脚同法。
2. 基础稳定后获准完整上台版本：一脚上、另一脚跟上。
3. 再依序下台，站稳；完整上下为一回合。

**关键要领：**不跳换；脚完整踩稳；点踏与上落分别计数。

**常见错误：**点踏次数冒充完整上台；为跟节拍失去足位控制。

**试做与候选剂量／评估协议：**首轮各脚3次点踏；候选1–2组×6–10次点踏或4–6回合上落，择一，休息45–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**地面原地抬脚或降低台阶。

**进阶：**先增可控回合，再按计划加节奏；速度提高不证明肌力提高。

**停止或调整条件：**绊脚、腿软、失衡或关节痛增加。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**正侧含双足、台阶和扶手。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**左右步序、点踏/上落事件、回合时间与明显停顿。

**视觉不能直接判定：**心肺能力、地面反力、实际支撑压力。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同台高、版本、扶持与节奏下比较完成及用力自报。 统一保存当次、练后和次日反应，长期判断按第12.5节。
