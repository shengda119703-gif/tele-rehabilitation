# 176 T-AXU-035｜前臂支撑的负重腕背伸

**区域：**腕/前臂伸肌　 **等级：**L1

**目标：**逐步练习腕伸肌的负荷和回程控制。

**器材**

- 桌面
- 轻小哑铃/小水瓶；或空手

**开始条件**

- 腕背伸抗阻在当前许可内；急性未评估创伤或腕骨痛先处理。

**准备与起始位：**掌心向下，前臂稳定放桌面，腕伸出桌边；手握轻物，肘角记入版本。

**操作步骤**

1. 先空手上下活动，找舒适范围。
2. 呼气把手背缓慢抬起，前臂不离桌。
3. 停短暂后控制放低，避免重量把腕猛拉到底。
4. 如果计划指定辅助上抬/主动下降，明确使用另一手助力并单独记录版本。

**关键要领**

- 动作主要发生在腕，不抬整条前臂。
- 握持不必用尽全力，但物体不能滑。
- 回程平稳，手指不做额外猛抓动作。

**常见错误**

- 负荷过大导致前臂抬起或握持绷紧。
- 把所有肘外侧痛一律当适合高量离心。

**试做与候选剂量／评估协议：**首轮空手或轻物5次；候选模板1–3组×8–15次、组间45–60秒。动作形式、负荷和疼痛反应须按个体计划。

腕背伸等长与辅助上抬/主动缓降分别启用hold和eccentric协议（见习47）。固定重量、前臂支撑、腕起点；候选先短时轻等长试做，再按计划增加保持，不能仅凭计时确认发力。

**退阶：**空手、小范围或获准轻等长；不能因看不到收缩就要求加力。

**进阶：**先提高可耐受控制和重复，再小幅加重；改变肘角是另一个负荷变量。

**停止或调整条件**

- 腕背锐痛、明显肘痛上升、新麻木。
- 握持不稳或无法控制下降。

**机位与画面：**腕侧面近景，Hand与Body采用统一图像坐标。

**视觉可以观察**

- 腕投影活动、次数、前臂明显离桌和节奏。

**视觉不能直接判定**

- 肌腱应力、实际握力和Hand/Body未配准world的真实角。

**观察不足时：**握物遮住Hand时只按节奏与自报完成，不要求拿开重量重复整组。
