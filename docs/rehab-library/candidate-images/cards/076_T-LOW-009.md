# 076 T-LOW-009｜侧卧蚌式：徒手至弹力带

**区域：**髋　 **等级：**L1基础

**目标：**练习屈髋位旋转/外展控制，作为候选辅助训练。

**器材：**垫、小枕头、可选膝上弹力带

**开始条件：**侧卧可耐受，髋旋转在许可范围。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**双膝自选舒适屈曲，双足靠近；弹力带不压膝关节线。 检查带体和锚点；记录品牌型号、固定长度和设置，不由颜色直接推张力。

**操作步骤**

1. 躯干和骨盆稳定侧卧。
2. 双足轻靠，上侧膝缓慢打开。
3. 在骨盆不明显滚动的范围停一下。
4. 控制合拢后重复并换侧。

**关键要领**

- 打开幅度小也可以。
- 骨盆不要向后翻。
- 不夹紧脚趾发力。

**常见错误**

- 滚动整个身体制造开合。
- 带过紧导致动作失控或憋气。

**试做与候选剂量／评估协议：**候选模板：首轮无带每侧3—5次；一般1—3组×6—12次，带阻力只在全程可控时加入。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**无带、小幅开合或改坐姿主动旋转。

**进阶：**先增加控制和重复，再少量增阻；功能进阶仍需站姿任务。

**停止或调整条件：**髋前夹痛、外侧压痛或腰部新不适时停。

**机位与画面：**身体侧前方中景，双膝和骨盆可见。

**视觉可以观察：**开合次数与明显骨盆滚动。

**视觉不能直接判定：**独立股骨旋转角、特定肌肉激活和带张力。

**观察不足时：**采用教学计次，不因骨盆细点缺失清空训练。
