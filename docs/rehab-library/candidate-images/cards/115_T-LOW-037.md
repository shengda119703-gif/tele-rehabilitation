# 115 T-LOW-037｜坐位提踵：徒手至膝上负荷

**区域：**踝、小腿　 **等级：**L0低负荷支持—L2负重能力

**目标：**在较少站立平衡要求下训练屈膝位提踵。

**器材：**稳固椅；膝上软垫；可选哑铃/壶铃或合适负重

**开始条件：**坐位和前足负重允许，膝上接触可耐受且能安全放置器械。 外加负荷须可控，场地和支撑可靠；本动作不是最大负荷测试，不做到无法受控回程。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**脚全掌落地，膝处于舒适屈曲；重量通过软垫稳妥放在大腿近膝处而非关节线上。

见习27的大脚趾抬高、双拇趾弹力环与膝上负重是组合设置，不自动作为坐位提踵的默认做法；另查前足/足底和术后许可。未知物重或膝上接触时只记录实际条件，不复制30 kg给新用户。

**操作步骤**

1. 先徒手保持前足接地并抬跟。
2. 缓慢放回，确认脚不滑。
3. 需要外负荷时用手防止器械滚动。
4. 按可控节奏起落，组末先安全卸重。

**关键要领**

- 压力不集中在膝关节线。
- 脚趾不用蜷抓。
- 器械全程防滚。

**常见错误**

- 重物直接压膝盖或术区。
- 前足滑动却继续抬起。

**试做与候选剂量／评估协议：**候选模板：先徒手5次；一般1—3组×8—15次，轻负荷按可控回程选择，非最大负荷测试。 负荷按现阶段许可与可控余量选择，不按历史最好成绩直接恢复。

**退阶：**无负荷、降低高度或减少重复。

**进阶：**先增控制与次数，再少量加重；站姿进阶另查平衡和负重许可。

**停止或调整条件：**膝接触痛、跟腱/前足锐痛、脚麻或器械不稳时停。

**机位与画面：**侧面足部及膝上负荷可见。

**视觉可以观察：**跟起落和次数，需要足点/近景。

**视觉不能直接判定：**真实跖屈力、比目鱼肌选择性激活、膝上压力。

**观察不足时：**只用节拍陪练和自报完成；不因全身骨架缺失重拍。

**动作出处与对应原文：**[REF-S023]；Seated heel raise：膝上重量。

**证据性质与适用范围：**专科医院动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
