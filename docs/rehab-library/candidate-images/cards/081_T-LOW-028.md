# 081 T-LOW-028｜仰卧/坐位髋内收轻夹垫

**区域：**髋内收、腹股沟　 **等级：**L0低负荷支持—L1基础

**目标：**以可控轻等长负荷练习内收，不作为损伤诱发强挤压测试。

**器材：**柔软枕垫或软球、稳固椅/垫

**开始条件：**腹股沟急伤已明确允许轻等长收缩；不要求用户最大用力。 按当前伤情、负重许可和手术限制选择；既往力量强不能绕过急伤保护。

**准备与起始位：**屈膝仰卧或稳定坐位，软垫放双膝内侧，冻结体位。

**操作步骤**

1. 自然呼吸，双腿放松。
2. 以轻到中等主观努力缓慢夹住软垫。
3. 短时维持而不屏气。
4. 逐渐放松，记录腹股沟感觉。

**关键要领**

- 轻夹即可，不比谁力大。
- 压力逐渐建立和释放。
- 骨盆保持舒适。

**常见错误**

- 最大挤压诱发疼痛以找病。
- 静止画面直接判定夹力大小。

**试做与候选剂量／评估协议：**候选模板：首轮3次、每次3—5秒；一般1—3组×5—8次短保持，具体强度按许可和症状决定。

**退阶：**更轻、更短，或先做无负荷内收活动。

**进阶：**允许且耐受后转侧卧内收或短杠杆哥本哈根，不能直接跨到长杠杆。

**停止或调整条件：**腹股沟锐痛、抽筋、症状逐次增加或收缩后持续不适时停止。

**机位与画面：**正面或斜侧，可见双膝和体位。

**视觉可以观察：**保持计时、体位与明显腿移动。

**视觉不能直接判定：**夹力、内收肌激活和腹股沟病因。

**观察不足时：**计时陪练并收集自述，不以无可见动作判训练失败。
