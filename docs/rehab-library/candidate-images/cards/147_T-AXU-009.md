# 147 T-AXU-009｜颈部舒适范围主动低头

**区域：**颈部　 **等级：**L0

**目标：**恢复可耐受的低头活动与动作控制。

**器材**

- 稳定椅

**开始条件**

- 当前低头方向获准，无需先处理的近期创伤或新神经症状。

**准备与起始位：**坐稳，肩自然放松，眼睛平视，手机侧面近景。

**操作步骤**

1. 从自然中立位开始。
2. 缓慢让下巴朝胸前方向移动，到舒适位置即止。
3. 停短暂后平稳回到原视线高度。
4. 每次回正后确认没有新的头晕或手臂症状。

**关键要领**

- 不把下巴硬压到胸口。
- 肩和胸口尽量不跟着大幅前弯。
- 不靠手压头，保持呼吸。

**常见错误**

- 快速点头或手压到末端。
- 为达到统一目标角度继续疼痛活动。

**试做与候选剂量／评估协议：**首轮3次；候选模板1–2组×5–8次，组间30秒，角度和频次由个体计划确认。

**退阶：**更小幅度，靠背支撑；必要时只做轻点头控制。

**进阶：**逐渐扩大可耐受范围和生活低头时间，不先增加外载。

**停止或调整条件**

- 眩晕、视物异常或新麻木无力。
- 异常头颈痛或症状持续增高。

**机位与画面：**侧面头肩近景；Face有效时估计相对俯仰趋势。

**视觉可以观察**

- 低头与回正、近似范围、明显躯干前弯。

**视觉不能直接判定**

- 分节颈椎运动和神经状态。

**观察不足时：**以节奏与主诉完成，Face缺失不强制重复低头。

**动作出处与对应原文：**[REF-S012]；Neck flexion / Side flexion / Rotation / Chin retraction。
