# 137 T-AXU-017｜侧桥：屈膝支撑到长杠杆

**区域：**胸腰/肩/髋侧方耐力　 **等级：**L1

**目标：**练习侧方躯干支撑与耐力，逐级增加杠杆。

**器材**

- 垫；可选坚实墙面降阶

**开始条件**

- 肩肘侧向承重可耐受，能安全上下地面；不适者选墙版。

**准备与起始位：**侧卧屈膝，前臂撑地，肘大致在肩下；另一手放身前以便稳定。

**操作步骤**

1. 先调整肩肘位置，找到无明显压痛的支撑。
2. 呼气抬起骨盆，让肩到膝形成可控的整体线。
3. 短时保持并呼吸，出现技术下降前主动结束。
4. 慢慢放下休息，再换侧；站起之前先坐稳。

**关键要领**

- 支撑肩远离耳朵，不用头顶地。
- 骨盆不大幅向前后转。
- 保持时间以呼吸和控制为限，不比最长。

**常见错误**

- 腰下沉后仍依靠疼痛硬撑。
- 直接从墙版跨到单脚长杠杆并加负重。

**试做与候选剂量／评估协议：**首轮每侧2次×5–10秒；候选模板每侧2–3次×10–20秒、次间30–60秒。由计划确认，非力竭测试。

**退阶：**侧身前臂撑墙，或缩短屈膝侧桥保持时间。

**进阶：**先延长适度时间，再伸直双腿；稳定且反应合适后才加入较高需求版本。

动态侧桥及上腿外展分别增加需求；上腿外展独立 T-AXU-046。短杠杆、长杠杆、带阻分别保存，不能以保持更久抵消明显下沉。

**停止或调整条件**

- 肩不稳、锐痛、上肢麻木或明显腰痛。
- 无法控制放下或出现头晕。

**机位与画面：**身体前方略偏斜，侧向肩髋膝线清晰。

**视觉可以观察**

- 起落、保持时间、明显腰下沉和躯干旋转。

**视觉不能直接判定**

- 左右实际支撑力或组织负荷上限。
- 等长肌收缩强度和是否达到特定训练刺激。

**观察不足时：**用户确认开始/结束；遮挡时记录实际保持，不把静止当没做。
