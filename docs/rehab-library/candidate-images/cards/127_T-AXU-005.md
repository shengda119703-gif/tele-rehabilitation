# 127 T-AXU-005｜坐位轻柔屈背与后侧胸廓呼吸

**区域：**胸部/胸腰整体　 **等级：**L0

**目标：**练习舒适的屈曲活动与呼吸配合，不声称矫正胸椎结构。

**器材**

- 稳定椅

**开始条件**

- 已知骨折、术后或屈曲限制者获得相应许可。

**准备与起始位：**坐稳，双脚落地，双手轻放大腿或在身前轻抱。

**操作步骤**

1. 先自然吸气，不刻意挺胸。
2. 呼气时让上背轻轻圆起，肩膀自然向前但不耸起。
3. 在舒适位置完成一次自然吸气，感受背侧胸廓活动。
4. 平稳回到自然坐姿，再开始下一次。

**关键要领**

- 小范围即可，不用力把头压向胸口。
- 臀部保持稳定坐在椅上。
- 吸气能顺畅进行，动作不要求憋气。

**常见错误**

- 把腰部猛弯或头部强低当作伸展上背。
- 用肩髋角估计胸椎后凸矫正程度。

**试做与候选剂量／评估协议：**首轮3次；候选模板1–2组×5次，每次配1个平稳呼吸，组间30秒；按个体计划使用。

**退阶：**靠背支撑，只练呼吸与很小的躯干变化。

**进阶：**增加舒适活动范围后可衔接坐位伸胸；不加压追末端。

**停止或调整条件**

- 异常胸痛、气促、头晕。
- 新发尖锐背痛或呼吸被明显限制。

**机位与画面：**侧面坐位，头肩髋可见。

**视觉可以观察**

- 整体屈背与回正过程、动作节奏。

**视觉不能直接判定**

- 胸椎分节屈曲、真实胸廓容积或呼吸肌用力。

**观察不足时：**以呼吸和主观完成为主，不要求算法识别细微背部曲率。
