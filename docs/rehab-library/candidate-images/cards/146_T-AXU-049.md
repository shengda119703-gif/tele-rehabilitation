# 146 T-AXU-049｜半跪位小幅转胸

**区域：**胸腰整体、髋、躯干　 **等级：**L1

**目标：**练习稳定半跪位转胸，作为有支撑的动作控制任务。

**器材：**膝垫、可触及固定扶手

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**跪膝接触、前腿承重和躯干旋转获准，能独立进入退出。

**准备与起始位：**一膝在垫、另一足在前，双手胸前；扶手在侧。

**操作步骤**

1. 先建立稳固半跪位，必要时一手扶稳。
2. 胸口缓慢转向一侧，范围以无需足膝扭转为限。
3. 控制回正，少量回合后换前脚。

**关键要领：**先稳定；小幅；不追手碰地。

**常见错误：**腰膝猛扭；只凭头部固定判断胸椎旋转正确。

**试做与候选剂量／评估协议：**首轮每方向3次；候选1–2组×4–6次，组间30–60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**T-AXU-008侧卧开书或坐位转胸。

**进阶：**增可控范围后才轻负重，跪位和站位不混用。

**停止或调整条件：**跪膝痛、失衡、腰腿症状。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**斜前全身含前后支点；普通二维只能报告粗轨迹。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**身体点；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**回合、支点变化与整体转动事实。

**视觉不能直接判定：**真实胸椎独立旋转角、骶髂运动或膝扭矩。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**同支点追踪回合和症状；精细分节信息不评分。 统一保存当次、练后和次日反应，长期判断按第12.5节。
