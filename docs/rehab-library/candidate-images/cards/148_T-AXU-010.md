# 148 T-AXU-010｜颈部舒适范围主动抬头

**区域：**颈部　 **等级：**L0

**目标：**恢复当前允许的抬头活动，不作颈椎加压。

**器材**

- 稳定椅

**开始条件**

- 抬头方向试做可耐受，近期创伤或新神经症状已先处理。

**准备与起始位：**坐稳，胸口自然朝前，双肩放松；不把椅背顶在颈后。

**操作步骤**

1. 自然平视，先放松呼吸。
2. 缓慢抬高视线，让头部小幅后仰至舒适位置。
3. 平稳回到平视，不停留追求极限。
4. 检查有无头晕、视觉或上肢变化后再继续。

**关键要领**

- 只做舒适范围，不能用手把额头往后推。
- 胸腰不要同时明显后仰。
- 回正过程和抬起一样缓慢。

**常见错误**

- 仰到极限并长时间保持。
- 把不适解释成必须拉开的僵硬而继续增加幅度。

**试做与候选剂量／评估协议：**首轮2–3次；候选模板1–2组×5次，组间30秒；需由当前方向选择确认。

**退阶：**缩小范围或暂时只练回到中立位。

**进阶：**逐步恢复日常抬头需求；不加入颈部负重或加压。

**停止或调整条件**

- 眩晕、恶心、视物异常或新的放射症状。
- 异常剧烈头颈痛。

**机位与画面：**侧面头肩近景，Face记录近似俯仰。

**视觉可以观察**

- 抬头回正、明显胸腰随动和可见节奏。

**视觉不能直接判定**

- 颈椎血管状态、分节负荷或神经孔变化。

**观察不足时：**角度失跟时停用评分，用户可完成获准小范围或跳过。
