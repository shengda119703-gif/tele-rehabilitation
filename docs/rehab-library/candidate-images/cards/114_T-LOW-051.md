# 114 T-LOW-051｜双脚上升—单脚缓降提踵

**区域：**踝、小腿、离心控制　 **等级：**L1–L2

**目标：**在双脚助力上升后增加单侧缓降要求。

**器材：**平地、固定扶手

**单人适用：**条件独立；须能自行摆位、完成及安全退出，满足本卡开始条件。需要他人保护者按第12节分流。

**开始条件：**双脚提踵可控、单脚下降承重获准；跟腱修复/重建或新伤必须另确认。

**准备与起始位：**双脚全掌站平地、一手扶稳，旁边有随时落另一脚的空间。

**操作步骤**

1. 双脚一起抬跟。
2. 轻抬非训练脚，保持训练脚稳定。
3. 训练脚缓慢落到平地后另一脚再落回重置。

**关键要领：**先双脚抬起再抬非支撑脚；下降受控；不踩台阶。

**常见错误：**在顶端跳换脚；单脚落地后仍向台阶下压。

**试做与候选剂量／评估协议：**首轮每侧3次；候选1–3组×5–8次、下降约3秒，组间60秒。 所有数值为项目候选模板，不是正常/异常或进阶阈值。

**退阶：**全程双脚提踵或坐位版本。

**进阶：**先延长可控缓降/增回合，再按计划轻负重。

**停止或调整条件：**跟腱锐痛、突然无力、踝失稳。 同时适用第4节的症状管理与第12节安全退出规则。

**机位与画面：**侧面足近景＋双膝，区分哪只足离地。；固定相机、水平放置，身体/目标不过度遮挡。

**视觉模块：**足部近景；“能观察”是候选能力，自动测量仍须独立验证。

**视觉可以观察：**双脚上升、另一脚离地、单脚下降事件及下降时间。

**视觉不能直接判定：**真实离心力量、跟腱愈合或双脚承重比例。

**观察不足时：**保留已确认片段与来源；不可见指标记unknown，转陪练、本人补记或安全的替代任务，不补造有效回合/角度/发力。

**复评与训练成果：**按上升助力与下降侧保存，不能计作完整单脚上升测试。 统一保存当次、练后和次日反应，长期判断按第12.5节。

**动作出处与对应原文：**[REF-S022]；Eccentric training：双脚上升、单脚缓降。

**证据性质与适用范围：**医院动作说明。运动形式有公开出处；本卡的减负荷、扶持、候选剂量及视频规则属于实施版本，不能据此声明完整方案已验证疗效。
