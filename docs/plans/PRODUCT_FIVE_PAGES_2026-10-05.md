# 五页产品重组 · 2026-10-05

用户授权：本人默认使用，首页 / 康复 / 健康 / 用药 / 家庭；其余细节自主决定。此次包括可逆的产品功能新增，并非只做视觉 polish。

| 入口 | 主操作 | 详情归属 |
|---|---|---|
| 首次使用 | 本机身份 → 可跳过选择题 → 初始安排 | 不冒充邮箱 / 微信登录；资料只问一次 |
| 首页 | 与管家对话、查看今日日期安排 | 头像进入档案；待办按需展开 |
| 康复 | 当前计划、日期安排、开始评估 | 手动计划、自动安排与条件确认保留；历史在健康 |
| 健康 | 上传资料、记录身体情况 | 指标、附件识别确认、统一记录、报告 |
| 用药 | 按日期与时间记录已服用 / 跳过 | 原医嘱档案、逐次更正和审计 |
| 家庭 | 关联家人的获准近况 | 双向独立授权，只读；本机关系与跨设备区分 |

业务保护：Agent Runtime、grounding、否定 / 假设 / 不确定解释、撤回、测量和医疗判断不改。日期排期与逐次服药记录在独立 SQLite 产品库中增量保存，不迁移康复库。家庭分类授权不开放私密事件、聊天和附件。原能力通过详情和设置保留。

初始计划边界：现有自动计划必须依赖有效评估，问卷不能伪造测量。无有效评估先保存首次评估安排，界面明确尚未生成动作计划；若要根据疾病问卷直接开动作与剂量，需另行授权医疗规则设计。

设计：黑白灰，单列主任务，日期控件使用 Qt 原生 QDateEdit；React Bits RubberSegment 已重新检索，弹性拖动不适合日期记录，不用其源码 / 依赖。使用现有 Qt tabs、输入和按钮，保留焦点、键盘及浅深主题。
