## 本轮要求

手机是独立主端，电脑仅代表演示云端。用户只有手机时也可完成个人流程。沿用 0.19.2 正式五页界面，不重新设计前端。用户本轮明确要求手机本地运行，故从归档 `4a4a0b8` 恢复 Android 构建/模型内核；不撤回主线双端整合、不覆盖 Qt 或现有 PhoneHost。

## 实现分工

- `android_offline/tools/prepare_assets.py` 原样复制 `mobile_rehab/static/`；`ui-lock.json` 记录逐文件 SHA256。只在生成的 HTML 插入本地接口脚本。0.1 页面源码保留用于兼容测试，不进入新版 APK。
- `bundle_product.cjs` 使用原 TypeScript 编译器，将原 `ProductService` 与 59 个依赖模块打包。本人健康记录、逐次用药、否定/更正/不记录语义沿用原领域规则，不通过另一套模拟对话替代。
- `web/store.js` 保存本人文字状态，IndexedDB 保存资料原件与录像。原 0.1 数据不删除；同一测量版本的旧动作和已适配健康指标导入，旧计划/感受/未适配项目保留迁移副本。旧 IndexedDB 资料原件不删除，但暂未转换为新版资料条目。
- `web/local-api.js` 为正式页面的 `/api` 请求提供手机本地实现。评估 → 建议 → 保存计划 → 录像训练 → 反馈 → 汇总均走真实本地结果。实时指导不冒充已保存的评估。
- `web/motion.js` 调用捆绑 MediaPipe Pose/Hand WASM。53 项康复、8 项健身、2 项体态目录从原项目生成，不是重新列动作。低性能时降低分辨率/采样频率，仍使用原录像时间，不拿推理耗时当动作时间。
- 健身保存可见的多项角度、关键时刻、人体投影与器械轨迹。膝角缺测、髋角持续可见的深蹲使用明确标记的髋部往返观察，不生成缺失膝角。NCC 模板跟踪 + 标尺标定 + 时间窗导数估算速度、加速度、自由重量外力和功率，不能表示肌肉实际发力或关节力矩。原显式模拟器械报告保持独立，不入个人库。
- `web/ocr.js` 的 Tesseract.js 6.0.1 使用本地中英文模型；结果只进可核对草稿，不自动生成身体指标。手机系统有 on-device SpeechRecognizer 才使用本地语音识别，无服务时保留键盘输入；没有悄悄切到网络语音。
- `MainActivity.java` 保留受限 HTTPS 本地资源 WebView、相机/文件选择与导出，补充系统打印、本地语音和可选云端原生菜单。原生传输不加载远端页面、不忽略 TLS 错误、不跟随重定向。HTTP 仅允许明确私网 IPv4 或 localhost，供可信 LAN 演示。
- `mobile_rehab/phone_cloud.py` 是独立辅助服务，仅保存手机私有文字备份与获准家庭摘要，不读取桌面患者库。设备 token 与 owner 固定绑定，家庭邀请码一次性/15 分钟有效，双方按健康、康复、用药分别授权，默认无共享，聊天与资料原件不会进入家庭摘要。

## 使用

安装 `android_offline/dist/tele-rehabilitation-mobile-0.2.0.apk`，直接进入首页，不需要连接码或电脑。应用包名沿用 `cn.tele.rehabilitation.offline`，使用原签名，可在旧版本上覆盖安装；不要卸载旧应用来升级。

康复页选择“手机录像”来源查看或执行本机计划；本地适配层默认选该来源。评估选择动作并录制/选择视频，分析完进入计划，确认适合活动后保存。按提示录像训练，查看报告并填写真实疼痛/疲劳反馈。健康、用药与本地管家分别从底栏进入。

长按右上角“我的档案”头像，可打开原生“手机与云端”菜单。导出/恢复文字备份、连接/暂停云端均从这里操作。恢复前保存 `ankang-phone-product-2:before-restore` 副本；空间不足不覆盖当前状态。录像、附件原件不进文字 JSON 备份，需单独导出。源代码保留该副本恢复途径，尚无独立一键回滚按钮。

电脑演示云端可在仓库运行：

```powershell
& ./tools/mobile-standalone/Start-PhoneCloud.ps1 -HostAddress 0.0.0.0 -Port 8770
```

手机原生菜单填写 `http://电脑局域网IP:8770` 和该服务启动窗口的连接码。此码不是原 1396/8765 连接码。个人功能仍不依赖这个服务；家人也需要在各自 APK 连接同一云端服务，然后在原“家庭”页生成/输入邀请码并分别选择共享范围。

默认工具绑定 localhost；上述显式 `0.0.0.0` 才用于 LAN。防火墙由用户自行决定，代码不代为更改安全设置。异地访问需可达的 HTTPS 域名/反向代理；没有公共 HTTPS 地址时，不因 APK 已完成而宣称跨互联网已通。不要将桌面患者数据库或带连接码的网页直接开放到公网。

## 构建

沿用本机 `.runtime/apk-tools/` 的 JDK 21 / Android SDK 35。依赖与语言模型不入 Git，构建前：

```powershell
cd android_offline
npm ci
& ./tools/prepare_ocr.ps1
& ./tools/build.ps1
```

还需本项目既有 Pose/Hand 官方模型、原领域的 TypeScript 构建依赖与项目 Python 环境。模型校验依据既有 manifest；OCR 下载脚本只下载缺失模型，严格验 hash，不覆盖 hash 不符的文件。签名密码由当前 Windows 用户 DPAPI 文件读取，不输出密码、不替换旧密钥。合作伙伴构建需自己的环境；要覆盖本机旧 APK，必须保留同一签名材料，不能将私钥推入仓库。

## 未宣称完成的部分

- Redmi K60 Ultra 本轮未连接 USB，实际耗时、功耗、原生相机兼容与系统本地语音服务需实机验收；模拟器不等同于手机真人准确率。
- 全动作已接入测量/流程，但并非全部完成真人录像验证。体态是二维观察，不是骨盆前倾等精细骨性标志诊断；真实肌肉力量不可能仅靠普通视频直接测出。
- 当前辅助云端不是生产多账号系统：没有密码登录/找回、后台运维台、通知推送与多设备冲突合并。手机与桌面各自数据库不会自动合并。手机号/微信登录、互联网公网可达性未配置。
- RTSP/ONVIF 外部网络摄像头、跨相机三维标定、云端重模型转交以及录音文件离线转写未接入这个 APK。原桌面/PhoneHost 功能不因此删除。
- 用户冻结前端，正式页面里仍有原“电脑/上传”固定措辞。数据实际在手机本地，云端只在显式配置/授权下接收；本轮不为了改文案重写正式前端。
