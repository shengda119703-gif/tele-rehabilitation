# 0.18.1 下一步动作指导

日期：2026-09-13

## 用户体验变化

动作卡和大字指导现在表达“下一步做什么”，不再直接把摄像头的当前识别阶段当作提示步骤：

- 尚未确认起点时，提示保持准备姿势。
- 起点被状态机确认后，立即提示开始本动作。
- 出程过程中保持同一动作提示，不因单帧变化跳步。
- 已观察到目标证据、站位或回程后，提示缓慢回到起点。
- 完整回位并记录一次后，提示开始下一次动作。
- 短暂缺测期间保留最后一条已确认的文字意图，但隐藏阶段图片，不根据无效证据推进。

界面增加“下一步”标识；普通动作卡与远距离大字界面使用同一条指令和同一阶段图片。

## 实现边界

`GuidancePolicy` 新增观察阶段到下一步指令的独立映射，并同时提供 `observed_phase` 与 `cue_key`，避免显示层混淆“已经观察到的状态”和“要求参与者接下来执行的动作”。准备、动作、回位的识别和计次状态机没有改动。

训练中的峰区不再仅因进入 `PEAK_OR_HOLD` 就提前要求回位；只有观察到目标、连续保持完成、站位完成、实际回程或训练执行器进入恢复阶段时才切换回位提示。没有设置可判断终点的评估动作仍由本人按舒适幅度决定终点，系统在观察到回程后更新提示，不声称预测动作完成。

动作质量纠错、多人或身份不明、输入中断、隐私暂停、训练暂停 / 休息 / 完成以及保存失败继续高于普通动作提示。引导计时模式保持固定时钟逻辑，并继续注明不自动判断角度和次数。

本次没有调整关键点置信度、几何计算、稳定时间、目标、计数、训练剂量、模型或摄像头契约。

## 验证

本机完整软件回归通过 1645 项主测试和 4 项子测试。合成测试覆盖准备确认后推进、回程后推进、坐站、训练峰区不提前回位、短暂缺测不乱跳，以及普通 / 大字界面一致性。软件测试不代替真人动作节奏和提示可理解性验收。
