# Agent 纵向变化解释 · 0.22.0

康复管家新增对“我有进步吗”“最近有什么变化”的证据化回答。

## 实际行为

1. 只读取当前用户、当前来源和当前使用情境下的已保存记录。
2. 按动作、侧别和评估模式分组，选择最近一次记录作为比较基准。
3. 复用 `recorded-conditions-4` 纵向比较：来源、机位、模型、动作定义、预处理、基线和计划参数等记录条件必须完整且一致。
4. 最近两次都必须已经结束、有完整动作和有效角度。
5. 输出观察幅度与完整动作次数的前后数值；最多展示 4 个动作。
6. 条件不同、条件缺失或数据不足的组不比较，并告诉用户原因。

## 边界

输出描述的是摄像头二维记录变化，不等于关节临床 ROM，也不单独证明康复改善或退步。DeepSeek 只能解释本机生成的文字，不能更改数字或把数值变化升级成医疗结论。本功能只读，不会保存新记录、修改计划或自动开始训练。
