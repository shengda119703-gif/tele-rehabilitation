# 自动评估生成训练计划演示 · 0.18.3

日期：2026-09-13

## 演示入口

进入“训练中心”，点击“一键生成演示计划”。软件会切换到“演示患者 · 自动计划”，并打开“根据评估自动安排训练”窗口。该窗口直接展示“测试情况 → 可安排项目 → 训练顺序”的完整闭环。

## 演示数据与生成结果

演示包含四项合成评估：左肩外展 12°–76°、左肩前屈 16°–88°、左肘屈伸 35°–120°、右膝伸展 25°–105°。每项有效观察比例为 0.91–0.96，完整动作 5–6 次。数值仅用于软件演示，不是正常范围、临床阈值或真人测量。

系统没有读取预先写死的最终计划，而是把这些评估交给现有 `build_body_profile` 和 `general-activity-rules-1`：检查最新评估、7 天窗口、有效比例、完整动作和测量契约，再自动选择四项练习。生成结果均为 5 次 × 1 组、组间休息 60 秒；个人二维投影目标依次为 63.2°、73.6°、103.0° 和 41.0°。目标来自本人演示评估范围的 80% 工程适配，并非正常值或处方剂量。

## 隔离与重复演示

- 用户固定为 `demo-automatic-rehab`，来源为 `SYNTHETIC`，情境为 `TEST`。
- 合成记录带有 `annotation_origin=synthetic_demo` 和明确说明。
- 重复点击会归档该演示用户此前的活动自动计划，再创建一份新的；不会删除旧证据，也不会修改其他用户。
- 合成来源只能查看计划。界面禁用预览，不会伪造摄像头采集或让演示计划进入真人训练。
- 真人展示训练执行时，应切回实时摄像头，并使用该真人自己的有效评估生成计划。
