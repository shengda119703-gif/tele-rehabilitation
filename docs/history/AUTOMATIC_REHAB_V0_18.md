# 自动评估到训练闭环 · 0.18.0

## 用户现在怎么用

完成并保存身体评估后，进入“训练中心”，点击“根据评估自动安排 / 继续训练”。系统直接读取当前用户、来源和使用情境下的测试，不要求再次填写动作、侧别、次数或组数。用户只确认摄像头无法知道的事情：今天是否不适、是否有医嘱 / 疾病 / 术后限制、站立是否有稳固支撑，以及档案要求协助时陪同者是否在场。

系统每轮安排最多 4 项。做完一项并保存后，记录疼痛和疲劳；无疼痛、不疲劳可一键记录。随后回到自动安排继续下一项。完成一轮后重新安排时，未训练过的有效评估优先，避免一直重复目录前面的动作。

## 身体情况与计划如何生成

- 覆盖当前 53 项动作及左右侧，共 106 个评估条目。只有已经取得有效评估的条目才会进入候选；“已接入”不等于每项都已有真人准确度验证。
- 只读最近 7 天内、当前用户 / 来源 / 使用情境一致、最近一次已正常结束、有效观察比例至少 0.8、至少 1 次完整动作且测量定义仍一致的自动评估。
- 引导计时不含自动分期，不能作为计划依据；最近一次失败不会回退到更早成功记录。
- 每项先安排 1 组、1–5 次，次数不超过该评估已观察的完整动作数。投影角目标位于本人本次观察范围内，默认取出程的 80%，范围太小、方向异常或坐站时不设角度目标。
- 自动计划保存评估 ID / 指纹、测量契约、规则版本、官方来源、适用性确认和完整参数。每次开始都从数据库重建验证；改动参数、越序、换人、评估更新或确认过期会要求重新生成。

上述 7 天、0.8、80%、1 组、最多 5 次和每轮 4 项都是 `general-activity-rules-1` 的保守工程参数，不是临床界限，也不是来源直接给出的个体处方。

## 53 项动作的来源层级

系统把证据分成两种，不混写：

1. “官方动作条目匹配”：肩前屈、肩外展、肘屈曲、坐位伸膝、踝背屈 / 跖屈、髋外展、髋后伸、坐站，来源页面描述了相近动作形式。
2. “本人评估适配”：其余肩 / 肘 / 膝 / 髋方向、腕、手指、颈和躯干任务。动作来自本项目已冻结的摄像机二维测量契约；WHO 来源只支持从少量活动开始、按功能能力调整的一般原则，不是这些具体动作和参数的处方证据。

公开依据：

- [WHO Guidelines on physical activity and sedentary behaviour](https://www.who.int/publications/i/item/9789240015128)
- [WHO Physical activity：从少量开始并逐步增加](https://www.who.int/health-topics/noncommunicable-diseases/physical-activity)
- [NHS Strength exercises](https://www.nhs.uk/live-well/exercise/strength-exercises/)
- [NHS Sitting exercises](https://www.nhs.uk/live-well/exercise/sitting-exercises/)
- [North Tees NHS Chair Exercises](https://www.nth.nhs.uk/resources/chair-exercises/)
- [North Tees NHS Bed Exercise](https://www.nth.nhs.uk/resources/bed-exercise/)

## 训练监督和报告

原有动作状态机继续负责实时分期、计次、目标角度、已配置的躯干 / 屈肘问题和动作时间。新增摘要把完整次数与三类质量证据分开：已观察目标达成、需调整、未能核实。没有设置目标、被遮挡或缺测会进入“未能核实”，不会被算作动作错误，也不会因做够次数就声称全部动作正确。

报告保存来源计划、评估依据、证据层级、规则版本、每次动作和本人感受。疼痛大于 0、疲劳达到 5/10，或选择不适 / 疲劳结束，会停止本轮自动续练；系统不自动加量。

## 边界

这是一般关节活动与基础功能的自动建议，不诊断疾病、不推断肌力、不生成特定疾病或术后处方，也不能保证患者“高质量完成”。摄像头只能监督已实现且当前可见的指标。档案已有康复原因或限制时自动计划停用，保留专业人员人工计划入口。所有算法测试使用 SYNTHETIC / TEST 数据；真人、双摄实测和临床有效性需另行验证。
