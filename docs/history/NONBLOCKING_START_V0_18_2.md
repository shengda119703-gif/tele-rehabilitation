# 0.18.2 顺畅启动与主要参与者聚焦

## 用户体验变化

- 康复预览后不再要求先让所有目标关节变绿，也不再强制记录舒适起点、活动方向或坐 / 站基线。
- “确认准备”“开始评估 / 训练”和组间继续不再被多人、暂时无人、必要点缺失或辅助画面不清楚拦截。
- 陪同者可以进入画面。每路姿态分析自动选择一个主要参与者，并优先沿用模型轨迹；轨迹变化时按上一位置就近延续。
- 预览阶段不再连续弹出缺关节告警。任务运行后，不清楚片段跳过，画面恢复时自动继续。

## 测量调整

- 肩外展、肩前屈、肩后伸和肩内收使用肩—肘肢段相对固定画面竖直线的二维投影角，不再要求髋点。
- 头颈前屈 / 后伸使用同侧眼—耳线相对固定画面水平线的二维投影变化，不再要求肩—髋躯干线或髋点。
- 新旧定义使用新的 `measurement_contract`，纵向比较不会把旧定义和新定义当成相同条件。
- 未提供手工基线时，方向型动作以首个有效姿势为本轮零点，并由第一次至少 5° 的明确活动确定画面方向；其他需要个体起点的动作在首个有效值建立分期起点。
- 坐站未提供人工基线时，把提示后的首个有效姿势作为本轮坐位起点，以相对膝角和髋高度变化建立保守站位区间。

## 仍然保留的数据原则

“允许开始”不等于“当前已经测到”。真正参与某项几何计算的点缺失时，该片段仍为空值，不补点、不记次数、不伪造角度。相机流未建立、双摄数据结构损坏、保存失败以及训练评估来源不成立等情况仍会明确报错，因为任务在这些情况下无法产生或安全保存一致记录。

主要参与者聚焦是画面内的临时空间跟踪，不是身份识别。两路摄像头也不进行跨画面人脸匹配、三维重建或角度平均。

## 验证边界

本版通过本机软件回归和已配置的本地模型集成检查。没有重新打开真实双摄，也没有完成老人 / 患者真人动作的准确度、误跟随和长时间运行验收。
